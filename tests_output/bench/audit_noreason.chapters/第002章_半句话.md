# 第2章 半句话

陈默在楼道口踩到那滩外卖汤渍，鞋底带起一串黏腻的声响。感应灯冷光打在汤渍上，里面浮着一截蓝色尼龙绳的碎头，和他钥匙扣上那截一个色。他蹲下看了两秒，没看出名堂，跨过去，骑上共享单车。

骑出巷口，手机在兜里震。房东的短信，一行字：账期到了，九千八。他按灭屏幕，把手机塞回兜里。风从城西旧巷子卷出来，吹得共享单车链条嗒嗒响。等红灯时他低头看了一眼前筐，筐底不知谁塞了张外卖小票，边角被风吹得翻起，露出半截取件码。他没用手指去碰，绿灯亮起，车把一拧，过了路口。

回到出租屋已经三点过。房间在五楼，没电梯。他开门，把纸箱倒扣在瓷砖地上。父亲的东西一样样往外摆：两沓旧账本，一摞发黄的发票，几支笔芯干裂的签字笔，三张停缴的社保单。分到最后，他把那本种子书单独放进书桌抽屉最里层，压在租房合同下面。没锁。手从抽屉边沿抽回来，停了一秒，又去翻纸箱里剩下的东西。

全是废纸。他把纸箱踩扁，靠在门后。

手机屏幕还亮着，房东那条短信没关。他点开通讯录，找到“爸（老宅）”。拨出去。

听筒里传出机械女声：您拨打的用户已关机。

他准备挂断。手机屏幕上跳出一行提示：您有一条未播放的通话录音。

陈默点了播放。

录音约四十秒。前段是翻动纸张和抽屉开合的杂音，像有人把一叠纸从左手归到右手，再放到桌上。中段父亲的声音压得低，混着衣领摩擦的响：“这本子留给陈默。告诉他，账不是命运收的，是。”

门铃从录音外头掐进来，声音断掉。整条录音里没有“种子书”三个字。陈默手指收紧，拇指按在音量键上。

他倒回录音，听三遍。中段那句话每个字都清晰，末尾的半句每次都断在同一个位置。第三遍他把手机凑近耳边，左耳听见一串底噪：电子女声在很远的地方报了一句，您有新的外卖订单，编号零三一七。

他停住，从裤袋里抽出那张外卖单底联。单号印在边角：0317。

陈默把外卖单摊在桌上，从抽屉里取出种子书，翻到内页写“案：0317”的那一页。纸页发软，撕痕泛毛。他把笔从桌上捡起来，笔尖抵在页角那串数字旁边。

窗外的风把外卖单吹得翘起一角。椅子咯吱响了一声。他没有落墨。笔尖在纸面压出一个极浅的点，然后他合上本子，关灯，躺到床上，把本子压在枕头底下。

这一夜睡得很浅。半梦半醒间他翻了个身，后脑撞在枕头下的硬角。手机屏幕自动亮起来，显示时间：2点17分。

他坐起来，拿过手机。屏幕还停在通话记录页面。他点下“爸（老宅）”。听筒里不再是关机提示音，而是一段彩铃。父亲自己的声音，语速比他平时说话快一点，像录的时候被人催过：

“您拨打的用户已在服务区外。留言请按”

彩铃断在忙音里。陈默没挂断。屏幕上的通讯录展开，页面停在这一条。号码下方有一行创建于三年前的备注：0317，他生日。

他拇指悬在删除键上，没按。

他点开备忘录。父亲留存的唯一一条记事：

3月17日22:47，去东门街路口。

屏幕暗下去前，他抬头朝窗外看了一眼。楼下路灯下，一个外卖骑手的头盔反光一闪而过。骑手没进任何一栋楼门，车就停在路边。

枕边手机屏幕又弹出一条推送：您有新的通话录音已保存。

陈默没点。屏幕上方时间跳到2点18分。楼下那辆外卖电动车启动的声音传上来，一直没有驶离。
