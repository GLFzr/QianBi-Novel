# 第8章 血偿

公交站的长椅裂了一道缝，缝里积着昨夜没干透的泥水。陈默没坐，站在站牌后面，手机屏幕扣在掌心。墨痕贴着冰凉的玻璃，指头一动它就跟着滑。物流群里有人回他昨天的话：东门街路口去年也出过事。底下跟了十几条。有人说白车司机是代驾，有人说不是。他退出群聊，点开林兰的对话框。最后一条还是他发的“程师傅出事了吗？回我”，下面干干净净，时间16:52，电池图标闪了一下红。他把手机塞进口袋。站牌线路图被太阳晒褪了色，东门街那站的字只剩半个。

公交车来的时候，他投币上车，挑了最后一排。窗户没关严，风把座椅套上的烟味吹过来。梧桐树影一段接一段扫过车厢，他数着，没数清。下车，上楼，开门。

出租屋的灯是冷白的。他把种子书从枕下抽出来，搁在桌上。书脊对着灯，布面增厚的那处在光下显出一圈更深的轮廓，像一圈干透的水渍，但棱角分明。他从笔筒里抽出美工刀，刃口推出两节，刀尖抵住书脊内侧的缝线。第一针挑断，线头缩进布面里。第二针，布口张开一点，露出夹层内容物的边。第三针，一张对折的纸从缝里滑出来，落在他手心里。

纸是薄的那种，泛黄，边缘齐整，裁过的。他捻开。父亲的字。三行。

**案：0310 已结。代价已偿。勿追。**
**案：0311 已结。代价未偿。**
**案：0317 未结。收账日：3月17日。**

最后一行被铅笔反复描过，字槽凹进纸面。陈默的手指顺着那行往下走，走到“收账日”三个字停住，没再移。灯下，字迹里嵌着一层灰蓝的沉色。他把纸对折，塞进钱包内层，按了按。翻种子书内页确认页痕，“擦伤”两个字比昨天更淡，边缘分解成细碎的墨点，像被谁从边上开始蹭掉。

他翻出物流群往上划，找到有人发的过程师傅女儿的号码。拨出去，响了五声。“喂？”她的声音哑，背后有推车的响动。

“是程师傅的女儿吗。我那天在医院跟你爸同一个病房，姓陈。想问问他情况。”

那边停了一下。“不太好。刚醒，迷糊着。”她又停了，像在理顺说不清的话，“他一直问那个骑手怎么样了。我们也不知道什么骑手。护士问，他就说骑手。医生说是脑震荡带的。”

陈默握着手机的手指收紧，墨痕贴着机身。他问：“他以为是自己撞的？”

“应该是。”程雨说，“一直在问。问得我都不敢应。”

挂了电话，他把手机扣在桌上。种子书还摊着。页痕上“擦伤”二字完全不见了，那片纸面干净得像从未写过。空白往下一点，一道极淡的压痕正在显出来，笔画细得几乎看不出。

**0317前，勿再动笔。手记。**

字比父亲日常的笔迹更工整，横平竖直，像抄过很多遍。他用手指摸那道凹槽，触感和旧手表背面划痕一样，刻进去的。

钱包里的薄纸还在。他抽出来，对着灯看。“代价已偿”四字旁边，纸面有一片灰痕，像铅笔来回擦过没擦净。他伸出指甲，沿灰痕轻轻刮。纸毛卷起来一点，底下浮出笔画很重的两个字。

血偿。

他手抖了一下，薄纸落在桌上。捡起来的时候手指有点不听使唤。

他把薄纸翻过来，对着灯。背面贴着另一张更小的纸片，折痕压死，之前被厚度藏住了。他抠住一角慢慢揭开。小纸片上只一行字。

**别信我。**

下面是一列日期和地点，一行一个，末尾都写着“未还”。最下面一行：3月17日 东门街路口 22:47。底部还有一行小字，“都是没还的”。

电梯叮一声停在楼层。脚步声从电梯出来，经过他门口，没有停，往楼梯间去了。走廊声控灯亮了一下又灭，光从门缝底下漏进来一条，又收回去。

脚步声远去。陈默站在桌边，薄纸和种子书并排摊在灯下，掌侧墨痕蹭过封面边缘，灯光从侧面打来，封面上“种子书”三个字在桌面投下一小片阴影。他伸手去合封面。掌心按上布面那刻，比周围凉了一度。

手机在桌上亮起来。程雨的短信。屏幕上只有一行。

**你是谁？为什么问骑手。**

他盯着那行字看了几秒。拇指悬在键盘上，打了两个字又删掉。屏幕暗下去，映出他自己模糊的脸。他重新点亮，敲：我是物流公司的，想了解一下事故情况。发出去之前又全选删除。

程雨的头像是一张风景照，看不出年纪。对话框上方显示“对方正在输入”，持续了十几秒，又停了。陈默把手机放下，去厨房接了杯凉水。水喝到一半，手机又亮。

**你认识我爸？**

他回：不认识。跑这条线的，听说出了事，问问。

**那你怎么有我号码。**

陈默捏着杯子，杯壁上的水汽凝成细流，顺着指缝往下淌。他想起物流群里那条消息，发消息的人只写了“程师傅女儿电话”，没写名字。他当时存的时候没多想。现在要解释这个来源，等于把群里的自己暴露出去。他打字：群里有人发的。

对方没再秒回。过了将近一分钟，才弹出一行。

**你能不能帮我个忙。**

陈默盯着这五个字，后颈有些发紧。程雨的下一条紧跟着进来。

**我爸一直念叨骑手，我们问不出来。你要是认识跑那条线的，帮我打听打听，那天到底有没有骑手被撞。交警说现场没找到第二个人。**

他站在厨房瓷砖地上，凉意从脚底往上走。交警没找到第二个人，因为第二个人不在现场。第二个人是他写在纸上的。程师傅撞了护栏，误以为撞了骑手，而那个骑手从头到尾没存在过。他写的138秒把林果果从路肩挪开，代价转出去的时候，在程师傅脑子里种了一个不存在的骑手。

他回到桌边，打字：我帮你问问。

**谢谢。有消息告诉我。我爸这边，医生说观察两天。**

陈默回了一个“好”字。他把手机翻扣在桌上，屏幕的光从边缘漏出来，照着薄纸上一列“未还”的字迹。3月17日那行压在最后，像整张清单的底。

他拿起薄纸，对着灯又看了一遍。背面的小纸片还摊在桌上，“别信我”三个字笔画松散，跟父亲平时记账的字不一样，像是写的时候手在抖。他把两张纸叠在一起，夹回钱包内层，拉上拉链。

种子书还摊在灯下。他翻到页痕那页，“擦伤”两个字已经彻底没了，纸面平得像从没写过东西。空白处那道新压痕还在，笔画很细，但凹槽深。0317前，勿再动笔。手记。他拿手指顺着压痕划过去，凹槽的触感和旧手表背面那道划痕一模一样。

他把种子书合上，摞在薄纸刚才的位置。封面朝上，“种子书”三个字在灯下泛着暗蓝。他盯着那三个字看了很久，直到眼睛发酸。

然后他打开手机备忘录，翻到三年前父亲写的那条：3月17日22:47，去东门街路口。他在下面打了一行新字：还剩12天。打完之后他盯着那个数字，删掉，重新打：12。又删掉。最后他把手机锁屏，扔到床上。

他坐回桌前，把种子书重新翻开，翻到最后一页。页脚那个0319还在，墨色比昨天浅了一些。他用指尖碰了碰，没有蹭掉。他合上书，没有放回枕下，而是竖着靠在桌角，书脊朝外。那处增厚的布面在灯光里凸出一条细棱。

他关了灯。黑暗里，桌上手机屏幕突然亮了一下。他拿起来看，是程雨发来的最后一条。

**我翻了我爸手机。出事前半小时，他接到一个电话。号码没存名字，通话11秒。你要不要看看。**

屏幕的光照着他的脸。他把那串号码复制下来，切到拨号盘，粘贴。号码跳出来，他盯着那十一位数字，拇指停在拨出键上，没有按。
