# 第21章 空柜

凌晨五点四十分，殡仪馆东门铁门虚掩，路灯亮着半排。陈默站在门边，手机屏幕停在阿莲那句“明天早上六点，殡仪馆东门，别带别人”上。他没有回消息。他松开手机，隔着布料按了一下胸口口袋，信筒的硬角、半张纸片的折痕、五截线的团块叠在一起，压出一道浅印。他抬头看了一眼东门那扇天亮前不反光的玻璃，玻璃上只有路灯的倒影，没有人的轮廓。

六点过七分。阿莲没有出现。他拨她的电话，响到第七声，转进短信。他没有再拨第二遍，把手机握在手里，推门进楼。

值班室的灯关着，桌上一只没喝完的水杯，水位线落下去一指宽。椅背搭着一件外套，袖口朝外，像是人走得很急，随手搭上去的。他伸手碰了一下杯壁，凉的。他沿着走廊往里走，经过三号停尸间的门，门关着，门缝里透出一线白灯。他没有停，继续往前。走廊尽头的暂存间方向，传来一声闷响，金属卡碰金属，短促，像什么撞在柜门上又弹回去。

他推开暂存间虚掩的门。灯管在头顶嗡嗡响，一排排冰柜门在白色光线里反着暗光。冷气从门缝里渗出来，贴着脚踝往裤管里钻。阿莲站在两扇半开的柜门之间，右前臂和半边肩卡在门缝里，手背青紫，指甲边缘发绀。她整个人斜着，半边身体的重量压在那道缝里，嘴唇咬成一条直线，没有出声。警铃没有响。整个暂存间只有灯管的电流声，和她压在牙关里的呼吸。她额头有一层薄汗，贴在鬓角，灯光下亮晶晶的。

陈默两步上去，左手扳住外侧那扇门，右手抓紧门沿，往外拉。门轴发出涩声，缝隙扩大了两指宽。阿莲顺势把臂从缝里抽出来，人往后倒，肩胛撞在身后另一扇柜门上，发出一声闷响。她蹲下去，按住前臂，手背的淤青在灯光下泛着紫，指甲盖底下的颜色还没完全退。她低头看了一眼自己的手，没有出声，把前臂往白大褂袖子里缩了缩，像是要盖住那道淤痕。

“门自己关的。”她喘了两句才说出整句，声音压得很平，“我过来查柜，刚碰到门，它就自己合上，把我带进去了。”

陈默没有接话。他低头看了一眼自己的左手，小鱼际那道墨痕在冷白灯光下泛着暗蓝，尖端停在第三节指节的纹路里，没有变化。他收回目光，转头看卡住她的那扇柜门，编号：04-11。

柜门半开，里面是空的。底板上叠着一件蓝黑工装，折叠得很整齐，领口压平，袖口向内折，前襟右侧口袋鼓着一角。光线从灯管正上方落下来，照出布料上细密的洗白纹路，和他胸口口袋那张照片里的工装同一路旧渍。他蹲下去，没有先碰工装，先看柜门内侧。门轴处有一道新的擦痕，金属的毛边还没被氧化，是最近才被夹过的痕迹。

他抽出那鼓着的一角。一张叠了两折的纸，纸边卷起，带着那种放久了之后微微发潮的软。展开，两行字。

第一行是墨字：“22:45:03—22:45:45，删除签名：周。”

第二行是铅笔字：“柜已经空了，账还给你。”

阿莲按住前臂站起来，凑过来看了一眼纸上的数字。她没有碰纸，隔着一小段距离读完了那行墨字，问：“是不是我哥那42秒。”

陈默没有点头也没有摇头。他把纸折好，和工装叠在一起，装进胸口的塑封袋，拉链拉到头。阿莲看着动作，没有拦。她把前臂往白大褂袖子里又缩了缩，没有提那截淤青，只说：“这间柜子是空的。我昨晚查过，里面还有东西。”

“你昨晚看见什么了。”

“没看清。柜门开着一道缝，里面黑，我关上了。”她顿了顿，“今天再打开，就空了。”

手机在裤兜里震了一下。陈默单手撑开屏幕，殡仪馆内部转运系统的页面开着，一条新条目跳出来：

“03-17，06:05，已由家属领取。”

阿莲站在门口，看见他手机屏幕的光映在脸上，低声说了一句：“今天早晨没有家属入楼。没有人进出过。”

“你几点到的。”

“五点四十。”阿莲说，“比你早二十分钟。我从西门进的，路过值班室，看见门开着，灯灭了。”

“值班室灯是谁关的。”

“我不知道。”阿莲的声音压得更低了，“我以为是老白换班前关的。”

走廊的灯在他们头顶亮着，暂存间的门在身后慢慢合拢，发出一声轻响。两人走到监控室门前，阿莲靠在门框边，按住前臂伤口，指尖沾着一点干涸的紫。陈默从口袋里摸出钥匙，插进锁孔。

手指停在没转的角度。走廊灯在头顶嗡嗡响，灯管的光在门缝里跳了一下，又稳下来。他回头看了一眼走廊尽头，三号停尸间的门缝里，那线白灯已经灭了。
