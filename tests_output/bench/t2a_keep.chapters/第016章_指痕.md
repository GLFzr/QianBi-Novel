# 第16章 指痕

空气里的蓝黑墨水味没散。身后的人也不动，像一棵长在落叶堆里的树，呼吸都压得极低。

陈默左手小鱼际的墨痕被那股旧气贴着，边缘发热。他数到第三秒。

对方先开了口：“你爸核线那天，也在柱根蹲过很久。”

声音不年轻，也不老，像含着一口风在说话。语气平得没有起伏，陈述一件常见旧事。陈默注意到对方说话的节奏很慢，每个字都落在实地上，像是先在脑子里过了一遍才放出来。这种慢法，是提前计量过的吐字速度。

陈默没有转身。他的手在口袋里，指根贴着那截刚合拢的绳头，开口问了一句：“你是周记，还是替周记来取线的？”

身后沉默半拍。半拍够了。落叶在两人之间的空隙里被风推了一下，擦着地面发出细碎的声响。对方没有立刻接话，那半拍拖得比实际长，长到陈默可以确认对方对这个问题是有准备的，只是选择不顺着答。他把这半拍记下来，跟程师傅说话时那种停顿做比对，不一样。程师傅是舍不得说，这人是算着说。

“线干净。”对方说，“账不干净。”

陈默把这句话拆成两层。第一层，对方知道他口袋里绳头已经合拢，知道这根线的来路，甚至知道他在柱根蹲下去、把绳头完整带出来的动作。第二层，对方用了“账”字。来人替人管账，不是周记本人。他等了两秒，见对方没有补充的意思，才开口接下一句。声音放得很平。

“你爸最后一次核线。”对方又说，“是替他自己核的。”

风从货场缺口灌进来，卷起一片干叶，擦着水泥柱根滚过去。陈默的余光扫到柱顶那个粉笔字，落笔的角度斜着，从左上往右下压，撇长捺短，是右手的习惯。他低头看了一眼自己左手小鱼际那道墨痕，弧向正好相反。两个字用右手写成。他父亲惯用左手。他母亲以前提过一句，家里那台旧缝纫机只有他父亲能调，因为所有旋钮的方向都是按左手习惯排的。

“他把账算在谁头上？”

对方没有答。风把衣摆拍了一下，陈默听到金属磕在水泥面上的声音，很轻，像一把钥匙被放在柱顶。那个动作是刻意放稳的，金属边缘在粗糙的柱面上滑过一小段才停住。他这才转身。对方已经退到铁门边，半张脸埋在阴影里，只出来一句：“你爸核完线，把钥匙留给我。现在归你。”

“明天21:03，线在你手里，账由你核。”

铁门被推开一条缝，门轴锈得发涩，那声音在空货场里拖了很久。对方侧身进去，门缝合拢，脚步声没有远去，像停在门内一步的位置，等着什么。陈默没有追。他数了三个呼吸，门内的脚步声才开始移动，往货场深处走，越走越轻，最后被货场的空旷吞掉。

他先看柱顶。粉笔字“周记”旁边多了一把钥匙，锈迹把匙齿糊成一片，铁环上缠着半圈黑胶布，胶布边缘卷起，露出底下暗红色的铁锈。他没有立刻去拿，蹲下来，把粉笔字落笔的方向又看了一遍，再对照自己左手墨痕的弧向。两个字，右手写定。

他蹲着又看了一圈柱根。水泥柱和泥土交接的地方压着半枚脚印，鞋底的纹路是新的，尺码比他的大两号，和之前看到的那枚重叠但没完全对位。半枚脚印的后半段被一片干叶盖住，叶子是刚落的，叶脉还湿。

他站起来，拿起钥匙。钥匙比想象中沉，像里面封着什么东西。他凑近看了看，匙齿磨得很薄，不是常用磨损，更像被什么东西咬过。铁环上的黑胶布缠了两圈，第三圈只缠到一半，断口不齐，像是临时收的手。他把胶布边缘拨开一点，底下露出一道很细的刻痕，被铁锈填平了大半，只有借路灯的斜光才看得到轮廓。0317。和钥匙背面的0321隔着一条铁脊。他没有动那道刻痕，把胶布原样按回去。

翻开种子书时，风把他的衣角掀起一角。页码夹缝里那条竖线已经不往深处走了，停在“03”旁边。线头下方落了一小块深色墨点，边缘潮润，像笔尖蘸墨后在纸上顿了一下，没有继续写。他把书页边缘捻了一下，确认墨点是新落的。墨点落在“03”两个数字中间偏下的位置，像被一个顿住的笔尖正好蘸到那里。他合上书，指腹在封面上停了一瞬，没有翻开再看第二遍。

他拿钥匙的那只手垂在身侧，钥匙的轮廓隔着裤袋布料硌着腿侧。他借路灯的光把钥匙翻过来，背面有刻痕。刻痕极浅，压在一层锈底下，他用指甲沿沟底刮了一下，先刮掉上面那层浮锈，才看清笔画。0321，数字的收尾都带着同一个向下的顿笔，像写字的人习惯在最后一笔多压一点力。和旧表背面那道叠刻是同一只手。

他把钥匙放回塑封袋，和旧表、绳头并排放好。塑封袋的封口压下去时，他隔着薄膜又摸了一遍钥匙背面的刻痕，沟底有毛刺，新刻的，和旧表背面那道疤一样的触感。

转身往外走的时候，货场二楼有一扇窗亮了一下。一小片长方形的冷白灯，嵌在暗红的砖墙里，像谁掀开一道帘子又放下了。三秒，灭了。他站在原地，数到三，灯没有再亮。口袋里三件物证贴着腿侧，旧的、新的、还有那根已经合拢的绳，隔着布料互相硌着。他拿出旧表，表盘还是21:03，秒针纹丝不动。他抬头看了一眼那扇灭了的窗，把塑封袋口按紧，转身原路返回。

走出货场入口十几步，手机在口袋里震了一下。他摸出来，屏幕亮着。父亲的旧号码，一条短信，没有标点：“钥匙能开你爸在货场里最后一间办公室。21:03，灯会再亮一次。”

他回头，货场二楼那扇窗重新亮起冷白灯。隔着锈铁门的缝隙，一个人影站在窗前，没有动，像一直在等。
