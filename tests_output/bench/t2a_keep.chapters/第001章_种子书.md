# 第1章 种子书

钥匙扣上那截蓝色的尼龙绳从父亲账本封皮上拆下来，绑了七年没换过。陈默站在筒子楼底下，手指搓着绳结，也懒得抬头看四楼的窗。

手机在裤兜里震了一下。房东的催租短信，上周五那条刚交掉，这是新的一条：“小陈，月底前把上月的补上，别让我再打电话。”他锁了屏，呵出一口白气。城西这条死路，外卖不进，中介的人也不愿意拐进来。路边停着两辆锈了链条的电动车，一只野猫从墙根探了个头又缩回去。他三天前卖掉父亲那辆电瓶车，到手七百六，抵了半月的房租，剩下的缺口还挂在那儿。

楼道里走出一个穿深灰外套的女人，手里攥着钥匙，身后跟着个扎马尾的小姑娘。林兰把钥匙递过来，指尖在锁孔圈上顿了顿，又抬眼看了四楼的窗一眼：“你爸那几天说，有东西要留给你，我按着他说的没碰。”话到这儿停住，她舌尖像压着半句话。林果果拽了拽她妈的外套下摆，手里攥着个没吃完的糖葫芦。

“你爸有句话”林兰低头拨了一下女儿的发绳，又改了口，“算了，回头我自己跟你说。”她弯腰牵过林果果，头也不回往巷口走。

小姑娘走出几步又回了一下头，嘴里含着糖葫芦含糊地问：“妈妈，那个叔叔为什么把我家的钥匙还回来？他是不是也不要那个房子了？”

林兰没答腔，只把女儿往前带了两步，声音低下去：“大人的事。”

陈默没接话，钥匙在手里转了个圈。父亲留下的东西他心里有数，旧账、木工工具、一辆卖了不到八百块的电动车。有东西要留给他，翻不出什么花样。

他拧开门锁，门轴带起一阵灰，屋里的气味呛鼻子。凉茶在桌面上放得发黄，杯口凝了一圈褐色的茶渍，一张旧报纸摊着，日期停在半个月前，桌面有个水渍干掉的圆圈，杯子放上去之后没再挪过。墙角立着父亲的刨子和锯，木头把手的位置磨出一个光滑的凹坑，他指腹在那道凹坑上按了一下。他先把电闸拉下来，再去拨中介的电话，响了四声才接。

“陈先生是吧，您那老破小动迁还观望呢，先挂上，有信儿我通知您。”电话那头传来嗑瓜子的脆响，他挂断。房租下个月三号到期，邮箱里的水电单叠了四张，他记得一共一千六百三，欠一条都压着物业不办停水。

他开始分类。木工工具，刨子、凿子、角尺，归进一个纸箱；衣物叠好塞进垃圾袋，回头给收旧的用。收据册、电费单、账本理成一叠。手指翻过每一页时快得不用过脑，哪本是记日子的，哪本是记钱的，一眼就分得出来。他在公司做过七年财务，上个月裁员名单下来之前，还在替同事核对一笔重复报销。

隔壁在装修，电钻从墙那头没停过，他听着声音把最后几本册子分成两摞，又蹲下来把桌面那杯凉茶端去倒掉。洗水池的黄渍用了两把洗洁精才冲干净，他拧上水龙头的水，顺手把窗台也抹了一道。

分类到床头柜时停住了。抽屉最深处压着一本薄薄的旧笔记本，混在账本里。他抽出来，封皮是暗蓝色布面，边角磨得发白，比父亲的账本轻，捏在手里像捏一叠空壳。翻开封面内页，第一行是父亲的笔迹，蓝黑墨水，笔顺压得很稳：“种子书。记人未长成的事。”

斜角还有一行小字，铅笔写的：不可贪。页角有一串数字，手写，案：0317。他认得父亲写字的样子，账本上的数字都向右歪，这串数字笔锋直，下压重，不是父亲的字。

他翻了几页。全是空白，只有纸页边缘有一条毛糙的撕痕，像有人从某页撕掉了什么东西。他翻得慢下来。空白页一张接一张，全是空格子。整本本子翻完，一个日期、一个名字都没有，只有那行字和那行铅笔字。他把笔记本合上，塞进随身的背包夹层里。他不想细究。一细究就得在这屋里多待几天，而房东的信箱里还压着上月的欠条。

走到玄关时他又折回窗台。花盆底下压着张发黄的纸片，他探指头夹出来，上面写着两个字：陈默。余下的字被水渍咬断了，墨迹晕开成一片淡蓝。他把纸条放回原处，又从旧抽屉里翻出父亲常用的塑封袋，收好，塞进背包外侧。

锁门的时候，楼道口窜进来一个戴黄色头盔的外卖员。电动车刹得急，后轮碾上门前那摊湿泥，车尾一偏，箱底漏出的饮料渍在地面反着光，空气里一股糖浆洒出来的味道。外卖员一只脚撑地，单票边角折出一截印花，他捏着手机问：“3门317是这栋不？”

陈默说：“317在这栋不存在的门牌。”

外卖员低头核对手机屏：“这地址填的不就这个？我跑这一趟得超时了。”他弯下去把箱带重新扣紧，骂了句脏话，“行了哥，我再找找。”

他跨上车拧油门时，单票被风掀起来。印花的边角露出一串数字，取件码尾号正好是0317，日光把水渍照得发亮，那串数字折在陈默眼前，和背包里那本笔记本页角的数字叠在了一起。他站着没动，钥匙硌在手心里。外卖员碾过水渍冲出巷口，车尾一甩，消失在拐角。

他低头，看见自己左手里还攥着那张纸角。他把它夹回种子书的页里，锁上门。风把楼道里没撕干净的旧贴纸吹得卷起来，纸面翻出移、迁两个半边字。

到公交站才摸出异样。背包外兜里多了一样东西，硌手。他伸进去一掏，一块旧的机械表躺在掌心里，表盘上一圈细裂痕，指针停在22点47分。表把的纹路里卡着一点灰。他翻过来，表壳背面被人用硬物划过一串数字，笔画歪斜：0317。

他明明只碰过窗台和床头柜。他立在公交站台上，把表又翻回正面。秒针不动。表带的折痕是新的，像刚从谁手腕上摘下来。站台的铁皮顶棚漏着一条缝，夕阳从缝隙里斜切下来，正照在表盘的裂痕上。陈默听见自己咽了一口唾沫。没有车进站。他站在原地，表盘上的22点47分静静对着他。
