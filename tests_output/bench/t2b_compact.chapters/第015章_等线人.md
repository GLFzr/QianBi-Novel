# 第15章 等线人

夜里，陈默把旧表收回塑封袋，关灯。窗外的白色轿车没有走，车灯全黑，只有右前灯那道擦痕在路灯下泛着白。他没有拉窗帘，也没有回拨那个号码，只是把手机倒扣在桌上，屏幕朝下，等它自己熄灭。

他摊开地图，铅笔尖在坐标上点了三下。北纬31.17，东经121.47。旧表表盘21:03，背刻0321压在0317上。程师傅那句“你爸当年也这样核过线”。四样东西叠在同一张纸上，他看了很久，铅笔在“南岸货场”四个字底下划了一道。“货场方向”的指称，落点在东门街路口偏南约三百米，旧货场入口。

他合上地图，没有收进抽屉，压在那本种子书底下。窗外的白车还停着，钉在路灯下的影子。他背靠墙坐了一夜，闭着眼，没睡实。天蒙蒙亮时，他听见楼下传来一声水箱的嗡响，白车引擎盖上的夜露动了一下，然后车灯亮了，右转，驶出巷口，没有往东门街方向去。

天亮后他去了修车摊。程师傅不在，铁皮柜上压着叠好的蓝黑工装，白布条绣的0317朝上，内侧口袋已经空了，收账日纸片不在了。他翻工装夹层，指尖碰到一道极细的墨痕，笔锋走向和收据残角上那行字同路。他又摸了一圈，确认那道痕只到夹层中段就断了，像一句话说到一半被收回去。他没有声张，把工装放回原处，蹲下装线。

线槽口又多了一道竖刮痕，角度比昨天那道偏了半度，比那道更新。边缘发亮，刚被什么东西碾压过，还没有来得及氧化。

身后传来水桶落地的钝响。程师傅提着半桶水回来，水面晃着一层薄灰，他把锉刀往柜面上一磕，声音又脆又短：“周记明天来取线。你今天是等他还是走？”

陈默没答。他从口袋里掏出旧表和手机，摊在柜面上，屏幕亮着那串坐标。他手指点在“南岸货场”四个字上面，没有移开。

程师傅低头看了一会儿。他蹲下来，手指点了点货场那两个字，在地图粗糙的纸质上碾了一下：“早年那地方有个货场，废了十几年了。你爸去过。”

“去做什么？”

“在入口水泥柱上画了一道线。”程师傅抬眼，“就一道。画完就走了。”

“为什么画线？”

“你爸核线，核完线都要留一个记号。那天他画在柱上。”程师傅的声音低下去，“线是周记的规矩，货场是你爸的账。你能分开就分开，分不开就都别去。”

陈默想再问，程师傅已经把工装又往前推了一寸。程师傅的手指按在白布条上，压住0317那三个数字，指节发白。陈默没有再开口。

他把旧表和手机收回来，起身时膝盖在柜角刮了一下，声响闷短。程师傅也没有再说话，只低头用锉刀在柜面上来回磨了一个空。陈默走出摊棚的时候，身后的锉刀声停了。

下午，陈默独自走到坐标地。

东门街路口偏南约三百米，杂木围栏锈得看不出原来的颜色，栏上挂着一块掉漆的铁皮，铁皮上还有半行看不清的蓝漆字。荒地，草长得齐膝，中间露出一截旧货场的石基。水泥柱还在，断了一半，断裂面上长着青苔，柱身被雨水冲刷出一道一道灰白的水迹。他蹲下来，柱根泥土里压着一截蓝尼龙绳头，切口是旧磨损面，方向朝巷口。

他没有立刻去碰，先绕着柱根走了一圈。泥土表面有踩痕，不止一双，新旧叠在一起，最近的脚印纹路清晰，尺码比他大两号。他蹲回去，伸手，完整带出那截绳。长度约二十五厘米，切口磨损面发亮，边缘有一道细小的毛边，像是被什么硬物反复磨过。他把绳头和钥匙扣上那截并排摆在地上，切面咬合，纹路对上了。又和账本封皮线头对了一遍，绳芯的颜色从旧磨损里露出来，泛着灰蓝色的光。中间缺的那一拃，刚好填平。

他站起来，拍了拍膝盖上的泥。视线扫过水泥柱顶，粉笔字，新的，一笔一划写得很慢，两个字：周记。不是父亲的笔迹。他低头看了一眼自己左手小鱼际的墨痕，那痕迹比昨天又深了一点，边缘微微凸起，印在皮肤上，更像一道愈合的疤。

他站了一会儿，没有动。没有翻开书，但页脚的位置，页码夹缝里有什么东西正在渗出来。他低头看了一眼，一条极细的竖线，从夹缝深处浮到纸面边缘，自动补位。像一个字写到一半，笔尖刚刚提起来。他合上书，把书放回背包，拉链拉到一半时停了一下，又拉开，往夹缝方向看了一眼。竖线还在，没有变。

绳头放进口袋里。他转身要走，脚下一顿。身后有脚步声踩着落叶，一步一步，走到离他很近的位置才停。落叶被碾碎的声音在裤脚附近断掉，停得干脆，来人故意收了步声。

陈默没有回头。他低头又看了一眼左手小鱼际那道墨痕，边缘的凸起微微发热，像被什么贴着。

“你踩了三片叶子。”他说，“第三片是脆的。”

身后的人没有接话。空气里浮起一线蓝黑墨水的味道，很淡，混在草和土气里，在原地站了很久的那种旧气。
