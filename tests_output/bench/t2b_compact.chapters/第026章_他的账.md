# 第26章 他的账

台灯压着维修单一角。背面那行字已经干透，墨色从蓝黑沉成暗紫，纸面收皱。他把维修单和信筒、传单并排摆在桌面上，信封里那张单页纸抽出来压在最上面。三样东西叠成一册没有封面的账。

花盆下纸条他没有翻看，原样压进维修单同一格。手机屏幕朝下扣在桌角。

页角编号在台灯光里反着光。案：0317。他没有翻书，脑子里过的是另一个人：三号停尸间那条线的另一端，他见过两回。一回在改造他岔路口的傍晚，一回在殡仪馆西门路灯下。那个外卖骑手，黄工服，圆脸晒得发红。周航。

他从胸口抽出便签，压在维修单旁边。3月17日必须联系小周。

他捏着便签坐了一会儿。这通电话打过去，等于把改写过的人拉到明处，把周航标过价的人情重新翻出来。但便签上写的是必须联系。他按下拨号键。

响了很久，没人接。三十秒后，一条定位落进对话框：外环线尽头，一个还没亮灯的物流站点。后面没有多余的字。

他把便签压回胸口，推门下楼。程师傅修过的那辆旧自行车靠在墙根。他跨上去，链条没有响，力直接落在后轮上。

外环线路灯一半是黑的，夜风带着铁皮仓库的锈味。链条声在空旷的柏油路上格外清楚。

物流站点在外环线最后一盏路灯后面。路到尽头，两侧是没亮灯的铁皮仓库，一扇卷帘门拉到半人高，门缝里透出一线黄光。周航蹲在门口，膝前摊着刹车线，三根，一根旧的，两根新的。他左手捏住线头，锉刀在接口处刮出一道亮痕，刮完拿拇指抹了一下，举到灯下看。

周航还是那身黄工服，帽檐压得低，蹲姿很稳，脚后跟几乎没有离地。

陈默把车支住。脚撑落地，金属声在空地上滚了一圈。

"这车是程师傅修的。"周航开口，锉刀没停，"链条张力调得正好，他用过劲。"

陈默看了一眼车前轮，蹲下，隔着工具箱和周航面对面。

他抽出种子书，翻开，放在工具箱上。灯光从侧面斜过来，照亮那一页。

"周航，日期，时间，地点，动作细节。"

那是他第一次改写留下的格式。第二行空白，什么都没有写。

周航的锉刀停了。他低头，手搭在线卷上，离书页隔着半个工具箱的距离，看了很久。帽檐下的脸半明半暗，连呼吸都放轻了。

陈默摸出笔，笔尖悬在第二行上方，停了片刻，落下三个字：陈继先。写完套回笔帽，笔尖没有再碰纸面。

周航低头看得很慢，从第一个名字挪到第二个，看完抬眼扫了陈默一下。

陈默后来想，他应该写自己的名字，但他写的是他爸的。这个格式下面出现一个名字，意味着这个人被记过账。他把他爸写进去，等于承认他爸也是账上的一笔。

远处有车经过，光扫过卷帘门，又灭了。门缝里的黄光重新亮回来。

"我认得这个格式。"周航说，"我爸教过我。"

陈默的手停在书页边缘。他问："他在哪？"

周航没有接这句话。他放下锉刀，从钥匙环上拆下一把钥匙。铜的，磨得发亮，钥匙环的磨损处凹下去一道深槽。他把钥匙放到工具箱上，和陈默面前的种子书并排。

"他不是周记。他是被周记取过线的人。"

取线。程师傅也说过这个词。同一个说法，两根线压成一根。

"我爸当年让东墙那棵冬青树替你爸站了一夜。"周航的手按在钥匙上没松开，"这把钥匙埋在树底下，挖出来的时候锈得看不出牙口。殡仪馆西侧门。他留的。"

陈默的指节屈了一下。老白说过，你爸连续三个凌晨站在东墙那棵冬青树下。周航说，我爸让那棵冬青树替你爸站了一夜。两个人说的是同一棵树，同一个位置。中间隔着的，是这把钥匙。

周航松开手，钥匙留在工具箱上，接着往下说。

"我爸取完那根线，当天夜里去了殡仪馆东墙，在冬青树下站了一夜。第二天开始忘事。先忘钥匙搁在哪，再忘锁门，最后连自己叫什么都不记得。只有一件事忘不掉。"

他顿了一下。"3月17日。每年这一天他会清醒一整天，把椅子搬到路沿上，从早坐到晚，等人来取线。有人问他等谁，他摇头。问他等什么，他说线。再问，就什么都不说了。"

"这一天像一枚钉子钉进墙里，别的都拔光了，只剩这一枚。"

说完，周航抬眼，朝陈默左手的方向扫了一下。灯影里，墨痕的颜色比周围深了一档，看不出他是在看墨痕，还是在看别的东西。

陈默把种子书合上，插回后袋。

"账真的是这样记的吗？"周航问。

陈默没有回答。风灌过来，卷帘门晃了一下，黄光跟着抖。他的目光越过周航的肩，落在周航背后。

卷帘门半开的门缝里，门内侧站着一双鞋。鞋尖对着他们。鞋面落了一层灰，鞋底边缘沾着一圈湿泥，颜色和殡仪馆东墙根下的泥一样。

那双鞋动了一下。鞋尖转向内侧，退了半步，退进门缝的阴影里。门缝里的黄光被一道影子挡了一瞬，又亮回来。

门内空了。

陈默低头，伸手，把钥匙从工具箱上拿起来。铜的磨损处硌着手心，凉的。放进胸口口袋时碰到信筒的硬纸边，碰出一声轻响。他手指停了一瞬，往更深的地方推了推。

他背对着周航把书和钥匙都收好，站起来。身后周航的声音追过来，压得很低：

"你今晚不该来的。"
