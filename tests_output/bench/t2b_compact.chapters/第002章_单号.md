# 第2章 单号

路灯一盏接一盏往后跑。陈默蹬着共享单车穿过城西那段没修完的路，车轮碾过沙石堆，车筐里的背包跟着颠。手机又在震，他没停，骑到出租屋楼下才掏出来。房东的消息：周六晚上十点前把水电费交了，不然周一停水。他锁上车，夹着背包上楼，楼道里的声控灯亮了两层又灭了一层。

进门开灯。纸箱摊在地板上，纸箱底垫着的旧报纸上印着三天前的日期。他把父亲那堆物件分成三堆：工具、衣物、账本。分类到最后一摞时，手指碰到那本薄笔记本，动作顿了一下。他把种子书单独从纸箱里拿出来，放进抽屉最里层，不上锁，又把几张废纸盖在上面。抽屉回推时发出咯一声，他盯着抽屉缝看了两秒，抬手关上柜门。

他坐在床沿给父亲手机号打电话。窗外的路灯透过没拉严的窗帘缝，在床单上切出一条光带。第一声还没响完，听筒里就传出机械女声：您拨打的号码已关机。他准备挂断再按销号流程走，手机却在此时震了一下，屏幕弹出一行字：有一条未播放的通话录音，是否收听。他愣了愣，点了是。

录音大约四十秒。前十几秒是一片杂音，布料摩擦，抽屉开合，什么东西在桌面上磕了两下，像是有个人在收拾房间，动作刻意放轻。接着是父亲的呼吸声，他在说些什么，声音很低，像是怕隔墙有人听。陈默把手机贴紧耳朵，呼吸也放轻了，听见几个片段："……这个放那边……别动那个。"又过几秒，父亲的声音清晰了些，他说："这本子留给陈默。告诉他，账由谁收，得他自己去弄明白。"门铃声从听筒里响起，录音断在那一个字上。

陈默坐在床沿没动，手机还贴在耳朵边上。他听了一遍，又是一遍。第三遍时他把耳朵凑得更近，录音末尾门铃响过之后的底噪里，传出一个电子女声的播报："您有新的外卖订单，编号0317。"

他猛地抬头。外卖单。今天在筒子楼楼道里，那个外卖员手里攥着的单票，取件码尾号是0317。他当时只当是巧。他翻身下床去翻那件外套的口袋，外套还搭在椅背上，他摸了两下，果然在夹层里摸出那张外卖员塞给他的单票底联。单号区印着：0317。

同一串数字，一天之内第三次出现。陈默站在衣柜前，手里攥着那张底联，纸角被他捏出了折痕。手机屏幕亮着，录音停在最后一秒。他走到桌前，拉开抽屉，把那本种子书从最里层抽出来，翻到第一页。那行蓝黑墨水的字已经看熟了：种子书。记人未长成的事。旁边铅笔写着不可贪。页角那串数字压着纸纹：案：0317。

他拿起桌上一支旧圆珠笔，笔尖抵在纸面上，压住那串数字，停住。只要写一个字，就能知道这本子到底有没有用。但他不知道这一个字会付出什么。笔尖在纸面上来回磨了两下，留下一道浅痕，没有墨迹。他合上书，关灯，躺下，把种子书压在枕头底下。

夜里两点十七分，他翻身碰到枕头下的硬角，醒了。手机屏幕亮着，不知什么时候弹出一条通知：您有新的通话录音已保存。他点开通讯录，指尖滑到那个备注为"爸（老宅）"的号码。号码底下有一行创建于三年前的备注：0317，他生日。

陈默看着那三个字。他生日，三月十七日。所以那是日期。他顺手点进备忘录，屏幕停在最后一条记事，是父亲留的，只有一行字："3月17日22:47，去东门街路口。"

窗外路灯还亮着。楼下马路牙子上停着一辆外卖电动车，骑手没进任何一栋楼，头盔在灯下一闪，又暗下去。手机屏幕上方，时间跳到2点18分。楼下那辆电动车响了一声，却没走。
