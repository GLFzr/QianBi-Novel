# 第21章 空柜

凌晨五点四十分，殡仪馆东门铁门虚掩，露水把柏油路打出一层暗光，半排路灯亮着，另一半憋在雾里，在路面拉出长短不齐的影子。陈默把种子书和信筒按在胸口，来回走了两趟，停在门边。风从停灵区灌出来，宣传横幅哗啦响了一串，混着消毒水和铁锈的闷味。他解开外套第二颗扣子，确认胸口那个口袋里的东西没有压皱，又扣回去。手机屏幕停在阿莲那条消息上：明天早上六点，殡仪馆东门，别带别人。没有新消息。他锁屏，又解开，最后把手机塞回裤兜。

天边压着灰白一线，太阳还没露头。他翻过左手，小鱼际的墨痕在路灯下发暗，细短的线头已经爬进第三节指节的纹路里，比昨夜深了一档。五截线、单页纸、半张纸片都叠在胸口，他只等六点整。

六点过七分，阿莲没来。

他拨过去，第七响转成短信提示音。挂断，重拨，还是同一段录音。铁门虚掩得太安静，安静得像是专门替他留的。他推门进院，值班室灯关着，门没锁，烟灰缸是干净的，充电线插在插座上，人不在。他退回走廊，停下来。

走廊尽头传来一声金属响动，很闷，像什么被卡住又弹回去。

他朝那个方向走。

暂存间的门虚掩着，缝隙里漏出一线白冷光。他推开门，冷气迎面扑出来，混着长期空置的铁锈味。阿莲卡在两扇半开的冰柜门缝之间，右前臂嵌在缝里，肩膀被夹着，半边身体歪在门上，脚尖在地砖上打滑。她咬着下唇，听到门响，眼睫抬起来，认出他，唇线松了一下又咬回去。指甲盖泛着一层灰蓝，像冻了很久。

他两步跨过去，脚蹬住地，两手各扳住一扇门往外拽。冰柜门重得像灌了铅，胳膊绷到发抖也只挪开一指缝。他侧过身，用肩膀顶住门框借力，再拽，门缝又开了一点。阿莲往外抽手臂，抽一半疼得停下，吸了口气再抽，整条手臂滑出来，压出一道青紫色印痕。他抓住她手腕把人带离柜门，门在身后弹回，哐的一声闷响。

阿莲贴着墙根滑坐，额前全是汗。她前臂内侧那道压痕从手腕延伸到肘弯，边缘红白分明，皮肤上印着一圈橡胶条的花纹。手臂在抖，她伸手把头发拨开，喘了两口气，没哭也没叫。

“门自己关的。”她说。

陈默蹲下去，手垫在她后脑让她靠墙：“几点进来的。”

“六点差两分。早到了一会儿，想把03-17先拍清楚。”阿莲抬下巴朝那排冰柜一指，“推开柜门举手机，旁边这扇门自己合过来。抽手，慢了一拍。”

“哪扇。”

“就卡我这扇。”她偏了偏头。

陈默站起来，顺着她指的方向走到第四排，右起第二扇。编号03-17，柜门半掩。他抬手拉开，冷气扑出来，柜里是空的。担架面干干净净，只压着一道撤走重量的浅痕，轨道滚轮停在原位。

他推回03-17，转回卡过阿莲的那扇门。编号04-11。拉开。

柜里空着，底板上叠着一件蓝黑工装，对折得很整齐，领口压在底下，前襟口袋鼓出一个角，形状像叠起来的纸。他伸手抽出那个角，是一张叠了两折的纸，纸缘发黄，卷边。

他展开纸，平摊在柜门板上。

第一行是蓝黑墨水字，笔迹像他的，又像是有人借了他的手，写得比他平时刻意：22点45分03秒至22点45分45秒，共42秒。删除签名：周。

第二行是铅笔字，缩在纸的右下角，字形很小：柜已经空了，账还给你。

他指腹沿着纸缘压过一圈，停在折角处。纸叠过两折，折痕压得极深，按折痕展开，是提前叠好放进来的。42秒，正好是阿莲哥哥旧案监控缺失的那段。删除签名落在同一个周字上。他把这句话压下去，没有说出口。纸面移开，露出那件工装。前襟没有绣线，跟照片里03-17柜内那一截对不上。他摸了一下领口内衬，那里有一道缝合过的旧痕，线脚细密，像是原来绣着什么，拆掉了。

阿莲按着手臂走上来，在柜门边站定。她探身凑到纸面上方，膝盖抵着柜门，手指悬着，没有碰纸，沿字行移了一遍，停住。“这是我哥那42秒吧。”她说。

“还没对上。”陈默把纸沿原折痕叠回去，塞回工装口袋，整件卷起来装进随身的塑封袋，拉链拉到顶，别在腰后，“这个我先拿着。”

阿莲没追问。她扶着柜门站起来，跟着他往外走。

刚进走廊，手机在裤兜里震。他单手滑开屏幕，内部转运系统推来一条：03-17，06:05，已由家属领取。

他停下脚步。阿莲注意到他停，凑过来，半寸的距离，两个人的肩膀碰在一起，她在那条消息前停了很久，没有说话。她转身走到走廊尽头，推开通往外面的门一道缝，冷风从外面钻进来，她站在门框里停了一瞬，又关回来。

“外面没人。家属通道上了锁，西门只有夜班卡能开。我六点零五分人在暂存间，那扇门从头到尾没响过。”她的声音压低，“登记册在门卫那儿，今天早晨那份，我来的时候还是白纸，没人翻过。”

走廊灯在头顶嗡嗡响。03-17的领取时间是06:05，跟阿莲被困几乎同一分钟。可登记册是白纸，门没有响过，系统里却落下一个家属的名字。两件事对不上，他没有开口说。他左手垂在身侧，墨痕的尖端在灯光下又往上爬了一点，不凑近也看得清。他把手机收进裤兜，指腹碰到胸口信筒的硬边，又松开。

两人走到监控室门前。阿莲靠到门边，按住前臂伤口，白大褂袖口洇出一小片暗红。陈默把钥匙插进锁孔，手指停在钥匙柄上，没有转动。走廊灯仍嗡嗡响。

“你先进。”阿莲说，“我在门口。有人来我先拦。”

他拧动钥匙，锁芯转开，推门进去。监控屏亮着，画面停在暂存间第四排柜的全景。他伸手要调回放，屏幕右下角先弹出一条内部消息。

发送时间：06:03。备注栏：家属。内容只有三个字：

“他来了。”

门外走廊风挤进一道，门扇合拢，锁舌咔嗒一声落回锁槽。门把手上，阿莲的血印还湿着，被走廊风吹出一道斜尾。
