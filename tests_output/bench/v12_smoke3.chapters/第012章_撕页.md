# 第12章 撕页

程雨走出快餐店玻璃门几步，又折回来。她没进门，只把手伸进来，掌根压着一张对折的纸巾，按在陈默手里。手指冰凉，沾着刚才那杯热水的潮气。

“撕的那行下面还有字，是‘0317前必有一笔’。我没敢全撕。”

她说完转身跑向路边，钻进一辆等着的出租车。陈默站到门外，路灯把纸巾照得发白。圆珠笔字迹在光下泛蓝，他把纸巾折好放进口袋，指尖碰到种子书硬壳边角，硌了一下。

他掏出手机想记时间，屏幕亮起时，脑子里空了一块。医院走廊、出租车、快餐店门口那辆减速又加速的车，中间全没了。他只记得程雨坐下，记得自己打了一行字给她看，记得那杯温水是温的。之后就是现在。太阳穴跳了两下。

他翻开种子书。页痕上“已有一人偿过”下面浮出一行新字，墨色比往常沉得多。

旧账将满。

四个字，不等宽，笔画收得紧。陈默把本子合上，借着路灯又翻一次。字还在。风从巷口穿过来，吹得书页边角翻了一下，他用拇指压住。

他拦了辆出租车回城西。车过东门街路口时，他叫司机靠边停。护栏变形段还在，白车被拖走了，地面碎玻璃被人扫到路牙边，堆成一小撮。修鞋摊老周收了摊，木板凳倒扣在架子上。路口信号灯正在调试，黄灯闪了三轮。

他没下车，让司机继续开。到老屋巷口，一辆电动车堵在楼道门洞。外卖员单脚搭在踏板上，手机支架横着，屏光映亮下巴。他抬头看了陈默一眼，没说话，拧了拧把手，电动车擦着墙根拐出巷口。车尾贴着美团标识，尾号被泥糊了半截。

陈默记下那个模糊的尾数，转身上楼。

楼道灯坏了两层，他摸扶手上到三楼。敲林兰家的门，三下，指关节叩在铁皮上声音发闷。没人应。他把耳朵贴近门板，里面有电视声，调得很低，像是新闻播报，含混得辨不出内容。他停了手，退后半步。屋里遥控器按了一下，电视声没了。

隔壁门开了一条缝，一个穿汗衫的老头探出头。

“找林兰啊？带孩子出去了吧。”

陈默点头。老头缩回去，门合上，锁舌咔哒一声。他站在走廊里，能听见自己呼吸在空楼道里的回声。

他用自己的钥匙开了隔壁父亲那间。屋里霉味比上次重，窗台那盆绿萝枯了半边。他直接走到书架前，最上层积灰，手摸过去沾了一层。一本旧台历侧着插在书堆里，封面印着“2019”。

他抽出来，翻到三月。

3月17日那页被沿着装订线撕走了。他凑近看撕口，纸根还留在装订钉上，毛边几乎没有，撕得很仔细，像是用尺子比着扯的。他合上台历又打开，确认那页确实不在。

手指摸过纸面时，指腹感觉到规律性的凹痕。字写在上一页时用力压下来的，反向凸在下一页上。他拉开抽屉，翻出一截铅笔头，斜着在凹痕区域轻轻涂。

三个字慢慢显出来。

收账日。

笔迹他认得。父亲写字有个习惯，横画收笔时会往右下压一点，“收”字最后一捺拖得比常人长。“账”字贝字旁写得窄，右边长，像要把什么东西裹住。

陈默把台历搁在桌面上，翻开封面塑料膜。膜内侧夹着东西，他倒过来抖了抖，一张对折的纸片滑出来，落灰里。

汇款单存根。边角发黄，纸质比现在的薄。2018年7月13日，收款人林建国，金额五万元整。汇款人一栏写着父亲的名字，字是银行柜员机打的，圆头圆脑。

日期在林建国坠亡前一天。

他把存根翻过来。背面有铅笔字，被拇指磨淡了半边，还能识读。

替人挡，替天改不得。设局者不可信。

最下面落款一个“珩”字，最后一竖拖出个弯钩。

陈默把存根凑到台灯下。灯管跳了跳，他拧紧灯座。“设局者”三个字笔压明显比前后文重，尤其是“局”，最后一笔把纸都划出了毛边。铅笔芯在那个字上断过一次，留下一个针尖大的灰点。

他把存根和纸巾一起夹进种子书最后一页，走回书房窗边。对面三楼，林兰家的灯亮着。窗帘拉着，缝里有光透出来。他站定没动，等了大约两分钟。窗帘缝里有人影晃了一下，随即一只手从里面把窗帘拉严。那只手虎口位置有道深色印子，隔着玻璃和窗帘的距离，看不清是胎记还是划痕。

陈默没打电话。他收回视线，把种子书合上。五指收紧，书脊硬边压进掌心那处旧墨痕里，有点钝痛。他走到门口，停下。

台历还摊在桌上。他走回去，打算合上。手碰到封底时，前面的月份页翘了一下。一月那页空白处有一行铅笔字，被划掉了，划痕很轻，压痕还在。

7.14 海堤三号脚手架 林

他凑近看。“林”后面还有个字被划得几乎看不出来，笔画的轮廓残留着一个框。像“局”，又像“园”。

7月14日，林建国坠亡那天。

陈默翻开一月那页，对着灯照背面。划痕穿透了纸，背面有个浅浅的凸起。他没有再拓。合上台历时，窗外的风把窗帘吹起一角又落下。

他把台历放回书架原位，食指在书脊上停了一下。楼道里，林兰家的方向传来一声闷响，像凳子腿磕在地板上。
