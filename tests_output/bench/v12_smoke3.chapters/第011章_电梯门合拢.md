# 第11章 电梯门合拢

出租车后座有股烟味，坐垫塌下去半掌。陈默报出市三院，司机嗯了一声，打表。

他低头翻手机备忘录，翻到程雨的名字，按开通话记录。昨天18点11分来电，通话时长3分42秒。仅此一项。内容全空，点进去只有波形图，一条平直的线。他记得昨天接过这通电话，记得自己说过好、嗯、知道了，但想不起在哪个时段、什么场景。老地方是哪个出口、哪个咖啡馆、靠窗还是靠里。手指在屏幕上划了三次，划出一片湿印。

司机从后视镜看他一眼，单手把着方向盘问走哪条路。陈默抬头，声音卡了半拍，才说走东街，过桥。司机嘟囔一句导航让走滨河。他说东街。车拐进慢车道时，雨刷刮过一层薄雾，玻璃上糊开两道灰痕。

住院部走廊的灯管有一段在闪。拖把靠在墙角，墩布头滴着水，消毒水味被潮气压住，闷在瓷砖上。陈默推开十六床的门，脚步收在门框外。程师傅面罩扣着，雾气在透明罩里一潮一退，床头心电监护的绿线走得平。陪护椅空着。椅面凹陷还在，手摸上去没有余温。

他拉开床头柜第一层抽屉。病历夹、纸巾、充电线、一包拆了口的饼干。第二层半开，内里杂物堆得乱，明显被翻过。他把手探进程师傅枕下，从靠墙那侧摸到床板，空的。剪报册不在。

陈默推醒程师傅。老人眼皮掀开一道缝，手指动了动。问他剪报册，老人喉咙里含混出一句：“被拿走了。那个戴帽子的。”

护士端着药盘进来，看见陈默愣了一下。他问傍晚有谁来过。护士翻了翻监护记录，说有个男的，自称程师傅朋友，待了不到十分钟，帽檐压得很低，穿深灰夹克，右手虎口有块深色印子，像胎记，也像旧伤。陈默问几点。护士想了想，说换班前，六点半左右。

手机在裤兜里震。程雨来电。接通后背景有风声，叶片被吹得簌簌响，程雨压着哭腔说：“有人在跟着我，我在医院后门那个小花园。”陈默让她待在灯底下，别走远，别关电话。他拔腿就跑，走廊拖把被他带歪，墩布头在地上拖出一道水印。

小花园的长椅旁，戴帽男人站在程雨面前。右手插兜，左手按在椅背上，身体微微前倾。陈默从侧面冲上去，插进两人中间。男人转过头，帽檐下露出半张脸，颧骨高处有一道旧疤。他叫出陈默的名字。

陈默没应。程雨缩在他身后，手抓住他外套后摆。男人把右手从兜里抽出来，虎口那道深色印子在路灯下泛着哑光。他看着陈默，问程雨：“你爸的剪报册在哪。”又转向陈默：“你替他收着？”

陈默挡在程雨前面，右脚本能往后挪了半步。男人的视线从他脸上滑到背包侧兜的位置，停了半秒。陈默没答，左手悄悄抓住背包带。男人看了他三秒，松手，退进树影。脚步踩碎几片干叶，声音往围墙方向去了。

陈默没追。回头看程雨，她手还在抖，指尖发凉，嘴唇白了一圈。他把她带回住院部，从背包侧兜抽出种子书。翻到页痕那页，“0317前，勿再动笔。手记。”下面那行“已有一人偿过”墨色发沉，笔画边缘泛着灰黑。他捏住笔，笔尖悬在纸面上方，离页面不到半寸。

程雨在他身后说：“他问我，书里的账，你爸还了多少。”

陈默手腕一颤，笔尖蹭到纸面，没落墨，只留下一道极浅的压痕。他合上书，塞回背包。拉上拉链，拉链头在槽里顿了一下才咬合。他对程雨说，换地方，今晚不住这。

走廊尽头电梯叮一声。门打开，灯亮着。戴帽男人站在轿厢里，右手按住开门键，虎口那道深色印子正对着陈默。他没动，只是看着他们。陈默拉住程雨往后退了一步。

男人松开按键。门缝开始收窄，最后一道光里，他把手抬起来，按下了关门键。

门合拢。楼层号开始跳。

程雨摊开手心。掌心里是一角撕下的剪报纸，纸边毛糙，一半被汗浸透了。上面只剩半个偿字，竖心旁被撕口截断，右半边的尚歪在毛边上。陈默伸手要接，程雨先合上手指，把纸角收回掌心。

“他拽我胳膊的时候我撕的。”她说，“我不知道撕到了哪一页。就这一角。”

陈默看着程雨合拢的手，没有去掰。他转身按了下行键，另一部电梯的指示灯从一楼慢慢往上爬。数字每跳一格，他脑子里就过一遍刚才那男人的脸。帽檐压到眉骨，只露半截鼻梁和下颌，叫出他名字时没有犹豫。对方认识他，或者认识他父亲。

“你以前见过他吗。”陈默问。

程雨摇头，声音还压着：“他问我剪报册在哪的时候，语气像在问他自己的东西。他说‘你爸从我这拿走的’。我没听懂。”

电梯到了。门打开，里面空着。陈默让程雨先进，自己跟进去，按了一楼。轿厢下行时他站在门边，右手插在背包侧兜里，指尖搭着种子书硬邦邦的书脊。他没有再翻开的打算，但手指需要一个着落。

那角纸，他开口，能给我看吗。

程雨犹豫了两秒，摊开手心。纸角被汗洇得发皱，半个偿字笔画粗重，是铅字印刷体。陈默凑近看了一眼。竖心旁被撕口切得只剩一竖，右半边尚的上半截还在，底部被撕掉。他想起剪报册第三十七页的标题字体，和这个一致。

“这是册子里的页。”他说，“你撕的时候，旁边还有字吗。”

程雨闭上眼，像在回忆。“有。我撕的时候瞄到一行，上面有‘偿’字，下面好像还有一行小字。他拽我，我就没看清。”

电梯到一楼，门打开。住院部大厅空荡荡，夜班保安在导诊台后面打瞌睡。陈默带程雨从侧门出去，绕到停车场。他没有叫车，站在路灯下把手机地图放大，找附近还在营业的便利店或快餐店。屏幕亮着，他余光扫到程雨正望着停车场入口方向。

“他会不会跟出来。”程雨问。

陈默说不会。他其实不确定，但这句话必须说。

他找到一家两公里外的二十四小时快餐店，收起手机。走之前他把背包转到胸前，拉链头朝内，一手护着。程雨跟在他半步后面，手里那角剪报纸被她折了两折，塞进外套内侧口袋。

走出医院大门时，陈默回头看了一眼住院部五楼。十六床的窗户亮着，程师傅应该还在睡。他又看向后门小花园方向，树影里没有人。路灯把两个人的影子拉得很长，一前一后叠在水泥地上。

明天，陈默开口，声音比平时低，你爸的剪报册，除了你和我，还有谁知道。

程雨想了一会儿。“我爸那些工友。还有……我妈。”她顿了顿，“我妈走得早，但册子里有几页是她剪的。我爸说过，册子里的东西不能给外人看。”

陈默脚步没停。册子被拿走，对方要找的是书里的账。他父亲在册子第三十八页背面写了“代价已偿：林建国”，那册子本身就是一本账。戴帽男人问“你爸还了多少”，问的是种子书的账，还是剪报册里的账。两个账本，一本在明，一本在暗。

快餐店灯牌远远亮着。陈默推开玻璃门，选了靠墙的位置，让程雨坐里侧。他去柜台要了两杯热水，回来时程雨已经把纸角重新摊在桌面上，用纸巾压着边。

陈默坐下，没碰那角纸。他打开手机备忘录，打了一行字递给程雨看：今晚别用手机联系任何人。程雨看完，点头，删掉那行字，把手机屏幕扣在桌上。

窗外马路上有辆出租车减速，又加速走了。陈默等那辆车尾灯消失在路口，才把背包拉链拉开一条缝，确认种子书还在。他合上拉链，拿起水杯喝了一口。水是温的，咽下去时喉咙有点紧。

程雨忽然说：“他叫我名字的时候，没叫全。只叫了‘程雨’两个字，像确认我是不是。”

陈默放下杯子。那男人叫他全名，叫程雨只叫名。一个用了确认，一个用了辨认。他不知道这区别意味着什么，但记住了。

“天亮了再说。”他开口，声音压得很平，“你睡一会儿，我看着。”

程雨没动，手按在纸巾上，纸角边缘的毛刺翘起来。她低头看着那半个偿字，忽然问：“陈默，你爸的本子，和这个有关吗。”

陈默没有立刻回答。他看向窗外，快餐店灯牌的光映在玻璃上，叠出他和程雨的倒影。倒影里，他身后的玻璃门外，马路对面的人行道上，一个戴帽子的轮廓正从路灯下走过去，步子不快，右手插在兜里。

他转回头，看着程雨的眼睛。

有关，他说，但今晚不聊这个。

他伸手把纸角从纸巾下抽出来，翻了个面。背面什么都没有，空白纸面被汗浸得发黄。他把纸角重新推到程雨面前，手指离开桌面时，指尖在桌沿停了一瞬。

收好，他说，明天找个人多的地方，你再告诉我撕到的那行字下面写了什么。

玻璃门外的轮廓已经走过去了。陈默没再看第二眼。
