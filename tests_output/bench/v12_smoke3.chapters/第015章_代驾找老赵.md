# 第15章 代驾找老赵

站台顶棚缺了一块，风从豁口灌下来，把线路图吹得哗啦响。末班车拐过路口，尾灯缩成两粒红点，很快被楼角吃掉。陈默站在黄线外，手机屏还亮着，屏幕上是站牌背面那行字的照片，记号笔写的，笔画拖出毛边：代驾找老赵，电话尾号0316。

他退出相册，把那串号码按进拨号盘。嘟声响到第六下，被人按掉。再拨，听筒里换成忙音，接着是无法接通。

他没等下一班。烧烤摊的油烟从巷口漫过来，混着炭火和孜然的味道。他背起包往巷子深处走。

这一片入夜才活。卷帘门拉到一半的小饭馆，门口马扎上坐着端碗的人，白汽糊在玻璃上。修车摊收了，工具柜锁在路灯杆下。陈默沿街走，一辆一辆看路边停着的折叠电动车。代驾的车好认，车把上挂着绿色平台牌，后架竖着折起来的车架。他数到第七辆，才想起自己在数什么，停了下来。

他其实拿不准要找的人是不是代驾。站牌背面那行字只给了三个词：代驾，老赵，一个尾号。夜市口是这一带入夜后唯一还醒着、还能聚人的地方。他把那张照片又调出来看了一遍，确认老赵两个字的走之底连成一笔，写得很急，和站牌上一模一样。

夜市口在两条巷子的交叉处。便利店灯牌底下停着三辆车，四五个司机挤在马路牙子上抽烟，谁的手机立在膝盖上开着接单页面，绿光一闪一闪。陈默走近，听见有人冲其中一个喊。

“老赵，这单你接不接。不接我先眯一会儿。”

应声的是个矮个子，五十上下，穿件旧皮衣，袖口磨得发亮。他正低头划手机，拇指在屏幕上划了两下，把烟头在鞋底摁灭，站起来。

“哪儿的。”

“城西。”陈默报了那条巷子的名字。

老赵上下打量他。夜里风硬，陈默把包带往肩上提了提，站着没躲。“四十五。走不走。”

“走。”

老赵从后架搬下折叠车，抖开，拧了拧车把。他自己跨上驾驶位，陈默坐后座。旁边那个年轻司机冲他们抬了抬下巴：“赵哥慢点。”

电动车驶出夜市口，拐上主路。

夜里车少。老赵开得不快，等红灯停稳了才开口：“你住这片？”

“嗯。”

“这片快拆了。”老赵喉咙里哼了一声，“我早些年也在这儿住过。筒子楼，一层共一个水房，冬天水管冻上，得拿开水浇。”

陈默应了一声。老赵也不在意，自顾自往下说：“干代驾七八年了。闺女今年上大学，一年学费小一万。白天在家睡一阵，晚上出来跑，比开出租强。”

说到闺女，他右手在车把上松了一下，又握回去。

电动车穿过一段没路灯的窄路，后座颠了一下。

半路，老赵的手机响了。

他低头看了一眼屏幕，车速慢下来，右手把手机换到离陈默远的那一侧，声音压得很低。

“嗯。”

“明天城北那老小区。”

“七点半我过去。”

“知道知道。”

一共几句话，说完就挂了。

他把手机塞回兜里，半晌才开口：“一个老客户，跑长途的。”

陈默把这句话放过去。他把听见的几个词在心里过了一遍。城北，老小区，七点半。老赵说的是明天。

夜风从侧面吹过来，衣领贴着后颈。他想过要不要问，问一句明天去哪儿，问一句那个老客户是谁。话到嘴边又吞回去。问了，老赵也许会记住他这个人，记住这天夜里坐过他后座、问过他私事的乘客。禁令还压着，他不能用别的方式补，就只能靠不问。

前方路口的绿灯闪了，老赵拧油门穿过去。转向灯亮的那一下，陈默看清他左手虎口有一道月牙形的旧疤，浅白色，弯在拇指根上，和戴帽男人虎口那块深色印子不在一个位置。

到巷口，陈默扫码付了钱。老赵把折叠车搬下来，撑开，准备调头。巷口那盏路灯瓦数低，光只照到车轮，照不全整车。后架上那只布包正好落在灯下。

灰扑扑的旧布，边角磨出白茬。正中绣着一圈缠绕的线形花纹，线脚褪得看不出原色，只能认出走势是一圈套一圈，像盘起来的什么。

老赵临上车，半回过头。

“明天那单跑完就不跑了，回家给闺女打个电话。”

他拧油门走了。

陈默站在巷口。电动车驶出十几米，一辆过路的车开着远光迎面过来，灯光扫过后架，那只布包上的绣纹亮了一下。褪色的线在强光里显出一种深灰，和背包侧兜里那本旧书的封皮，一个颜色。

电动车在下一个路口拐了弯，拐向的正是东门街方向。尾灯被路口的楼影吞掉。

陈默掏出手机，备忘录里敲下三行字。老赵。明晚七点半。城北老小区。打完他看了看，锁屏。种子书贴着侧兜，他把手按上去，隔着布摸到硬壳的边角，凉的。

他转身往巷里走，走了七八步，脚底下放慢。老赵那句话跟上来，明天那单跑完就不跑了。跑完。他停住，没回头，把这句话在心里拆了一遍。跑完，说明老赵认定明晚那单能顺利收尾，说明他根本不知道明天会发生什么。

巷子两侧的窗户大半黑着，只有二楼一户亮着灯，电视声从纱窗里漏出来。陈默掏出手机，翻到通讯录里那个尾号0316的号码。他今天拨过两回，一回被按掉，一回无法接通。现在他盯着那串数字，拇指悬在拨号键上方。老赵本人已经见过，页痕指的人不会有错。可这号码是谁的，为什么写在站牌背面，为什么和程师傅卷宗里的0316同源，他一个都没解开。

他没拨。禁令压着，页痕说0317前勿再动笔，没说不能打电话，但他觉得这条线不该从号码那头拽。老赵接约单时侧身压低声音那个动作，他记得清楚，那是常年跑夜车的人对客户信息的本能护着。陈默如果现在拨过去问，等于告诉对方有人在盯。

他把手机收起来，继续往里走。走到单元门口，摸钥匙的时候碰到背包侧兜，种子书硬壳的边角硌了一下手。他没把书抽出来，只把兜口按了按，确认拉链还拉着。

楼道里声控灯坏了，他摸黑上到三楼，开门，没开大灯，只拧亮厨房那盏小的。水壶烧上，他坐在桌边，把手机备忘录那三行字又看了一遍。老赵。明晚七点半。城北老小区。

他点开地图，搜城北老小区。跳出来三个结果，一个在城北偏东，两个在西北角。哪个是老赵说的那个，他不知道。七点半，老赵从城东夜市接单出发，到城北最快也要四十分钟。也就是说，出事的时间点可能在七点半之后，也可能就在他骑车赶去的路上。页痕只写了明晚，地点和形态都空着。

水开了。他倒了一杯，没喝，看着杯口的热气往上走。脑子里的账本翻过一页。0316，吴某，网约车碰撞案。程师傅记下这个编号的时候，一定也像他今晚这样，坐在某盏灯下，把线索一条条摆开。区别是程师傅没有种子书，只能靠纸和笔。而他手里有一本，却不能用。

他端起杯子喝了一口。烫。舌尖缩回去，他把杯子搁下，起身走到窗边。窗外是巷子，路灯底下空荡荡的，烧烤摊的余烟在拐角散开，比刚才淡了。远处东门街方向，有一盏车灯拐进巷口又拐出去，不是老赵的电动车，速度太快。

陈默站了一会儿，回到桌边，把便签从钱包夹层里抽出来，压在手机下面。账期已满。下一次不是记忆。他翻到便签背面，空白的。他拿起笔，想写点什么，笔尖悬在纸面上停了几秒，最终只把便签重新折好收回去。

明天白天，他得去城北那三个老小区里找一个。不用笔，用腿。他关掉厨房灯，躺到床上，眼睛睁着。天花板上有路灯透进来的一小片光，随着外面偶尔过的车晃一下。他翻了个身，面朝墙。身后背包侧兜里那本书安安静静，没有墨痕浮出来。
