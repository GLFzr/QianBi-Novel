# 第2章 单号

夜色压得很低，路灯把楼下的湿地面照成一摊一摊亮斑。陈默把共享单车锁进车棚，转身时鞋底碾过一片水光，带出一串黏腻的声响。他低头，水面上漂着一截蓝色尼龙绳头，泡得起了毛，边缘泛白。跟账本封皮上那根，像同一种蓝。他没有蹲下去看，跨过那片水，上楼。

手机在口袋里震了两下。他掏出来，房东的短信，省了客套：十五号前再不到账，就办退租。他按灭屏幕，推开出租屋的门。屋里一股隔夜的闷味。他先把纸箱搁在地上，箱底是老屋抽屉里清出的几件零碎：一把旧扳手，两管胶水，一部老手机。手机是老屋床头柜里翻出来的，他当时看了一眼，顺手带了回来。他蹲下来，把充电线插上。老手机的电早放干了，屏幕黑着，要等一会儿才醒。

他把外套脱了，扔在椅背上，从背包侧袋里拿出那本软皮本。蓝布包角，边角有些翘。他拉开床头柜最底层的抽屉，把本子放进去，推到最里头。抽屉没有锁。他用手摸了摸本子封面，才慢慢合上抽屉。

这时手机屏幕亮了。老手机充进了电，开始自动开机。震动过后，屏幕停在一个待机界面，顶栏弹出一条通知。

有一条录音未播放。录制时间，是父亲走的前一天。

陈默坐回床边，按下了播放键。录音开头是窸窣的杂音，布料蹭过话筒的闷响，像手机被压在什么东西底下。接着是一段拉抽屉的声音，很慢，停了停。然后，一个熟悉的、带着痰音的嗓子从很远处透出来，压得很低，像怕隔墙有耳。

“卡在工具箱里……那张卡取不出来。柜子底下有眼药水，垫着那张布要换，湿了。”声音停了一下，又说，“算了，留着。留给陈默。”

他拇指抵住屏幕边缘，指甲盖泛白。窗外的夜很静，录音里父亲的声音糙得不像是他印象中的人，低得快含进喉咙里。

“跟他说，那本子不是账。要留给他。这本子留给陈默。告诉他，账不是命运收的。是——”

门铃响了。录音断在那里。长长的底噪里只剩下空旷的电流声。

陈默把手机举在耳边，直到录音自己走完。他又按了一次播放。第二次。第三次。第三次的时候，他听清了门铃声后那一截几乎被吞掉的底噪。很轻，很远，像谁家厨房的电视没关严：一个机械女声在报订单号，尾音拖了半拍。编号零三一七。他倒回去，又听了一遍。编号零三一七。

他从外套口袋里掏出那张对折的单据。下午那外卖员塞给他的，捏着问路，人走了，纸留在他手里。他把单据展开，褶皱里露出取件码喷墨：尾号B317。风掀开过的边角还留着折痕。他盯着那串数字，又看了看手里老手机上显示的录音日期。

同一个数字，今天出现过多少次了？纸角，表壳，外卖箱上翘起的单票边，现在又多了一道。父亲的录音里，门铃背后躺着一句报单号的女声。零三一七。像一条锁链，一节一节，从他父亲死前那间老屋里伸出来，扣到他面前。

他拉开抽屉，把软皮本取出来。翻到写着“案：0317”那一页。青色墨痕钉在纸角，像有人把钢笔压碎了才写下去。他握着笔，笔尖悬在那串数字旁边，轻轻贴住纸面，压出一个浅浅的点。许久，他抽回笔。没有落墨。他把软皮本合上，关灯，躺进床里。本子压在枕头底下，硬角硌着后颈。

睡意来得迟缓，还作废。他盯着窗外的路灯光在天花板上的投影，翻了几次身，手机屏幕自己亮了。凌晨两点十七分。他摸过手机，指头无意识地划到通讯录最底下。那个号码还在，备注是两个字：“爸（老宅）”。号码备注栏里有一行小字，是很多年前存的，他快忘了。他点开，看见那行灰字：0317。他生日。

他顿住。又往屏幕下面划了划，在备忘录里，存着一条只有文字的旧记事，时间停在父亲走的前两天：3月17日22点47分，去东门街路口。

他侧过头，看向床头柜。那枚旧表还搁在柜面上，表盘朝着天花板，玻璃上的裂纹在手机光里泛着蛛网样的白。指针停着。二十二点四十七分。他一直没给它上过发条，它从第一晚起，就停在那个时间上。3月17日，22点47分。明天，就是3月17日。

窗外低低地传来一阵引擎声。陈默撑起身，从窗帘缝里看下去，路灯底下停着一辆外卖电动车，骑手坐在车上，头盔没摘，车没熄火，也没开走。引擎声在夜里细细地着。

手机又震了一下。他低头，屏幕顶端弹出一条新的系统通知。您有一条新的通话录音已保存。他指尖停在通知栏上方，没有点开。窗外，那辆电动车的引擎声压了压，又低低地续上，像不急着走。
