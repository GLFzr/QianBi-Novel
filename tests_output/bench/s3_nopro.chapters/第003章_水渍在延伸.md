# 第3章 水渍在延伸

闹钟响的时候，窗外的雨刚停。陈默伸手去摸手机，指尖先碰到床头柜上一张摊平的纸。外卖单底联，单号那行朝上，尾号0317。他盯着看了五秒，不记得自己什么时候把它从外套口袋里翻出来放平的。他坐起来，把那张纸翻了个面，压在手机底下，好像这样就能让它别再出现在视线里。

手机里有条语音留言，林兰的声音压得低：“陈默，一楼走廊渗水了，可能是你家厨房水管没关紧，你过来看看。”时间是六点四十。

到老屋时水已经漫过一楼走廊的半面墙根。他上楼拧紧厨房总阀，那摞昨天的碗还在水池里，台面上一列水渍正沿边往下滴。水龙头是关的。水从台面与墙的缝隙里渗出来，沿着瓷砖缝走成一道细线，在灶台角上拐了个弯，滴到地面。他把碗洗了。水声停下来时，他忽然算不出一件事：昨天午饭吃的什么。

他站在水池前，把昨天从头到尾过了一遍。早起，回老屋，清遗物，翻出种子书，遇外卖员，回家，听录音，凌晨两点十七分。这段里没有午饭。那一段整块地空着，像一本被人撕掉几页的账，翻过去直接是下一页。

他甩了甩手上的水，翻包找物业缴费单想核对水费户号。笔袋底部，手指触到一张对折的纸。他抽出来，展开。

自己的笔迹，蓝黑墨水，字有点急：“3月17日必须联系小周。”

他不记得写过这张便签，不记得“小周”是谁，更不记得3月17日需要联系这个人做什么。他把便签对折，塞进胸口衬衫口袋。口袋里的东西，贴身收着。

下楼时，楼道口停着一辆电动车。穿黄色工服的外卖员正从车筐里往外拎泡沫箱，台阶上的雨水还没干，地砖一角翘起，缝里积着亮晃晃的水。陈默认出那顶头盔。他叫住他：“师傅，你叫什么？”

外卖员抬头，是个年轻人，脸被风吹得发红，咧嘴笑了笑：“周航。昨天那单尾号0317的，是我送的。”

陈默点头。他看了眼周航脚下那级台阶，积水正好漫过翘起的砖角，鞋底踩上去会滑。他退到楼道阴影里，拉开背包，手指攥住软皮本的边。心跳顶在喉咙口。

他不知道自己为什么选这一件。不救命，不挡灾，只写一个握扶手的小动作。他翻开空白页，笔尖在纸面上方停了三个呼吸。

他写下：周航，3月11日9时52分，滨河道12号一楼台阶，右手握紧扶手，停住半步。

落墨。纸面安静，笔迹干在那里，像刚写进一本普通笔记本。他等了三秒，纸页既没有变化，也没有任何回应。

他把本子合上，塞回背包。十五秒后，楼道口传来一声闷响。

他冲出去。周航半跪在台阶上，右手死死攥着扶手栏杆，没摔下去。泡沫箱从车筐里甩脱，倒扣在台阶边，汤水从箱沿溢出来，顺着地砖的缝隙流成一道细线，不偏不倚接在昨日那滩旧水渍的延长线上，又往前爬了一小段，停住。

周航骂了句脏话，爬起来拍了拍膝盖，弯腰去捡泡沫箱，回头冲他笑了一下：“这台阶真滑。”

陈默站在原地，手心里的种子书不烫、不响。他把它塞回背包，拉链拉到一半，发现自己的手指在抖。

午后他回到出租屋，灶台上摆着三只空泡面碗。他挨个端起来看，碗底汤渍都干了，是不同时间吃的。他站在灶台前，搜遍脑子里所有关于中午的记忆，只有一片空白。

三碗面。他记不起其中任何一碗。

傍晚，雨又下起来。陈默蹲在老屋门口翻种子书。走廊灯坏了，他开了手机电筒，白光斜打在纸页上，页角那道昨天被笔尖压过的浅痕里，浮起半行字，淡得像水泡过又干透的旧痕：“14:07 东门街路口。”

他不认识东门街。

隔壁的门开了。林兰撑着一把滴水的伞过来，手里捏着一串钥匙：“昨天你落在我这儿的。”她身后跟着个小女孩，扎马尾，背着粉色的书包，正低头抠书包带上的挂件。林兰收了伞，随口说：“果果明天七点要去东门街那边上科创营，我本来还愁下雨怎么送，她爸说顺路。”

陈默的拇指无意识地压在纸面上那半行字上，压住了“14:07”。

“你说哪里？”

林兰把钥匙递到他手里：“东门街路口呀，滨河道那头，有个红绿灯的。”

她说完领果果转身回屋，门在身后合上。陈默站在走廊里，手电的光还亮着，照着页角那半行灰字。隔着一道纸纹的距离，那半行字下面，正慢慢浮出极淡的第二笔。他看不清那是什么字。

楼道尽头，老屋的门半掩着，水龙头没关紧的滴水声从里面传出来，一下，又一下。
