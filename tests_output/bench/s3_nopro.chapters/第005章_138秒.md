# 第5章 138秒

老屋厨房的水龙头还滴着水。陈默拧了三次才把它彻底关死，退回底楼的旧沙发里。种子书摊在茶几上，台灯压着页角，那行字在灯光下像一道干涸的河床：“停留：138秒。”他盯了很久，久到纸上的字开始浮起来，又散开。他伸手翻过一页，是空白。再翻一页，还是空白。他把书合上，关灯，躺下，又坐起来把灯打开。凌晨三点，他坐在灯光里，手边没有别的东西，只有这本软皮本。

他不知道自己在等什么。等页面变回去，等自己醒过来，等有人告诉他这一切都是他失业后胡思乱想出来的幻觉。

铅笔一直在手里。他无意识地在页角空白处划了一道，很轻，几乎没留下痕迹。掀页的时候，那道划痕附近，多出一行极细的字。

他停住。那行字贴在页脚上方，像是刚渗出来的。墨色比旧痕深一些，边沿还泛着一点潮光：明 07:12 停留处有车刹不住。

他抬手摸了摸那行字，指腹蹭过纸面，墨没有洇开。他翻过整本书，每一页都查过，没有第二处新字。他又回到这一页，把台灯拉近，纸面被光线照得发透，那行字的笔画压进纸背，收笔的弧度他认得。记账用圆珠笔的人，写不出这种顿挫的钢笔锋。那是他父亲的字。

凌晨三点四十七分。陈默松开书，脊背抵住沙发扶手，后脑磕在木头上，闷响。他闭了一会儿眼，又睁开，那行字还在。

他想起种子书封面内页那些不能算作记录的记录。他翻到最前面，从打封纸里抽出一张薄毛边纸。那是父亲贴在内衬纸上的，被护得平整，只有一行铅笔字，和页角那道斜批一样，写着不可贪。

他把毛边纸铺在台灯下，用铅笔在笔画上轻轻描过。写字的人压笔很重，三个字深深地陷进纸浆里。他把纸翻过来，对着灯光，看见背面的笔压。笔画比正面还要密，那些压痕叠在一起，深深浅浅，几乎辨不清字。他调了调灯的角度，终于从交错的笔划里辨认出一行更浅的字，写在不可贪的背面，字号更小，笔尖反复碾过纸面才落成：改写是替人挡，不是替天改。

陈默把纸放下。毛边纸的一角被他捏皱了，他抚了抚，纹路抚不平。那句话在他脑子里转了几圈，落定。替人挡，他挡的是周航脚下那级湿台阶，是林果果鞋带散开的那几秒。至于替天改，他想起父亲备忘录里那条记事。3月17日22点47分，去东门街路口。他父亲当年想改的那件事，是不是也写在某一页纸上，最后没能收住。

凌晨四点二十六分，他拨出林兰的电话。听筒里传来机械女声：“您拨打的电话已关机。”他挂断，又拨了一遍。还是关机。他盯着屏幕看了几秒，原本打算发一条消息告诉她明天别走东门街，手指停在输入框上方。他什么都没输入，锁了屏。这一刻，他比任何时候都确定，他不可能绕过去。

他回到种子书前。第一次给周航落笔时，他只写了一个动作。现在要写的那件比扶一次栏杆重得多，但他父亲留下的纸提醒过他，不能贪。最多改掉她系鞋带的138秒，让那辆刹不住的车擦着她过去。他翻开新一页，蓝黑钢笔吸饱墨水。

凌晨五点十二分。他写下：林果果，07:12，东门街路口，因鞋带散开蹲下系鞋带，停滞至绿灯转红后第3秒才起身。

墨迹在纸面上微微凸起，像一道极浅的疤痕。他合上本子，钢笔从指间滑脱，太阳穴一抽，像有什么东西从后脑里被抽出去。他按住左边的太阳穴，指腹抵着那块跳动的皮肤，喘息了几下，一股眩晕涌上来。

他低头，左手小鱼际上多了一道墨痕。那道痕画得很直，擦不干净。他试着回忆昨天午饭吃了什么，昨天的晚饭，以及他今晚到底吃没吃过东西，那段记忆从他脑子里消失了。他记得自己走进厨房，灶台是空的，碗柜里少了两只碗，但他说不出那两只碗是什么时候不见的。

他坐在沙发上，没有力气翻开种子书确认页角。是页码，是编号，他一时分辨不出来，但那串数字的轮廓已经很大程度地印进了眼睑内侧。他闭上眼，能看见那个数字从书页深处浮上来的样子，纸浆的纹路都带着。0319。一道新编号。和父亲留下的0317只差两个数，中间缺了一个0318。他不知道那中间缺掉的一笔，是谁写下的。

他盯着窗玻璃上映出的灯影，想说点什么，喉咙却干得发不出声。

门外响起脚步声。在凌晨四点的楼道里，那种声音很轻，但也很清晰。一步一步，从楼下一路走上来，越来越近。然后停在他家门口。

陈默坐直，五指还搭在台灯开关上。脚步声停住之后，有十秒，什么动静都没有。空气像从楼道里抽空了。他正在犹豫要不要开门的时候，门外响起一个压低的女声：“陈默，我知道你醒着。”
