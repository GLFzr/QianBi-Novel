# 第6章 07:12

窗外的天还蒙着一层灰。陈默猛地惊醒，后脑撞在沙发扶手上，钝痛顺着颈椎往下钻。他先看自己的左手，小鱼际那道墨痕还在，没多也没少。然后他摸到手机，屏幕还亮着，停在通话记录界面。最上面一条，昨晚18:42，拨给父亲的旧号码，通话时长42秒。他不记得自己拨过这通电话。他往下翻，想找那条记录是谁存的，翻了两页，什么都没有。记忆里那一段是空的，跟昨天午饭一样，被人整块挖走。

他划到相册，最新一张照片拍的是老屋窗台。窗台上有一样东西，旧手表，表盘停着，指着22点47分。他抬头看向窗台，空的，只有一层薄灰。昨天傍晚他确实坐在窗台边看过种书，可他记得窗台上没有手表。他盯着那张照片看了很久，把手机扣在膝盖上。然后他拨出那个旧号码，听筒里传来机械女声，已关机。他挂断，又把通话记录里那42秒的录音文件调出来，文件名是一串日期数字。他拇指停在播放键上，没有按下去。该去东门街了。

六点五十分，东门街路口的早高峰已经起了个头。陈默把共享单车支在修鞋摊旁边，站定，位置和他昨天观察林果果时是同一侧人行道。修鞋的老周正拿锥子剔鞋底，抬头看了他一眼，没说话，又低下去。陈默核对信号灯，绿灯约38秒，红灯约52秒，跟昨天数的一致。车流加密，公交车进站又出站，挡住半条斑马线。七点零七分，他看见林果果从路口西北角转出来，背粉色书包，左手腕那截褪色红绳还在。她一个人，没有大人陪。

她走到斑马线前站定，等灯。陈默的视线落在她脚上，左脚鞋带，系得很紧，端端正正一个蝴蝶结。他呼吸一滞。他写的是07:12鞋带散开蹲下系，可她站得好好的。他下意识往前迈了半步，风灌进领口。他压住自己，没收脚。绿灯亮了。林果果起步。走了两步，左脚鞋带松了。

线头从蝴蝶结中心脱出去，两截鞋带像被什么东西解开的绳结，几秒就散完。她停下，蹲下去系。后面一个小学生绕过她先跑了。她低着头，手指在鞋带上绕了两圈，又整理了一遍。起身的时候绿灯刚转红。她没急着走，站在斑马线尽头等下一轮。

白色轿车从东侧直行道驶出来的时候，陈默看见刹车灯亮了，又灭，再亮，车轮像是碾在冰面上。车头偏向路肩，没有减速的迹象。他听见金属护栏被撞击的声响，声音钝得发闷，像一记铁锤砸在湿泥里。护栏弯折，变形段往前滑了数米才停住。变形的起点离林果果刚才站过的路肩不到半米。

碎砾飞溅。有行人喊了一声。林果果往后退了两步，低头看裤脚，灰白校裤上蹭了一道灰痕。她没哭，蹲下去拍了两下，站起来抬头看了一眼那辆顶着护栏的车，然后跟着人流绕过事故段走了。司机趴在方向盘上没动，有人已经掏出手机拍照。陈默站在马路对岸，手心全是汗。他把外套拉链拉到顶，转身走开。风从背后灌过来，他感觉不到冷。

回到老屋已经快中午。陈默在门口站了一会儿才进屋，翻开种子书回读页痕。页角的压痕还在，墨迹比他落笔时深了一些。在靠近纸边的地方，叠出一行小字，很小，像从纸背透上来的汗渍。他凑近，一个字一个字地辨。多次改写致第二人擦伤。路人，男性，左臂轻微剐蹭。

他没有写过这个。他写的是林果果系鞋带的138秒，从头到尾没有第二个人的名字。他合上书又翻开，那行字还在。他想起车祸现场那辆白色轿车的右前灯下方，有一道斑驳的擦痕，车漆蹭掉了窄窄一条，露出底下的金属色。可他看到车的时候，车已经顶着护栏。

他反复核对页角，想找到关于第二人的更多字。没有。只有这一行，像账本上被铅笔轻轻记了一笔的支出，等着哪天来对账。他把种子书塞进外套内袋，贴着胸口。

手机屏幕还亮着，那通42秒通话的详情界面停在未播放的录音图标上。他拇指按上去，顿了一下，还是压了下去。

录音里先是杂音，布料摩擦的声响，像手机被压在枕头底下。几秒后，他的声音从里面传出来，低，哑，带着浓重的鼻音。他听见自己说：“爸，距离那个日期还剩十三天。林果果的事，是我写的。这是第一次没告诉你的账。如果这就是你说的代价的样子，那我已经付了。”

录音里有一段空白。然后，一个男声回了一句什么，声音压得很低，像隔着一堵墙，话尾被截断了。录音结束。陈默举着手机，屏幕显示已播放完毕。那个男声不是他父亲的语音信箱。那是活人的声音。他拇指停在回拨键上方，窗外救护车拉着笛从楼下驶过，很长的一声。他没有按下去，把手机翻面扣在桌面上。
