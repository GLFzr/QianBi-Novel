# 第4章 空档期

物流网点的墙面上钉着一张片区配送图，塑封膜起了泡，边角卷起来，东门街出口的位置被人用红笔重重描了三道叉。叉痕压得很深，笔尖划破过塑封膜，留下一道毛糙的白边。陈默趴在柜台上填入职表，老调度端着茶杯晃过来，扫了一眼他填的地址栏：“滨河道那头？劝你别接东门街的件。”

“为什么？”

“那条口子咬人。”老调度拿笔杆敲了敲图上那三道叉，“连续两年了，配送员在那儿出过事。上个月刚撞一个，人没事，车废了。”

陈默把表递过去，没接话。老调度也没再追问，叼着烟嘴去里屋了。陈默站在柜台前，目光在那三道叉上停了一会儿。红色的叉叠在一起，像有人每次经过都忍不住再补一笔。他走出网点，手机弹出租房催缴短信，他看了两秒，摁灭。原本想直接回出租屋，脚却在路口转了向。共享单车往东门街蹬过去的时候，他跟自己说，只去吃碗面，看完就回。

东门街路口比他想的窄。两车道，没有安全岛，斑马线画得潦草，白漆起了皮。路面有一条被白漆重新描过的裂缝，横在斑马线前两三米的地方，像一道没愈合的疤。新公交站牌立在盲区里，拐弯的车要过了站牌才能看见过街的人。他在修鞋摊旁边支好车，蹲下来假装系鞋带，把信号灯的秒数记了一遍。绿灯亮十九秒，黄灯三秒，红灯四十七秒。他数了两轮，数字一样。

修鞋的老周头也不抬，锥子扎进鞋底，手腕一拧：“别蹲那儿，那口子邪门。”

“怎么邪门？”

“上个月一个骑手栽在这儿，车都拧成麻花了。”老周拿锥子指了指地面，“这个路口的孩子过马路都蹦着来，不蹦不行，那车出来不饶人。”

陈默站起身，拍了拍膝盖上的灰。他摸出手机看了一眼时间，下午四点出头，东门街社区学校刚放学。保安站在门口，学生三三两两往外走。他本来没想等谁。他只是在修鞋摊旁边多站了一会儿，像一个等人的大人。他把手插进兜里，指腹碰到种子书软皮的边角，又缩回来。

然后他看见林果果背着粉色书包从校门里出来，一个人，旁边没有同学。她走得不快，书包带滑到胳膊肘，她也不扶。她走到斑马线前，没看灯，抬脚就要过。保安在身后喊了一嗓子：“嘿，看车！”她吓了一跳，跳回线内，等绿灯亮了才蹦着过去。

她蹲在对面人行道边系鞋带。左手腕上一截褪色的红绳滑到袖口外，她低头系了很久，久到陈默掏出手机按下了计时器。十二秒。她起身的时候往他这边扫了一眼，没认出他，转身拐进了巷子。他锁屏，把手机塞回兜里。十二秒，他告诉自己，只是系个鞋带。可页痕上那行字写的是138秒，十倍不止。他不知道138秒够一个人做什么。够她走到路中间。够一辆车刹不住。

黄昏来得快。陈默坐在便利店落地窗前，纸碗里的关东煮凉了，竹签搁在碗沿。他把手机相册里那张页痕照片放大，怼在眼前看。下午在老屋里拍的时候，那半行字还停在“14:07 东门街路口”。现在再看，字迹已经变了，笔画收拢又展开，最后定成一行新的字。没有抬头，也没有名字，只留一行：“停留：138秒。”

他看了很久，久到便利店自动门开开合合，进来的人买走烟和饮料，店员开始擦关东煮的锅。他退出照片，打开微信，林兰的对话框还停在昨天的语音留言上。他打了一行字：“明天果果有人送吗？”想了想，删了。又打：“东门街路口最近在修，让果果绕一下。”还是没有发出去。他锁了屏，把手机搁在桌面上，像搁一块烧红的铁。他付了钱，走出便利店，夜风裹着汽车尾气的暖意扑上来。

手机在口袋里震了一下。他以为是房东，掏出来，屏幕上却是林兰的头像。她发来一张照片，光线很暗，像是站在老屋墙角拍的：一张旧木头书桌的桌角，油漆剥落的地方，露着一串刻进去的数字。0317。刻痕很深，嵌着年深日久的灰，笔画收尾处有反复描刻的痕迹，像有人刻完又用指甲顺着笔画刮过几遍。

下面是林兰发来的六个字：“你是不是也在查这本？”
