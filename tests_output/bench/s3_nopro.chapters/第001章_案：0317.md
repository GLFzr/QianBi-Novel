# 第1章 案：0317

钥匙扣上拴着一截旧蓝色尼龙绳。陈默认出那截绳子，是父亲系账本封皮用的，用了七年，边沿磨起一层发白的絮。绳子拴着铜钥匙，钥匙圈上又添了一枚陌生钥匙，是林兰刚塞过来的。

“你爸走前说过，有样东西要留给你。”林兰站在楼道口，声音往下压了压，“我按他说的没碰。”

陈默低头捏着钥匙，铜面硌进指腹：“什么东西？”

“他后半句没来得及说。”她脸朝向四楼那扇灰玻璃窗站了一瞬，“你自己上去看吧。”

她还想再交代一句，身后的女儿拉了拉她衣角，小声说“妈，晚了”。林兰把话咽了回去，冲他点了点头，牵着女儿走出楼道。陈默没有留着追问。追着问就得在这栋楼里多耗一天。房租压了两个月底，中介挂出去的卖房信息只有一句“先观望”。这屋里的旧物他早盘算过，值不了几个钱，时间再搭不起了。

门锁有些锈，他拧了两下才转开。推门时扬起一层灰，尘土味混着凉茶和旧木头的气息扑出来。那张桌上的凉茶没倒，缸沿结着一圈茶垢。报纸摊着，日期是父亲走的那一天。窗台上的盆栽枯死，土干裂成几瓣，指头一碰就簌簌掉渣。屋里每一件东西都停在原地，像总等一个没做完的动作。

他先站着把全屋扫了一遍，才动手。木工工具拢到南墙下，旧衣物分层叠进纸箱，收据本码成一摞。他做这类事比旁人快，因为他给旧物备着一套固定去处：卖、扔、留、问。卖的是电瓶车。扔的是旧家电。留的是户籍本。问的，是账。

父亲做了一辈子账，留下的东西也该是一本账。可他翻遍书桌和衣柜，没见账册。等他把床头柜最底层那个抽屉整个拖出来，才在底板下摸到一个硬壳。

软皮封面，蓝布角，很薄。翻开前两页，空白。账本不会这么薄，也不该一张账页都没有。他翻到封面内页，父亲的字他一眼就认得出，左手握笔，笔锋往左偏：“种子书。记人未长成的事。”

斜角还有一行铅笔小字，笔画压得浅，像是只写给某个人看：“不可贪。”

他停了一下，手指停在纸面上。页脚处有一串钢笔编号，青色墨痕，压得几乎划破纸背：案：0317。他父亲记账用圆珠笔，不用钢笔。

陈默合上本子，没有往里翻。再翻就得在这儿多停一阵。他把软皮本塞进背包侧袋，拉链扣紧。

继续清到窗台，搬起那盆枯死的海棠时，盆底落出一张对折过的纸。纸被水汽泡软了，展开时字迹大半已经洇没，只剩两个字还立得住：陈默。写得端正，一笔一画，是父亲的手笔。他把字条叠回去，放进与软皮本同一个夹层里。

锁门时他想把钥匙从锁孔里拔出来，手指在那截蓝尼龙绳上多停了一刻。他没有回头，转身下了楼。

楼道口停着一辆电动车，外卖箱绑在后座。戴黄头盔的骑手低头对着手机屏幕，车尾压着地上那摊水渍，箱底的饮料漏了，湿了一片。陈默侧身让路，骑手却叫住他：“哥，3门317在几层？”

“三号楼没有317。三楼门牌到307。”

“可订单上写的就是317。”骑手把手机转过来说。他正要再答一句，风掀起外卖箱侧边的单据，取件码一行露出来，尾数正是0317。

这四个数字他刚见过，在那本软皮本的页角上。

陈默没响。他拉开背包侧袋的拉链，手指没有碰到软皮本，先碰到一个不该在这个袋子里的东西。薄的，圆边，金属的凉意顺着指腹爬上来。他掏出来。

一块表。旧式机械表，表盘玻璃裂了一整圈细纹，指针停在同一个位置：22点47分。他把表翻过去。

表壳背面有人用硬物一下一下凿刻过，刻痕里嵌着灰，刻的正是同一串数字：0317。

站台在五十米外，车流过去了两班，他站在原地。表壳在掌心里慢慢焐出温度。他又拉开背包，从夹层抽出那本软皮本，翻到页角。路灯亮起来时，青色墨痕与金属刻痕并进同一道视野里。数字的收笔方向，也是一样的。

公交车到站，门在他面前弹开。他合上本子，把表攥在手心，抬脚跨了上去。
