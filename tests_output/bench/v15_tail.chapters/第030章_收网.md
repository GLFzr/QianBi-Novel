# 第30章 收网

天亮时，陈默把六册账本按年份码回纸袋，胶带封口，在桌面留了张字条给程师傅。物归你那儿。他把纸袋搁在椅子正中间，拄拐下楼。

巷口的面铺今天没开。老板在里头发面，白汽顶着塑料棚一鼓一鼓。老魏的车停在路边，双闪没关，他从副驾拿了瓶水扔过来。陈默一夜没睡，喉咙干，拧开喝了两口。

老魏从车上下来，手里拎一只塑料文件袋。

“你要的东西我复印了两份。”他把袋子递过来，“群聊截图、转账流水、点单编号对照。原件在我这儿，这份你拿着。”

陈默抽出里头一页。表格是手抄的，字写得扁，一笔一划不连。

“你怎么确定是他。”

“照你说的，报单的和跑单的是两个人。”老魏把烟在车门上磕了一下，没点，“可他漏了一处。他点单，第一个扣1的永远是一辆没牌照的面包车；出事故那晚，那辆车没出车。人没出门，单子出了。”

“两个号，一个人。”

“对。”老魏拉开车门，“我把东西留给老连长了。他退了休，现在帮经侦打零工，认识人。昨天他看了两页，让我今天带你上分局。”

陈默把文件袋夹进腋下，上了副驾。车掉头出巷口。老魏把窗降了一半，风灌进来，吹得塑料皮翻卷。

“你那笔跟他结完了？”

“没结。”

“那你先去把该交的交了。”

陈默没接话。他把文件夹放在膝盖上，翻开一页，手指压着那一列编号往下挪。0318、0319、0321，中间跳了几个。跳过的那些日子，老路弯道口出了事。他把文件夹合上。

城北分局在一条老街尽头。楼旧，楼道墙皮往下鼓。老魏带他到三楼东头一间问询室，里头一张桌子，四把折叠椅，墙角搁着一台落灰的饮水机，水桶里的水只剩一个底。

接待他们的是个三十出头的警员，姓冯，眼细，头发剪得短。老魏喊他小冯，递烟，他不接，抽了张纸巾擦桌子。

冯警员把材料摊开，一页一页对。群聊截图，点单编号，转账流水。

“编号按日期来。”他跟陈默确认。

“对。”

“出事那晚跳到下一天，隔了一天没排。”

“对。”

他把那张转账流水抽出来，指尖压住中间几行。“收款账号的尾号，跟群里那个互助金专用号是一个。”

“群里募的钱，名义挂的是互助会。”陈默说，“出事家属收到的那笔，走的是另一条渠道，金额是流水上的三分之一。”

冯警员的笔停了半拍。他把材料按原来的顺序摞好，推回桌心。

“这事凑得齐。”他抬眼，“接下来立案，冻结账户。人我们自己去见。”

“什么时候。”

他看了眼表。“今晚。”

收网定在晚上十点。

陈默坐在面铺后头的折叠凳上，拐杖横在脚边。面铺收了，老板把桌子摞到最里头，剩一条矮凳。老魏把车停在斜对过，人蹲在车尾，指间夹一根没点的烟。

物流园岗亭里只亮一盏灯。门卫换了个生面孔，靠在椅背上打瞌睡，头一点一点往下沉。

十点零七分，群里跳出一条消息。

南环夜班，接单扣1。

老魏掏出手机，扣了1。

十点十七分，一辆灰色面包车从西边拐进来。车灯压得很低，贴着路牙滑到岗亭对面，停住。车门开了，下来一个人。深色夹克，个不高，帽檐压着，手里提一只帆布包。

他站在车边没走。眼睛先扫过面铺那排摞着的折叠桌，再扫过对街那排停着的货车，最后落回岗亭里打瞌睡的门卫身上。

他退了一步，伸手去拉车门。

对街两辆货车后面站起来两个人。物流园侧门开了，又出来四个。制服，没开灯，脚步压得很轻。冯警员走在最前面，喊了一声名字。

那人顿住，把帆布包往上一抡。

包在半空被截下来。人跟着被按在车头上。车灯照着半条街，包里崩出一摞薄册子和一叠打印纸，散在车轮边。最上面那张是路线图，红笔标着编号和日期。

陈默撑着拐杖站起来。那人半张脸贴在车头上，侧过来。四十出头，瘦，颧骨高，下巴上横着一道旧疤。他不认识这张脸。

老魏从货车后头绕过来，手掌拍在他肩上，压了两下。陈默把拐杖换到另一边手。面铺老板扒着卷帘门往外看，探了半个头，又缩回去。岗亭里的门卫被惊醒，站在门口，手里攥着半截手电。

冯警员把帆布包和手机装袋，走过来。

“剩下的话，进去说。”

笔录做到后半夜。陈默没走，坐在走廊尽头的椅子上。头顶灯管坏了一根，剩那根亮着，白得发青。楼下窗口透上来一股夜里的凉气。

楼梯口上来两个警员，押着一个人。那人走在中间，头低着，手铐在身前。走到陈默面前时，他脚下慢了半拍。

他身子歪了一下，鞋底像硌着什么。那只脚抬起来又落下。鞋和地砖之间掉出个东西。

纸。薄，对折了四折。

两个警员没察觉，继续往前走。那人被带过走廊拐角，进了审讯室的门。

陈默坐着。走廊里空了，只剩灯管的电流声。他撑起拐杖，单脚挪过去，弯腰把纸捡起来。

纸被踩过，边角脏了。他展开。

正面一行铅笔字，笔画硬，收笔压得重。

0383在你身边。

他盯着这七个字。灯从头顶照下来，纸面发白。

他把纸翻过来。

背面也是一行字。钢笔，蓝黑墨水，横平竖直。收笔那一顿的写法，他在种子书封面内页上见过。

阿莲。
