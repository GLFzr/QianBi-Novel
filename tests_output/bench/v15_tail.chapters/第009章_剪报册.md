# 第9章 剪报册

医院走廊的灯管坏了一根，剩那根嗡嗡响。陈默把程师傅的手机搁在护士站台面上，说是伤者工装口袋掉出来的。护士登记姓名时抬眼看了他一下，指了走廊尽头：“骨科三床，往里走。”

病房里三张床挤着。程师傅在中间那张，左腿吊在牵引架上，胳膊夹着血压袖带。监护仪的线从领口伸出来，数字跳得慢。床沿下面挂着一只引流袋，透明管里一条暗红。靠窗那张空着，被褥叠得方正。

陈默在折叠陪护椅上坐下。铁腿蹭地砖，发出一声。

他等了半个来小时。程师傅忽然睁了眼。

眼睛睁得很直，瞳孔散着，看的是天花板。嘴唇动了两下，喉咙里滚出一个音。陈默凑近。

周珩。

声音很轻，从很深的地方送上来。陈默的手停在椅子扶手上。

“手机，他打的。”程师傅的喉结上下动，“半个月前。”

“打了几个？”

程师傅没答。眼皮慢慢合上，监护仪的数字又跳了一下。他睡着了，呼吸沉下去，喉咙里黏着麻醉没散尽的痰音。

陈默坐了一会儿。另一床的老头翻了个身，陪护的家属趴在床尾，喉里发出细微的鼾声。床头柜上搁着一只帆布包。背带磨得起毛，包身鼓着。他把包拎过来，放在膝上。

拉链卡了一下，他用拇指顶开。里面是换洗衣物、一副老花镜、半包烟、一只铁皮茶叶罐。茶叶罐底下压着一本册子，牛皮纸封面，边角卷起，比巴掌大一圈。

他把册子抽出来。封面上没字，只在右下角用圆珠笔描了一个编号。他翻开。

第一页贴着半张报纸剪报。标题是《三车连撞致一人亡》，日期四年前。剪报旁边一行手写的字，黑色墨水，笔画硬，起收笔都压得很重。

0311。

陈默往后翻。第二页，第三页，第四页，每一页贴着一则本地新闻。电动车坠河、工地坠物、煤气中毒、溺水、高坠。死者年龄不等，有男有女。每则旁边都有一行手写的数字，格式一模一样：四位数，前两位月份，后两位日期。数字按时间顺序排，越往后越新。

他数了翻过的页数。三十七页。第三十七页的剪报是上周的，标题《深夜货车侧翻，一死一伤》，旁边写着0316。

他往回翻到第一页，又对着那串0311看。笔画、压痕、墨水颜色，跟种子书页角那行案：0317是同一个路数。硬笔尖戳进纸面，把纸纤维压出毛边。

他翻到最后一页。

这页没贴剪报。空着，只夹了一层薄纸。他把薄纸抽出来，展开。

半张纸，沿中线撕开，边缘毛糙。纸上是钢笔字，蓝黑墨水，笔画规整，横平竖直。

下一笔是0317，不要记我。

陈默的手停住了。他把纸翻过来对着窗户看。反面的字迹洇得更深，那笔横折的顿点和父亲账本上的写法是同一只手。纸角有半个铅笔印，像写这张纸时底下垫着什么东西。

门口进来一个护士，推着小车，车轮轧过地砖缝发出一声脆响。陈默把薄纸对折，夹回册子里，合上，塞进帆布包。他把包搁回床头柜原来的位置，坐回椅子。

护士绕过他，掀开程师傅的被子看引流管。她动作很快，拆开一包新纱布，换完，推车出门，顺手带上病房门。门轴发出一声轻响。

陈默等门关严，又把册子从包里抽出来。

他没翻里面。他直接把册子合拢，翻到封底。牛皮纸的背面，右下角有铅笔字。

程建国记，2004——

年份后头没有写结束。破折号拉得很长，一直拖到纸边，像是写到一半手停住了。

这行字底下，还压着一行更小的铅笔字，颜色更浅。他凑到窗边看。

不可借，不可还，记到死为止。

铅笔写完这几个字，笔尖在止字最后一竖上停了停，把纸戳了一个小眼。

陈默把册子合上。帆布包放回床头柜。他坐回椅子，两只手搁在膝盖上，指头相互压着。

程建国。收据上那个名字。东门街十二号，换两个接头，三百五，去年十月。册子从2004年记起。那年程师傅四十出头。他在替谁记。

陈默抬头看程师傅。床上的人睡得沉，嘴角有一小片干了的白沫，胸口一起一伏。窗帘拉着半边，光从缝里漏进来，落在输液管上，管里的液面泛着亮。

床头监护仪的数字跳了一下，报警灯没亮。

他掏出手机看时间。中午过了。他不记得自己中午吃过饭没有。早上在修车行门口蹲守，救护车来，接电话，之后呢。他的手指在屏幕上划开相册。照相图标底下，最近一张的时间戳是今天上午十一点零几分。他不记得拍过。

手指停在那张缩略图上。他没有点开，锁了屏。

走廊里有人推着车经过，轮子声从近到远。他把手机塞回兜里。

手机响了。

屏幕上跳出一个名字。林果果。

他接起来，那边先是一阵风，再是林果果的声音，比她平时要轻，像是捂着话筒说的。

“别回家。”

陈默握着手机，指节收紧。

“果果，你在哪。”

“别回家。”她又说了一遍，声音压得更低，背景里有公交车进站的报站声，被风削掉一半，“有人在你楼下。”

“谁。”

“不知道。一个女的，站你单元门口，站了快一个钟头了。我放学经过看见的，她没按门铃，就站着。后来我妈打电话叫我快点走，我就走了。”

陈默脑子里过了一遍。老屋门外那个压低的女声。凌晨五点，隔着门板说我知道你醒着。现在又到了城北出租屋楼下。

“你现在在哪。”

“公交车上。叔叔，那个女的，她手里拿着东西，像是本子。”

陈默的太阳穴跳了一下。他转头看床上。程师傅没醒，呼吸匀着，监护仪的数字还在跳。床头柜上那只帆布包敞着口，剪报册的牛皮纸封面露在外头，封底那行铅笔字他刚才翻过，没来得及细想。

“果果，听我说。你回家，锁门，别出来。你妈电话打得通吗。”

“打得通。她让我别管。”

“那就听你妈的。”

那边沉默了两秒。风灌进话筒，呼呼的。

“叔叔，你是不是在查什么事。”

“没有。”

“你骗人。”她声音里有一点赌气，又很快收住，“我妈也总骗我。你们大人……”

公交车报站声又响，盖过了后半句。陈默听见她挪动身体，书包带子蹭过座椅的闷响。

“果果。”

“嗯。”

“到家给我发条消息。”

“好。”

电话挂了。陈默把手机从耳边拿下来，屏幕暗下去之前，通话记录里林果果三个字下面，时间是十二点四十七分。他盯着那个时间看了两秒。他不记得自己中午吃过饭，也不记得上午十一点拍过什么照片。相册里那张缩略图他没点开，但手指记得划过屏幕的触感，凉的。

他把手机翻了个面，扣在膝盖上。

走廊里又有人经过，这回是护士推着换药车，轮子碾过地面接缝，咯噔一声。门被推开一条缝，护士探头进来。

“十二床，换药。”

陈默站起来，把椅子往后退了半步。护士推车进来，掀开程师傅的被子，拆旧纱布。他退到窗边，背对着床，手插进口袋。右手碰到那只手机。程师傅的手机。他还没想好怎么处理，是交到护士站，还是等程师傅醒了再说。手机在他口袋里震过两次，他没看。

“你是家属？”护士头也不抬。

“不是。街坊。”

“那麻烦你联系一下他家里人。住院要签字。”

“他手机在我这。”

护士抬头看了他一眼，没追问，低头继续缠纱布。陈默转过身，窗外是医院后院，几棵梧桐，叶子被风翻出灰白的背面。他想起程师傅帆布包里那本剪报册，2004年记起，每一则新闻旁边手写编号，格式跟种子书页角一样。0316是上周的。0317是下一笔。

纸条上父亲的字：下一笔是0317，不要记我。

不要记我。记。程建国记。封底那行铅笔字下面还有一行小字，他翻到最后才看见。不可借，不可还，记到死为止。

护士换完药，推车出门。门合上之前，她回头补了一句：“他要是醒了，按铃。”

陈默点头。门关上，病房里又只剩监护仪的电子音和程师傅的呼吸声。他走回床边，把帆布包拉链拉上，放到床头柜最里面。然后他掏出自己的手机，给林兰发了条消息：果果到家了吗。

消息发出去，没有立刻回。他把手机放回兜里，手碰到程师傅那只手机。屏幕亮了一下，通知栏最上面还是周珩那通未接来电，下面一行0317。他盯着那行数字，拇指悬在屏幕上方。

手机在他手里震了。

来电显示是一串陌生号码，跟昨天那个一样。他接起来，听筒里先是一阵静，然后纸页翻动的声音又响起来，一页，两页，翻得不快，像有人在慢慢查一本厚册子。

翻到某一页，停住。

一个男人的声音，很轻，像隔着一层布：“0317在谁手里。”

陈默没出声。

那边等了两秒，纸页又翻过去一页，声音断了。
