# 第22章 归零

程师傅把手机推过来时，指头压着屏幕没松。

“你看这个。”

东门街十二号后院库房，卷帘门拉下一半，外头雨丝斜着扫进来，在门槛内积了一道湿印。程师傅坐在旧藤椅上，左腿架着张塑料凳，膝头搭件灰夹克。手机屏幕的蓝光落在他脸上。

群聊截图。群名城北夜班互助群，一百来号人的头像排在左边，最上面挂着一条消息，发件人ID两个字：归零。

今晚东线，有补贴。接单扣1。

底下跟着二十几个1。

“补贴多少。”陈默问。

“一单加八十。”程师傅把手机往他这边又推了半寸，“上个月有人接了。跑了三晚，第四晚在东线被岔口出来的货车顶了。人现在还在骨科。”

陈默把拐杖靠住藤椅扶手，接过手机往下翻。群里往前几天的记录，归零一天发一条路线，东线、南环、城西工业区轮着来。路线后面都缀一个四位数，格式固定，月初到月中排下来，缺了几个号。

他指头停在一处。

前面一条是0321，下面一条直接跳到0323。中间那条空了。而那晚的聊天记录里，有人发过一句“昨晚东线出事了，谁接了”，下面没人接话。

“缺的号都在哪个位置。”

“我标过。”程师傅从夹克口袋里摸出一张折了四折的纸，展开推过来。上面用圆珠笔抄了十几行号，几处画了横线，横线旁写着日期，还有撞、翻、掉沟几个字。

陈默一行行对下来。横线画到的位置，都是群里出过事的夜晚。群主的号从0317开头往下走，画横线的号跳过去，第二天接着往后排。

“这个号不是流水号。”他说。

“什么。”

“是日子。”陈默把手机翻到群公告那页，指给程师傅看，“路线按日期编的。0317是十七号，0318是十八号。那天谁接单，谁就是在这一天出的事。”

程师傅的手在膝盖上停住，来回蹭了两下。他低头看那串号，看了好一会儿。“你爸当年也这么算过。”

陈默抬起眼。

“他来过我这儿一趟，就坐你现在这把椅子上，拿我那本册子翻，一边翻一边在本子上写号。”程师傅嗓音往下压，“写完他说，有人在拿日子钓鱼。我问谁。他说不知道，得往下看。”

陈默把那张纸折好，收进口袋。他重新拿起手机，点开归零的头像。资料页干净，没头像照片，地区填的是外地。往下划拉，加入时间对不上群主创建时间，注册地在另一个城市。

他把群成员列表从头翻到尾。一百多号人，头像大多是电动车、货车，少数几个用风景照。翻到最底下，一个新加进来没几天的号，昵称是两个字。

老陈。

他盯着这两个字停了两秒。

这个昵称不是他自己加的。群里没有第二个叫老陈的。他把这个号的资料点开，注册时间对不上他的号，加入群的日期在两天前。他退出群，去通讯录里翻父亲那个旧号绑定的软件账号。

登录是三个月前的。

“程叔。”他把手机递回去，“这个群，你能把我拉进去吗。别用我名字。”

程师傅接过手机，看他一眼。“你要干什么。”

“看看他发号的时候，谁最先回。”

“回什么。”

“扣1。”陈默说，“我想知道第一个扣1的，是不是每次都是同一个人。”

程师傅没再问。他点开群，拉了一个新号进去，昵称随手填了三个数字。陈默掏出自己的手机，在群里待了下来。

当晚十点零七分。归零发消息。

明晚南环，走老路，有补贴。接单扣1。

消息沉下去半分钟。第一个1跳出来，头像是一辆没牌照的旧面包车，昵称两个字母。陈默把那个昵称记下来。翻回前面几天的记录，同一辆车，每次都是第一个。

他把这个昵称和归零的ID并排放。

手机屏幕上，群成员的头像一列列往下排。他往下拉，翻到那个被撕掉一页的通讯录残根。他从内袋里把通讯录掏出来，翻到撕页那处，对着台灯把残根抬起来。

纸根边缘平直，一根根参差。断口处残留着一个字的左半拉，偏旁像彳的起笔，收笔处被撕口切断，剩下半边墨迹。

他把通讯录摊在膝盖上，又从群里翻出归零那个ID，两个半字对着灯比了比。

偏旁的位置对得上。

程师傅坐在旁边，看着他的动作。“你认出这个人了。”

“认出一半。”陈默把通讯录收回去，塞进内袋，“另外一半被撕掉了。”

他退出群成员列表，点开群聊输入框。他打了一个字，删掉。又打一行，停住。程师傅的藤椅在身后响了一声。

他最终敲了三个字，发送。

老陈。

三个字沉在群聊记录最底下，像一颗石子落进水里。群里还在刷1，一条条冒上来，把这三个字往下顶。

三秒后，屏幕顶部弹出一条私聊。

归零的头像一片空白，对话框自动顶到最上方。第一条消息：

老陈，你终于来了。等你很久。

陈默盯着屏幕。群消息还在往下滚，那三个字已经被新的1盖过去了。程师傅凑过来看，呼吸停了一下。

第二条消息跟着跳出来，和他之间隔了不到两秒。

你儿子腿好了吗。
