# 第10章 第三个空洞

忙音。

那头的男声说完“0317在谁手里”，断得干脆，连一句多余的都没留。陈默把手机从耳边拿下来。陌生号码，通话时长二十七秒。他在医院走廊的长椅上又坐了一会儿，才起身去护士站。

护士给程师傅登记，说住院要家属签字。他说自己不是家属，街坊。她递过一张表，让他留个电话。他写了，说晚点再过来。

出门时起了雨。公交站台顶棚积着水，一滴接一滴往下淌。他站到檐下，翻出林兰的对话框，打“果果到家了吗”，发送。回复没来。

回城西老筒子楼是四点过一点。

巷口的歪脖子槐树底下积着一洼水。他从楼道口往里走，拐弯，看见单元门里站着个人。

林兰。

她没打伞，头发潮了，贴在额角。一只手攥着林果果书包的背带，另一只手拎着书包，包底拖在水磨石地面上。看见陈默，她往前走了一步。

“我家里进人了。”

陈默把钥匙攥在手心。“什么时候？”

“今天下午。我接果果放学回来，门锁没被撬，可屋里被翻过了。抽屉开着，衣服扔在床上。”她嗓子发干，“东西一样没少。就少了一张照片。”

“什么照片。”

“果果一岁多那张。一直夹在相框里的。”

陈默掏钥匙开老屋的门。楼道感应灯灭了一下，他跺了下脚，灯又亮。林兰没有马上跟进来，她站在门槛外，把书包从一只手换到另一只手。林果果从她身后探出半个头，看了陈默一眼，又缩回去。

“报警了吗。”

“丢了张照片，报什么。”她把书包带攥紧，“我怕的不是照片。”

陈默侧身让她们进来。屋里潮，桌面上那只铝饭盒还搁在台灯旁，凹痕面朝上。林果果站在门里，不往里走，抱着书包看窗台。窗台上的枯花盆还在。

“果果，坐。”陈默拖出一把椅子。

林果果摇头。林兰说：“她不敢回。”

陈默没说话。他给女孩倒了杯水，搁到她手边。她接了，没喝。屋里静了一阵，只有雨丝扫过雨棚。

“林姨，”他掏出手机，“我这儿有果果的照片。上回在老屋拍的。”

他本意是让林兰宽心，想说照片没了还能重拍。他点开相册，往下划。

第一张是今天上午拍的。缩略图上是一角牛皮纸，灰褐色，右下角一行铅笔字。

他点开。

剪报册的封底。

牛皮纸边起了毛。铅笔字是“程建国记”，年份跟在后面，靠一道长长的手画线一直拖到纸边。角落里还有一行更小的字，他没看全，但知道那是“不可借，不可还”。

图片详情里，拍摄时间写着今天十一点零七分。

陈默把手机拿近了一点。十一点零七分，他该站在东门街十二号门口，或者正看着程师傅被抬上担架。那本剪报册夹在帆布包里，要等一个多小时后，他在医院翻包才第一次见到。

他手指停在屏幕上。

“这是哪儿的本子。”林兰问。

陈默没答。他试着回想十一点零七分。救护车笛声从东边过来，两个白大褂下车，杂货铺女人把他从街沿上拽回去。再往后是断的，下一段记忆直接跳到医院走廊，他手里拎着那只帆布包，坐在陪护椅上。

中间空了一块。跟今天中午一样。

“陈默。”林兰叫他。

“没事。”他锁屏，把手机扣在桌上。

林兰看着他。看了一会儿，她开口：“陈默，你爸失踪前找过我一次。”

陈默抬头。

“他给我一个牛皮纸信封，让我替他保管。”她一字一字说得很慢，“他说有一个日子。到那天，如果没人来敲我家门，就把信封交给你。要是他不在，先有人来了，就把信烧了。”

“哪天。”

“3月17日。”

屋里的雨声忽然清晰。陈默的手搭在桌沿上，指节压着铝饭盒的边。

“那天有人来过吗。”

“我从早上等到晚上。”林兰说，“没人来。”

“信封还在。”

“在。”她把书包带松开，又攥紧，“可今晚我不带给你。”

她低头看女儿。林果果正仰头看他们，两只手抱着水杯。林兰把女儿往身边拉了拉。

“先这样。我回去再想想。”

她牵起果果往外走。陈默送到门口。感应灯又灭了，这回他没跺脚。母女俩的背影往楼梯下去，果果的书包在暗里一下一下晃。

门关上。

陈默回到桌前坐下。他从外套内袋里抽出种子书。深蓝布面，磨掉大半颜色，四角封边裂了口。他翻到封底。

封底内侧那片旧撕痕还在，纸纤维毛糙。撕痕旁边多出一道细墨痕。不长，浅，中间折过来，指腹能摸到底下有一道凹。

昨天没有这道。

他把书翻过来，从第一页开始翻。前面大半册还是空白。翻到中间的时候，纸的手感变了，变厚，边缘起毛，像被人反复捻过。他捏住两边往上一提，书脊从中间裂开一道极细的缝，前后像两叠纸拼在一起。

他往后翻。后一半纸挺括，边角干净，没有翻动过的痕迹。

他把书立起来，背着灯看。光从纸缝里透过去，中间那道裂缝清清楚楚。

他翻到空页。

纸面是白的。正中偏下有一点墨迹，淡，比页角那行“案：0317”还淡，几乎融进纸色。像写完以后有人拿指腹沿着笔画抹过一遍。

第0382笔，还不出。

陈默的手指停在那行字上。他拿拇指去蹭，指腹从“还”字上擦过去。纸是干的。字没动。他捏住那页的纸边，往上提了一点。纸面弓起来，字跟着起伏。手指松开，纸又落平。

那行字还是那几个字。
