# 第15章 铁皮柜

巷口的黑伞收了。陈默走到拐角时，只看见石板上一滩被踩乱的水渍，往墙根方向拖了一截。雨点打在上面，把边缘打散。

他转身回库房。

铁皮门虚掩着。推开时门轴哑响一声。墙上的拉线开关在右手边，他拽了一下。顶灯亮起，一条黄光落在靠墙那排档案箱上。屋里纸和灰混着的气味没散，屋顶一处漏雨，地上摆着只塑料桶接水，滴答，滴答。

库房最里侧，柜子靠墙立着，底下垫两块红砖。

铁皮柜，灰绿漆，四角包铁皮。他走过去把柜子往外拖了半尺。柜脚蹭过水泥地，砖底积着一圈黑水。锁扣是黄铜的，铆钉发亮，比柜门上原来的锁眼大出一圈。他对着锁眼看了一会儿。

那把缠胶布的小钥匙从内袋摸出来。铜齿在灯下发暗，胶布上圆珠笔写的0317备用被雨洇过，蓝晕开了一小块。他对着锁眼比了比。

没有插进去。

手搁在柜门上。锁孔周围被磨得亮，一圈新的亮痕，比柜子其他地方都干净。开过。不止一次。

钥匙推进去。涩。退出来，换了个角度，再推。咔。

锁舌弹开。柜门往外一拉。

门缝刚开两指宽，有东西从里面滑出来，磕在砖块上弹了一下。

一张照片，边角卷着，落在地上，正面朝下。他弯腰捡起来。

黑白的。两个人站在一间板房门口。背景是半拆的脚手架，墙上安全生产四个字，漆掉了一多半。左边那个人瘦，白衬衫，袖子卷到肘，左手腕上露出一截表带，表盘朝里翻着。一只手插在裤兜里，肩膀有点塌，脸朝着镜头，嘴角压着，二十来岁的样子。

他认得那双眼睛。

右边那个高半头，工装，一只手搭在瘦个子肩上，另一只手拎着一只黑色方盒，像旧式相机。这人的眉眼他在修车行见过，把现在那张脸往下拨二十年就是。

他翻过照片背面。

铅笔字，淡。横平竖直，收笔压得重。

1999年。年份后面还有字，被磨得只剩最后一笔，一竖带钩。

他把照片搁在柜子顶上，曲着指头压住一角。

柜子里码着三摞。最上面那摞是活页夹，夹着打印纸，纸角卷边，几页底下印着油渍，摞得比柜门高度高出半指，开门时往里歪了一下。他抽出来。

第一页是名单。手写的标题：城北夜班司机互助群。下面是名字、车型、夜班路线、手机号。名字有三种笔迹，蓝色圆珠笔一种，黑色中性笔一种，一两行铅笔。父亲的字在里面，他认得那个横折的顿笔。

他往后翻。第二页，第三页。名单一直接着，路线划到城北、城东、城西几个方向。翻到第七页，他的手指停下来。

一个名字。老赵。

名字外面用红笔画了个圈，画了两遍，第一遍没圈圆，第二遍沿着前一道路径走，圈成一个不规则的椭圆。圈旁边写着两个字。

下一个。

他把这页抽出来，凑到灯下。红圈的颜色深，跟父亲台历上圈3月17日用的那种红是同一支笔。后面几页又翻一遍，没有第二个红圈。

第二摞是卷宗。最上面是他在外间库房翻过的网约车司机碰撞案，认定书、截帧清单、那张0316编号纸都在。底下压着几份更厚的，纸边发黄，标签上写着城西工地、滨河路。他没动。

第三摞是一只牛皮纸信封，没封口。抖了一下，滑出一本旧通讯录。

巴掌大，黑皮面，边角磨得发白。翻开，前面几十页写满名字和号码，多数是修车行和周边铺子的熟人。有几个名字被铅笔勾过，勾完又在旁边标了日期。往后翻到中间，有一页被撕掉了，只剩装订线上一排参差的纸根。撕口平直，像用尺子比着撕的。剩下半页上有三四个名字，最后一行的字只剩了半个。

通讯录封皮内侧有个小纸袋。他伸指头进去，摸到一张单页。展开。

一行字，钢笔，父亲的笔迹：老赵。殡仪馆后门。等问0317的人。

陈默把单页放在柜顶上，压在那张照片旁边。他掏出手机，照着名单上那串号码拨。

嘟。嘟。

两声之后接起来。那边很静，听筒里连一点底噪都没有。接电话的人也没先出声。

老赵。陈默开口。

对方停顿了一拍。一个男声，比他预想的沉，语速慢。

我知道你会打来。

陈默听着。柜门的铁皮边凉，贴着指节。

你爸说，等一个会问0317的人打电话。老赵说，我等了三年。

陈默没有接话。

明天下午四点。殡仪馆后门。老赵的声音往下压了一点，别早来，也别晚到。我只有那半个钟头。

电话断了。屏幕上的通话时长停在五十一秒。

陈默把手机从耳边拿下来。柜子里还散着旧铁和纸灰的味道。他把照片、单页、那页圈着老赵名字的名单，依次收进外套内袋。灯还亮着，塑料桶里的水滴答，滴答。

他把柜门合上，铜钥匙在掌心转了半圈，齿口咬住锁孔。铁皮柜老旧，锁舌弹进去时发出一声闷响，像有人从里面顶了一下。他停住手，又拧回来，重新拉开。柜子深处那摞卷宗下面压着一只牛皮纸信封，没有封口。

抽出里面的东西。三张照片，同一卷胶卷洗的，边角有暗房裁切的毛边。第一张是父亲和程师傅站在车行门口，两人都年轻，父亲穿一件洗得发白的工装夹克，手腕上那只旧手表清晰可辨，表带是后配的，颜色和表壳对不上。第二张只有父亲一个人，坐在驾驶座上，手搭方向盘，窗外是东门街路口，照片背面写98年冬，第一次。第三张是夜景，车灯照着一面墙，墙上用粉笔写了个数字，模糊，但能认出是0317。

他把三张照片翻过来，在单页背面记下98年冬和第一次几个字，笔尖在第一次下面点了两下。

柜底还有一沓装订好的打印件，A4纸，左侧订书钉已经锈了。封面贴着一张手写标签：夜班司机互助群，成员登记表，1999年3月。翻开第一页，表格里填着二十几个名字，年龄、车型、车牌、入群时间，最后一栏是备注。备注栏大部分空着，只有三个名字后面有字。一个写已故，一个写失联，第三个名字是老赵，备注栏被红笔圈了两圈，旁边写下一个。

陈默盯着那两个字。红笔的墨色偏暗，像是血干透后的颜色。他翻到最后一页，表格底部有一行铅笔小字，父亲写的：老赵知道路怎么走。别让他一个人走。

他把登记表放回柜顶，和照片、单页并排。铁皮柜里还剩一个东西，用旧报纸包着，扁的，比巴掌大一点。拆开，是一张折叠的地图，东门街一带的旧版，上面用铅笔画了七八个圈，每个圈旁边标着日期。最早的是99年3月17日，最晚的是去年秋天。最后一个圈画在殡仪馆后门，日期空着。

他把地图折好，连同其他东西一起收进内袋。外套沉了，左边坠着，走路时能感觉到纸角抵着肋骨。他关灯，锁门，黄钥匙拧到底，拔出来。巷子里路灯刚亮，昏黄的光从头顶那盏破灯罩里漏下来，照出空气里细密的雨丝。他掏出手机看了一眼。

明天，下午四点。殡仪馆后门。

屏幕暗下去之前，他看见通知栏里多了一条新消息。号码是林兰的，只有一行字：果果说，昨晚有人站在我们新家楼下，撑黑伞，没走。
