# 第13章 账期已满

手机震了七下。陈默没接。屏幕亮着那个陌生号码，从医院一路跟回老屋，一阵，停一阵，又一阵。第八下的时候，震动停了，屏保的钟跳了一下，暗下去。

他从内袋里掏出种子书，摊在桌上，翻到页角那页。0381旁边那点墨还在，比昨夜深了半分。他把笔帽拧开，笔尖对准0317下面那行空白。

总得有人写一笔。父亲能圈定一个日子，程师傅能记满一本册子，这些账不该就这么悬着。他选了最简单的，日期，加半个名字。

笔尖落下去。墨坠到笔尖口，悬着，不落。

他把手腕再压一点。那滴墨悬在纸面上方，被一层看不见的东西托着，颤了一下，缩回笔尖里。他在纸面上划了一道，只留下干痕。笔尖上那点蓝黑还凝着，纸就是不吃。整页纸都是凉的，干的，摸上去跟别的页没有两样，偏偏他要写的那一块，墨落不下去。

他换了一支笔。黑的，还是干痕。他翻回封面内页，在父亲那行字旁边落笔。墨一下洇开，在种子书三个字边上洇出个小圆点。

只有那页不认。

他试了三回，回回一样。笔尖悬在纸面上，墨珠凝着，悬而不落。

他把笔搁下。笔尖那点墨滴到桌面，聚成一小汪。他拿纸巾按了。

门被敲了两下。轻，急，不像父亲那三下。

他起身开了门。

林兰站在门外。走廊地上放着两只编织袋，林果果背着书包，怀里抱着那件粉色外套。感应灯亮了一下，照出三个人影。

陈默问，搬走？

后半夜的火车。林兰把编织袋往门口挪了挪，房子让中介先挂着。果果转学，回我娘家那边。

陈默侧身让了半步，又没让开。他看了看那两只编织袋，看了两秒。

进来说。

不进了。林兰把女儿往身边带了带，说两句就走。

她顿了一下，像在找地方开口。

你爸失踪前找过我。她说，交给我一只牛皮纸信封，让我替他收着。他说，三月十七号那天，要是没人来敲我家门，就把信交给你。要是先有人来了，就把信烧了。

那天有人来吗。

我从早等到晚。林兰说，没人来。可我还是没带给你。

为什么。

林兰低头看女儿。林果果正仰着脸看她。她把手搭在女儿肩上。

你爸那晚把东西交给我，人就不对劲。手在抖。她说，我不想把你也搭进去。这两天我想明白了，捂着也没用。那信封我留着。哪天你真要，去老院找我娘，她知道放哪。

陈默没接着问。楼道里的灯灭了，又被谁跺亮。林果果从母亲身后探出头。

叔叔。她说，那个本子，你还在用吗。

林兰把她的头按回去。

走了。林兰拎起一只编织袋。

陈默没拦。他靠着门框，看她们一级一级下楼。编织袋磕在台阶棱上，一下，一下。楼道尽头那扇单元门开了，又合上。巷口传来行李箱轮子碾地的声音，越来越远。

他回屋关了门。

父亲书桌上摊着一本旧台历，去年的，停在三月初那一页。他把台历往后翻，翻到三月十七号。

那一格被红笔圈了三遍，一层压着一层，纸背都硌出了印。

圈旁边有两个铅笔字，写得圆，收笔轻，跟父亲的字不是一路。

收账日。

他站在桌前，手撑着桌沿。三月十七号。通讯录里那行备注，备忘录里那条记事，桌角刻的那串数字，程师傅册子里那一页。全指到同一天。

他往前翻。三月十六、十五、十四，每一格都干净。再往前，二月，一月，照旧是父亲那几条零碎的字。只有十七号，圈了三遍。

他退到椅子前，没坐。窗外雨丝扫在玻璃上，细细的。

门缝下面有东西。

纸的边角从门底露出来一点，被穿堂风翻动。他走过去，蹲下，把它抽出来。

一张没裁齐的纸，落款处空着。上面一行字，打印的，宋体，一个错都没有。

0317账期已满。下一次不是记忆。

他把纸翻过来，背面是白的。对着窗边的光看，纸面干净，指头蹭过去，没留下印子。楼道里的感应灯没亮。他拉开门，走廊是空的，尽头那扇消防门关着，楼梯拐角也空。楼下的单元门，林兰十几分钟前刚走过，这会儿一点声音都没有。

他把门关上，反锁。

种子书还在书桌上，摊在页角那页。他把它拿起来，坐到地板上，背靠着床沿。

空页中央那行字还在。第0382笔，还不出。

字底下多了一点东西。

他把书凑到窗边漏进来的一线光下。0382那两个字旁边，纸面凸起一小块，比昨天那点墨大。他用手指蹭了蹭，蹭不动。那轮廓弯着，圈着，收成一个攥紧的形状，像一只手。掌心里有个小小的缺口，凑近了看，是个17。

他合上书，又翻开。刻痕还在。

窗外巷口，路灯照着湿漉漉的地面。灯下站着一个人。旧式的黑伞，伞面低垂，遮住了脸。那人面朝他这扇窗。

陈默没动。

伞面抬了一寸，又落回去。雨在伞骨上积成细流，顺着边沿往下滴，滴得很慢。那人没有走近，也没有走开，就站在路灯和墙根之间那道斜影里，像一根钉进地面的旧桩。

陈默数了数自己的呼吸。十七下。

他伸手去够桌上的手机。屏幕亮起来，通知栏空着，时间停在十点四十七分。他把手机翻过去，又翻回来。数字没变。他把手机贴在耳边听了听，没有声音，连底噪都没有。

再抬头时，巷口空了。

伞没了，人也没了。路灯下只剩一圈被踩乱的水渍，往墙根方向延出去一小截，像有人退着走。陈默盯着那截水渍，直到它被新落的雨点打散。

他重新翻开种子书。掌心那个17还在，但旁边又多了半道细痕，从0382的3底下起笔，往左勾，勾到页边就断了。断口处纸纤维微微翘起，像被什么从里面顶过。

他想起父亲那半张纸条。不要记我。

他把书合上，没再翻。膝盖上压着那点重量，沉，但不烫。窗外雨声密起来，打在防盗窗的铁皮沿上，一声接一声。他没有起身去拉窗帘。

门缝底下，那张纸还躺在地砖上，宋体字朝上。他看了很久，把书从膝上拿开，站起来，走过去，弯腰，把纸捡起来。折成四折，塞进外套内袋，跟那张3月17日的便签贴在一起。

口袋里两张纸，一张是自己的笔迹，一张没有落款。

他回到床边坐下，没开灯。手机又亮了一下，相册推送了一条新照片提醒。他没点。屏幕暗下去之前，他看见缩略图里是这间屋子的窗台，窗台上搁着那本种子书，书页翻开，页角朝上。

拍摄时间：十点四十七分。

屏幕黑了。他没再按亮。雨声里，巷口方向传来一声很轻的金属碰响，像是伞尖点了地，又收回去。
