# 第4章 空档期

物流公司在城北工业区边缘，铁皮厂房改的，卷帘门拉到一半，里头码满蓝色塑料周转筐，筐上贴着褪了色的片区标签。陈默进去时前台没人，台面上搁着一叠入职登记表，旁边压着一支笔头干了的圆珠笔。他抽了一张，趴在台面上填。

老调度从里间出来，五十来岁，灰工装，袖口卷到手肘，手里拿着一张片区配送图，用图钉按在墙上。图上红笔标了不少记号。东门街出口那里画了三个叉，笔道粗，反复描过。

“明天有趟去东门街的件，”老调度点了点图，“要有人去踩点，你可以跟。”

陈默的笔停了一下。他抬头看那张图。“东门街那个口子，怎么标了三个叉？”

老调度拧开保温杯喝了一口。“那弯口最容易出事。去年一台厢货在那刮倒一个骑手，上个月又撞了一个，人还在医院躺着。夜里拐弯，视线短，新装的护栏又挡了一块。”他把杯盖拧回去，“你刚来，别走那条线。”

陈默把最后一行填完，交了表。老调度看了一眼表上的名字，没说什么，摆摆手让他明天来。

出了厂房，手机震了一下。房东发来的，问月底了，涨的那部分能不能先转。他站在台阶边上回了一个“明天”，把手机塞回兜里。台阶下堆着几截废弃的铁管，锈水淌了一地，在水泥地上分出一道暗红的岔。

他只去东门街吃碗面，就回。

共享单车骑了二十来分钟。东门街路口比他想的宽，四车道，中间有隔离栏，西北角一根公交站牌，新漆过，站牌杆下面有一摊白色粉笔画的箭头。沿街的梧桐刚修剪过，断口处冒着浅绿的浆。人行道里侧那家修鞋摊已经摆出来，老周坐在小马扎上给一双皮鞋上线，摊边搁着一只搪瓷盆，泡着几把旧伞。

陈默把车停在摊子旁，蹲下来看路面。脚下有一条裂缝，被人用白漆重新描过，从人行道边一直延伸到路肩。裂缝旁边就是斑马线，往前几米是转弯的盲区，绿化带挡住了一截视线。他站起来，沿着斑马线走了一个来回。信号灯配时他数了一遍。绿灯三十几秒，红灯五十几秒。

“后生，看路呢？”老周头也不抬，手上的麻线拉得紧。

“顺路看看。这路口常出事？”

“上个月一台出租车剐了个骑电瓶的。”老周把锥子别回鞋底，“那条口子咬人。这路口的孩子过马路都蹦着来，车一拐弯就看不见他们。”他用下巴朝校门方向指了指。

陈默没接话，蹲回摊边，把烟盒摸出来又塞回去。他坐了一阵，看车流一忽儿密一忽儿疏。手机响了。

林兰。她那边有碗碟碰撞的声音。“陈默，果果科创营挪到下午了，今天不用送。对了，你昨天怎么还拿着那本子。我爸以前也总翻一本旧本子，后来他走了。”

陈默握手机的手停了一下。风从巷口穿过来，把他额前的头发吹到一边。他等了三秒。“他后来什么时候走的？”

电话那头静了一拍，碗碟声也停了。“忘了，都是老早的事了。”林兰把话岔开，说要去接果果，挂了。

他听着忙音。修鞋摊的老周哼着一段走了调的曲子。街对面，新漆的公交站牌下站了一排等车的人。

下午四点十七分，东门街社区学校放学。

陈默坐在马路斜对面的台阶上。铁栅栏门开了，小学生涌出来，书包一颠一颠。他一眼就看见林果果，穿着校服，背粉色书包，跟在两个女生后面说笑。左手腕上缠着一圈褪色红绳，洗得发灰。

她在斑马线前等灯。旁边有个穿环卫服的大叔推着车经过。她蹲下去系鞋带，系到一半，同伴在前面喊她，她抬头应了一声，又低头把结打紧，前后蹲了十几秒。起身时灯还没变。她蹦着跑过斑马线，追上同伴。环卫大叔在后头喊了一嗓子：“看车。”她回头冲大叔摆了摆手，笑了。

陈默的手指在裤兜里摸索了一下。他掏出手机，按下计时器，又锁屏。他不知道为什么要按。

黄昏。便利店落地窗外，东门街方向的灯一盏一盏亮起来。他买了一碗关东煮，坐在窗边高脚凳上，把手机里的种子书照片放大。页角那半行压痕，他对着灯光又看了一遍。上午他翻的时候那行字还是“14:07 东门街路口”，现在下面多出一行更淡的印子。他把屏幕凑近灯。

停留：138秒。

没有名字。没有日期。没有地点。就这三个字加一个数字，像谁用指甲在纸纤维上按出来的。陈默把照片又放大一格，纸纹在屏幕上糊成一片灰。他关掉照片，把手机扣在桌面上。纸面上没有写“林果果”，可他知道那是给谁的。

晚上回到出租屋。室友的碗还在水槽里泡着，催租单被胶带贴到了冰箱门上，换了地方。他把背包搁在椅子上，拿出手机给林兰发微信。输入框里打了“明天果果有人送吗”，打了两行，删了，又打“明天果果几点到科创营”。他盯着这行字看了几秒，长按删掉整段。锁屏。

手机在桌上震动了一下。本地新闻推送。

“东门街路口明日起进行人行道检修，晚间部分时段临时调整信号灯配时。”

他往下划。新闻配图是一张路口俯拍照片，白色轿车正压着斑马线右转，车尾灯拖出一道红。他放大图片看那辆车。刹车灯亮着，车头已经越过停止线。他看这张图的时间比看页痕还长。

窗外能看到东门街方向的灯光，隔着两栋楼，一闪一闪的。他把新闻关掉，点开林兰的对话框。她的头像还停在下午那通电话上。

他打字：“林姨，你家以前那本旧本子，还在吗？”

发出去三秒，对面显示已读。林兰回得很快，像手机一直拿在手里。

“你是不是也在查这本？”

紧跟着弹出一张照片。木头书桌的一角，边沿磨得发亮，上面刻着一串数字，横竖分明，像用钥匙尖或刀尖划出来的。桌脚边还落着半截铅笔头。

0317。

陈默把照片放大。那串数字的写法他见过，笔画硬，每一笔都压得很深。

他拇指停在屏幕上，没有回。窗外东门街方向的灯光又闪了一下，对面那栋楼的轮廓在夜色里暗下去。手机屏幕还亮着，照片底下林兰的头像旁边，跳出一行“对方正在输入”。
