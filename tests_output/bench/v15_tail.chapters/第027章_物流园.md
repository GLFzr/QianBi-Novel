# 第27章 物流园

天没亮透，陈默就出了门。拐杖头在巷子台阶上磕了一下。他攥着那张对折的站牌照片，折痕硌着拇指。

公交坐到城北物流园终点，四十分钟。园区大门朝西，铁栅栏刷蓝漆，岗亭里亮着一盏灯。空气里有柴油味混着冷库漏出的水汽。面铺在斜对过，两张折叠桌支在人行道上。

老魏坐在靠里那张桌边，面前搁着两只空碗，头发刚洗过，湿着。看见陈默，抬了抬下巴，指对面那张凳子。

“坐。吃了没。”

陈默把拐靠在桌腿上。老魏让老板下两碗面，多搁葱。他摸出烟，抽一根夹在指间转。

“你爸那通电话，我记了三年。那阵我刚加群，谁的话也不听。他打来说老路弯道底下是空的，别走。我挂了。第二天那路段封了半个月。”

陈默没接话。面端上来，热气腾腾。

“我后来想还这个人情，找不到人。”老魏把烟塞回烟盒，“你那天打电话来，老路弯道、边坡渗水，跟你爸一个调子。”

“孙师傅在哪。”

老魏用筷子头往岗亭那边点了点。“夜班，刚下，这会儿在值班室没走。”

吃完两人过马路。岗亭里的小伙子打了电话，摁开闸键，铁栅栏门往两边缩。园区里一排钢架棚，棚下码着托盘，几个穿反光背心的工人推车进出。值班室在进园左手边，砖房，窗户贴着报纸。

孙师傅五十来岁，头发全白，看见老魏进来，把手机扣下。老魏说了句来意。孙师傅打量陈默一眼，看那条拐。

“老魏的话我信。你要查什么。”

陈默掏出手机，把群聊截图调出来。归零发单的格式、编号、接单记录。

“你们园区往外发的件，单号什么格式。”

孙师傅在旧电脑上敲了两下，屏幕上跳出面单预览，他指着右上角。

“前两位是线路，中间四位是出单日期，后三位流水。”

陈默把群编号跟面单格式并排摆着看。0311、0316、0317。格式对得上。群里那些号全是从物流系统里直接扒出来的单号。

“这单号谁能在外面查到。”

“手机小程序。输入单号能看物流轨迹。承运信息在里头。”

陈默把归零的头一个单号抄在配送单背面，递过去。孙师傅敲进电脑，点查询。屏幕跳出一条轨迹，发件网点在城北物流园。承运信息那栏往下拉，底下挂着一个注册手机号的尾号。

“号主注册信息看不到，系统只留尾号。”

陈默掏出自己手机，打开物流小程序，把单号输进去。轨迹页往下拉，底部一行小字：下单账号注册于三年前。

三年前。

“住场里谁有后台权限。”

孙师傅想了想。“驻场那几个主管。再就是外包的调度，早两年外包方撤了，账号没销，还挂着。”

“外包方哪家。”

他从抽屉抽出一张旧单子。陈默接住。公司名下面印着一行地址。这个地址他认得。上回查阿良的42秒，视频托管的登记单位也是这个地址。两条线落在同一个地方。

他把单子收进内袋。“你们园区有没有个人租的储物柜。”

“员工更衣室里有一排。早先管理员弄的，现在没人用。”孙师傅起身带他往后头走。更衣室不大，靠墙一排铁皮柜，六七个，有的门锁斜挂在铰链上。

这一排的样式陈默认得。灰绿漆，四角包铁皮，垫脚的砖块，跟程师傅车行后库房里那只一样。

“这些柜子谁租的。”

孙师傅回桌前抽出一本旧登记簿，翻了几页，指着其中一行。承租人一栏写着三个字。

周珩。

租用日期六年前。备注栏一行铅笔字，横平竖直，收笔压得重：常驻。勿动。

“这个名字我眼熟。”孙师傅说，“两三年前有个撑黑伞的男的来问过这排柜子，问是不是都空着。我说是。他没说什么就走了。”

陈默把登记簿合上。他抽出那半张站牌照片，背面朝上。

“归零002，你们园区有这编号。”

孙师傅摇头。“没这号。”

陈默走到更衣室那头，蹲下去，用钥匙试最靠里那只柜子的锁孔。插不进。锁眼比钥匙大出一圈。跟程师傅那只一样，换过锁。他直起腰。

走廊尽头有人推车过，铁皮柜被震了一下，门缝里落下一点灰。

“这排柜子多久没人开过。”

“记不清。得有三四年了。”

陈默把配送单背面那串数字折好，跟名片一起塞进内袋。他往外走，拐杖头在门槛上磕了一下。

园区大门口一辆厢货正在倒车。他站在岗亭边，掏出手机，把单号又输了一遍。轨迹页最下面那行小字后面，还有一行更淡的灰色字，是注册来源。

他放大屏幕。

城西某储物柜租赁服务点。

他把手机锁屏。老魏从面铺那头走过来，递他一根烟。他说不抽。老魏自己点上，吸了一口。

“查到了。”

“查到一半。”陈默说。

老魏弹了弹烟灰。“你爸那只柜子，在城西。你要是去，跟我说一声。”

陈默没应。他往公交站走，拐杖一步一磕。走到站牌底下，停住。那块站牌蓝底白字，跟他手里照片上那块一模一样。他绕到站牌后面，蹲下去。

灌木叶子底下，一截铁皮柜的角露在外头。跟更衣室那一排同款。柜门上锁着一把黄铜锁。

他伸手按了一下。铁皮是凉的。

他站起来，给老魏拨了电话。

“城西那个储物柜，我现在去。”

那头顿了一秒。“地址我给你发过去。”

电话挂了。他站在站牌后面等短信。灌木底下的铁皮柜露出半截柜门，锁眼在光里一闪。

手机震了一下。短信到了。他点开。地址后面缀着一行小字，是老魏加上的。

“柜子登记人我查了。周珩。”
