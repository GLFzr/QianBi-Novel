# 第3章 水渍在延伸

闹钟响在雨声之前。

陈默睁眼，先看见床头柜上那张外卖单底联。纸被摊平了，压在他的眼镜盒旁边，单号栏六位数字朝上，0317。他不记得自己什么时候把它从裤兜里翻出来。昨晚只记得本子塞进枕下，灯一关就没了。

林兰的语音躺在微信里，五点半发的，开头三秒是雨落铁皮棚的杂音：“陈默，你家一楼走廊渗水了，我早上出门踩了一脚。可能是你厨房水管没关紧，你去看看。”

他拨回去，林兰没接。他把手机揣上，套了件防水外套出门。

到老筒子楼时雨还没停。一楼走廊墙根洇了一长条湿痕，灰墙皮鼓起来，指头一按就掉粉。渗水从过道一路往里走，尽头是父亲那间。他开门。

厨房台面上积着一小片水，沿台边往下滴。昨日那摞碗还在原处，碗底那点汤水结了层暗黄的膜。他伸手拧水龙头，阀是关紧的。水是从台面接缝里渗出来的。他关了总阀，抄起抹布擦台面，顺手把那摞碗洗了。

水声停下来的时候，他站住了。

他不记得昨天午饭吃过什么。掀开那一格抽屉，里面空的，连碗的形状都没有。

他拧着抹布的手在池边停了一会儿。楼下有人推着板车过巷，轮子碾过积水，嘎吱一声。

他翻包找物业缴费单，翻到笔袋底部，指头碰到一张对折的硬纸。抽出来，是一张便签纸，边角被水洇过，字是他的笔迹，黑色中性笔，有一笔压穿了纸背。

3月17日必须联系小周。

手指有点凉。他不记得写过它。不记得小周是谁。3月17日，还有六天。

楼道里传来脚步声和塑料箱磕墙的闷响。他把便签对折，塞进外套内袋，贴着胸口。下楼时，楼道口有个穿黄色工服的外卖员正把泡沫箱从车筐里拎出来。雨后的台阶泛着水光，地砖缝里蓄着水，台阶靠墙那侧有一级明显松动，踩上去会翘。

“师傅，问一下，”陈默在门洞里开口，“你叫什么？”

外卖员抬头，二十出头，脸被雨打得发红。“周航。怎么了？”

“昨天3门317那单，是你送的？”

周航咧了下嘴。“对，昨天那单尾号0317的，是我送的。今天这单尾号不对，但地址还是这栋。我导航老指这儿。”

陈默看了眼他脚下那级松动的地砖，又看了眼车筐里那只泡沫箱。箱盖没扣严，缝里渗出浅褐色的汤水。周航正拎着箱子准备踩上去。

陈默退到楼道阴影里。他从外套内袋抽出种子书，翻到空白页。蓝黑墨水的笔拧开，笔尖抵在纸上。他停了三秒。

纸面安静。不烫不响。就是一本旧笔记本。

他落笔。字写得慢，每一笔都压稳：

周航，3月11日9时52分，滨河道12号一楼台阶，右手握紧扶手，停住半步。

写完最后一个字，纸面仍旧安静。他合上书页。心跳撞着肋骨的内侧，一下一下，数得清。

十五秒后，楼道口传来一声闷响。

陈默冲出去。周航半跪在台阶上，右手死死攥住锈迹斑斑的扶手栏杆，指节发白。他没摔。泡沫箱从车筐里甩出去，倒扣在台阶边，箱盖弹开，浅褐色的汤水从箱沿溢出来，顺地砖缝往下淌，流成一道细线，在台阶根部停住。那道细线不偏不倚，接在昨日那滩旧水渍的延长线上。

周航骂了一句脏话，爬起来拍膝盖，弯腰捡箱子。他回头冲陈默笑了笑：“这台阶真滑。”

陈默应了一声。

“谢谢啊，你那声提醒。”周航拎着箱子重新上车，拧油门，走了。

陈默站在原地。手里的种子书不烫、不响。他把笔帽按回去，听见咔的一声。它刚动过一次。

午后他回出租屋。灶台上三只空泡面碗，摞着，碗沿有干掉的面汤印。他不记得自己吃过其中任何一碗。水槽里那只室友的碗还在，昨天就在那儿。

他翻手机找昨晚的通话记录。拨出记录里有一条凌晨2点17分拨出的号码，时长十一秒，尾号0317。他盯着这条记录看了半天，没点回拨。

傍晚雨又下起来。他在老屋门口翻种子书。楼道感应灯坏了一盏，他借着门缝透出来的白光，看见页角那道压痕。昨天没有。昨天页角只有案：0317四个字。现在那串数字下面隔着一道纸纹的距离，多出半行极淡的压痕，像铅笔描过又被擦掉。

14:07 东门街路口。

纸是凉的。字迹发灰，摸上去没有凹凸。

他不认识东门街。

隔壁门开了。林兰撑着一把滴水的黑伞走出来，身后跟着扎马尾的林果果。林果果背着书包，立在门边啃一只包子。林兰收伞，把一串钥匙递过来：“昨天落你这儿的，早上忘拿了。”

陈默接了。

“你家水管没事吧？”

“总阀关了。”

林兰点点头，又像是顺口：“果果明天七点要去东门街那边上科创营，我本来还愁下雨怎么送。”

陈默捏着种子书的手指收了一下。他低头看那半行压痕。他问：“你说哪里？”

“东门街路口呀，”林兰拉了拉女儿的书包带，“滨河道那头，有个红绿灯的。她爸明早顺路送。”

林果果咬着包子抬头看了陈默一眼，没说话。

陈默把种子书合上，后背抵着门框。楼道外面雨丝斜着扫进来，打在走廊地面上。雨伞滴下的水在墙根积了一小洼，那道水痕沿着地砖缝往楼道深处延伸。

他问：“果果明天几点到那个路口？”

“七点，她爸送。”

陈默低头。页角那半行压痕在灯下发灰：14:07。上午七点。纸上是下午两点七分。

“她平时也那个点走那边吗？”

林兰奇怪地看他一眼：“今天不去，明早要去东门街路口那个红绿灯，她爸顺路送。”她牵起果果的手转身，“走吧，回去写作业。”

门关上了。

陈默站在走廊里。手电白光照着纸页。那半行压痕下面，隔着一道纸纹的距离，正慢慢浮出极淡的第二笔。他凑近看，看不清那是什么字。

楼道尽头，无人处的拐角，滴水声从老屋里传出来。一下。又一下。
