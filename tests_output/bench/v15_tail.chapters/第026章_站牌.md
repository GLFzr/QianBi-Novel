# 第26章 站牌

陈默把窗帘拉开半幅。

巷口那盏路灯还亮着。伞没了，灯下圈着的水渍还在，边沿比刚才浅了一层。他把外套抓过来，拐杖夹进腋下，单脚往鞋里踩。鞋带没系，拖在脚后跟。

下楼。楼道感应灯一盏盏亮起来，又一盏盏灭掉。

推开单元门。巷子里空的。歪脖子槐树底下那盏灯把砖面照得发白，他走到路灯底下，花砖上的积水渗了一半，剩下的半圈里，有三道浅浅的印子往外拖。

他顺着印子看。印子拖到巷口，没了。

巷口外面是人行道。凌晨一点多，主街上没车，路灯一排亮到另一头。人行道上没有人。

他往外走了几步。

花砖边沿缺了一角。缺口里卡着一张纸，边角卷着。

他蹲下去抽出来。四寸照片，白边，正中一张公交站牌。

站牌蓝底白字。站名三个字：物流园。底下三条线路的箭头排着。站牌右侧一根灯杆，灯杆上贴一张告示，掉了半边，只剩抬头四个字。照片取景正对站牌，四边留白匀匀的。拍得很稳。

他把照片翻过来。

背面白底，两行铅笔字。笔画不快，一笔一笔压平。

上一行：下一个案例。

下一行字略浅，像写完后又描过一遍。

归零002。

他盯着这两行。风从主街那头过来，把他额前的头发吹到一边。他把照片对折塞进内袋，站起来往两头看。左边路口，右边也路口。都没有人。

回出租屋。反锁门，拧开台灯，把照片摊在灯下。

他拿放大镜压着边看。站牌玻璃右下角有一小块反光，反光里露出一线深灰的布料边。拍照的人站在站牌同侧靠右，离得近。玻璃上还有一道刮痕，从中间往右走。

镜头中心压在站牌中线上。不是抓拍。有人站定了，对准，按快门。

纸是光面的，边角裁得不齐。打印机出纸后手撕的。

他把照片翻过来，看那两行字的笔压。归零002四个字比上面一行浅，收笔慢。

手机在桌上震了。

本地号，没有备注。他接起来。那边先是一阵风，然后是老魏。

“是我，老魏。”

“嗯。”

“今晚那段路。”老魏停了一下，“我回来的时候，弯道口那两只锥子还在。”

“你掉头了。”

“没掉。”那边有车门关上的声音，“我停在那看了两分钟。第二只锥子底下，柏油是软的，鞋跟一踩就陷进去。我再快十码，人车都得进去。”

陈默没接话。

“我打电话不是问你放的。”老魏说，“我就问一句。你白天那通电话，从哪知道那段路的。”

“路过看见的。”

老魏在那边笑了一声，很短。“路过看见的。行。”

“你爸以前也给我打过一回。”老魏说。

陈默的手指按在桌面上。

“三年前，也是这个调子。别走老路，路底下空。我那时刚加群，谁的话也不听。后来我换了路线，没出事。再后来那段路封了半个月修。”

“他什么时候打的。”

“记不清。就记得那年三月，晚上冷。”老魏那边挪了一步，“我不认识他。他打完电话人就没了。我找不到谁还他这个人情。”

陈默没答。

“物流园门口有家面铺，六点半开。”老魏说，“明天早上来。你要查物流园，园里夜班保安孙师傅，我熟。你爸以前跟他打过两次照面。”

“你怎么知道我要查物流园。”

那头停了一下。“我不知道。我瞎说。”

电话挂了。

陈默把手机搁在桌面上。他伸手把照片翻过来。两行铅笔字还在灯下。上一行压得深，下一行浅。他把两行字在心里排了一遍，又翻回正面看了一回。

站牌上物流园三个字，笔画的间距他认得。

这是他上回去东门街踩点时，在公交站牌上见过的那种蓝底白字。同一个印刷厂出来的。

他把照片折好，塞进外套内袋。内袋里那张3月17日的便签、那张焦边纸、那副地图，边角抵着它。

他起身去关台灯。

手刚碰到开关，楼道里的感应灯亮了。灯从门缝底下透进来一线，横在地砖上。

楼下没人跺脚，那线光却一直亮着。

他站在门边，手还搭在开关上。门缝底下那线光没灭。

他把手从开关上收回来，摸到门把手。铝拐杖靠在门框边，他先拿拐杖，再拧锁。锁舌缩回去的声音很轻，门外那线光没动。

他拉开门。

楼道里空着。感应灯亮在头顶，灯罩里积着几只死苍蝇。楼梯拐角堆着几袋旧衣服，是四楼那户搬走时留下的。他往楼梯口挪了两步，拐杖头点在地砖上，一声，两声。

没人。

他正要退回去，脚底踩到东西。纸。半张A4纸，从楼梯扶手缝里塞进来的，边角被门缝夹出一道折痕。他把拐杖靠墙，单脚蹲下去捡。

纸上印着公交站牌照片的背面。跟内袋里那张是同一张纸的另一半。上面那行字他刚才在屋里看过，下一个案例。底下还有一行，铅笔写的，比上一行浅，笔画发虚，像写的人手在抖。

归零002。

002是阿拉伯数字，归零两个字是汉字。他盯着那三个数字看。序号。第二个。归零是他见过的第二个。

第一个是谁。

他把纸翻过来。正面是同一张站牌照片，但角度偏了半寸，拍到了站牌杆底下的地面。地上有一道白粉笔画的箭头，跟他上回在东门街路口看到的那道一样。箭头指着站牌后面的绿化带。

绿化带里露着半截铁皮。

他认得那铁皮。程师傅车行后库房铁皮柜上那种，边角卷起来，锈从焊缝往外爬。照片里那截铁皮上有一行喷漆字，被灌木叶子挡掉一半，剩下三个字能认：零。

门缝底下那线光灭了。楼道里暗下来。他站在门边，手里捏着半张纸，拐杖还靠在墙上。

楼下传来一声关车门的响。很轻，但在夜里传得清楚。接着是脚步声，从单元门口往巷子口走，鞋底蹭着水泥地，不快。

他扶着墙单脚跳到窗边。楼下巷子里，路灯照着一小截路面。一个撑黑伞的人正往巷口走，伞面压得很低，看不见脸。走到歪脖子槐树底下，那人停了一下。

伞面抬起来一寸。冲四楼窗户的方向。

停了两秒。伞又压下去，人出了巷口。

陈默没开窗。他退回桌边，把手里那半张纸跟内袋里那张拼在一起。两张纸的撕口对得上，拼成一张完整的站牌照片。正面是站牌，背面两行字。上一行下一个案例，下一行归零002。

他翻到正面。站牌上物流园三个字的间距，跟内袋里那张一模一样。但拼合之后，照片右下角多出来一小块画面，是刚才那半张纸单独看时被折进去的部分。画面里站着一个人，背影，穿深色外套，手插在兜里，正往站牌方向走。

背影的左腿是直的。右腿微微向外撇。

他认得这个走姿。上回在城北老路弯道口，他摆完反光锥往回撤的时候，监控里自己的背影就是这个样子。右腿撇，因为左腿刚被撞过，走路时下意识把重心往右压。

这张照片拍的是他。

拍摄时间，是他第一次去东门街踩点那天下午。

他把照片扣在桌面上，手背压着。手背上的墨痕还在，淡得快要看不见。他盯着那点墨痕看了一会儿，把照片重新翻过来，凑到台灯底下。

照片里那个背影的右手腕上，露出一小截表带。

金属的。表盘边缘的轮廓，跟他内袋里那块碎表对得上。

他伸手摸内袋。表还在，壳背0317的刻字硌着指腹。他把表掏出来，跟照片并排放在灯下。照片里表带扣的位置，跟他手里这块表壳上的划痕对得上。同一条。

他上回去东门街踩点那天，手腕上没戴表。表是昨天才从四楼掉下来的。

那照片里这块表，是谁戴在他手腕上的。

他把表收回内袋，照片折好，两张纸叠在一起塞进去。拐杖重新握在手里，他走到门边，把门锁上。锁舌弹回去那一声很脆。

楼道里感应灯又亮了。这次他听见了跺脚声。从楼上下来，一级一级，踩得很实。经过他门口时没停，继续往下走。

脚步声出了单元门。巷子里那盏路灯照进来一线光，在地砖上拉长。光里晃过一片影子，伞形的。

影子停在单元门口，没动。

陈默站在门后，手搭在锁上。门外那片伞形影子慢慢转过来，对着门。伞尖在水泥地上点了两下。

然后一个声音从门缝底下挤进来。不高，嗓子刚睡醒似的，尾音磨着沙。

“陈默。你爸那本子，翻到第几笔了。”

他没应声。

门外那人等了几秒，伞尖又点了一下地。“不说也行。你翻到002，就该知道前面那个001是谁。”

脚步声重新响起来，往巷口走。陈默听见伞面收拢的响动，金属伞骨一节一节叠回去。然后是车门关上的闷响。引擎发动，车灯从巷口扫过来，在四楼窗户上划过去一道白光，灭了。

巷子重新静下来。

他站在门后没动。手里攥着拐杖，指节发白。内袋里那两张拼好的纸贴着肋骨，跟碎表、便签、焦边纸、地图叠在一起。他低头看门缝底下。感应灯还亮着，光里落着一张东西。

又一张纸。比刚才那张小，对折了两次，从门缝底下推进来的。他蹲下去捡，展开。

上面只写了一行字，圆珠笔，笔画潦草。

“你爸没还完的，轮到你。001是我。002是你。”

底下没署名。但纸的右下角，有一个用指甲掐出来的印子。一个圈，起笔重，收尾拖出一截。

跟种子书封面内页那行字的收笔，一模一样。
