# 第29章 待处理

台灯亮了一夜。陈默把纸箱从桌上挪到地上，美工刀沿封口划开，胶带崩断一截，弹到手背又落下去。六个硬壳册子码在最上面，底下垫着两张旧报纸，日期是九八年的。

他把册子一本本取出来，按脊上贴的年份排开。九九年。零零年。零一年。零二年。中间有两年合成了一本。最后一本最薄，贴着去年的标签，只有前头三分之一厚。他翻开第一册。

纸面比后面的黄。表格是手画的，横竖都不直，墨水是蓝黑的。第一行填着001，九九年三月十七，城西工地。往下翻，每行填满六格：编号、日期、地点、对象、原状、改写。最右一栏窄，写着代价。第一笔的代价栏画了个圈，圈里一个字：忘。

他一笔一笔往下走。有的行填得密，一天挨着一天。有的页空着，只留一道铅笔划过又擦掉的浅痕。翻到第四十几笔，有一行写：外卖骑手，男，二十三岁。原状栏：雨天过桥，车轮打滑。改写栏：绕东边积水路段。代价栏空着。再往后，有一笔的对象栏写着：邻居，女，六十三，姓赵。原状栏：买菜过马路。改写栏：迟半分钟出门。代价栏里写了一个字：忘。

他记得赵婆婆。老屋隔壁那家，脑门上有一颗痦子，前年夏天摔过一跤，从那以后没再骑过自行车。父亲替她改的这一笔，就在那一年。

他把册子合上，又翻开。这一页的字，每一行都端正，收笔压着纸，蓝黑墨水渗到纸背。

窗外的天开始亮。巷子里有人推板车过，轮子碾过积水，声响拖得很长。

他翻到最后一册。纸比前几册白，字也新。翻到靠后一页，手指停住。

最后一行，编号栏里写着三个字：待处理。日期栏空着，地点栏写着四个字：东门街路口。对象栏两个字：陈默。原状、改写、代价三栏都是空的。

旁边有一行铅笔小字，收笔压得重。

不可写。

他把灯拉近，光落在那一行上。不可写。封面斜角那三个铅笔字是不可贪，这一行的笔锋更稳，没有抖。他往上翻，找这一册里其他记录的格式。编号、日期、地点、对象、原状、改写、代价，一样不缺。只有这一条，编号栏写着待处理，日期空着，剩下三栏也是空的。前一条记录是去年秋天。这一条压在末页。

他把册子压在摞上，手按着封面。台灯照着手背，墨痕淡得只剩一道浅青。

手机在桌面上亮了。

阿莲。

“我在馆里。”她那边很静，压缩机嗡嗡的底噪一波一波，“我哥那烟盒，我翻过来了。”

翻过来。

“内侧还有一层。”她说，“之前那张照片把中间挡着，没看出来。今天我把照片揭下来，底下有一行刻痕。”

什么字。

“0383。”

陈默把手机换到另一只手上。

“刻得深。”阿莲说，“像用指甲抠的。边上还有一点没擦净的墨。”

什么时候刻的。

“不知道。”她停了一拍，“昨天之前还没有。”

巷口的板车走远了，声音淡下去。陈默伸手把台灯往桌沿推了半寸，光收成一圈，圈在最后一册的封皮上。去年秋天，父亲在住院前把这一册写完。前面三百八十一笔。末页留了三个字。

“你还在城西。”阿莲问。

回来了。

“账本拿到了。”

拿到了。

那边静了两秒。压缩机又响一声，比刚才长。

“最后一册，”阿莲的声音压低半度，“有没有写0382。”

陈默的目光落在册子封皮上。写了。

“那0383呢。”

“没有。”他说，“末页只有一条，写的是三个字，待处理。”

阿莲没接话。那边有椅子腿蹭地的动静，一下，又一下。她开口时，声音比刚才平。

“0383底下还有半个字。”她说，“被指头抹糊了，我对着灯看了好几遍。那个字的起笔是横折，往下带一勾。”

陈。陈默说。

“你怎么知道。”

“你刚才说0382的时候，我就在想这个。”他把册子从摞顶挪到桌心，摊开，纸面对着头顶那盏灯，“你哥出事那天写在烟盒上的，是我爸留给你的第一句。刻在底下的那半个字，是留给我的第二句。”

阿莲那边沉默了很久。久到陈默能听清她呼吸的节奏，跟她上回在化妆间里右手发抖时一样，深一下，浅一下。

“陈默。”她终于开口，“我哥出事那晚，烟盒上那半句话后面，还有一个标点。”

什么标点。

“一个逗号。”她说，“一直拖到现在，我才看明白。那句话没写完。”

窗外天光爬上对面的楼顶，把第一层窗框照出一条灰白的边。陈默低头看桌面上摊开的册子。末页那一行字还压在灯下，铅笔的三个字在光里泛着一点灰白。他把册子缓缓合上，掌心压住封面，指节抵着桌沿，没有松开。

电话那头传来窸窣的响动，像阿莲把烟盒从什么角落里抽出来，又像她在翻找别的什么。陈默没催。灯下那册账本的封面被他掌心焐出一小块温，纸页边缘的毛糙硌着指腹。

“烟盒内侧。”阿莲的声音忽然近了，像她把手机换到了左手，“我哥出事那天穿的那件夹克，我一直没洗。烟盒在内袋里，压扁了。刚才我又拆开夹层，里头还有一层，用刀片划开的，缝过。”

缝过。

“线是黑的，跟烟盒一个色，不细看认不出。”她停了一下，“我挑开线，里面那张纸上刻着字。跟烟盒内侧一样，用刀尖刻的。0383。”

陈默的拇指在账本封面上停住。0382是末页那个数，画了圈，旁边写着他的名字。0383比它多一笔。

刻在什么上。他问。

“一张薄纸，跟烟盒衬纸一样，裁得方方正正。”阿莲说，“字底下还有一行，刻得浅，我拿灯侧着照才看出来。写的是‘阿莲手’。三个字。”

陈默没接话。窗外那层灰白的边正一寸寸往下退，对面楼顶的轮廓在光里硬起来。他想起殡仪馆化妆间里阿莲那只右手，指尖抖着，粉扑落在地上。那会儿她说是老毛病。后来在冷柜区，她点破他手背墨痕的时候，那只手稳得能捏住他的手腕。

你手现在怎么样。他问。

电话那头静了两秒。然后是一声很轻的、像把什么东西搁在桌面上的响动。

“抖。”阿莲说，“从昨天夜里开始，拿不住细东西。刻字那张纸，我用镊子夹着看的。”

陈默把账本翻开，翻到末页。0382那一行底下，铅笔那三个字还压着纸面。他盯着那三个字看了很久，指腹顺着笔画走了一遍，收笔的地方凹得深，像写的人在这儿顿了一下，又顿了一下。

“0383在你哥烟盒里。”他说，“0382在我爸账本末页。中间差一笔。”

差的那一笔是什么。

他没答。灯下那页纸的边角翘起来一点，他伸手去按，指腹触到纸背，有一小块凸起。他把册子翻过来对着灯。纸背靠近装订线的地方，有一道极浅的铅笔痕，像是写完正面那行字之后，笔尖从纸面透过来，在背面蹭了一道。那道痕的形状，是一个没写完的横折，往下带一勾。

陈默的呼吸停了一拍。

阿莲。他说，“你刚才说，0383底下那行字，刻的是‘阿莲手’。三个字，你确定是三个。”

“确定。我数了几遍。”

“你哥写0382的时候，烟盒上那句话后面拖了个逗号。”他把册子翻回正面，合上，掌心重新压住封面，“他写到一半停了。现在0383底下又给你留了三个字。你哥写字有个习惯，你知不知道。”

阿莲那边呼吸重了一下。什么习惯。

“他写数字，从来不在前面加零。”陈默说，“0382，0383，他要是想写382，就写382。前面那个零，不是他加的。”

电话里只剩电流的底噪。陈默低头看着自己压住封面的那只手，指节发白，手背上那道墨痕在灯下泛着一点青。他想起父亲批注里那句已有人偿过，想起账本末页那个画了圈的0382，想起阿良烟盒上那个拖到现在的逗号。

“那个零，”阿莲的声音从听筒里出来，很轻，像怕吵醒什么，“是谁加的。”

陈默没回答。他把账本从桌面拿起来，塞进外套内袋，贴着胸口。册子的硬壳边角抵着肋骨，跟那块碎表停着的位置隔了一层布。他站起来，铝拐杖在桌沿磕了一下，发出一声短促的金属响。

你还在殡仪馆。他问。

“在。今晚值夜。”

“别碰那个烟盒。”他说，“把夹层原样缝回去。线用黑的，跟原来一样。”

陈默。

“嗯。”

“0383底下那三个字，我哥刻的时候，手是稳的。”阿莲说，“一笔没抖。”

陈默握着手机，站在那盏灯底下。窗外天光已经漫过对面楼顶，把整条巷子照得灰白。他低头看了一眼自己的左手，小鱼际那道墨痕旁边，又浮出一个小点，比针尖大不了多少，颜色比昨天深。

我知道。他说，把手机从耳边拿下来，拇指按灭屏幕。
