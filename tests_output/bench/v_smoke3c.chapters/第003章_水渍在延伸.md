# 第3章 水渍在延伸

窗外雨停之前，手机闹钟先响了。陈默睁眼，看见床头柜上摊开的外卖单底联，单号0317。他盯着那四个数字看了五秒，不记得自己什么时候把它从包里翻出来放平的。

屏幕上方浮着一条语音留言，林兰的，凌晨五点多：“一楼走廊渗水，可能是你家水管，你回来看看。”

他洗脸时脑子里还压着底联的边角。出门前他把底联折好塞回背包侧兜，手指在拉链上停了一下。

老屋厨房的台面上，一列水渍正沿着台边往下滴。昨日那摞碗还在原处，水龙头是关紧的。水是从台面缝隙里渗出来的。他拧紧总阀，顺手把碗洗了，水声停下来时，他忽然意识到一件事：他不记得自己昨天午饭吃过什么。那里空了一块，像一页被撕掉的时间。

他翻包找物业缴费单，指头在笔袋底部摸到一张对折的便签。展开，自己的笔迹：“3月17日必须联系小周。”

他不记得写过它。不记得“小周”是谁。更不记得3月17日需要联系这个人做什么。他把便签对折，塞进胸口口袋。

下楼。楼道口一个穿黄色工服的外卖员正从车筐里拎泡沫箱，雨后的台阶泛着水光，地砖松动，雨水积在缝里。这人他认识，昨天误闯进来，递过他那张0317单底联的年轻人。

“你叫周航？”陈默叫住他。

外卖员抬头，愣了一下，报出名字，又补一句：“昨天那单尾号0317的，是我送的。”

陈默看了眼他脚下那级台阶。鞋底踩上去必滑。他退到楼道阴影里，翻开种子书，蓝黑笔尖抵在空白页上。他知道规则吗？不知道。他只知道昨夜录音里那句没说完的话。

他写下：周航，3月11日9时52分，滨河道12号一楼台阶，右手握紧扶手，停住半步。

落墨。纸面安静得像一本普通笔记本。

十五秒后，楼道口一声闷响。陈默冲出去。周航半跪在台阶上，右手死死攥着扶手栏杆。他没摔。泡沫箱从车筐里甩脱，倒扣在台阶边，汤水从箱沿溢出来，顺着地砖缝流成一道细线，不偏不倚接在昨日那滩旧水渍的延长线上，停住。

周航骂了句脏话，爬起来拍拍膝盖，弯腰捡箱，回头冲他笑：“这台阶真滑。”

陈默站在原地，手心里的种子书不烫，不响。但他知道，它刚动过一次。

午后回到出租屋，灶台上三只空泡面碗。他不记得自己吃过其中任何一碗。他翻手机想找昨晚的通话记录，屏幕显示凌晨2点17分拨出一通电话，时长11秒。尾号0317。

他记得自己听完录音就睡了。那11秒是谁拨的？

傍晚，雨又下起来。陈默蹲在老屋门口翻种子书，页角在楼道白炽灯下压出一道极淡的痕，像铅笔描过又被擦掉，只留半行：“14:07 东门街路口。”

他不认识东门街。

隔壁门开了。林兰撑着一把滴水的伞过来，手里攥着一串钥匙，昨天落她家的。她身后跟着个扎马尾的小女孩，林果果。林兰收了伞，随口说：“果果明天七点要去东门街那边上科创营，我本来还愁下雨怎么送。”

陈默低头。纸页边缘那道压痕发灰。他问：“你说哪里？”

“东门街路口呀。滨河道那头，有个红绿灯的。”

陈默拇指无意识压住纸面上“14:07”那半行字，指腹蹭过纸纹。他没有把页痕给林兰看。他合上种子书，后背抵着门框，问：“果果明天几点到那个路口？”

“七点，她爸送。”

陈默低头又看了一眼纸面。他早上七点出门，纸上写的是下午两点七分。两件事叠不到一起，除非那行字说的是另一天，或者另一个人。

“她平时也那个点走那边吗？”

林兰奇怪地看他：“今天不去，明早要去东门街路口那个红绿灯，她爸顺路送。”她说完领果果转身回屋。门关上。

陈默站在走廊里，手电白光照着页角。那半行压痕下面，隔着一道纸纹的距离，正慢慢浮出极淡的第二笔。他看不清那是什么字。

楼道尽头，无人处的拐角，水龙头没关紧的滴水声从老屋里传出来，一下，又一下。

他数着滴水声。一下，两下。第三下没落下来，楼道尽头的声音停了，像是有人伸手拧紧了那枚龙头。陈默后背贴着门框，手电光没动，纸页上那道第二笔在光圈边缘停住，笔画朝左下方斜，像一撇，又像半道折痕。楼道里没有风。他侧过头，走廊尽头那扇通往老屋的门半掩着，门缝里透出一线暗光。他出门前拧紧过总阀，厨房的水龙头也关死了。那滴水声停了，门缝里的光却还亮着。

陈默把种子书收进外套内袋，手电照向走廊尽头。光柱扫过地面，昨日那滩旧水渍还在，上面覆着一层新干的汤痕，两道痕迹连成一条细线，直直指向那扇半掩的门。手机在裤袋里震了一下。他摸出来，屏幕亮着，一条新消息，来自一个没有备注的号码：“14:07，东门街路口。别带本子来。”发送时间，2点17分。陈默抬头。走廊尽头那扇门缝里的光，灭了。

他站在黑暗里，手电光还亮着，照在空荡荡的走廊尽头。那扇门关严了，门缝里没有光，也没有声音。他走过去，手搭上门把，金属冰凉。他拧了一下，门锁着。他出门前确实锁了门，钥匙还在他口袋里。那刚才半掩的门缝里透出的光，是谁开的？

他退后一步，手机屏幕还亮着，那条消息停在上面。他盯着那行字，拇指悬在回复框上。他打了一个字：“谁？”没有发送。走廊尽头的水管发出一声闷响，像被什么东西轻轻敲了一下。他收起手机，转身下楼。走到楼道口时，他停住，回头看了一眼。那扇门缝里，又透出一线极细的光。
