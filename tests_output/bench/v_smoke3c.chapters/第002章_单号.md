# 第2章 单号

他踩到那滩汤渍的时候，鞋底带起一串黏腻的声响。楼道口的感应灯亮着，冷光铺在水渍上，像一行边缘被泡烂的字。他蹲下去看了两秒，没看出所以然，跨过去。走出两步才偏头，那滩水渍边缘浮着一截蓝色的尼龙绳碎头，毛边散开，颜色与父亲账本封皮一模一样。他摸了摸背包侧袋，钥匙搁在里面，钥匙扣上那截蓝绳子也还在。那么水渍里这一截，不是他的。他跨出巷口。

共享单车停在路边。他解锁骑上去，手机在口袋里亮了一下。房东的消息：“房租别拖过这周。”再往上翻是中介的回复：老破小动迁观望，先挂上。他锁屏，蹬车。风灌进领口，脑子里反复滚着那本本子封面上的字：“种子书。记人未长成的事。”几个字，一路跟到出租屋楼下。

出租屋在六楼，没有电梯。他进门，开灯，把纸箱拖到地板中央。旧衣物一件件抖开折好，塞进垃圾袋。木工工具拿湿布抹了一遍，码回工具箱。收据按年份理成几摞，用夹子别好。种子书从背包夹层抽出来，单独放进床头柜最里层的抽屉。抽屉里空荡荡的，他专门腾出来给它。这是他唯一没有归进“旧物”类别的东西。抽屉不上锁，合上时，手指在边沿停了一拍才收回。

坐回床边，他想起该办的事。父亲的手机号还挂着，人没了，号留着没用。他翻出通讯录，备注栏写着“爸（老宅）”，按下去。听筒里传来机械女声：“您拨打的电话已关机。”他正要挂断，屏幕弹出一条提示：“您有新的通话录音已保存。”

他愣了一下，点开。

录音约四十秒。前段是窸窸窣窣的杂音，纸张翻动，抽屉开合，塑料布被掀起来。中段是父亲的声音，低低的，含混，压得很紧，像怕被谁听见。背景里有一声轻微的电子嗡鸣，像包里的行车记录仪还开着。

“……本子留给陈默。告诉他，账不由命运收。收账的是”

门铃从听筒里炸出来，录音断了。

陈默拇指悬在屏幕上，没有松开。父亲的声音他认得，可这语气他从来没听过。他倒回去，又听了两遍。第三遍，他在门铃混杂的底噪里辨出一个电子女声，很轻，像外卖店里那种自动播报：“您有新的外卖订单，编号0317。”

他放下手机，翻开背包侧兜。一张外卖底联叠在兜底，边角折了一道，像被水泡过又阴干的。取件码区印着“0317号”。他不记得自己收过这张单子，更不记得它怎么进的包。他捻着那张底联，今天之内，页角的钢笔编号、底联的取件码、录音底噪里的播报，三处叠在一起。之前他告诉自己这是巧合，现在巧合凑成了排。

他把底联摊在床头柜上，拿起种子书，翻到写有“案：0317”那一页。笔尖抵住纸面，黑色墨水在笔尖聚成一小滴，悬着。他没有落笔，呼吸放慢。旧纸的气味冲进鼻腔，他盯着那行歪斜的钢笔字看了一会儿，仿佛要从笔画之间找出一个答案。很久之后，他把笔收回去，合上本子，关灯躺下，把本子压在枕头底下。硬角抵着肩膀。

凌晨两点十七分。他翻身，肋下硌到枕底的硬角。坐起来，摸到外衣口袋里那块旧表，表壳背面的划痕在黑暗里硌着指腹：0317。手机屏幕自己亮起来，他点开拨号盘，又按下那一串号码。这次听筒里没有忙音，传出一段人声，是父亲自己录的：“您拨打的用户已在服务区外，留言请按——”

尾音落下，一声忙音截断。号码还挂着彩铃，可充电的手机永远不会有人接了。他退回通讯录，备注栏下还有一行小字，创建于三年前：“0317，他生日。”

他盯着那行字。0317在页角上，在底联上，在订单播报里，在表壳背面，现在又落在自己的通讯录里，钉在他和父亲之间。他没有删，也没有放下手机。屏幕暗下去之前，他点开备忘录。父亲留存的唯一一条记事躺在那里：“3月17日22:47，去东门街路口。”

他抬头。楼下路灯把街面照出一圈昏黄，一辆电动车停在灯下，骑手戴着头盔，腿撑着地面，没有进任何一栋楼的门。手机顶部弹出一条新通知：“您有新的通话录音已保存。”屏幕上方的时间跳到2点18分。他还没有点开，楼下那辆电动车发出引擎声。响了一下，又停住，没有驶离。

他拇指悬在通知栏上，窗外那辆电动车又响了一声，这次带上了链条的摩擦声，像人捏着刹车反复试力。陈默把手机翻了个面，屏幕朝下扣在床单上。

录音不会跑。楼下那辆车会。

他掀开被角下了床，赤脚走到窗边，窗帘拉开一条缝。路灯底下那辆电动车还停在原处，骑手低着脑袋看手机，屏幕光把他下巴照亮了一瞬。不是小周。这人身形更瘦，头盔是全黑的，没有外卖平台的贴标，车尾也没有保温箱。

陈默放下窗帘，退回床边。他重新拿起手机，屏幕还亮着，通知栏那条录音提示安静地躺在那里。他点开录音，听筒里先是一段空气流动的杂音，接着是父亲的呼吸声，比刚才彩铃里那句更近，像人贴着话筒在说话。

“陈默。3月17日，别去东门街。”

声音顿住。背景里传来门锁转动的声音，父亲又说了一句，这次低得几乎只剩气声：“账不由命运收。收账的是——”

录音结束。时间00：14。

陈默把手机放下，窗外那辆电动车终于动了。引擎声由低转高，轮胎碾过柏油路面的声音从楼下传上来，一路往东，越来越远，最后消失在街口的风里。

他看了一眼屏幕。2点19分。距那条备忘录里的时间，还剩二十个小时二十八分钟。
