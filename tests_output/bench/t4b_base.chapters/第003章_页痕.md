# 第3章 页痕

闹钟响时雨停了。床头柜上摊着一张外卖单底联，单号区印着0317。陈默坐起身，不记得自己昨晚什么时候把它从包里翻出来，还压得这么平。

手机一条新留言。林兰的声音压得低，背景里有小孩的动静：“陈默，你爸老屋一楼走廊渗水了，可能是二楼厨房水管没关紧。你空了回来一趟，我在墙根垫了布，撑不了多久。”

他赶回老屋。刚过八点，楼道里一股潮味。

厨房台面一道水痕沿台边往下滴，那摞没洗的碗还在原处，龙头拧到头，关得死紧。水是从台面与墙的接缝里渗出来的。他蹲下看了一眼，直起身，把总阀拧上。

他洗碗。水声哗哗的。水停的瞬间，他意识到一件怪事：他不记得昨天午饭吃过什么。那里空了一块，像一整页被抽走了。他手插在没擦干的碗里，水凉得渗进指缝，嘴里却嚼不出任何一样昨天的味道。

他甩甩手，翻背包找物业缴费单。账本、收据、合同掏了一桌，笔袋底部摸到一张折成四折的便签纸。

打开。他的字迹。蓝黑墨水，笔画没有犹豫：“3月17日必须联系小周。”

他不记得写过这张便签，不记得小周是谁，也不记得3月17日要联系这个人做什么。他把便签对折，塞进胸口衬衫口袋。

下楼时，楼道口有人正弯腰从电动车车筐里拎泡沫箱。黄工服，头发被雨打得贴在额前，是昨天问“三单元317往哪走”的那个外卖员。他认得陈默：“叔，昨天那单尾号0317的，我送的。”

“你叫什么？”陈默问。

“周航。怎么了叔？”

陈默看了一眼他脚下的台阶。地砖翘起一角，缝里积着雨水，连着那滩旧水渍。“没怎么。慢点，滑。”

周航低头看了一眼，鞋在边沿蹭了蹭，拎着泡沫箱往上走。陈默退进楼道阴影里。

种子书在背包夹层。他拿出本子和蓝黑墨水笔，翻开空白页，笔尖抵在纸面上，停住。他只知道录音里那句没说完的话，不知道这一笔落下去，账要从哪里开始算。他写：

“周航，3月17日清晨，滨河道12号一楼台阶，右手握紧扶手，停住半步。”

纸面安静，没有异样。他合上书页，心跳撞着肋骨。

十五秒后，楼道口传来一声闷响。陈默冲出去。

周航半跪在台阶上，右手死死攥着锈掉的扶手，人没摔下去。泡沫箱甩脱了，倒扣在台阶下，箱沿磕裂一道口子，汤水从缝里漫出来，沿着地砖缝细细一道，不偏不倚，接在昨日那滩旧水渍的延长线上，又往前渗了半寸才停住。

“操。”周航骂了一声，拍着裤腿站起来，去捡箱。箱盖裂了，菜汤漏了大半。他冲陈默咧嘴，“这台阶真滑。”

陈默站着没动。手心的种子书不烫，不响，像一本死物。但他知道它动过了，他添了一笔不知道什么时候会收的账。

午后回到出租屋。灶台上三只空泡面碗摞着，调料渣干在碗底，他不记得吃过其中任何一碗。翻手机通话记录，凌晨2:17拨出一个号码，时长十一秒，尾号0317。他看了很久，锁了屏。

傍晚，雨又下起来。陈默在老屋门口清理积水，蹲着把渗进楼道的水往外扫。直起身时，看见种子书落在门垫边。他捡起来，就着楼道的感应灯，翻到下午落笔那一页。

页角有一道极淡的压痕，像铅笔描过又被擦掉。他凑近看，半行灰字：“14:07 东门街路口。”

水汽浮在纸面上，字像隔着脏玻璃。他不认识东门街。

隔壁门开了。林兰撑着一把滴水的伞，手里捏着一串钥匙，是昨天落在他爸老屋里的那一串。她身后跟着扎马尾的小女孩，半张脸藏在雨衣里，露出一双眼睛。

“陈默，钥匙串落你家了。”林兰收了伞，“果果，喊陈叔叔。”

“陈叔叔好。”声音含含糊糊的。林兰把伞靠到门槛上滴水，随口说：“明天一早七点，果果要去东门街那边上科创营，她爸顺路送。我还愁这雨，下到半夜估计能停。”

陈默握着种子书，页角那半行灰字正好顶在虎口的位置。他问：“你说明早？”

“嗯，七点。东门街路口。”林兰回头看了一眼自家门，“滨河道那头，有个红绿灯的。”

陈默低头。拇指压在“14:07”那半行字上。页角是下午两点七分，果果是早晨七点。中间隔着一整个白天，还压着他爸备忘录里那个3月17日。

他问：“果果明早要经过那个路口？”

“她爸送到路口，老师在红绿灯底下等，统一带队过去。”林兰弯腰给果果拉了拉雨帽，“怎么了？”

陈默没有答话。林兰便带果果往自家门口走，半个身子探进门里，朝他抬了抬手：“钥匙你先收着，老屋还渗水就言语一声。明天我走得早，有事打我手机。”

门在她身后合上。走廊里安静下来，只剩雨棚上嗒嗒的滴水声。

陈默还站在走廊里，感应灯灭了。他借手机屏幕的微光看掌心里的种子书。半行灰字边缘，隔着一道纸纹的距离，又一道痕迹正在慢慢浮出，发灰，比刚才那一行深。另一道笔画，极淡。他看不出那是什么字。

楼道尽头，老屋的门没关严。门缝里传出一声滴水声。

他把纸箱推到墙边，想起老周昨天在楼道里说过的话：这种催租短信，拖着就好，房东比你还怕房子空着。

一下。又一下。
