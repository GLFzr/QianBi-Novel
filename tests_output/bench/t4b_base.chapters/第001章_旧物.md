# 第1章 旧物

钥匙串上拴着一截灰蓝色尼龙绳，接口磨出毛边。他爸用了七年，人走那天，钥匙还挂在这扇门上。

周六下午两点，城西这条巷子拆了一半，砖墙豁口长出一棵构树。回收旧家电的喇叭隔着一道墙闷闷地响。手机里躺着两条消息：房东周五催租，中介回话，动迁还在观望，先挂出去。房租差一千六，他还没想好去哪凑。

林兰牵着女儿林果果，在楼洞口等他。看见他，她攥钥匙的手慢了半拍。

“你爸过世前说，有个东西要留给你。我照他说的，没碰。”林果果拽她衣角，林兰把后半句咽回去，“等你空了，我再跟你说。”

陈默接过钥匙：“现在说也一样。”

林兰没接话。她弯腰对女儿说了句什么，林果果回头看了他一眼。母女俩走出巷口，裙摆扫起墙根的灰，话也没补齐。

陈默上四楼。锁孔涩，拧两下才开。屋门推开，一股积灰的气味扑出来。凉茶罐还立在桌上，旧报纸摊开在他爸倒下那天的日期上。开窗，窗轴生锈，卡在半截。

清理比预想快。衣物塞进纸箱，木工工具归到墙角。他爸是木匠，刨刀养着油，油味盖过灰。他帮他爸盘了二十年账，水电，木料，工钱，一笔一笔，哪处错了扫一眼就知道。账本和收据分到一堆，留到最后。

床头柜最下层的抽屉几乎清空。手指探到最里侧，碰到一个薄薄的硬物。不是账本的手感。他拉出来，一本约莫二十页的旧笔记，透明书皮泛黄，边缘磨得发白。

翻开封面内页。蓝黑墨水，他爸的笔迹，笔画端正：“种子书，记人未长成的事。”斜角一行小字，笔锋收紧：“不可贪。”

陈默认得这两个字。他爸一把长刨的刨底烫着同一句话，说用工具的手不能贪快。

他翻了几页，空白。靠书脊处留着细窄的撕痕，像有人认真地把什么从纸上扯走，一页一页，只剩毛边。他合上笔记本。页角有一行铅笔字，压痕很深：“案：0317”。他爸写字拖笔，这一行收笔果断得多，是另一只手留下来的。

他爸走了十一天。留下的东西里，账本有，收据有，工具也有。唯独不该多出一本他从未见过的簿册。陈默把笔记塞进背包夹层，拉好拉链。他没有再多翻，再看下去，他得在这屋里多耗一天。后天回公司销假，时间卡得刚好。

背起包，走到门口，停住，又折回窗台。

那盆花他归置时挪过位置。他弯下腰，指头探进花盆底部，碰到一卷纸，裹着塑料膜，泛黄发脆。拆开，是他爸的字迹，完整的只剩两个字：“陈默”。后面的字被水渍泡烂，洇成一团干涸的痕迹。他看了一会儿，重新卷好，装进封口袋，放进背包侧袋，和那本笔记挨在一处。

锁门。锁芯涩，他转了三次才锁严。

楼道里一股防锈漆掺着旧木头的气味。脚步声从楼下蹿上来，一个黄头盔外卖员冲到楼梯口，单手撑墙：“大哥，3门317是哪一户？”

3门317。他在这栋楼住了十几年，头一回听到这个门牌。“这里没有317。”

外卖员愣了一瞬，低头按手机：“订单写的就是3门317。”他跨回电动车，车身歪了一下，车把上的订单被风掀起一角。白色签条上的取件码露了一截，末尾四位清清楚楚：0317。

电动车碾过湿泥冲出巷口，溅起一行泥点。

陈默站在楼道口，手指探进包侧，碰到笔记本翘起的纸角。他掏出来，是写着“案：0317”那一页的角，应该是拉链夹带出来的。他把纸角按平，塞回夹层，拉好拉链。

取件码每天几百个，尾号撞上不稀奇。他告诉自己。

他沿巷子往公交站走。风大，他拉开侧袋找耳机，手指先碰上一块冰凉的硬壳。

那不是他放进去的东西。

摸出来看，一只旧手表。表壳镀层剥落大半，表盘玻璃从角落裂进一条缝，停在数字10和11中间。指针静止，落在二十二点四十七分。他今天没戴表出门，更没往包里放过表。

把表翻过来，用指甲剔掉表背缝隙里的灰。一行歪斜的刻痕像是硬物一下一下凿出来的，积了灰垢，被剔掉之后露全。

0317。

他抬头朝巷尾望。老屋四楼的窗户陷在整排窗格里，一个暗下去的缺口。他记得出来时门锁了三圈，窗是他亲手推到一半的。

掌心里的金属被体温焐出一点潮意。他本该把表放回原处，或留在站台，当它从没出现过。他没有。

公交车的灯光从前一个路口扫过来。他背着表，转身，往巷子深处回去。他走到楼洞口，跺了一脚，声控灯没亮。他又跺了一下，灯闪了闪，灭了。

四楼那扇半开的窗，玻璃忽然反了一下光。像有人从里面，把它又推开了一点。
