# 第14章 叠刻

手机在窗台上趴了一夜，屏幕朝外，录像键亮着。陈默蹲在窗边，膝盖抵住墙根，一整夜没合眼。

那条“看见了吗”之后再无动静，像一块石头扔进井里，连回响都没等来。

窗帘敞着。白色轿车停在楼下，车灯全熄，夜露沿机盖缝一路湿到雨刷根部。屏幕里的车身轮廓纹丝不动，他盯着看了很久，久到眼睛发涩。手机屏幕亮着，录到的只是一段静止画面：路灯底下，一段黑车壳，一枚右前灯上带擦痕的弧面。凌晨起了点风，卷着一片塑料购物袋贴地滚过，停在车头灯前。车没动。

大约过了小半刻，右转灯闪了两下，橙黄色光在雾里晕开一团。

车头摆正，倒出车位，右转驶出巷口。车身经过路灯下那一瞬，他看清车牌尾号：317。尾灯在路口停了片刻，像是等人的停顿，然后灭了，往东门街方向去。

他下楼。停车位的积水里躺着一枚旧表。表带蜷着，表盘玻璃有一道斜裂纹，指针停在21:03。

不是22:47。

积水有一指半深，表搁在水边干燥的那块砖上，表带尾端朝巷口方向，顺着他离开的方向。

他用纸巾把表包起来，放进塑封袋，又对着手机相册里那张老屋窗台的照片看了两遍。同一只型号，表把的磨损位置一致，表带的皮纹也是同一路的折痕。相册里那枚停在几点，照片太糊，看不出。

晨雾里，修车摊的铁皮柜泛着潮气，油布下拖出一缕机油味。街口还没什么人声，只有一只野猫蹲在矮墙头，看他俯身掀油布。

陈默蹲下去，先掀开油布一角。指尖触到一根不该在那里的刹车线，新的，表面油亮，槽口上有一道竖刮痕。线身缠着一圈白胶带，胶带上面没有任何字。他把昨晚装好的线、换下的旧断线跟这根新线并排摆在油布边，三根线，刮痕一共三处。旧断线锈蚀段上的磨痕是横的，昨夜槽内壁那道也是横的，都不及这根新线上那道竖痕来得亮。那痕像是刚从什么金属上咬下来的。

程师傅支好摊，把水壶搁到铁皮柜顶，看见油布动过，没多问。他蹲下来理工具的时候，目光在那根新线上落了一瞬，才说：“那是周记留的。取完线，留一根在油布下，放三天。三天没取走，就是不想装，我收掉。”

“取线的人不留话？”

“留话干什么。留一根线，比话实在。三天是规矩，也是期限。他第四天来取，拿回去还是一样用，但规矩就是三天。”

陈默的指尖停在竖刮痕上，指头沿着那道痕慢慢滑到底：“我爸当年。”

程师傅弯腰拎起水壶，没看他：“你爸当年，也留过一根。第三天来取的。那天收摊前我把油布盖好，先没等他，走了一段又折回去，他蹲在摊边，线在手里，没走。”

“那天路口少了一个人？”

“我没这么说。”程师傅灌了口水，“你自己核线，核完自己知道。”

机油锈味沉在潮湿的空气里。陈默把三根线收拢，新线放回油布下，没取。

午间雾散了些，东门街的地砖缝里还渗着湿气。环卫师傅蹲在清扫车旁啃馒头，蓝色工装的袖口露出一截旧疤。陈默递了根烟过去，他没接，但把塑料皮记录本从车斗里抽出来，搁在膝盖上翻开。

“路口那根横杆，装过几回？”

“你是修车的还是派出所的？”环卫师傅抬眼扫他，又低了头，指尖抹过发皱的纸面，“横杆更换记录，3月17日。装杆人……”

他顿住。

陈默没有催。

“这字，跟你手上一路。”环卫师傅把本子歪过来，让他看签名栏。栏里三个字，蓝黑墨水，顺锋起笔，笔压偏深。和种子书上的字迹一个写法。陈默的字。

环卫师傅又看他一眼，这回看的是他的手。“你们年轻人，装完也不留个电话。人倒是记得，个子高，穿件蓝黑工装，装完蹲路边抽了一根烟，没说话就走了。那天风大，烟灰刮了我一车斗。”

陈默把本子还回去。手指在口袋里捏着那枚铜纽扣，没有拿出来。

傍晚天光发灰，林兰来还钥匙，钥匙挂在食指上，在门框边晃了一下。她今天没进门，站在门口，把手机屏幕递过来。

“林果果翻旧电话本，翻到一行铅笔字，爸的笔迹。拍了照发我。”

照片里一行细铅笔字：周记，3月17日，21:03，南岸货场。

“这页是从本子后半本撕下来的，页边不齐整。”林兰说，“林果果说夹在两张空白页中间，她说像张记号页。”

“她自己翻到的？”

“她把本子摊在茶几上翻的，翻到那页就不肯动了。后来还是我拍的照。”林兰退了半步，“钥匙放鞋柜上，走了。”

门带上后，陈默没有立刻去看钥匙。他把旧表从塑封袋里取出来，表盘21:03，和照片里那行字并排摆在桌沿。又翻出父亲备忘录，那一页只有一处记录：3月17日22:47，去东门街路口。

没有21:03。备忘录里没有货场二字。备注里“0317，他生日”那一条也停在屏幕顶部，没有第三行。

陈默把表翻过来。背面一道刻痕嵌在旧划痕里：0321。不是0317。

表盘21:03，刻痕0321，南岸货场。三样东西，第一次叠在同一件物件上。他把表放回塑封袋时，指尖触到背面那条划痕的底部，沟底有毛刺，是新刻的边。

夜里风停了。白色轿车又停在原位，右前灯上那道擦痕正对着他的窗。车熄着火，窗全黑，从没挪过地方。

手机亮了一下，父亲旧号码发来第二条短信。一个坐标：北纬31.17，东经121.47。

他摊开地图，指尖顺着经纬线滑过去，落在东门街路口偏南约三百米。那里有一块空地，杂木围栏，荒了很久，地图上连个名字都没标。

三秒后，同号码又进来一条：“明天21:03，南岸货场，你会来。”

陈默盯着你会来三个字，没有回。他把手机扣在窗台，蹲下身，把旧表从塑封袋里取出来，对着窗外反光看表背。刻痕沟底是白茬，新刻的。0321压在0317上面，第二遍，笔力比旧的那遍深，下刀的角度也更垂直，像有人用了更大的力。
