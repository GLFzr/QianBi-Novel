# 第8章 锉刀

程师傅的目光还停在陈默左手小鱼际那道墨痕上，锉刀别回口袋，补了一句：“你还没答我，你欠谁。”

陈默蹲在棚布边缘，手还搭在刹车线上：“欠我爸。”

程师傅没接话，低头继续锉了两下，又停住：“这行字，我认了十几年了。”他指指工具箱底压着的半张旧收据，收据背面露出一角数字，被油渍浸得发黄，但笔画还算清楚：0317。陈默的指尖在刹车线上停住，没动。程师傅也不看他，声音像在自言自语：“当年一个穿蓝黑工装的人来修车，落下的。之后再没来过。”

陈默问：“那人什么样？”

程师傅把锉刀搁在膝盖上，想了想：“三十多岁，不爱说话，修车的时候盯着我的手看。”他抬眼，“你是来还账的，还是收账的？”

陈默没答上来。程师傅没追问，只把自己那条刹车线往他手里一推：“你手上既然有活，就帮我看看这条线。”陈默低头，那条线已经锈出白茬，捏一下就有铁屑掉下来。他指指工具箱：“松紧还能调。”程师傅说：“那就调。”

陈默调到一半，收据背面那串数字始终在视野边缘晃。他停下手：“这串数，你记了十几年？”

程师傅从工具箱里摸出一截旧线头，也是锈的：“记它干什么，认得就行。后来我还想过，那人是不是出事了，不然怎么修完车连收据都不要。”他把旧线头扔回箱底，“再后来就不想了。”

陈默把刹车线调好，缠回原位，又检查了一遍卡扣。他站起来时膝盖蹲得发麻，棚布外太阳已经偏西，把摊子前半片地砖晒得白亮。程师傅没起身，坐在矮凳上看着他，“你调得比我想象的细。”陈默说：“做过财务，手细。”他转身要走，程师傅在背后又问了一句：“你爸那件工装，是什么颜色的蓝？”陈默顿住，回头：“我没见过他穿工装的样子。”程师傅点了点头，没再说话。

下午三点，陈默从修车摊出来，退到马路对面公交站蹲守。他给周航拨了电话，响了四声接起，周航那边报站声混着风：“程师傅？他从不欠别人的账。他那摊子，你给多了他还会追出来找钱。”

陈默挂了电话，翻开种子书。页角那行预告还在，字迹是他自己的，笔画却虚着，墨色浅一层，像铅笔画上去还没压实。虚线。他盯着那行字看了很久，把笔帽拧开又拧上，没有落笔。他以为不写，就不会应验。

站台的铁皮被太阳晒了一下午，坐上去发烫。他没有挪开，一直坐着，看修车摊的方向。程师傅蹲在棚布下，把那辆旧电动车又推出来，左手拿布擦车架，右手还是垂着。日光从棚布缝隙漏下来，在他肩上切成几道细条。六点的晚高峰过去，天色暗下来，路灯亮了一排。陈默把种子书合上，放回外套内袋，没有走。

二十点四十七分。一辆送水自行车从支路坡道冲下来，车速很快，车后架的水桶哐哐地撞在挡泥板上。快到修车摊门口时，刹车线“嘣”一声崩断，金属丝弹开，车把猛地脱出，直直钩住程师傅左脚踝，把他整个人带倒在地。水桶滚出去，砸在路沿上，盖子飞了，水淌了一地。程师傅侧躺着，一条腿压在车架下，没出声。

陈默冲过去，半跪着把车架抬开，手背被车架边缘刮了一下，蹭出一道白印。程师傅的左踝外侧擦破一层皮，血珠渗出来，淤青在皮下慢慢鼓起来，颜色发紫。他动了动脚趾，说：“骨头没事。”陈默把断线捡起来看，断口锈成褐色，掰一下就能碎。不是他白天调过的那条。他捏着那根锈线，指腹被铁屑扎了一下，没有出血。他想起白天在工具箱底看见那截旧线头，一样的锈色。

陈默扶他在摊边坐好，回到站台翻开种子书。页角那行预告的虚线已经变成实线，墨色沉进纸纹里，像落笔很久的旧字。墨线从预告末尾延伸出去，一路画到页脚，停在“案：0319”和“案：0317”之间。他左手小鱼际的墨痕颜色转深，从深蓝变成墨黑，摸上去有一点凸起，像纸页上那行墨线一样，长进了皮肤里。

他翻过页角，指头碰到一张纸片。不是他放进去的。半张收据残角，纸质和他白天在工具箱底看到的那张一模一样，但更旧，边角卷起。背面有一行字，笔迹陌生，笔画细瘦，像用圆珠笔写的：“他会管不过来。”

路灯下，程师傅坐在摊边，捡起那条崩断的刹车线，凑到光里看。他对着断口看了一会儿，翻过线头，又看了一遍，声音被晚风送过来：“0317啊。我认这串数，认了十几年了。”

他抬眼，目光平直地望向陈默：“你爸以前，也穿一件蓝黑工装。”

陈默握着那半张收据残角的手指收紧了。纸角边缘的卷边在他掌心里硌出一道印。他张了张嘴，嗓子干涩，没能立刻接上话。夜风从公交站方向吹过来，带起修车摊边那摊未干的水渍上一圈细微的波纹。程师傅低头，把断线缠了一圈收进口袋，像收一件认了很久的东西。他起身时左脚踝吃了一下力，没出声，撑着车架站着。那两圈旧绷带仍然裹在左臂上，在路灯下发暗。
