# 第21章 空柜

凌晨五点四十分，殡仪馆东门铁门虚掩，路灯还亮着一半。他握手机数秒，屏幕停在阿莲那句“明天早上六点，殡仪馆东门，别带别人”上，没有回消息。他把手机揣回口袋，抬眼看了一圈东门。门缝里透出一线白的光，是走廊灯没关，照在水泥地上，像一条细长的裂缝。他站在门边没进去，等。风从门缝里挤出来，带出一股消毒水的味道，底下压着很淡的铁锈味。他闻了一会儿，把这两种味道记下来，没有动。

六点过七分，阿莲没有出现。

他拨了电话，响到第七声转短信。他没有等短信进来，直接推门进楼。值班室灯关着，桌面水杯的水还温着，人刚走不久。杯沿搭着一只笔，笔帽没盖，笔尖朝外，像是写了一半放下。他伸手碰了一下杯身，温度隔着瓷壁透出来。他又看了一眼桌面，键盘上压着一张便签，空白，没有字。他沿着走廊往暂存间方向走，拐过转角时听见一声闷的金属卡碰声，像两扇铁门撞在一起又卡住，声音在瓷砖墙里撞了一下，很快消失。

他等了两秒，没有第二声。他加快脚步。

推开暂存间虚掩的门，冷气扑面，混着一股消毒水的气味，底下压着一点铁锈味。阿莲半个右臂和半边肩被夹在两扇半开的冰柜门缝里，手背青紫，指甲发绀，嘴唇因为咬牙压成一条线。她背对门，整个人半跪着，右臂卡在门轴那头，左手指尖抠着柜门边沿，指节白得发灰。警铃没响，整个暂存间静得只剩灯管的电流声呲呲作响。排在两侧的冰柜门排着整齐的队伍，只有她卡住的那一扇开了一条斜缝，像一排牙齿里缺了一颗。

陈默两步上去，扳住门扇往外拉。门轴锈得涩，第一下没拉动，他换了个角度，右脚蹬住柜底，把整扇门往外掰。金属摩擦声撕开寂静，门缝松出一指宽，阿莲的右臂从里面滑出来，她整个人顺着柜门滑坐到地上，肩膀撞在门框上，发出一声闷响。

她靠着柜门坐了很久，才开口。声音哑得像嗓子眼里堵了什么：“门自己关的。”

陈默蹲下，看她前臂。衣袖压出一圈深痕，皮肤底下的血管泛着暗色，指甲根发紫。他想伸手按她虎口判断有没有骨折，她先一步把手抽回去，问了一句：“柜里的人呢。”

陈默没应她，视线越过她肩头，落在卡住她的那扇柜门上。编号04-11。门半开着，柜内空着，底板上叠着一件折好的蓝黑工装，前襟口袋鼓着一角。他先看了一圈柜门内侧，锁舌没有变形，门缝干净，找不到撬痕。门是自己开的，或者是被人从外面开的，没有硬来的痕迹。

他没有先动工装，用左手撑住柜门让她能看清里面：“这柜本来就空的？”

阿莲盯着空柜看了一会儿，摇头：“这柜有人。昨天我亲手推进去的，早上还在。”

“你确认是这柜？”

“我推了一晚上柜子，不会认错。”她声音里的气力回来了一点，带着一种被压平的火气，“04-11，我记得。这柜里停的是一具车祸的女体，早上我还要给她做修复，人没了，我能不知道？”

陈默弯腰，从工装口袋抽出那张叠了两折的纸。纸面泛黄，折痕压得深，他展开，第一行墨字是他自己的笔迹，收势却不像他写出来的。一行是：“22:45:03—22:45:45，删除签名：周。”另一行是铅笔字，笔迹陌生：“柜已经空了，账还给你。”

他盯着账还给你四个字，手指在纸边停了一下。第二行铅笔字的笔锋他没见过，但那个账字的收尾和货场办公室里账会分家的账是同一个弧度。写这行字的人和写账会分家的人，是同一个。他没说这个判断，把纸折好，抬眼。

阿莲还看着柜内，嘴唇动了动，想说什么又咽回去。她抬起没受伤的左手，指了指柜底板边缘：“这柜子是昨天我擦过的，不会认错。”

陈默顺着她的手指看去。柜底板边缘有一道细痕，是被什么东西反复摩擦过的痕迹，颜色比周围的金属浅。他蹲下来，用指尖沿那道痕摸了一下，很浅，但方向是横的，和他在刹车线槽口见过的刮痕同一个走向。

“工装不是我放的。”阿莲的声音从背后传来，“我推柜子的时候，里面只有遗体。”

陈默把工装连同叠纸一起收进塑封袋，拉上封口。手指在袋面上按了一下，确认封口封死，才站起来，扶着阿莲往外走。她前臂疼得吸气，但脚能走，靠着自己往门口挪了两步。走到门口，她停了一下，回头看那扇空柜：“这柜里的人要是被运走了，转运单上应该有记录。”

手机在裤兜震了一下。他单手撑开屏幕，内部转运系统的条目弹出来：“03-17，06:05，已由家属领取。”

他停住，把屏幕转向阿莲。她看完，半晌才说：“这个点没有人进过楼。”她顿了顿，补了一句，“这个早晨，一个人都没有。”

陈默把手机收回去，锁屏。他没有说03-17和04-11是两个柜号，他重新看了一眼那张叠纸上的时间戳，22:45:03到22:45:45，四十二秒。这个时间，和昨天阿莲说的一模一样。他扶着阿莲走出暂存间，走廊灯在头顶亮着，脚步声在瓷砖墙上叠成两层，一路跟着他们走到监控室门前。

阿莲靠在门边按住前臂伤口，陈默握住钥匙，插进锁孔。他没有转。走廊的风从暂存间方向灌过来，吹得门把手上的金属反了一下光。陈默低头，看见自己手背沾着阿莲的血印，一道斜的，干了一半。他把手背在裤腿上蹭了一下，血印没掉干净，留下一道浅红。

他转开锁孔推门进去。监控屏幕亮着，画面停在暂存间4排柜的全景，时间戳00:00。他正要调回放，屏幕右下角弹出一条内部消息，发送时间06:03，备注栏写着家属，消息内容只有三个字：“他来了。”

身后阿莲的血印在把手上凝成一小圈，门在走廊风里慢慢合上。
