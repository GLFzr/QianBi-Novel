# 第4章 空档期

他把种子书放进背包夹层，去物流网点办入职。网点墙上的片区配送图贴着东门街口的一段，红笔打了三个叉，叉叠着叉，像被人反复确认过。他随口问了一句。老调度抬眼看看图，又看看他：“最容易出事的弯口，连续两年有配送员在那儿出过事，上个月才撞了一个。”他顿了顿，补了一句，“明天有趟去东门街的件，要有人去踩点，你可以跟。”

陈默走出网点，手机弹出租房催缴短信。他站在台阶上把短信看完，锁屏。街上风大，卷着梧桐毛絮往领口里钻。他告诉自己，去东门街吃碗面，就回。

共享单车停在修鞋摊旁边。东门街路口比他想象中宽，路面正中有一条新补的白漆裂缝，裂缝尽头是刚立起来的公交站牌。车流从滨河道拐过来时有个盲区，转弯灯和直行灯差了三秒，直行车刚起步，转弯车已经压到斑马线边缘。他在修鞋摊的矮凳上坐了一个小时，看信号灯走完四轮，把每一轮的时长记进手机备忘录。摊主姓周，一边敲鞋掌一边说：“这路口的孩子过马路都蹦着来。”陈默问他什么意思。老周指指对面社区学校的铁门：“放学那阵，你等着看。”

电话响起来，是林兰。她说果果的科创营调了时间，挪到下午一点半上课，早上不用送了。陈默嗯了一声，正要挂，林兰又说：“你昨天怎么还拿着那本子？”她顿了顿，“我爸以前也总翻一本旧本子，天天翻，后来他走了。”陈默握住手机，过了两秒才问：“他什么时候走的？”林兰说：“忘了，都是老早的事了。”电话挂断后他站在修鞋摊旁边没动，手机屏还亮着，通话时长停在两分十七秒。他想起自己昨天手里那本种子书，林兰看见的不止是它被拿着的动作。

下午四点十七分，社区学校铁门打开。陈默站在修鞋摊旁边的树影里，看见林果果背着书包出来，左手腕上一根褪色的红绳，在路口等灯时蹲下来系鞋带。她蹲了十二秒，起身时绿灯已经闪了两下。她蹦着跑了两步，保安从门卫室探出头喊了一嗓子，她才站住退回斑马线。陈默掏出手机按了计时器，又锁屏。屏幕灭掉之前他看了时间，四点十七分，正是页痕上那个数字的钟点。他没继续想下去。他蹲在树影里又等了十分钟，直到林果果的背影拐进东门街尽头的巷口，才起身把共享单车解锁。

黄昏他在便利店落地窗前坐下，要了一碗关东煮，把手机里页痕的照片放大。下午看过的画面和照片叠在一起。页面下方那行“14:07 东门街路口”正在变，压痕淡下去，新的墨迹从旧痕里浮出来，只有四个字和一组数字：停留：138秒。没有名字。他盯着那组数字，脑子里一遍遍回放下午林果果蹲下系鞋带的样子。她蹲了十二秒。本子写的是另一个数字。他关掉照片，又打开，关掉，又打开。竹签戳着碗里的鱼丸，凉了半碗他才吃完。店里收银台的收音机报着晚间新闻，东门街人行道检修的预告飘过一半，被他一个字不落地听完。

他回到出租屋已经是晚上。给林兰的对话框里打了一行字：“明天果果有人送吗？”删掉。又打：“东门街口这两天在修路，让果果走大路。”又删掉。最后发了一句：“果果明天几点放学？”

林兰秒回：“你关心她干嘛？”

他锁屏。手机在桌面上震了一下，本地新闻推送：东门街路口近日将进行人行道检修，临时调整信号灯配时。配图里一辆白色轿车正驶过路口，车头朝着社区学校的方向。他盯着那张图看了很久，想起页痕上那组数字。138秒。他没算过从蹲下到起身是十二秒，但本子写的是另一个数字。它知道的比他多。他把新闻截图存进相册，往回翻，和下午拍的页痕照片放在同一张屏幕里，看了很久。

他正要把手机放下，屏幕又亮起来。林兰发来一张照片。老屋墙角那张木头书桌，桌面堆着旧报纸，桌角刻着一串被磨过的数字，笔画歪斜，但他认得出来：0317。下面跟着一行字：“你是不是也在查这本？”
