# 第5章 138秒

凌晨三点，台灯还亮着。陈默坐在老屋床沿，种子书翻开在膝盖上，页面上那行字已经看了不下一百遍：停留：138秒。纸页边缘被他捏得发软，他合上书压到枕头底下，躺下去，又坐起来抽出来。压痕没有变化，四组数字安静地嵌在纸纹里。他盯着看了很久，终于相信今晚它不会再变了，才把书合上放在枕边。窗外的风刮了一下又停，他数着自己的呼吸，等着天亮。

三点四十七分。他刚有点睡意，眼角余光扫到页面边缘多出一点墨色。他猛地坐起身，翻开书，那行“停留：138秒”下面多了一行小字，笔迹更像父亲书桌上那支钢笔压出来的：“明 07:12 停留处有车刹不住。”他没有写这行字，页面自己添了墨。他翻到封面内页，又翻到页角，编号还是“案：0317”，没有新增。他关掉台灯，又打开，那行字还在。他抬手摸了一下字迹的墨，指腹上没有沾染，字是干的，像早就在那里，只是他刚才没看见。

他翻出父亲贴在种子书内衬的批注纸。那张纸薄得透光，对折过一次，正面是“不可贪”三个字。他抽出铅笔，轻轻拓着纸背的笔压。纸纹深处透出一行更浅的字，笔画断续，像写完后又被人拿橡皮擦过：“改写是替人挡，不是替天改。”他盯着这行字，呼吸慢下来。父亲写这行字的时候知道什么。他替谁挡过，又为什么停下来。铅笔尖在纸面上悬着，他把它放回笔筒，把批注纸小心地夹回内衬。纸角压着另一个更小的折痕，他掰开看了一眼，是空白的，什么也没有。他把纸翻回正面，“不可贪”三个字在灯下显得比白天更深，像有人用指腹反复摩挲过。

凌晨四点二十六分，他拨出林兰的电话。听筒里传来机械女声：您拨打的用户已关机。他又拨了一遍，还是关机。他看了一眼时间，离七点十二分不到三个小时。他放下手机，在黑暗里坐了一会儿。窗外路灯的光斜斜切在床单上，他把手机屏幕按亮又按灭，按灭又按亮。然后他翻回种子书写有格式的那一页，重新读了一遍父亲留下的记录。第一次改写周航时他几乎没多想，只写了动作。这一次他看明白了：写下的每一个字都会从自己身上抽走一些东西。太便宜了。

四点五十分。他把笔帽拧开，又拧上，重复了三次。窗外的天色开始泛灰，老屋楼下的路灯还没灭。他把种子书翻到新的一页，蓝黑墨水笔尖抵住空白页，停了很久，笔尖的墨在纸面上晕出一个小点。他想起林果果蹲在路口系鞋带的侧影，那根褪色的红绳，她起身时绿灯已经闪了两下。他还想起林兰还伞那天说的那句话：“果果明早七点要去东门街那边上科创营。”七点。页痕写的是七点十二分。十二分钟的差，就是那秒钟的容错。

五点十二分。他落笔。

“林果果，07:12，东门街路口，因鞋带散开蹲下系鞋带，停滞至绿灯转红后第3秒才起身。”

合上本子的瞬间，太阳穴一抽。有什么东西从后脑勺被抽走，像一根线被拽着往外拉。眼前黑了一瞬，他扶住床头柜，指尖碰到台灯底座，灯罩晃了一下。耳边嗡鸣持续了三四秒，他数着，等它过去。他低头，左手小鱼际上多出一道墨痕，钢笔划过的形状从皮肤底下渗上来。墨痕颜色很深，边缘不齐。

他坐在床沿，没敢翻开本子确认。他试着回想昨天午饭吃了什么，脑子里只有一片雾，昨天傍晚那一段也模糊了，像隔着水看路灯。他握了握拳头，又松开，那道墨痕留在掌心，不褪色。他又试着回忆昨天傍晚自己去了哪里，只能捞起几个零碎的片段：便利店，关东煮，玻璃窗上的雨痕。中间那一小时从时间轴上消失了，只剩下两端的接缝。

五点四十。他拿起手机，相册里多了一张照片：老屋窗台，旧手表，表盘朝上，指针还是22点47分。他不记得什么时候拍的。通话记录里有一通打给父亲旧号码的已拨电话，时间显示昨晚，时长42秒。他不记得自己打过。他盯着那串号码看了很久，想起父亲录音里那句没说完的话。账由谁收。他按了一下播放键，听筒里只有忙音。他又拨了一次，这次连忙音都没有，电话直接断了。

他的目光落回种子书页角。新落笔的那页下方，无声无息地浮出一行小字：0319。笔墨很新，笔画笔直，像刚写上去又被压过。他记得父亲页角的“案：0317”，这行数字跟它隔着一个编号的距离。0317，0319。中间那一个编号去哪儿了。他正想再翻，门外楼道传来脚步声。一步，两步，在他门口停住，没走。

他等了几秒。脚步声没离开，也没敲门。台灯的光罩着书页，左手墨痕还湿着。他把种子书合上，压进枕头底下，又停住动作。那行字他已经记住了，不用再翻。门缝底下透进来一小块影子，有人站在外面。门外传来一个压低的女声：“陈默，我知道你醒着。”
