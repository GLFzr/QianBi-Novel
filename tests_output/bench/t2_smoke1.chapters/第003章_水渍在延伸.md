# 第3章 水渍在延伸

手机闹钟响的时候，窗外雨刚停。陈默睁眼，先看见床头柜上那张摊平的外卖单底联，单号区印着0317。他盯着那四个数字看了几秒，不记得自己昨晚什么时候把它从包里翻出来放平的。枕边手机压着一条语音留言，林兰的声音带着楼道里的空旷回音：“一楼走廊渗水了，从你家厨房墙根往下淌，你抽空回来看下。”

他骑到老屋时雨又开始下。一楼走廊的墙根湿了一片，水痕一路延伸到楼梯口。他开门进屋，厨房台面上那摞没洗的碗还摆在原处，水渍沿着台边往下滴。水龙头是关紧的，水是从台面缝隙里渗出来的。他拧紧总阀，把那摞碗洗了，洗到第三个时指腹摸到碗沿一道干裂的米粒，硬得硌手。水声停下的一瞬间，他忽然意识到一件事：他不记得昨天午饭吃过什么。那种空是一整块缺，边缘整齐，中间什么也没有，连一点菜叶、一点米粒的气味都留不下。

他翻包找物业缴费单，指头在笔袋底部碰到一张对折的便签。展开，上面是自己的笔迹：“3月17日必须联系小周。”纸角有一个湿掉又干透的圆弧印，放过水杯的痕迹。他盯着这行字看了很久，手指发凉。他不记得写过它，不记得小周是谁，也不记得3月17日要联系这个人做什么。他把便签对折，塞进胸口口袋，指腹在纸面上按了一下，隔着衣料能摸到那道折痕。

他下楼时，楼道里那股湿泥味混着雨气扑面而来。楼道口站着个穿黄色工服的外卖员，正从车筐里拎泡沫箱，准备踩上那级湿台阶。陈默认出那张脸，昨天误闯进来问他“3门317”的那个年轻人。雨后台阶泛着水光，地砖松动，缝里积着水，踩上去鞋底必然打滑。陈默在楼梯拐角站定，叫住他：“你叫什么名字？”外卖员抬头，头盔带子勒在下巴上，露出一张晒得发红的圆脸：“周航。昨儿那单尾号0317的，是我送的。”

陈默退到楼道阴影里，翻开种子书。蓝黑笔尖抵在空白页上，停了三四秒。他看了一眼周航的背影，又看了一眼那级台阶上积水的裂砖。他写下：周航，3月11日9时52分，滨河道12号一楼台阶，右手握紧扶手，停住半步。落墨时没有任何异样，纸面安静得像一本普通笔记本。笔尖离开时在末笔拖出一道极细的尾巴，他合上书，心跳撞着肋骨，一下比一下重。

十五秒后楼道口传来闷响。周航半跪在台阶上，右手死死握着扶手栏杆，指节发白。他没摔。泡沫箱从车筐甩出去，倒扣在台阶边，汤水从箱沿溢出来，顺着地砖缝流成一道细线，不偏不倚接在昨日那滩旧水渍的延长线上，停住。周航爬起来拍拍膝盖，弯腰捡箱子，扭头冲他笑了笑：“这台阶真滑，得找物业修修。”陈默站在原地，手里的种子书不烫、不响。但周航确实没摔。

午后他回出租屋，灶台上摞着三个空泡面碗，碗底还残留着冷掉的油花。他不记得自己吃过其中任何一碗。他翻手机找昨晚的通话记录，屏幕显示凌晨2点17分拨出过一个号码，通话时长11秒，尾号0317。他盯着那串尾号看了很久，锁了屏，又打开，再锁上。

傍晚雨又下起来。他站在老屋门口翻种子书，走廊白炽灯下，页角压出一道极淡的痕，铅笔描过又被擦掉的痕迹，只留下半行字：14:07 东门街路口。纸是凉的，字已经干透。他不认识东门街，那个地名在他脑子里没有任何坐标。

隔壁门开了。林兰撑着一把滴水的伞出来，手里握着钥匙串，身后跟着扎马尾的林果果。她把钥匙递过来：“落在我这儿的。”又补了一句，“果果明早七点要去东门街那边上科创营，本来还愁下雨怎么送。”

陈默低头看纸面，那半行压痕在灯下发灰。他问：“你说哪里？”

林兰收伞，甩了甩水：“东门街路口呀，滨河道那头，有个红绿灯的。”

“果果几点到路口？”

“七点，她爸顺路送。”

陈默又低头。页角写的是14:07，下午两点七分。林兰说的七点，是早上七点，中间隔着六个多小时。他问：“她平时也走那边吗？”

林兰奇怪地看他：“今天不去，明早才去。”她说完牵过林果果转身回屋，门在身后合上，锁舌咔嗒一声。

陈默站在走廊里，雨水从伞尖滴下来，落在他脚前那块地砖上。手电筒的白光压在页角上。那半行字的下面，隔着一道纸纹的距离，正慢慢浮出极淡的第二笔。他看不清那是什么字，笔画是竖的，又像是撇。他凑近了看，纸面却只剩灯光。

身后老屋的门没关严，厨房里传来水龙头没关紧的滴水声。一下，又一下。他回头看了一眼。那声音停在门缝里，没停。他又把目光落回页角。灯下那极淡的第二笔，似乎又往下走了一小段。
