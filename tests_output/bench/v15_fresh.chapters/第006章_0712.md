# 第6章 07:12

陈默是被后脑的钝痛弄醒的。

老屋沙发窄，他睡姿歪着，脖子一道硬筋。睁眼先看窗，天还灰着，手机压在胸口。时间五点四十。

他划开屏幕，一条拨出记录顶在最上面。昨晚十八点四十二分，打给爸（老宅），通话时长四十二秒。他点进详情，又退出来，重新看了一遍号码。

他不记得拨过。

相册往下一拉，多出一张照片，拍摄时间也是昨晚。拍的是老屋窗台，木头台面上一小片灰，窗框的漆起了皮。照片正中压着一只手表，深色表带，停在某个角度。他抬头看窗台。台面上那一片灰还在，表没了。

十八点到十九点。那一个小时是空的。他试着想自己昨晚吃了什么。掀开那一格，底下什么都没有。

他从沙发上起来，洗了把冷水脸。拧毛巾时手停在池沿。他决定先去东门街。七点十二分之前。

六点五十，他把车停在修鞋摊西侧。

早高峰的东门街比昨天更挤，公交一辆接一辆靠站，车门开合带出一股尾气。他站在昨天蹲过的同一块地砖上，抬头看灯。绿灯亮了一阵，转红。他数了一遍，绿灯约三十八秒，红灯约五十二秒。

西北角空着。

他摸出手机看了一下时间，又塞回去。风把梧桐断口那股青浆味吹过来，混着早点摊的油。一个穿校服的小学生从他身边跑过，书包拍着后背。

七点十一。

林果果从西北角拐出来。

粉色书包，灰白校服，左手腕那圈褪色红绳还在。身边没有大人。她走到斑马线前，等灯，两脚并着，双手扣在书包带上。

陈默的目光落到她脚上。鞋带系得很紧，两个结打得规整。

他呼吸停了一拍。他写的是鞋带松开。可她站得直直的，鞋带没有松。

绿灯还没亮。他往前迈了半步，右脚已经出了人行道边线。他张了张嘴。

灯变了。绿灯。

林果果起步，脚跟抬起，走了两步。

左脚鞋带突然散开，带子拖到地面。她低头看了一眼，蹲下去，把带子从鞋面上绕回来，两根交叉，打结。她打了一遍，觉得松，拆开重打。旁边一个低年级的小学生越过她，先跑了。

她起身的时候，信号灯刚跳到红。

同一秒，东侧直行道上一辆白色轿车驶进路口。刹车灯亮了一下，又灭。车头往右偏了半米，没刹住，顶着护栏滑过来。

金属摩擦的声音压过整条街的喧闹。

护栏被撞弯了一段，齿状的断口翘起来。车头抵着弯折处停下，引擎盖弹起一道缝。变形那段护栏的位置，正对着林果果刚刚站过的路肩，不到半米。

碎砾溅开，有几颗弹到人行道上。

林果果往后退了两步，低头看自己的裤脚。灰白校服裤上蹭了一道灰痕。她抬手拍了两下，没拍干净，也就不拍了。她抬头朝路口看了一眼，脸上没什么表情，像刚被一阵风刮到。

旁边一个中年女人喊了声“哎哟”。司机趴在方向盘上，没动。有人掏手机拍照了。

林果果绕过事故那一段，跟着前头的学生往学校方向走了。书包一颠一颠的。她走到拐角，回头看了这边一眼，又转回去。

她不知道自己刚站过的位置，被一辆车撞变了形。她大概只记得自己系了两次鞋带。

陈默站在马路对岸。他把外套拉链一直拉到下巴，手指是湿的。他往后退了一步，坐倒在修鞋摊那张小马扎上。老周没抬头，手里的麻线照样拉紧，往鞋帮上又走了一针。

“今早这口子又咬人了。”老周说。

“嗯。”陈默应了一声。

十一点四十，他回到老屋。

门没关严，走廊拐角那滴滴答答的水声还在。他进屋，把种子书从内袋掏出来，搁到桌上，翻到页角那页。

回读的墨痕在纸角靠里的位置叠出来。他昨天看的那几行还在。停留：138秒。再往下，多出一行他没写过的小字。

字比前几行浅，笔道细。

多次改写致第二人擦伤。路人，男性，左臂轻微剐蹭。

他合上书，再翻开。那行字还在。

他回想刚才的白车。车头顶着护栏的时候，右前灯下面有一道擦痕，灰白，斜着划过去，边缘带着毛刺，像刚蹭到什么东西。可他看过去时，车已经停在护栏跟前了。

第二个人是谁。在哪蹭的。什么时候。

他试着往回想。昨天下午、昨晚、今早，每一段都记得。他找不到第二个人。

最后一格，昨晚十八点到十九点，还是空的。

陈默把书合上，塞进外套内袋，贴到胸口。他站起来，走了两步，又坐回椅子上。他把手机掏出来，翻到那条通话记录。

昨十八点四十二分，打给爸（老宅），时长四十二秒。

屏幕下方挂着一个录音图标，红色小圆点，下面四个字：未播放。

他拇指移过去，悬在播放键上方，停住。

窗外的水管还在滴。屋里有股昨天渗水没散尽的潮味。他想起页痕里那句话，那辆车在他看见它之前，已经蹭过别的什么。

他把手机翻过来，扣在桌面上。过了几秒，又翻回来。

屏幕亮着，录音图标上那个红点还在。他按下了播放键。

前几秒是电流杂音，沙沙的，像隔着什么东西。然后是他自己的声音，压得很低，讲得很快。

“爸，距离0317还剩十三天。”

停顿了一拍。杂音里混着一个男人的动静，像咳嗽，又像椅子在地板上拖了一下。

“林果果的事，是我写的。”

他自己那头顿了顿。

“这是第一笔没跟你说的账。如果这就是你说的代价，那我已经付了。”

杂音里那个男人回了一句。话头刚起，录音断了。

四十二秒。结束。

陈默举着手机。屏幕显示录音已播完，进度条停在末尾。他把进度条往回拖，拖到杂音那一段，反复听了三遍。

那个男人的声线，不像自动语音的合成音，也不像彩铃。是个活人的嗓子。

他把手机放在桌上，拇指还压在屏幕边上。窗外的水声又响了一下。
