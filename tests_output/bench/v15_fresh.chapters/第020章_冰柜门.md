# 第20章 冰柜门

小孙举着手机的手没放下来。

“三年前三月十七号，凌晨两点四十七分。”

陈默的铝拐杖从墙边滑倒，砸在地砖上，弹了一下。他没弯腰。屏幕上那行时间戳，跟父亲旧号录音被门铃掐断的时刻隔了十五个钟头。同一个日子，前后两处。父亲那晚删掉了阿良的42秒，第二天傍晚录下了留给他的半句话。

小孙退开半步，脚下踩到湿的东西。

走廊尽头淌过来一道水线，黑褐色，浮着油光，贴着砖缝爬。空气里一股味，先是焦，底下压着一层甜。

“什么味。”

阿莲没答。她把那副橡胶手套塞进罩衫口袋，转身往走廊那头去。

“总闸在工具间里。”她的声音被走廊吞掉一半，“先断。”

陈默单脚撑着，扶墙往后挪。拐杖头磕在水泥地上，闷响一声。他走到工具间门口。

门半开着。烟从门缝里往外冒，薄，灰白，贴着门板下沿钻出来又散。里面传来拉闸的动静，一下，两下。第三下时灯灭了一瞬，又亮起来。压缩机在门后响，起先沉，忽然一声拉长，像有东西卡住了转子。

“阿莲。”

门后没人应。

然后是一声闷响，从门板后面顶过来，整扇门往外弹了两指宽，缝里扑出一股黑烟，夹着火星，溅在水泥地上灭了。工具间里的灯管闪了两下，黑了。

“阿莲。”

门从内侧顶死了。他推了一把，门板晃一下就回来，有东西卡在门后。他把耳朵贴近门缝。里面有咳嗽，急促，被烟压得断成两截。

走廊右墙上，消防栓柜的玻璃门没上锁。他拧开柜门，一把消防斧挂在卡扣上。斧柄有胶套，握上去发涩。他把拐杖靠墙，单脚稳住，抡斧砍在门板上。斧刃进去一寸，卡住。他拽出来，再砍。第三下，锁舌旁裂开一道缝。门板厚，铁皮包边，斧子吃进去慢。

他用肩膀抵住门板，膝盖顶着门框，往内撞。门开了半扇。

烟冲出来。他偏头。里面是黑的，冷柜后头亮着一小簇火，蓝黄，正舔着墙根一摞纸箱。阿莲蹲在离门两步的地方，一只手撑地，一只手扶着冷柜侧壁，肩膀一起一伏。她背后的排气扇停了。

陈默探身进去，右手抓住她胳膊。

她一个趔趄被带出门外，脚在门槛上磕了一下。门框上方的塑料线槽化了，滴下一小团，落在她袖子上，烫出一个焦黑的点。她没喊。她靠在走廊墙上，弯着腰咳嗽，咳得整个人往下缩。

“信。”咳音没散。

陈默没接话。

“工具箱里。”阿莲抬起一只手，指着工具间的方向。那只手在抖。指头搭在罩衫胸前，五个指节各自颤着，收不拢，“铁皮箱，最下一层。你爸的信。”

他看那只手。她也看到了。她弯下腰，把右手按在膝盖上。抖没有停。

陈默重新进了工具间。火不大，纸箱烧了一半，火苗被烟裹着，走得很慢。他绕开火走到操作台边。

铁皮工具箱在台子底下，压着一块毛巾。他掀开箱盖。里面是化妆笔、棉片盒、一小瓶卸妆油。最下一层垫着几本旧排班表，他扒开，压着一张对折的信纸。

信纸下沿焦了，焦痕从边卷上来，离字还有一指宽。他展开。钢笔，蓝黑墨水，横平竖直，收笔压得重。

“你哥的42秒是我删的。那天夜里两点四十七分，我用外协账号登进去，截掉了那段。”

他往下读。

“账不过三。我替你哥记了一笔，替不了第二笔。这一段我删过，改过，还是没把日子挪开。”

工具间外，阿莲的咳嗽停了。

他翻过信纸。

背面两行。一样的钢笔字。最后一笔在“改”字上顿了一下，墨洇开一点。

“下一个是阿莲。别改。”

底下还有一行，更浅，像写完了正面回过头补上去的。

“阿莲的账，我来还。你别碰。”

陈默把信折回去。折到一半停住，那道焦边一折就断。他把信平放在操作台上，走出工具间。走廊里的烟散了一点，警报灯还亮着，红光落在墙上，一明一灭。

阿莲靠在走廊墙上。她抬头。左手扶着领口，右手垂在身侧，微微地，一下，一下跳。

“信里说了什么。”

陈默把信递过去。她接了，展开，读。目光在两行字之间停了一下。脸上那层颜色退下去，像水漫过一层纸。

她把信折好，递回来。

陈默接了，折成四折，塞进外套内袋，跟那张3月17日的便签挨在一起。

“你爸还不了。”她说。

她从他身边走过去。走到楼梯口，停住，后背对着他。

“他已经死了。”

楼梯间的声控灯被她的声音触发，亮了一层，又暗下去。陈默站在原地，拐杖头抵着地砖缝。他想说点什么，喉咙里像塞了那团焦味。

阿莲没回头，手扶着楼梯扶手往下走。走了四级，又停住。

“我哥出事那天早上，还给我带了豆浆。”她说，声音从楼梯井里折上来，带着回音，“他说晚上带我去看新开的夜市。”

陈默把拐杖往前挪了一步。

“那封信，你打算怎么办。”

“不知道。”他说。

“你爸写‘别改’，是怕你改。”阿莲转过身，隔着半层楼梯看他，“还是怕他自己改不了。”

陈默没接。他确实不知道。信上那两行字，正面背面，像两个人写的，又像一个人在两个时辰里写的。他只知道一件事：父亲承认了删监控，承认了账不过三，承认了下一个是阿莲。然后他死了。

保安从走廊那头跑过来，手里提着一只干粉灭火器，白烟从工具间门缝里往外冒，不浓，但持续。他看了一眼门上的斧痕，又看陈默。

“人没事吧。”

“没事。”阿莲说，“压缩机烧了，麻烦你走一趟消防报备。”

保安点头，转身时嘀咕了一句“这月第二回了”，声音不大，陈默听见了。他看阿莲。阿莲也看他。

“上回是上个月十七号。”她说，“冷柜自己跳闸，我以为是电压。”

陈默把拐杖靠墙，掏出手机翻备忘录。上个月十七号。他在页痕里找过那个日期，0316，程师傅剪报册上倒数第二页。他抬头看阿莲。

“你工具间里，除了信，还有别的东西吗。”

“工具箱第二层，一个铁盒，我哥的。”阿莲说，“烟盒、打火机、两张车票。信压在铁盒下面。”

“信怎么会在你工具间。”

“我不知道。”阿莲的声音第一次发紧，“今早我开柜门拿手套，铁盒在上面，信在下面。我以为是哪个同事塞的。”

陈默走回工具间门口。烟已经淡了，他侧身进去，操作台上那封信还在。他没碰信，蹲下去，打开工具箱第二层。铁盒在，盖子合着。他掀开，烟盒、打火机、两张车票，跟阿莲说的一样。铁盒底下垫着一张对折的报纸，日期是三年前三月十七日。他把报纸抽出来，翻到社会版右下角。一小块讣告栏，被红笔圈了一个名字。

阿良。

讣告旁边，有人用铅笔写了一行小字。不是父亲的笔迹，笔画更细，更抖。

“账已过三。第四笔，换人。”

陈默把报纸折好，塞进内袋。他站起来，腿上一阵抽痛，扶住操作台边沿。阿莲站在门口，看着他的手。

“你手背上的墨渍，今天颜色深了。”她说。

陈默低头。左手小鱼际那道墨痕，边缘比早上多出一圈淡青。他没说话，把拐杖重新夹到腋下，走出工具间。警报灯还在闪。走廊尽头，电梯门开了，出来两个穿制服的消防员，脚步很快。

阿莲跟在他身后半步远的地方。走到走廊拐角，她忽然伸手，拽了一下他的袖口。

“陈默。”

他停住。

“你爸还不了，你也别还。”她说，“我自己来。”

陈默看着她。她眼睛没红，脸还是白的，右手垂在身侧，已经不跳了。

“你哥的账，你查了三年。”他说。

“所以我知道还不了。”阿莲松开他的袖口，“但信上写了，下一个是我。那笔账，我总得知道是谁记的。”

消防员从他们身边跑过去，带起一阵风。陈默把内袋里的信按了按，焦边硌着指节。他张了张嘴。

阿莲已经转身，朝消防员走过去了。
