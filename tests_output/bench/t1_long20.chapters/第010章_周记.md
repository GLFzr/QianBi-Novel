# 第10章 周记

路灯的光把修车摊前一地散落的工具拉出长影。程师傅蹲在地上，弯腰捡锉刀和扳手，动作很慢，左脚踝那圈淤青在灯光下发紫。陈默站在摊边，手心里的铜纽扣硌着掌纹。他没走。程师傅也没催他，把扳手拾进工具箱，突然开口：“你爸那件工装，当年是在我这修的自行车。”

陈默蹲下去，帮他收滚到棚布边缘的一颗螺钉。程师傅的左手停在一把锉刀上，指腹摩过刀身：“前几天周航半夜给我打电话，说了句话，我没听明白。”他抬眼看向陈默，“他说，有人替他安排过一条路，不必湿滑。账不用他自己记，有人替他记。”

这句话陈默听周航在电话里说过，从程师傅嘴里再听一遍，字还是那些字，分量不一样了。陈默把螺钉放回工具箱，手里那枚铜纽扣没有亮出来，只顺着修车两个字往下问：“周记这扣子，是修车铺的字号吗。”

程师傅的动作顿住了。隔了几秒，他把锉刀放回原位，声音像从喉咙深处挤出来的：“周记是一个人名。你爸当年让我等的人，就是他。”

陈默没有接话。他低头继续收拾散落的工具，把断线那截拿起来，准备扔进废料盒，指尖在锈蚀段停住。锈层表面有一道极细的新磨痕，不像自然锈蚀，像有什么硬物在锈面上反复划过的痕迹，边缘发亮，是新伤。他把断线翻了个面，又看了一遍，没有提，放回工具箱。

程师傅侧身坐着，陈默蹲到他左边，帮他重新固定左踝的绷带。指腹隔着绷带压上踝骨外侧时，他摸到底下的皮肉烫得发红。这种热度不正常，像皮下烧着一层火。程师傅自己没提，只低声说：“你明天来装线，用那截新的，别用旧的。”

陈默把绷带多绕了一圈，打了个结：“旧的怎么了。”

“旧的被磨过太多回，不敢用了。”

他把断线放回工具箱底，没有追问。陈默站起身时，视线扫过修车摊的铁皮柜侧面，黑笔写着一个歪斜的周字，笔画被雨水冲淡，发毛，但旁边那串数字还是可辨的：0317。他没说话，把手里那枚铜纽扣握进掌心，往东门街路口走。

路灯下空荡。斑马线正中被一根从护栏脱落的横杆横着，铁锈的杆身斜压地面，截断了一半的过街通道。陈默站在路口中央，没有绕过去。旧表停在22点47分，断线落地的时间是20点47分，铜纽扣背面是0317。一个数字，三条线，全压在他掌心里。他低头，掌纹里那枚纽扣的周记两个字磨得发亮，背面的0317像一道随时会裂开的旧口子。页痕预告的句子在意识里提前浮出半句，没有翻开书，他好像已经看见明天有人站到这个路口来。

他摸到胸口口袋，那张纸片的折角扎着手指。路灯下，他看清横杆末端绑着一截蓝色尼龙绳，绳头收尾的那个结，水手结，多绕了半圈，打法和自己钥匙扣上那截一模一样。他摸出钥匙扣，把两截绳并在一起。同一根绳的断口，同一双手打的结。那截绳子，他从父亲账本封皮上拆下来，绑了七年。横杆末端这一截，像是从同一个源头断下来的。路口空得只剩风，风拍着护栏，发出铁皮抖动的声响。陈默把那截绳从横杆上解下来，缠在手指上，黑色的数字0317被路灯照得一清二楚。他没有把它放回去。
