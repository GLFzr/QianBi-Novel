# 第19章 信筒

路灯下，陈默把传单翻到背面。墨字还在，一笔一划收得极稳，笔迹是自己的，但他很清楚昨夜今晨没有碰过笔。他把传单凑到灯下，借着光看笔画的深处。墨色刚干透，压痕还新，笔锋从起笔到收尾没有顿挫，是快速写成的，不像是犹豫着落笔的人写的。他没有拨号。他转身往回走，值班室的灯刚灭。走廊里的感应灯在他身后又亮起一盏，又灭掉，像有人沿着他的来路走了一遍。

岗亭里传来打火机的一声脆响。手电光从铁皮门缝里漏出来，照在他脚前的石阶上。

“值班室没人。”光柱晃上来，照见一张圆脸，“遗体化妆师在里头忙，你找她等天亮再来。”

“我找守夜的。”

手电光顿了一下。老白从岗亭里走出来，穿着一件洗得发白的蓝布工作服，口袋边缘磨出毛边，袖口沾着一点灰浆，像刚在哪里靠过。他上下打量陈默，忽然不说话了。光柱缓缓往下移，停在他左手手背上。

“你是陈继先的儿子。”

陈默没说话。老白把手电别到腰后，沉默了很久，才开口：“你爸连续三个凌晨，站在东墙那棵冬青树底下，天亮才走。不进门，也不跟谁说话。”他顿了顿，像在核对记忆里的某个细节，“第三天凌晨，我要锁大门，看见他还站在那里。我以为他睡着了，走过去看了一眼，他眼睛睁着，看的方向是二楼。”

陈默顺着他的话抬头。二楼走廊的灯全灭着，只有三号停尸间的窗框在夜色里泛着一点灰白。

“那天晚上有风，他站在树底下，衣摆被吹得翻起来又落下，人却一动没动。”老白的声音放低了，像在复述一件已经想了好几遍的旧事，“我问他进去等不，他不答。我又问他等谁，他也没答。过了很久，他才说了一句，说等的那个人来了，会从西边大门进去。”

老白从岗亭里摸出一只牛皮纸信筒，封口胶布贴死，边缘翘起一角：“第四天凌晨，他把我叫到岗亭，留下这个，说周一早晨有人来，把这给他。我不知道谁是周一早晨的人，但我知道他姓陈。”

信筒递过来。陈默接了，纸面粗糙，贴肉的那面微微发温，像是长期放在岗亭里被夜灯烘过的。他捏了捏封口，胶布底下的东西硬硬的，像一个长方形的小物件，又或者是折了几层的纸。他没有用力，只在那道硬度上停了一下，把信筒翻过来看了一眼底部。底部没有字，只有一道被水洇过的旧痕，形状像一个指印，干透了很久。

老白没松手，又补了一句：“你爸走的那年，你多久没见他？”

陈默没有答。他把信筒贴着胸口放好，问了一句：“他除了一句周一早晨，还说过别的没有？”

“说过。”老白站在薄光里，声音低下去，“他说，等的那个人到了，不用问他叫什么，看左手就行。”

陈默低头看了一眼自己的左手。小鱼际那道墨痕在路灯下泛着暗蓝，边缘微凸，像一个长在皮肤上的字没写完。风从殡仪馆大门方向灌进来，吹得岗亭的铁皮门咣当响了一声。老白没有再开口，退回岗亭里，手电光移向地面。陈默站在原地，胸口口袋的信筒隔着布料硌着肋骨。

阿莲从侧门折回来时，手里捧着一只锈铁盒。灯光下她的影子又细又长，走到两人面前，她看了陈默一眼，把铁盒递过来：“你刚才看的烟盒，里面那张收据，我这边还有一半。”

陈默接过来打开。铁盒里垫着一层报纸，报纸上躺着一角纸片，纸质泛黄，边缘的撕裂口和烟盒里那张能拼上。他把两张纸片并在一起，接口处的断茬严丝合缝，拼出来的字不多，但他认得那个句式。上半截是“他会管不过来”，下半截只剩两个字：“会管”。他把纸片翻过来看背面，背面有一道极淡的铅笔划痕，笔迹的走向和他在种子书夹缝里见过的那种很像。

“这个我打不开。”阿莲没有看他拼纸，目光落在他手里拼好的纸片上，停了一瞬，“监控缺失段，我试过恢复。文件还在机器里，但我打不开。”她抬眼，看了一眼老白手里的信筒，没有问，只说：“三号停尸间的窗口，明天白天我拍给你看。”

“你拍到什么？”

“拍到能看见的。”她答了一句，侧门方向传来另一扇门开合的声响，像有人在催她，她转身往回走了两步，又停下来，“烟盒里那张收据，我哥保存了三年。他不懂那是什么意思，只知道是他自己剪下来的。”她说完，快步走回侧门，影子在门框里消失。铁皮门合上时发出一声轻响。

老白看着她离开的方向，沉默了一会儿，才开口：“你不该来，她也不该来。”

“她来是她自己的事。”

“她来的不是你的事。”老白把手电换到右手，光柱斜斜地落在地面上，“你爸说，打开它，你会知道3月17日谁等着你。”他退开两步，“他说得对，他等的是收账的人。”

岗亭里的灯灭了，只剩铁门缝里漏出的一点薄光。陈默站在原地，没有拆。信筒的硬纸边贴着肋骨，隔着布料硌出一道浅印。他低头看了一眼左手墨痕，小鱼际那道痕没有发烫，也没有变化，安安静静地趴在皮肤上。他抬头看了一眼二楼，三号停尸间的窗是黑的，黑得像没有人在里面。风又灌过来一次，这次把铁门缝里的薄光也吹灭了。
