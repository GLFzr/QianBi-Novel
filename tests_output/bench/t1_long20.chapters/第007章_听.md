# 第7章 听

录音播完第二遍，陈默把耳机压进耳道，又播了一遍。末段那个被截断的尾音卡在最后一秒，他拖动进度条，从42秒往后退到40秒，一格一格地慢放。手机录音软件把波形拉成一片锯齿。那个含混的升调反复出现，像"儿"字尾音被什么东西咬掉了一半。他记在备忘录里：北方口音，尾音上扬。手机屏幕上方，通话记录的拨出键还亮着，第三通打给父亲旧号码的界面停在指尖下。他还没按。

他按了。铃声响到第三下，电话被接起。听筒里先是一段空白，然后一个压低的声音说："我劝你别查了。"陈默握着手机，喉咙发紧，报出那串数字："0317。"对面沉默两秒，声音更低："未来的账，你管不过来。"电话掐断。屏幕显示呼叫时长：0分7秒。他拨第二遍，只有忙音。放下手机，手心全是汗。他盯着屏幕上的号码，尾号那一串数字在黑暗里亮着，他又看了一遍，确认自己没拨错。

他翻开种子书。页角那行"多次改写致第二人擦伤"的墨色比早晨更深，像要从纸背渗出来。他盯了三秒，正要合上，余光扫到纸角下方多出一行字。笔迹是他自己的，横折收笔的力道一模一样。但他从来没写过那句话。"明日20:47，东门街公交站，他会被自行车把钩住，伤左脚踝。"他数了数，那行字压着页角原有的纸纹，像是早就长在纸里，直到这一刻才显出来。他伸手摸了一下，纸面平整，没有笔尖压过的凹痕。他没有落笔。他合上书，站起来，在屋里走了两圈，又坐下，重新翻开。那行字还在。

凌晨三点，他翻手机通讯录，从A翻到Z，没有姓程的联系人。

他拨林兰，关机。他拨周航，响了四声才接，对面传来风噪和电动车喇叭声，周航的声音带着倦意："喂，谁啊？"陈默说我是住老屋二楼的，上次楼道口那个。周航哦了一声："你没事吧，这么晚。"陈默问他认不认识姓程的人。周航停顿了一下："东门街有个修车摊的程师傅，总替人调刹车，你要找他？明天我路过帮你带句话？"陈默说不用，问清摊子的位置，挂了电话。他躺回床上，手机扣在胸口，想起页角那行字的笔迹是自己的，可内容不是自己的话。

凌晨四点，他坐回桌前，看着页角那行字。20:47。他想起公交站的电子屏，红色数字跳动的样子，想起站牌下每一块地砖的颜色。他没见过那个路口晚八点的样子，页痕先替他看见了。

四点十五分，他把种子书锁进抽屉，钥匙拔出来握在手心。走廊传来脚步声，很轻，单一节奏，一步一步走到门口，停住。他屏息，听见自己的心跳在耳膜里擂了三下。三秒后，脚步声原路退回，消失在楼道尽头。他没有开门，坐回床上，等天亮。窗外路灯的光从窗帘缝里透进来，在地板上拉出一道细长的影。他盯着那道影，直到它变淡，变成灰白的天光。

天亮后他带上一本新便签本出门。东门街公交站的风卷着灰，一辆施工车刚开过去，路面的灰还没落定。站牌的铁皮被太阳晒得发烫，他摸了一下又缩回手。修车摊在站牌斜对面，蓝色棚布支着，棚下一辆旧电动车架在木凳上，一个人蹲在旁边，右手垂着，左手握一把锉刀，来回修一条刹车线。动作很慢，锉两下，停一停，再锉两下。他蹲的姿势像一直在等什么，但手上的活又确实在做。

陈默站在站牌下，没过去。他摸出手机，翻到相册里那张窗台旧表的照片，把表盘放大到22:47的位置，看了很久。表盘的裂纹在放大后更清楚，从边缘一直延伸到表盘中心。照片是晚上拍的，窗台的框在画面边缘露出一小截，陈默看了几秒，认不出那是哪个窗台。他想起老屋的窗台，瓷砖是灰白色的，照片里的这个偏黄。电子屏跳出一行字：距离下一班车，还有21分钟。他没打算上车。

太阳升高，晒得站台铁皮发烫。他把便签本摊在小腿上，写下几个字：程师傅，修车摊，东门街。又写下今天的日期。隔一行，他写下：距离0317还有12天。风把便签本一角吹起来，他压住，抬头看了一眼监控杆，摄像头红灯闪得平稳。他收了笔，望回修车摊的方向。那人还在锉刹车线，换了个角度，右手始终垂在身侧，没有摆动的痕迹。陈默数着他的头低下去的弧度，一下，两下，像在给什么打拍子。他想起来，页痕写的是"20:47"，那个时间，这个人应该已经收摊回家了。

他站起身，往修车摊走去。背后那个蹲着的背影没回头，手里的锉刀停了一下，声音像从胸腔里挤出来："你是等谁，还是找谁？"

陈默在棚布边缘站定，太阳穴还留着昨天落笔后的抽疼："程师傅，能不能帮我调一条刹车线？"

锉刀彻底停住。程师傅转过身，脸上有一道新蹭的皮，从额角红到颧骨，左臂袖管卷到肘弯，露出两圈陈旧绷带，绑得太紧，他也没解开。他打量陈默两秒，把锉刀放回口袋里，没回答能不能，只问："你认不认识一个姓周的？跑外卖的。他昨天跟我说，有人替他'安排'过一条路，不必湿滑。"

陈默的脚钉在原地。程师傅看着他，目光移到他左手，又移回他脸上，补了一句："那人还说了句话，我没听懂。他说，账不用他自己记，有人替他记。"陈默低头看了一眼自己的左手，小鱼际上那道墨痕在日光下泛着深蓝。他抬起头，程师傅正看着那道痕，眼神没移开。
