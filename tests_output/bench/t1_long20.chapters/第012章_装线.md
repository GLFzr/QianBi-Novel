# 第12章 装线

晨雾没散，修车摊的油布已经掀开了。程师傅蹲在地上，左脚踝的绷带比昨晚厚了一圈，面前摊着那截拆下来的旧刹车线，断口锈蚀处被什么东西擦得发亮。陈默走过去，把手里的新刹车线放到油布边上。他昨晚把线在水里泡了一夜，取"线要顺"的借口。程师傅看了一眼，没问。

陈默蹲下装线。指腹先探进断线槽内壁，在槽口内侧摸到一道极细的刮痕，浅，亮，没有锈色，不是旧伤。他用指节比了一下，长约一指节。刮痕出现的时间，应该在他昨夜离开修车摊之后、今早之前。他没有声张，余光扫过程师傅，程师傅在油布对面蹲着，正看他装线。

程师傅搭手扶车架，陈默借换姿势碰到他左踝绷带，隔着布料摸到底下的热度比昨晚更高，烫得有些灼手。程师傅的动作没有停顿，像那一处根本不是自己的脚踝。陈默问："踝子还肿么。"

"不碍事，线装正就行。"程师傅不再接话。

陈默把热度记进心里，低头把线穿进槽口、卡好线头。他捏紧刹车把试了几次，手感偏紧但能停住。程师傅伸手紧了两下螺丝，说："用得住。"他把扳手放回铁皮柜，陈默的余光扫过柜脚夹缝。昨夜那截蓝色尼龙绳头不见了，夹缝里卡着一片灰白的东西，像是叠过的纸角。他没有当场去取，帮程师傅收拾完工具，道别，走向路口。

走出修车摊约三十步，他停住，捏了捏空手套，转身折返。程师傅不在摊前，油布上的旧线已经收走了。陈默蹲到铁皮柜边，从夹缝里抽出那张叠成方块的维修单。纸角压平，叠法平整，不是随手塞的。他翻到背面，一行细瘦字迹："你今天用的那截新线，也是旧绳。周记。"笔画连得紧，像有人按着呼吸写的。

他又翻回正面。昨天那行"他明天来，就告诉他周记是谁"被一条横线划掉，下面新写一行字："周记就是你爸让我等的人，他明天来。"墨迹干透，是同一支笔。

陈默把维修单叠回方块，正要塞回夹缝，余光扫到铁皮柜侧面。程师傅不知什么时候站到了那里，手里攥着那把新扳手，视线落在他刚伸进夹缝的手指上。

"你摸到线槽里的刮痕了吧。"程师傅说。

陈默没有动。程师傅低下身，把扳手放回铁皮柜，起身时补了一句："那刮痕是昨天夜里来取线的人留下的。"

陈默问："取线的人为什么要刮槽口。"

程师傅没有马上回答。他站在铁皮柜侧面，晨雾从他身后漫过来。过了几秒，他开口说："周记来取过线，他取完线都会刮一下槽口。你爸当年那根刹车线，也是周记取完线后你爸才来装的。"
