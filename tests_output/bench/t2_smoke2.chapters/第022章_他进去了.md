# 第22章 他进去了

监控室屏幕亮着，0:00到5:00的暂存间画面匀速滚动。阿莲抱臂站他身后，声音压得很低：“我昨晚下班前锁的柜门，今早来的时候，03-17已经空了。”

陈默没有说话，把进度条拖到00:00，开始逐格看。前二十分钟一切正常，灯管频闪了几下，地面没有任何影子。他放慢速度，一格一格地过，眼睛在画面边缘来回扫。监控的像素不高，柜门上的编号在放大后有些糊，但门缝的轮廓很清楚。00:15，画面右下角，03-17柜门向外开了一条缝。没有手，也没有影子，门缝自己扩开半扇，停顿两秒，又合拢。全程无人接近。

“锁是好的。”阿莲在身后说，“我昨晚锁的时候，锁舌是弹出的。”

陈默没应声，把进度条拖到02:10。同一扇门，同样的开法，门缝里滑出一截蓝尼龙绳头。绳子垂下来，像被什么东西从里面送出来，停顿一息，又被拽了回去。门合上。

“你看这里。”陈默把画面定住，放大。绳头缩回去的那一瞬，柜门边缘出现一道极细的磨损，白茬，新痕。他把画面继续放大，绳头的断口在像素里模糊成一片，但能看出不是旧磨损，边缘是亮的。他把02:10这一帧单独截出来，存进手机相册，和04-11柜里那截绳头的照片放在同一个文件夹里。

阿莲没有答话。她把视线移到屏幕边缘，呼吸停了一下。她右前臂还绑着临时撕下的布条，没有换药，青紫从手背一直延伸到腕口，在冷白的屏幕光下泛着暗色。她没有碰伤口，只用左手撑住桌沿，手指在桌面上轻轻按了一下，像在确认自己还站得稳。

04:37，门第三次打开。这一次开得更慢，半扇门完全洞开，柜内灯光亮起，照见空荡荡的隔板。隔板上留着一个人形压痕，浅而宽，像什么东西在上面放了很多年。压痕的形状从肩膀到腰侧，轮廓清晰，像一具身体贴着隔板躺了很久留下的印子。肩窝的位置比腰侧深一些，像有人长期以同一个姿势侧躺。门停了四十一秒，然后自己合上。

04:39，家属签名登记页弹出。签名栏落笔一个字：周。笔画的收尾带着一道向下的顿笔，和阿莲哥哥旧案删除记录上的那个周字同一个写法。陈默把两个签名并排放在屏幕两侧，放大，笔锋的走向重合，收笔的顿点落在同一个高度。他又调出铜纽扣背面那张照片，把三个周字并排。三个字的收尾顿笔在同一个位置，像同一个人写了很多年，手已经记住了这个动作。

阿莲攥住他袖口，没有出声。她的手指在布料上收紧，指节发白，好一会儿才松开。她松开的时候，布料上留下几道浅褶。

陈默没有停，调出阿莲带来的恢复工具，打开她哥哥旧案的缺失文件。文件跳出来，长度41秒。他按了播放。画面里，路口护栏边，一个人往后退了半步，手撑住护栏，整个人向后翻下去。翻落的瞬间，画面左下角有人抬手，腕口露出一圈蓝黑墨痕，纹路的走向和他左手小鱼际的墨痕叠得上。他按停画面，手指停在空格键上，没有让阿莲看清那只手是谁。

“没拍到脸。”他说。

阿莲的目光在屏幕上停了很久，没有追问。她只问了一句：“这一秒，是被剪掉的那一秒。”

“是。”陈默把画面关掉，“剪掉的是抬手的那一瞬。”

他没有告诉她，那只手的腕口墨痕和他左手小鱼际的纹路走向一致。他也没有告诉她，他按停画面的那一秒，自己的左手在桌沿下轻轻收了一下。

两人回到暂存间。04-11柜门正对着过道，此刻半开着一道缝，像有人刚来过。陈默走过去拉开门。柜内的蓝黑工装被换了个叠法，领口从朝上翻成朝下，前襟口袋露出一角白色纸片。他抽出来，纸片是叠纸的背页，上面原本只有三个字“周记在”，现在底下多了一行极细的铅笔字：“3月17日，你也在场。”笔迹不似父亲，也不似阿莲哥哥。字的间距很窄，像写的人把手指按在纸面上，压着写出来的。他翻过纸片看正面，正面是阿莲哥哥旧案的叠纸内容，没有变化。

他把纸片和那张工装照片一起夹进种子书页角。合书时，页角夹缝里没有新的墨痕滑出。

两人退出暂存间，绕到侧门通道。更衣室窗外，一辆白色轿车停在殡仪馆侧门外，车灯亮着没熄，车牌尾号317在凌晨的暗色里格外清楚。车头正对着通道出口，近光灯把地面切出一道白线，像在等什么人出来。车身上没有露水，引擎盖是干的，停的时间不长。

阿莲拉住他胳膊，问：“你是不是也进去过。”

陈默没有回答。手指隔着衣服碰到胸口那张照片，照片背面“他进去了”四个字抵着皮肤。白车副驾驶的车门这时开了一条缝，里面没有灯光透出。他看到座位上躺着半截蓝尼龙绳头，断口错位，和04-11柜里露出过的那截颜色一模一样。
