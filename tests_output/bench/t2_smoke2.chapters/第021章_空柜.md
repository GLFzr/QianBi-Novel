# 第21章 空柜

凌晨五点四十分，殡仪馆东门铁门虚掩，路灯还亮着一半。陈默插着兜站在门边，胸口口袋里的信筒和纸片隔着布料硌着肋骨。手机屏幕停在阿莲那条消息上，“明天早上六点，殡仪馆东门，别带别人”。他没有回。门内的白灯在风里晃着，照着水泥路面。他站在门边，没有靠墙，把手从兜里抽出来又插回去，反复了两次。他等了三十分钟，路灯在五点五十三分灭了一半，剩下的一半在风里嗡嗡响。

他数了后续的时间。五点五十六分，门内的白灯换了一盏，从常亮变成频闪，像接触不良。没有人出来调。六点零一分，铁门内侧的挂锁动了一下，被风带着撞在铁皮上，响了一声。他看过去，锁是挂上的，扣环没有套上锁梁。他伸手拨了一下，锁掉在地上，他捡起来，锁梁是干的，没有露水。

六点零七分，阿莲没有来。他拨她的电话，响到第七声，转进一段没有录制的静音。他没有再打第二遍，把手机放回兜里，推门进楼。值班室的灯关着，桌上水杯还是满的，杯沿没有水渍。椅子推开的角度很正，像人走的时候是站起来直接离开的。桌上摊着一本翻开的登记簿，笔压在空白页上，没有写任何字。他凑近看了一眼，登记簿翻到的那一页是空白的，日期栏还空着，但页脚有一个被指尖按出来的浅印，指腹的纹路看不太清，方向是朝下，像有人在页面上按了一下又收手。

他沿着走廊往里走，经过拐角时，听见一声闷响，金属撞在什么东西上，闷短，像被什么堵住了大半声音。声音从暂存间方向来。

他推开暂存间虚掩的门。灯管在头顶嗡嗡响，冷白光照着一排排冰柜。阿莲右半个身子卡在两扇半开的柜门之间，右前臂和半边肩被夹在门缝里，手背青紫，指甲发绀，嘴唇因为咬牙压成一条线。她看见他，没有叫，只用左手攥住门扇边缘，指节因为用力而发白。她没有说话，眼睛直直地盯着他，下颌绷紧，喉咙里滚出一声极短的闷哼。

陈默两步上去，扳住外面那扇柜门往外拉。门轴锈涩，发出短促的磨响。门缝没有松。他换了角度，把外套下摆掖进腰后，侧身，用肩抵住门扇前缘往上顶，同时右手握住她的手腕往外带。门扇动了一下，又卡住。他抬手按住门扇顶端的铰链位置，用力压下去，金属发出低沉的咬合声，门终于往前让开半寸。她整个人从门缝里滑出来，半边肩膀蹭着柜门边缘，白大褂袖子撕开一道口子。他托住她的背让她靠墙，她滑坐下去，右前臂垂在身侧，手背的青紫在冷白灯下泛着暗色。

她靠着墙坐了很久，喘气声从粗到细，才开口。

“门自己关的。”她抬起头，额上有一层薄汗，“柜里的人呢。”

陈默没应她。他转头看那扇卡住她的柜门，编号04-11。门没有锁，锁舌缩在锁孔里，门缝内侧有一道新蹭的划痕，露出白茬，是刚蹭出来的。他伸手拉开门，柜内是空的。底板上叠着一件折好的蓝黑工装，前襟口袋鼓起一角。工装叠得很整齐，领口朝上，两袖收在胸前，像有人把它当成一件待运的遗物叠好。他弯腰抽出那角，是一张叠了两折的纸。

纸上的墨字像是他自己的笔迹，又显然不是他写的：“22:45:03—22:45:45，删除签名：周。”铅笔字另起一行，“柜已经空了，账还给你。”

阿莲撑着墙站起来，凑过来看到前一行，声音哑下去：“这是我哥那四十二秒？”

陈默没有点头，也没有摇头。他把纸叠好，连同那件工装一起收进塑封袋。塑封袋口压下去时，他隔着薄膜又摸了一遍工装的领口布料，针脚粗密，和他手里那件旧工装是同一路走线。他把袋口按紧，塞进外套内袋。

他扶着阿莲往外走，她右前臂不敢用力，垂在身侧，白大褂袖口那一道撕口在灯光下露出里面浅色的内衬。走到暂存间门口时，手机在裤兜里震了一下。他单手撑开屏幕，内部转运系统的通知栏跳出一条新记录：03-17，06:05，已由家属领取。

他停住脚步，把屏幕转向阿莲。

阿莲看了一眼，沉默了几秒：“今天早晨，没有人进出过这栋楼。”她抬手指了指走廊尽头的门禁灯，“我六点前就在值班室，门禁没响过。门禁一旦开门会有提示音，那个声音我能听出来，今天没有响过一次。”

陈默收起手机，把塑封袋在外套内袋里按了一下，确认放好。阿莲没有再追问工装的事，只低头看了一眼自己右前臂，青紫从手背延伸到腕口，像被什么东西从皮肤下面顶出来的。她用左手把撕开的袖口捋平，指尖在伤口边缘停了一下，没有碰，收回来了。

两个人走到监控室门前。阿莲靠在门边按住前臂伤口，指缝里渗出的血已经凝成深色的一小片。她侧头看了一眼走廊尽头，门禁灯安静地亮着。陈默从口袋里摸出钥匙，插进锁孔，手指停在没转的角度。

走廊的灯在头顶嗡嗡响着，他等着。灯没有灭。
