# 第23章 定损人

手机屏幕先亮起来，按键的嘀嗒声从听筒里渗出来，三下。短信爬进通知栏，一串编号：JH-BX-2211。

陈默回收到。抬眼看窗外，楼下拐角那道影子还贴着墙根，像被谁用铅笔轻轻画了一道，没擦掉。他拉上窗帘，铜扣在掌心，扣面被体温焐得发黏，林字的凹痕压出一道红印。他把编号抄在纸条上，拧亮台灯。光从底座边缘漫上去，照出台历上那圈三重圆珠笔迹。

他翻手机里的聚合页。沈照经手的定损单，四起夜间事故。建设路上周三那条单的编号，他调出来比对。

建设路单：JH-BX-2207。
沈照定损单：JH-BX-2211。

前四位一样。JH。跟上BX。后面只差一个数。他把两条编号并排抄在一张便签上，笔尖在JH-BX底下划了一道线。这是内部结算体系的档案编号，两个不同口径的出处共用一套编码。

他又点开沈照那张定损单的详情。定损人一栏写着全名。经手时间，凌晨一点四十六分。跟方司机那趟单被改到凌晨一点，对得上。

陈默坐下来，把父亲遗书第三页从台灯底座下抽出来。折痕没回弹，纸脊拱着。他在空白处补了一行：JH-BX=沈照权限。然后给方司机拨号。

响到第四声，对面接起来，喂了一声。

“方师傅，建设路那趟单的保险回访。”陈默的声音压得平，像在念稿。“上周三，单子原本定二十三点，后来改到凌晨一点。系统里查不到改单原因，想跟您核实一下。”

电话那头安静了。人在咬着话想。他听见对方呼吸变慢，鼻腔里进出两下。

“你问这个干嘛。”

“备注要补一项。”

又静了两秒。

“群主。”方司机开口，声音比刚才低，“群主让我找沈会计，说那个点路上没人查。”

陈默的拇指按住手机背面，停住。

“沈会计。”他重复。

“你到底哪个保险公司的。”

“回访部的。备注补完了，谢谢配合。”

“你等等——”

他挂了电话，把手机搁在桌上，在第三页背面写三个字。沈会计。跟正面的沈照并排，隔着一道折痕。群主发路线，指定司机找沈会计改时间。沈照改派单，清掉检查口。一条链。JH-BX是这条链上的内部代码。

收拾背包。夹层里种子书，侧兜里旧表，铜扣换到外套内袋，贴着胸口。他换深色外套出门，石膏腿裹进裤管，在楼道口等公交。

建设路南口提前两站下。这条路比东门街更旧，两侧楼墙剥落，露出底下的红砖。路灯坏了两盏，黑一段亮一段。五金店卷帘门锈得发红，拉到底。173号是一栋六层旧楼，楼道口贴着一张褪色的通知，字看不清。三楼靠右一扇，302。窗帘拉着，中间留一条拇指宽的缝，暖光从缝里透出来。

他站到斜对面便利店的灯箱阴影里，背贴冷墙。隔着一条街，从窗帘缝里看进去。

一个人影侧坐在桌前。戴眼镜。镜片反着桌上的灯光，两点小白斑。手里翻着一沓纸，翻得很快，一页一页往下走，像在找东西。窗台上排着三个空矿泉水瓶，旁边搁一只搪瓷杯。

人影翻到某一页，停住。手指按住纸面，没有翻过去。

然后抬头，朝窗户方向看了一眼。

陈默缩进阴影。后背贴住墙，呼吸压下去。心跳撞着肋骨，一下，一下。过了几秒，他从阴影边缘试探着看过去。人影没有起身，低头继续翻纸。

街口传来刹车声，短促，扎耳。一辆电动车从拐角拐进来。骑车人摘头盔，后架绑着一个灰扑扑的旧布包。经过灯箱时，灯光扫过侧脸。

方司机。四十多岁，下巴一道浅沟，跟电话里的声音对得上。

方司机锁车上楼。一楼声控灯亮，二楼，三楼。台阶声一级一级停下来。302室的窗帘后，暖光灭了。整扇窗黑下来。

陈默的手掌压住胸口铜扣。扣边硌进皮肤，那道红痕深了一层。楼道里的脚步声在头顶停住，没有下来。

他摸出手机，翻到那条短信。别去建设路。发送时间：昨天17:43。他刚出殡仪馆大门。他对着302室黑掉的窗户拍了一张，又拍了一张楼下电动车的照片。存进相册。转身沿来路往回走，走出十几步，裤兜里手机震了一下。

是备忘录的提醒弹窗，日期是今天。上面只有五个字。

看窗台。别回。

创建时间：昨晚凌晨三点四十七分。他不记得自己写过。

他站在人行道边，把手机屏幕翻过去，又翻回来。五个字，创建时间那一行小字比正文还刺眼。昨晚三点四十七分，他在出租屋床上，石膏腿架在卷起的被子上，手机放在枕边。没有任何记忆里有过抬手打字这个动作。

他把备忘录往上滑。上一条记录停在四天前，内容是一串公交站名，是他踩点时随手记的。两条之间干干净净，没有编辑痕迹。这条像被谁从别处剪下来，端端正正贴进了他的手机。

建设路两侧的旧楼黑沉沉地立着，路灯只亮了一半，隔一根灭一根。他抬头看了一眼173号三楼。302室的窗户仍然黑着，楼道里的声控灯也灭了。方司机上去之后，再没有下来。

他本可以等。等到方司机出门，看清他手里拿的东西，或者跟到楼下听他跟谁打电话。但他想起细纲里自己压下去的那个判断：抓方司机只会打草惊蛇。方司机是跑腿的，是听群主话的人。真正要看清的是302室那扇窗后面的人。

他把铜扣从左手换到右手。扣面的林字已经被体温捂得不再冰凉。他转身，沿人行道往反方向走。经过五金店卷帘门时，脚底的石膏磕在地砖上，闷响一声。他放慢步子，没有回头。

走到建设路南口，公交站牌下只有他一个人。末班车还有七分钟。他靠在站牌柱子上，把手机相册打开。两张照片：一张302室黑窗，一张楼下电动车。电动车后架上的旧布包拍得清楚，灰扑扑的，跟他那天在巷口目送老赵时看到的包是同一款。他放大照片，布包侧面有一道浅色补丁，位置、形状都对得上。

他退出相册，点开短信。程雨那条编号短信还停在通知栏最上面。他打了三个字：到家了。发出去。半分钟后，对面回了一个句号。

他把手机收进口袋。公交车灯从街口拐过来，晃了一下他的眼。他抬脚上车，刷卡，走到最后一排靠窗坐下。车子启动，建设路两侧的旧楼一栋一栋往后退。经过173号时，他偏头看了一眼。三楼那扇窗还是黑的。但四楼有一扇窗亮着灯，窗帘没拉，一个模糊的人影站在窗边，面朝楼下。

他收回视线。公交车拐上主路，路灯一盏接一盏从车窗上滑过去。他摸出铜扣，在掌心里翻了个面。扣背的铜绿蹭在皮肤上，留下一点淡青的痕迹。

手机又震了一下。他低头看。还是备忘录。还是那五个字。但这一次，创建时间变了。

今天，二十三点零七分。

就是刚才。
