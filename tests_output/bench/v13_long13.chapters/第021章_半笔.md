# 第21章 半笔

信封口在指间撕开的呲啦声比预想中轻，像撕开一张旧收据。压缩机嗡嗡地走，陈默抽出第一页，父亲笔迹写着一行他不敢读第二遍的话：

我动过那本书。替过一个人。

括弧里补了一行小字，铅笔，压得很浅：2019年6月初。

他翻第二页，指腹压在纸面上蹭过，纸页发脆。父亲写：那天晚上我在东门街路口，按着格式把一笔本该落在我身上的事，转写给了阿俊。他知道，他自愿。我问他为什么，他说你活着，我能拿到的比命有用。条件是给你留一条后路。

写到后面字迹开始散，横画抖得厉害，收笔的顿点拖出细尾。父亲说阿俊手上墨痕褪不掉，那不是他的错。最后一句独立成行，落笔很重：账由人记着收。你将来会懂。

陈默把信纸搁在桌面上，从口袋里摸出手机，翻到夹层薄纸的照片，两指放大，逐笔比对。走之底的收笔弧度，顿点的深浅，横折起手处那个小小的钩。同一个人。他食指在那个替字上来回摩挲了三趟，指肚发白。

第三页只有三行。

城东区建设路173号302室。

找沈照。

别查0317，别找收账的人。

他盯着最后一行的收账两个字，耳边响起门缝下那张纸条上的话。下一次不是记忆。台历上写着收账日的那一格，薄纸上的未结，剪报册第三十七页的日期，全叠在这个词上。

沈照。这个名字他没有印象。通讯录里没有，父亲的旧物里没有，程师傅的剪报册里似乎也没有。但不一定。他记不住的东西太多。

他把第三页捏起来，对准原本的折痕。撕之前停了一秒。然后从信纸装订边撕下，纸根留着细密的毛边。折成四折，塞进钱包夹层，拉上拉链。动作和当初处理父亲薄纸时一样慢，一样准。

前后两页重新叠好，放在桌面正中间，压平。

门锁转动。

阿莲推门进来，侧廊的冷风跟进来一股，搪瓷缸里的冷茶晃了晃。她脚步在门口顿了一下，看见桌上的信纸。

她没问，走过来，低头读。

陈默看着她。她读到第一页那行字的时候，左手手背的墨痕在灯下颜色沉了一层，从浅青灰慢慢变成灰蓝。她往下读，读到阿俊名字的时候嘴唇抿紧了一下，很快松开。她读到那三个字，他自愿，停了两秒，指腹在桌沿刮了一下，没出声。

读完第二页，她抬起头。

两个人对视。

陈默把两页信纸推到她面前。

你哥的账，我来记。

阿莲低头看着那两页纸，没接。灯管在她额头上方亮着，工牌的反扣边缘露出一小截金属。她把锡纸碎片和记事本一件一件收进铁皮柜，动作很慢，每样东西放进去之前都在手里停一下。走廊外又传来喊声，三号柜，要复位。

陈默起身。石膏腿在地上杵了一下，膝盖撞上铁皮柜的角。柜顶一只旧铁盒滑下来，砸在桌沿，盒盖弹开。

一枚铜扣滚出来，在桌面转了两圈，停在信纸边上。

陈默低头看。扣面发暗，边缘磨得发亮，正中刻着一个字。笔画模糊，但轮廓压得住场面。林。

他还没伸手，阿莲已经弯腰，把铜扣捡起来，攥在手心，手指合拢，指节绷出白印。她站直，看着他，没说话，也没松手。

陈默张了张嘴，没问。他看了一眼她攥紧的拳头，又看了一眼她的脸。她的表情和进门时一样，只是嘴唇的颜色白了一度。

走廊里的喊声又催了一遍。

阿莲侧身让出门口的位置，攥着铜扣的手插回夹克口袋。

陈默把背包带往肩上提了提，走出值班室。侧廊的灯管只亮一半，尽头拐角暗着。他走过停推车的空地，穿过铁栅栏门，后门外的天已经暗下来。

路灯没亮全，一盏隔一盏闪着，地面的水渍里映出断续的黄光。他站在台阶下，把钱包按了按。第三页的折痕硌着指腹，硬。

建设路173号302室。沈照。

两个新地址，一个名字，一句警告。信里的每一个字都在往回指，指向0317，指向收账日，指向父亲那笔没还完的账。

他往公交站方向走。风把殡仪馆后门那串铜铃吹得响了一声。他掏出手机，在备忘录里打了一行字：建设路173号302室，沈照。打完看了一遍，锁屏。

身后铁栅栏门的方向，阿莲没追出来。三楼走廊尽头的窗户亮着灯，一个人影站在窗边，手里攥着什么东西，贴在胸口的位置。影子一动不动。

陈默看了一眼，回头继续走。巷口的路灯闪了第三下，灭了。

他走出巷口，手机在掌心震了一下。

一条陌生号码发来的短信，只有四个字：别去建设路。

陈默站住。风从巷子那头灌过来，吹得他石膏腿上的裤管贴紧小腿。他盯着那四个字看了三秒，回拨过去。响了一声，对方挂断。再拨，已关机。

他把手机翻过来，短信界面还亮着。号码归属地显示本地，一串数字干干净净，没有备注。跟门缝下那张纸条一样，跟三秒录音一样，这只手总能找到他。

陈默把短信截图，存进相册。他继续往公交站走，步子放慢了半拍。腿上的石膏比早上沉，撞过铁皮柜那一下，膝盖外侧隐隐发酸。

站台上只有他一个人。电子屏显示下一班还有六分钟。他靠着站牌立柱，把钱包从口袋里摸出来，翻开夹层。第三页折成四折，边角齐整。他没有展开，只是用拇指压了压折痕。

建设路。沈照。

这两个词在脑子里转。父亲信里写着找沈照，短信说别去建设路。一个指路，一个拦路。他不知道发短信的人站在哪一边，也不知道父亲留这个地址时，是让他去，还是让他知道有这么个地方存在。

公交车灯从远处晃过来。他上车，刷卡，挑了最后一排靠窗的位置。车厢里空，暖气开得足，玻璃上蒙了一层薄雾。他用指节在雾面上划了一道，外面街灯拉成长线，往后跑。

手机又震了。阿莲。

“你走了。”

三个字，没有问号。

陈默打字：“嗯。你哥的账我记着。”

发出去之后他盯着对话框。上方“对方正在输入”跳了两次，又消失。最后只回来一个字：“好。”

他把手机扣在膝盖上。车窗外的街景从城东往城西退，路过东门街路口时，他侧头看了一眼。站牌下没有人，烤红薯摊收了，只剩地上一圈焦黑的炭迹。路灯亮着，把那道白漆裂缝照得发白。

到站下车，走回出租屋楼下。楼道灯坏了，他摸着扶手上楼，石膏腿在台阶上磕出闷响。开门，没开灯，先把钱包放在桌上，第三页抽出来，展开，压在台灯底座下面。

然后他坐下，看着那张纸。建设路173号302室。沈照。别查0317，别找收账的人。

父亲写这封信的时候，阿俊还活着。七天后阿俊死了。父亲知道会发生什么，还是写了那个替字。陈默把脸埋进掌心，掌纹里还留着信封纸的粗粝感。

台灯底座下，第三页的折痕慢慢回弹，纸面拱起一道脊。像一枚没拆的扣子。
