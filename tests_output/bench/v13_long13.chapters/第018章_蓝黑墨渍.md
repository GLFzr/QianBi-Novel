# 第18章 蓝黑墨渍

黑夹克男人的后脚跟刚转过走廊拐角。

陈默撑着石膏腿从长椅上站起来，背包侧兜拉链撞在金属扶手杆上，脆响。他低头看了一眼钱包里那张拓着收账日压痕的台历照片，再抬头，拐角空了。他挪过去，只看见自动门缝隙里，夜风卷着几片落叶灌进来。门外马路对面，一个黑夹克背影正往巷口走，步子不快，没有回头。

护士在身后喊：“你腿不能跑。”

他站住。左脚落地，石膏磕在地砖上，闷。他扶着墙往回挪了两步，把背包从肩上取下来拎在手里。

分诊台后面，护士正把台面玻璃下压着的一角剪报往抽屉里塞。陈默走过去，右手按住抽屉边沿。“刚才那人查的是谁。”

护士抬眼。四十来岁，头发用蓝发夹别在耳后。“你是他什么人。”

他隔了两秒才说：“我父亲，是他查的那个人。”

这句话半真半假。他知道自己说的时候喉咙有点紧。

护士看了他左腿的石膏一眼，又看了一眼他按住抽屉的手，松了力道。“阿俊。三年前东门街路口，夜里送过来的，没救回来，当天转殡仪馆了。”她把剪报往抽屉里推，“那人上个月也来过，问另一个，三年到五年前的名字，我都记不清了。”

抽屉合上。剪报一角从护士指缝里露过一瞬，铅字边上有个黑体字，他只看见右半边，像夋。

他退回长椅，掏出手机，在备忘录里打下一行：阿俊，东门街路口，三年前，殡仪馆。又打一行：黑夹克，上个月来过。

急诊灯闪，白一阵暗一阵。他调出父亲旧号的通话记录，那条被掐断的录音条目还在。他没点播放，只在心里把两截句子拼在一起。账不是命运收的，是。后面是什么，录音没给。

他翻开种子书。页痕“小改即小偿，大改寻他偿”下面那片空白，墨色正从纸背往上洇，形状模糊，像一张还没显影的底片。他按了一下，指腹上什么也没沾。墨在纸里面，不出来，也不回退。

他起身往走廊尽头的饮水机挪。留观室门虚掩着，里面一个穿墨绿色工作服的女人背对他，正把一块白布折成方块。她把布压在台面上，转身。

两人隔着半扇门对上。她的目光从他脸上滑下来，落在他右手手背。

停住。

她走过来，步子不疾不徐，走到他面前站定，距离比陌生人近半步。她开口第一句不是问好。

“你手背上那个墨，用肥皂搓过吗，能搓掉吗。”

陈默的手往身后收了一下，又停住。他看她的脸。眼神很平，平到不像在提问，像在核对一个答案。

“擦不掉。”他说。

女人从工作服内袋掏出一个压扁的东西。烟盒，锡纸内衬被撕下来，叠了几折，边缘发黑。她展开，手指按住两个角，递到他面前。

蓝黑墨水写的字。被汗渍和暗褐色的印迹晕过，笔画发虚，能认出的只有前半句。

**账，命运收不走。**

后半截被撕口截断，纸毛立着。

陈默的胃往下沉了一寸。页痕上的蓝黑，自己手背上那道蓝黑，台历压痕里的蓝黑。现在第四处。同一色号。

“谁写的。”

“我哥。阿俊。”女人把锡纸翻过来，背面空白，“他那天被撞后还剩一口气，手里攥着一包烟。烟纸内衬一根一根都写，有的一个字，有的两个字，护士从他手上扒下来的，凑起来只有这半句能认。后半句让血洇了。”

她说后半句的时候语速没变。眼眶也没红。攥着锡纸两角的手指关节泛白。

“我叫阿莲。阿俊是我哥。”

陈默想起刚才护士抽屉里露出的那个字。夋。阿俊的俊。同一件事在半小时里从两个方向朝他合过来。

“你那个墨，”阿莲把锡纸收回内袋，动作很轻，像怕碰碎它，“我哥送进来那天，他左手手背上有一片一样的。护士说洗不掉。”

她掏手机，亮出一个号码。“明天下午两点，殡仪馆后门。我值班。你来找我，我带你看一样东西。别带警察，别带朋友。”

陈默记下号码。想问她全名，想问她哥的遗体在哪个柜位。她没给他机会，转身推开走廊门。墨绿工作服后摆翻起一角，白工牌上那个莲字一晃，后面还跟着半截编号，他只看清一个03。

门合拢。夜风从缝里挤进来一小股。

陈默坐回长椅，从背包外兜摸出旧手表。表盘停在22点47分，背面划着0317。他翻过来又翻回去，看表壳边缘。靠近表耳的位置多了一道新磕碰，银色底子露出来，米粒大。昨天他看的时候没有这道痕。

他把表扣在膝盖上，掌心盖住表盘。石膏里一阵钝痛，从腓骨中段往脚踝走。他拨程雨的号，响到第二声按掉。屏幕暗下去，映出自己半张脸。

他把种子书塞回背包侧兜，拉链拉到尽头，蹬着石膏腿一步一步挪出急诊楼。

台阶上风带河道的湿腥气。他掏出手机，把走廊里偷拍的烟盒锡纸照片调出来，和页痕当场结清的照片并排。两张图的蓝黑墨色在屏幕上显出细微差别：页痕的沉，烟盒的偏灰，像掺过别的东西。他放大烟盒照片，那半句话末尾那个是字的最后一笔，被什么洇断了。断口的位置，和父亲录音被掐断的地方，和林果果页痕里被省略掉的第二笔，落在同一行的相对位置上。

他盯着这三处断口看。三张图片在他指下缩放着，各自缺一截。缺的都一样长。

他把手机收进口袋，叫了车。

车行驶到半路，屏幕亮了一下。程雨共享实时位置，终点定在东门街路口。他指尖刚碰到屏幕，定位被撤回。紧跟着跳出一条文字。只有两个字。

别来。

陈默握着手机，半侧过头看车窗外。出租车刚过桥，河面上的灯影被水切成一条一条，往车尾退去。他把那两个字放大看了两遍，没回。手机翻过去扣在石膏上，屏幕的光从指缝底下漏出来一点，慢慢灭掉。
