# 第13章 账期已满

凳子腿磕地板的余韵还在，紧跟着又是一声更沉的响动，从林兰家那边穿过楼道传过来，像行李箱拉链被人猛地扯到底。

陈默的手已经按在自家门把上。他拉门出去。

声控灯亮了一层。林兰家的防盗门开着一条缝，暖光从缝里漏出来，落在水泥地上。门口扔着一双小孩的旧拖鞋，鞋底朝上，鞋帮上沾着泥点。他走过去，还没抬手，门从里面拉开了。

林兰侧身让开。

“进来。”

客厅比平时空。三只纸箱堆在墙角，胶带还没封，箱口露出一只锅盖和几根衣架。林果果坐在一只行李箱上，怀里抱着书包，眼睛落在自己的鞋尖上。电视关着，茶几上搁着半杯水，杯壁挂了一圈水珠，早凉透了。

林兰从围裙口袋里摸出一张折叠的旧纸，手背上有洗洁精的红痕。她把纸展开，递到陈默面前。纸边发毛，折痕叠了好几道。上面是父亲的笔迹。

“3月17日前若有人敲门，书给陈默；若无人敲，书烧掉。”

陈默把纸往灯下偏了偏。父亲的字他认得。一捺拖得长，“陈”字左边那一竖收得紧，末尾“掉”字最后一笔往右上挑。

“这是原件？”

“你爸留我的。”林兰把纸折回去，“他说日期到了再看。我一直压在米缸底下。”

“有人敲过门吗。”

“三天前。”林兰的声音压下去，“问隔壁是不是姓陈。我没开，从猫眼里看，一个戴帽子的男人，帽子压到眉毛。”

她停了停。

“当晚我给你爸上了炷香。翻出这张纸。”

厨房的冰箱嗡嗡响着。她抬起眼。

“你爸说你会难受一阵，但你不能垮。他早算到今天。”

陈默张嘴想问。林兰抬手，食指竖在嘴唇前。

“别问。知道多了，果果不安全。”

林果果把书包抱得更紧，下巴抵在拉链头上，始终没抬头。陈默想起站在东门街路口对面的那天早上，想起白车顶着护栏滑行的声音，变形段的铁皮离她站过的路肩不到半米。

“去哪。”

“不知道。”林兰提起行李箱拉杆，箱轮在地砖上滚了一声。

她走到门口，从围裙口袋里摸出一把钥匙，塞进陈默手里。金属凉，齿口有新磨过的痕迹。

“你爸放在我这的。说有一天你用得上。”

陈默攥住钥匙。林果果跟着母亲出门，经过他身边时抬了一下头，又低下去。防盗门轻轻合拢，声控灯灭。他一个人站在黑暗里，手心的钥匙硌着那道旧墨痕。

回到书房，他把钥匙搁在台历旁，拉出椅子坐下，翻开种子书的空白页。台灯的光落在纸面上，泛着旧书页的米黄。他要把林兰说的原话记下来：托付条件、戴帽男人、上香那晚、三天前敲门。

蓝黑笔尖落纸。

墨珠没有渗进去。它在纸面滚成一个球，往纸边滑开，留下一道干净的湿痕，像落在荷叶上。他挪了个位置再落。墨珠重复滚开，在纸面划出一道弧线，停在页角。他加大力道，笔尖压进纸，纸面凹下一道浅痕，墨还是不吃。手背绷紧，太阳穴跟着跳了一下。第三次，他换到封面内页，父亲写“种子书”那行字旁边落笔。页面纹丝不动。墨珠贴着纸面滑走，没留下半个点。

他把笔移开。墨珠反着台灯光转了一圈，像一滴渗不进油面的水珠子。他用拇指去按，指肚上干净一片，一点没进纸。

种子书拒绝落墨。这是他第一次被它挡回来。

他合上书，把台历拖到面前。3月17日那一格被三重圆珠笔圈住，圈是新的，笔油没干透，反着一点亮。旁边三个字。

收账日。

细瘦的笔迹，比父亲的字窄很多，一横一竖都收得紧。上一回他从反向压痕里把它拓出来，这一次正面就写着。台历封套的塑料膜松了，他把台历倒过来抖了抖。夹层里滑出一枚生锈的钥匙，落在掌心，五厘米长。柄上刻着一个字。他凑到灯下辨认。

兰。

窗外传来汽车启动的声音。他走到窗边。

楼下停着一辆出租车，双闪亮着。林兰把行李箱塞进后备箱，关上盖。林果果先上了车，书包抱在胸前。林兰扶住车门，抬头望了一眼老楼的三层。

她的目光扫过陈默的窗。

没有停。

她坐进后座，车门关上。车灯亮起来，慢慢拐出路口。尾灯缩成两个红点，被街角的楼挡掉。陈默在窗边站着。楼下路灯照着一小片空地，刚才停车的位置只剩一道轮胎压过的浅印。

他回到地板坐下，翻开手机，播放刚录下的那段音。林兰的声音从扬声器里出来，混着拉链的响和冰箱的嗡嗡声。他听了两遍，又摁停。

凌晨一点前后，书房门缝下传来纸张滑动的声音。

他低头。一张对折的便笺纸停在脚边。捡起来，展开。上面四行字，钢笔，笔画很稳，没有涂改。

“0317账期已满。
下一次不是记忆。”

抬头空着，落款也空着。他把纸翻到背面。一片白。

陈默走到门口，拉开门。楼道声控灯亮了。楼梯口空着，水泥地上只有从门口到楼梯的一段旧灰痕，没有第二个脚印。

灯灭下去。黑暗里，他捏着那张纸，站在门内没动。

他把纸条凑到鼻尖，纸面有股很淡的樟脑味，像从哪个柜子深处刚翻出来。陈默退回门内，锁舌落进扣槽，声音比平时脆。他走到书桌前，把纸条和生锈钥匙并排放在台灯下。钥匙柄上的“兰”字被铜绿咬掉半边，剩下三笔，像没写完的字。

他拿起手机，点开录音，把纸条上的四行字念了一遍，存成新文件。命名时手指停了一下，输入“0317账期”。保存。又点开通讯录，翻到林兰的名字。拨出。响到第五声，被掐断。再拨，关机。

他把手机扣在桌上，屏幕朝下。台历还摊着，3月17日那格三重圆圈在灯下像三只眼睛叠在一起。旁边“收账日”三个字，细瘦，窄。他伸手摸那行字的压痕，纸面凹下去，指肚能感觉到笔尖当年用力时的抖动。不是父亲写的。父亲写“珩”字最后一竖拖弯钩，写“收”字捺长。这个“收”字捺短，收得急。

陈默翻开种子书，翻到最后一页。汇款单存根夹在那里，背面铅笔字“设局者不可信”在灯下反着灰白的光。他把存根抽出来，和纸条、钥匙摆成一行。三样东西，三个方向：一笔钱，一把钥匙，一句断言。

他拿起钥匙，对着台灯看。钥匙齿形复杂，不是普通防盗门。柄上“兰”字旁边还有一道极细的划痕，像是用针尖刻的。他摸出手机拍了一张，放大。划痕是个数字，或者两个。第一个像“3”，第二个被铜绿盖住，只剩下半截弧线。

他把钥匙放回桌上，拿起纸条又看了一遍。四行字。钢笔。笔画稳。没有涂改。他注意到“账”字贝字旁写得窄，右边长。和台历上“收账日”的“账”字，同一个写法。同一个人。

陈默后背贴住椅背。台历封套里的钥匙，柄上刻“兰”。林兰临走前从围裙口袋里拿出的旧纸，父亲笔迹。戴帽男人敲门。收账日。纸条。所有线头在脑子里绞成一团，他找不到线头在哪。

他翻开手机备忘录，打了一行字：“账期已满，下一次不是记忆。投递者与台历‘收账日’笔迹同一。钥匙柄‘兰’字旁有刻痕，疑似数字3。”打完，他看了一遍，又删掉。手机比种子书安全，但手机也会丢。他把这行字抄在一张便签上，折好，塞进钱包夹层。

做完这些，他重新坐下。窗外的风把窗帘吹起一角，对面三楼林兰家的灯已经灭了。整栋楼只剩他这一扇窗亮着。他伸手把台灯拧灭。黑暗里，种子书的硬壳封面在月光下泛着一点冷灰。

他坐在椅子上没动。脚边，那张纸条被风从桌面吹落，轻轻贴在他拖鞋面上。他没去捡。
