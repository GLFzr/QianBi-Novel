# 第19章 盲区

计价器跳完最后一块钱，出租车在东门街路口前一个街口停下。陈默付钱推门，左脚先落地，石膏磕在路牙上闷响一声。河风从桥面方向灌过来，穿过石膏与绷带之间的缝隙，腓骨中段那处骨裂像被人拧了一下。

他拄着护栏站定，抬头。

监控杆在路口西北角，灰白色，横臂朝东南伸出，杆身缠着几圈褪色的反光贴。三年前阿俊被撞的位置，就在横臂投影落下去的那段斑马线上。白漆裂缝还在，护栏变形段还在，修鞋摊收了，老周的铝合金工具箱锁在路灯杆底下。

他掏出手机，点开秒表，沿路口逆时针走。经过公交站牌时站牌下没人，走到监控杆正下方，仰头找镜头朝向。横臂末端那个黑壳摄像头对着斑马线东段，视野很直。

一辆公交从东边进站。

车头切进站台区域，陈默按下秒表。车头挡住斑马线东端，车尾还在站台外。车身缓慢靠站，车门打开，几个人上车。车尾最后离开摄像头视野边缘，他按下暂停。

四十二秒。

他清零，等下一辆。第二辆进站时他压住呼吸，看车头遮住监控的那一瞬，看车尾离开的那一瞬。

四十一秒五。

两辆都在四十二秒上下。公交车进站停靠、上下客、出站，形成的物理盲区稳定得像一道固定的门帘。那段监控缺失不是被人为删掉的。三年前阿俊走到斑马线上的时候，如果正好有一辆公交进站，监控就只能拍到车头前的一截路面和车尾后的一截路面，中间那四十二秒，什么都没有。

陈默收好手机，走到公交站牌下面。

站牌是新换的，不锈钢底座，四角用膨胀螺栓固定在地砖上。底座西侧边缘的胶条被撬起来一截，翘口发黑，像用螺丝刀别过。他蹲下去，假装查看石膏绑带，右手从石膏外侧探进去，指腹贴着底座与地砖的缝隙摸。

指头碰到纸。

折叠的，有棱有角。他用两根手指夹出来，塞进口袋，动作连贯得像捡一枚硬币。站起来时，视线扫过马路对面。

便利店门口站着一个戴帽子的身影。

深色帽子压得很低，身上是件深色夹克，站在便利店门口的灯光边缘，脸在帽檐阴影里。身影没有进店，也没有走动，面朝陈默这个方向。

陈默没有转身走，也没有过街。他把左手插进口袋，右手假装整理背包肩带，手机屏朝上握着。黑屏上映出对面那个人影的轮廓。人影动了，头微微偏了一下，像在确认什么。陈默拇指在屏幕上划了一下，屏幕亮起又熄灭，伪装成随意按键。

七秒。

人影转身，沿人行道往东边走去，步子不快，也没有回头。走到路口拐角，被梧桐树影挡住。

陈默没有追。他直起身，靠住站牌立柱，从口袋里摸出那张折叠纸。

打印纸，A4裁成四折，边角磨得起毛。展开后三行字，宋体，十二号，行距均匀。

**阿俊　2019.06.14**

**程建国　2019.11.23**

**周珩　0317**

他的视线停在第三行。

周珩。0317。父亲的名字和那个编号并排躺在打印纸上，宋体字的笔画干净利落，不像手写体有情绪。可他的横膈膜抽了一下，从胃底往喉咙方向收紧。石灰石粉尘的味道好像突然出现在空气里。他张嘴换了两口气，胸口那处紧没有松开。左手小鱼际的墨渍贴着纸面，路灯的白光照下来，颜色沉得发暗。

他把纸翻过来。背面空白。纸张折过很多次，折痕已有毛边，四折，先竖后横，走向和他背包里那几件东西一样。他对着路灯比了比纸的厚度，和种子书内页差不多。

他把纸重新折好，塞进背包侧兜，拉链拉上。

手机在裤兜里连续震了三下。

阿莲的消息。第一条：**到了吗。** 第二条：**还在那吗。** 第三条：**我哥的烟盒你还带着吗。**

他盯着屏幕上的三条消息。拇指在键盘上敲了一个字，**明**。看了两秒，删掉。又重新打，**明天见**。发出去。

对面秒回一个**嗯**。

末班公交从东边进站，车灯扫过站牌，扫过他的脸，扫过监控杆。他站在原地没动，看车头切进站台区域，看车身缓缓靠稳。车门打开又关上，没有人上下车。公交车起步，车尾从监控视野里滑出去。

四十二秒。

公交车驶离，监控视野恢复，空路口重新暴露在路灯白光下。斑马线上什么都没有，白漆裂缝还在原处，护栏变形段被夜露打湿，反着一点灰。他站在原处看了很久，掌心那道旧墨渍在公交尾灯的红光里颜色又深了一层。

烤红薯摊的大爷推着铁皮炉子收摊经过他身边，炉膛余温烘到他左脸侧。大爷没有停步，头也不回地说了一句：“后生，这个路口晚上别站太久。”

推车拐进巷子，轮轴吱呀声越来越远。

陈默目送摊车消失在巷口，低头再看站牌底座。撬痕旁边有一道新的划痕，很浅，像有人用金属尖在漆面上划了一道。他蹲下去，手机灯打亮，调近焦距。

划痕的形状是个锐角，两边长度不等，长边往左下方斜下去，短边往右上收了收。

他把手机塞回口袋时，指尖碰到手表。掏出来，翻到背面，0317旁边也有一道划痕，长短两边的角度，走向。他翻出手机相册，刚拍的照片，再滑到前天晚上拍的旧手表背面特写。两张照片并排躺在屏幕上，划痕的角度和弧度完全重合。

他拇指悬在删除键上方，没有按。公交车尾灯从屏幕表面掠过，红光在划痕的凹槽里一闪而灭。他收起手机，把表扣回手腕，金属贴着那道墨渍，凉。

站牌底座的撬痕旁边，还有半枚模糊的鞋印，纹路被地砖上的灰土过滤得不完整。他蹲着看了两秒，没有拍照。站起身来，回头望了一眼便利店方向，门口灯还亮着，收银员正在整理货架。戴帽子的身影没有回来。

他把背包带子往上提了提，抬眼看向路口对面的梧桐树影，风把树梢吹得偏向东边。公交车进站的声音又从东边传来，这次他没看表。
