# 第31章 后窗

巷口墙根，手机在口袋里震了一下。

短信还亮着，七个人的本子里，有一本是你的。陈默没回头，先看门。茶社那扇合拢的木门，门缝底下那条红光还在，宽度没变，颜色比刚才深了一层，像有什么东西在门后动了一下，又停了。

他退到街口便利店的灯牌下，从内兜抽出周师傅那截纸卷。末行被蹭淡的半句下面，铅笔芯断过一次，留下一个针尖大的坑。他把纸卷举到与门缝红光同一水平线上，偏头对了一下角度。断笔坑的斜口往右上收，红光在墙面上铺开的边缘也往右上收，斜率一致。光源不在街上，在茶社内部右上方，一道没关严的门，或者柜子缝里漏出来的。

他盯着那道光看了两秒。门后有人，那人知道他已经走了，没追。

大路不能走。他贴住巷根的墙，绕到茶社侧面。两个垃圾桶，一道生锈的铁皮排水管，砖缝里积着半干不干的菜叶。石膏腿踩到碎砖上闷响了一声，他靠住墙停住呼吸，巷子里只有自己的心跳和远处一辆夜班公交的换挡声。

茶社后巷比前巷窄一半，尽头堆着几口破缸。后窗离地约两米，铁框，玻璃上糊了一层旧报纸，右下角缺了一块，暖光从缺口漏出来，还夹着翻纸的声音，一页，一页，不紧不慢。

墙角有一个废弃洗手池，底座歪着，他蹲到池子后面，石膏腿压在碎瓷砖上。视线从报纸缺口切进去——

一个人背影，坐在木桌前。深灰硬壳册子摞在手边，一摞七八本，他正一本一本地往铁皮箱里放。两只箱子，箱盖敞开。放完第一箱，他提起第二只箱子放到桌上，用马克笔在箱盖内侧描了一个数字。陈默眯眼看那个方向。第一只箱子内侧写的是 1-4，第二只是 5-7。

头目数了两遍。第一遍数完顿了一下，第二遍数完又顿了一下，像在确认数目没有错。七本。他一本一本地放，动作不快，每本放进去之前都在手里翻一页，像在核账。

陈默屏住呼吸。这个数字他见过。七个人。短信里说的七个人的本子。

翻纸声停了。

头目抬起头，朝后窗方向看了一眼。陈默缩到洗手池后面，石膏腿抵着池壁，一毫米也不敢动。过了三四秒，暖光里的翻纸声重新响起来。

就在这时，窗框从里面被推开了。

一个人影翻出来，落地的时候左小臂撞上送出来的铁皮柜角。柜角旧漆里有钉子尖露在外面，划开一道口子，血珠甩在墙面上，两颗，暗的。人影没有出声，单膝跪了一下就站起来，是阿莲。深灰上衣，头发扎得紧，兜里塞着东西。

她一步跨到洗手池后面，没看陈默，先把半本被撕毁的册子塞进他手里。封皮深灰，撕口毛糙，剩下不到一半。她压低声音，话短：“第八本，你手里。”

陈默接住册子。阿莲推了他一把，朝巷子深处扬了一下下巴，示意撤。

他没走。他把阿莲反手按到墙根拐角，从外套内兜抽出纸巾，压到那道伤口上。血很快浸透纸巾边缘，阿莲自己伸手按住纸巾另一头，没拒绝，也没谢。两个人靠着墙，都没有说话。巷子里那盏没人管的感应灯在半空里闪了一下，又灭。

陈默低头翻那半本仿本。封面布纹粗，边角不毛，没有旧纸那种被手指蹭出来的光。内页印着三个字，种子书，宋体，规规矩矩，不是手写。翻到页角，案：0317。印刷体，每一笔都平，没有顿笔，墨色偏灰，摸上去是干的，不洇纸。他把自己那本真书从内兜抽出来，翻到同一页，两串编号并在一起。真书那串蓝黑，起笔收笔带了压痕，仿本那串灰黑，浮在纸面上一层。

三处不对。纸新。墨色不对。编号没有手写感。

他把真书收好。掏出手机。

拨号音响到第二声，阿莲的手横过来，按住他的手腕。她什么都没说，只把手机从他掌心里翻过去，屏幕扣在墙上。另一只手翻开他手里那半本仿本的末页。

末页背面贴着一张照片。印刷四色，边角有折痕，像从什么地方撕下来又压平的。照片上的人穿着深色外套，站在城东夜市口的便利店灯牌下面，低头看手机。人很清楚。背景里能看到一辆折叠电动车的后架，后架上是一只褪色的旧布包，旁边立着一只绿色平台牌。

陈默认出了那个灯牌，那辆车，那只包。是他第一次搭老赵车的那一晚。

他拇指压着屏幕，没有拨出去。手机在掌心里还有余温。阿莲的手已经收回去，按在自己小臂上。伤口还在渗，纸巾一角红了。

他把 110 的通话记录划掉，屏幕暗下去。后巷远处的自行车链条响了一下，又没了。巷子尽头那几口破缸蒙着灰，看不清轮廓。

阿莲把半本仿本重新塞进他手里，撕了半截纸巾，用牙咬住一角，自己缠那道口子，血从纸巾边缘慢慢渗出来。她转身往巷子另一头走，走了几步回头看了他一眼。什么也没说，拐进一条更窄的岔巷，脚步声稀疏，很快没了。

陈默蹲在墙根，左手捏着半本仿本，右手攥着手机。照片的印刷纹路还留在手指上，一摸就糙。

他翻开仿本最后一页的装订线。半本的撕口旁边，有一道他没有注意过的小字，铅笔写的，字号比正文小两号，像后来加上的。他把手机灯贴近看。

真本持有者，于3月17日前交还。

下面盖着一个模糊的圆章印，朱红色，只剩半个边，像被水泡过。

他合上仿本，撑着墙站起来。石膏腿在碎砖上又磕了一下。茶社前巷那盏便利店的灯还亮着，什么声音都没有了。他把两本册子一真一假叠在一起塞进外套内兜，拉上拉链。

手机屏幕突然亮了一下。

还是那个陌生号码。第二条。

“还有二十四小时。别写。”
