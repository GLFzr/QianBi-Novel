# 第24章 看窗台

公交车最后一排，手机屏幕的光映在车窗玻璃上，备忘录的创建时间又跳了一次：二十三点零八分。陈默盯着那行数字，指头冰凉。他退回设置页，翻到“登录设备管理”，一栏陌生记录压在最底下，设备名只显示尾号。

0317。

他点进去。记录写着该设备十分钟前同步过一次，同步内容正是备忘录全文。创建时间与同步时间在同一分钟里发生，像有人一边打字一边把字塞进他的手机。他试着更改账号密码，系统弹出提示其他设备需重新登录，他按了确认。进度条走完，屏幕暗了一下。

不到十秒，顶栏又弹出一条新备忘录。

标题还是那五个字：看窗台。别回。

创建者显示本机，修改设备一栏是他的手机型号。但同步来源仍然挂着那行“未知设备（尾号0317）”。他把手机握紧，石膏腿顶到前排座椅背，磕了一下。改密码没用。对方没登他的号，是往他号里塞东西。

他切到通话记录，尾号0316的号码静静躺着。拇指挪过去又挪开，转去相册，翻出之前拍的老屋窗台照片。照片里窗台边缘空着，木面上一层灰。他放大看，灰层完整，没有痕。

他在下一站下了车。等红灯时给阿莲打电话，响两声就接通。

“这么晚。”阿莲声音低，背景里有铁器碰撞的响，像在整理什么。

“我去趟老屋。”他说。

那边停了一下。“别一个人去。”

“很快回来。”

沉默。他听见阿莲呼吸变了节奏，像咽了半口话又咽回去。

“你爸当年也说很快回来。”她说，先挂了。

陈默在绿灯亮起前把手机握在手里，屏幕贴着掌心，忽然不觉得凉了。他换了两趟公交，最后一段路走进城西巷子。老楼底下没人，声控灯坏了两层，他用手机手电照着上楼。石膏磕在水泥台阶上，响一声，停一下。

书房里还是他上次离开的样子。椅子原样，台灯位置没动，窗关着。他蹲下来，手机灯贴着窗台扫过去。光柱里浮着灰，台面边缘有一道弧形的压痕，方向朝外，像有人拿圆的东西压着往窗外推。压痕旁边半枚鞋印，只有前脚掌，鞋底纹路是六角形颗粒，一颗一颗排开。他用手机微距凑近拍，拍完又拍了一张全景。站起来时，从窗玻璃的反光里看见对面楼有两个窗户同时熄了灯。

他关了手电。站在暗处，眼睛贴着窗框。十几秒后，街面上出现一个戴帽的身影，站在电线杆旁边，仰头看老屋窗户，看了大约五秒。帽檐压着，看不清脸。那人收回目光，侧身往巷口走。陈默先蹲下拍了窗框和窗台全景，确认戴帽男人在画面里留了一个模糊侧影，才转身往楼下跳。石膏腿磕在楼梯上，他扶住扶手单脚落地，疼得闷哼一声。

追到街面，巷口只剩一盏坏掉的感应灯和三个垃圾桶。他跳着脚赶到路灯下，消防栓旁边躺着一枚被踩扁的烟头，滤嘴上有清晰的牙咬痕。他蹲下去，抽出一张纸巾，隔着纸把烟头包起来，塞进外套内兜。

巷子里没人。他后退两步，抬头。

老屋三楼的窗台边缘在路灯下泛着一道很窄的浅色反光，金属样的，不像是木面的颜色。

陈默翻出通话记录，拨了尾号0316。听筒里响了两声，女声报：“您呼叫的用户已启用短信呼。”他挂断。五秒后，一条短信进来，没有署名：

“您呼叫的用户已启用短信呼。您的号码已被记录”

他盯着最后六个字看了三遍。把短信截屏，存进备忘录里一个他自建的分类。分类名他打的是0317。

手机又震了一下。

还是备忘录。还是那行字。创建时间跳成二十三点十七分。但这一次，末尾多了一个句号。

看窗台。别回。

他退回巷口阴影里站着，外套内兜的烟头顶着胸口。石膏腿撑在水泥地上，有点晃。对面三楼那扇窗黑着，但窗台那道反光还在，钉在暗处。他摸出铜扣，扣面的林字被掌心焐得发温。他没再往老屋走，也没走远，就立在灯与影的交界上，等下一辆末班车。

风从巷口灌进来，把烟头和纸巾一起吹得贴紧了他内兜的布料。

他把手机翻了个面，屏幕扣在大腿上。公交车从主路拐过来，远光灯扫过巷口，照亮消防栓旁那圈烟灰。车没停，是夜班线路，司机大概没看见阴影里站着人。车尾灯缩成两个红点，消失在下一个路口。

他重新点亮屏幕。备忘录里那个句号盯着他。之前每一条都是短句，没有标点，像命令，像备忘，像随手敲下的一行字。现在多了一个句号，等于有人告诉他：我知道你看到了。这个句号是句号，也是已读。

他退出备忘录，打开通讯录，翻到程雨。打了一行字：建设路173号今晚有人来过。发出去。这次对面隔了快一分钟才回：你还在那？他打：走了。对面又隔了十几秒：明天我去调173号周边监控，你别再一个人去。

他没回这条。把手机塞进口袋，弯腰把石膏腿往阴影深处收了收。风从巷子另一头灌过来，垃圾桶边的酸腐味扑上脸。他想起阿莲在电话里说的那句“你爸当年也说很快回来”，当时他没接。现在站在这里，那句没接的话像块石头压在后脑勺上。

他掏出那枚烟头，纸巾包着，滤嘴的牙咬痕在路灯余光里显出一道浅坑。他凑近闻了一下，烟丝烧过的焦味还在，不重，但新鲜。他捏着纸巾角把烟头翻了个面，滤嘴接缝处有一小段被咬扁的痕迹，齿印间距很窄，像是习惯用门牙咬住烟嘴的人。他把这个细节记进备忘录，分类还是0317。

巷口对面那栋楼四层的灯还亮着。他抬头看了一眼，窗帘已经拉上了，人影没了。他收回视线，发现老屋三楼那扇窗的窗台反光弱了一些，像被什么挡了一下。他眯眼再看，反光又回来了。他判断是路灯电压不稳，或者有车经过时车顶反光扫过。

手机第三次震。还是备忘录。创建时间二十三点二十一分。内容没变，句号还在。但这次标题栏多了一个字：看窗台。别回。等。

他盯着那个等字。第一次出现新词。之前所有备忘录都是指令加警告，现在多了一个动作。等什么。等谁。等多久。他把这三个问题在脑子里过了一遍，没有一个能落地。他把手机锁屏，屏幕暗下去，映出他自己的脸，石膏腿，和身后那堵斑驳的砖墙。

他决定不走了。末班车已经过了，打车回出租屋要四十多块，他卡里余额不够。他退回老屋单元门，用那把生锈钥匙开了楼道门，声控灯没亮。他在黑暗里一级一级往上跳，石膏磕在台阶上发出闷响。上到三楼，他没进书房，在楼梯转角坐下来，背靠墙，把外套拉链拉到下巴。

从这个角度，他能看见书房门缝里透出的一点路灯光，和窗台那道反光的边缘。他把烟头从内兜摸出来，放在膝盖上，纸巾没拆。他闭上眼，耳朵里全是公交车发动机的余震，和巷口那阵风灌进来的声音。

手机放在腿边，屏幕朝上。二十三点二十六分，备忘录没有新动静。他睁开眼，盯着门缝里那道光。如果窗台上那枚旧手表真的会出现，他得第一个看见。

他把铜扣从口袋里摸出来，塞进左手掌心，五指收拢。扣面的林字压进掌纹里，硌着。他没再松手。
