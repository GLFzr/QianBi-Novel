# 第32章 欠账人

圆章的朱红蹭在指腹上，一道，斜的。陈默把手指按在裤缝上蹭了一下，没蹭掉。

仿本末页那行铅笔字压在眼皮里。真本持有者，于3月17日前交还。撕口、末页照片、圆章印，加上陌生号码那句“还有二十四小时”，三条线拧成同一根绳：茶社靠仿本在找真书，也把他这条线拽进去了。

他撑着墙站起来。石膏腿踩在碎砖上，一滑一磕，腓骨中段那处钝痛从脚踝往上返。墙根下那几口破缸蒙着灰，缸沿裂了一道长口。巷子尽头阿莲的脚步声还没走远，压在夜风和远处公交车换挡的底噪里，稀，但能分得清方向。

他往那条声音的方向追。

岔巷比后巷窄一半。两侧砖墙夹着一条缝，砖缝里的夜露被路灯照得发亮，像一层没干透的漆。路灯坏了两根，隔一段黑一段。陈默压低重心，右手贴着墙走，石膏腿拖在后面，尽量不碰碎砖。

走到巷子中段，他停住。

前方车棚底下有一点火苗。阿莲背对着他，右手攥着一张纸的一角，火苗正舔着纸边，纸卷起来，发黑。她低着头，另一只手挡着风，头发被吹散一绺，贴住脖子。

陈默几步上前，右手抓住她手腕。火苗偏了一下，烧到她的指节。她松开手，纸掉在地上，火星踩灭在砖缝里。纸面烧掉小半张，边上还看得清字。手写的，几十个名字，一列排下去，末几行被红笔圈过。

阿莲没有挣。她低头看了一眼那张纸。夜风把她额前的碎发吹起来，那绺头发落回小臂上，纸巾渗了红。

“你进去，到底为什么。”陈默松开手，退半步。

阿莲把纸从地上捡起来，捻掉烧焦的边。她没答。把纸对折，再对折，塞进夹克内袋。指尖上烧红了一小块，她没看。

车棚的铁皮顶欠了一块，风从缺口灌下来，把两人的呼吸都吹散了。

“茶社头目跟我说过，”她开口，声音比刚才低，“他手上七本仿本，编号01到07。”

陈默没接话。

“我哥三年前在茶社买过一本，编号03。”

她的手从夹克内袋抽出来，把那本半本仿本塞回陈默手里。指腹冰。

“我要知道第八本的编号。”她说，“如果也是03，我哥那笔账，早就跟到我了。”

陈默捏着仿本边缘，纸边粗糙。他看了一眼她的左小臂。纸巾已经透红，血从边缘往外洇了一小圈，还没结。她在医院走廊里认他手背墨痕的时候，就是这个眼神，平，直接把答案摆上桌。

“你退出去。”他说，“剩下的事我来。”

阿莲摇头。她往车棚里退了一步，背抵住铁皮。铁皮凉，她没缩。

“退出去了，那本03就没人管。你也管不了。”

她侧身，从车棚另一头走出去，步子不快，往茶社方向。走到巷口，回头看了他一眼。什么也没说。拐进一条更窄的岔巷，脚步声稀疏，很快没了。

陈默站在原地，石膏腿在砖上磕了一下。巷子里重新安静。

回到出租屋，过了凌晨一点。他把东西一件件摊在桌上。

仿本末页扯下来平放。铅笔小字，圆章印，撕口。他用手机微距拍了三遍，换着光，一直到纸纹和印泥边沿都能看清。

铁皮箱分装编号。他写在纸条上：1-4，5-7。跟照片并排。

头目原话。他打字，逐字敲：“你爸当年那本我们也有过一个抄本。”敲完检查两遍。

最后是阿莲按伤口那张纸巾。他没扔，从外套内袋取出来。沾血那一角已经硬了，边上发褐。他用手机拍下。

四样东西，四张照片，都存进一个新相册分类。分类名他打的还是0317。

他拨程雨电话。响两声就通。他把城南槐树巷13号后院改运互助茶社的地址、后巷金库、两只铁皮箱、七本仿本分装编号、末页圆章索取、头目原话，一句一句说清楚，说到最后一句时嗓子有点发紧。

“你把照片转出去，匿名报警。别写你，也别写我。”

电话那头安静了五秒。程雨的声音压得很低，问他是不是已经想好了。

“想好了。”

“派出所管那个片区。我明天一早发。”她说话的速度比平时慢，“你这两天，尽量别露脸。”

陈默应了一声，把手机从耳边拿开。石膏腿架在另一张椅子边，一夜没睡。

凌晨两点五十几分，程雨第一条短信进来。

“警察去了。后巷堵了两个搬箱子的。”

不到十分钟，第二条。

“头目跑了，从茶社暗门。箱子里七个本子扣了。”

第三条来的时候刚过三点。

“头目被截在河堤。口供里说，仿本模板是从城西殡仪馆一个姓周的老头那儿拿的。”

陈默逐条截图。翻到通讯录，周师傅那个号码停在屏上。拇指悬在拨出键上方，没按。

窗外天还黑。城西方向的路灯在雾里发黄。他把真书和半本仿本一真一假叠在一起，塞进外套内兜，拉链拉到底。

走到窗边，拉开一角窗帘。楼下巷口空着。再往远处看，便利店灯牌下，一个戴帽的身影正从灯圈里拐出去，朝城西方向。帽檐压着，肩比常人的窄，背影很快缩进楼影里。

他放下窗帘，没追。

手机在掌心亮了一下，又暗。屏幕上方浮出一行系统提示。

备忘录已同步。

他点开。创建时间刷到了三点四十七分。内容一行，横平竖直，和三天前门缝下那张纸条同一只手。

“还差一天。”

陈默把手机翻过来，屏幕扣在窗台上。窗外一辆过路车的灯光扫进来，在窗帘缝里划了一道，又收了。他左手按在内兜外，隔着布摸到那本旧书的硬壳。掌心那道蓝黑墨痕贴着布面，凉。
