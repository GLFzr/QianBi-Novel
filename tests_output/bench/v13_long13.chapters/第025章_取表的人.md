# 第25章 取表的人

后背靠墙靠到发麻。手机在膝盖上亮起来的时候，陈默先听见了自己后颈骨转动的声响。

程雨的短信，就一行字：“监控调到了。戴帽的。建设路173号对面。昨天夜里。”

他拇指悬在回复框上，停了两秒，敲了个“嗯”发出去。锁屏。屏幕黑下去，映出石膏腿的轮廓和身后那堵斑驳的砖墙。书包垫在腰后，两块东西硌着背：一块是钱包，一块是那枚铜扣。铜扣塞在左手掌心，扣面的“林”字压进掌纹，已经硌出了一道红印。

程雨那句“别再来建设路”压在对话框最底下，他没回。

凌晨三点多，书房里传来响动。

不是风。老屋的窗框被风吹动是闷的，像布包着木条撞墙。这个声音脆，频率快，一齿一齿地咬合着走。金属。齿轮。

声控灯没亮。

他睁开眼，屏住呼吸听。咔嗒，咔嗒，又响了三下，停住。石膏腿落地的时候，痛感从腓骨往膝盖窜，像有人用指头顺着骨头往上推一根湿铁丝。他撑墙站起来，单脚跳到书房门口。门缝里那道路灯光今夜特别亮，平铺在地砖上，像一块没裁齐的白布。

推开门。

窗台上多了一枚手表。

黑色皮表带，裂口从第二孔扯到第四孔。金属扣环生锈，表镜布满细密划痕，像被砂纸磨过一圈。他往前挪了两步，手机屏光照上去。

日期窗口：3月17日。时间：22:47。秒针停在九与十之间，斜着，卡在刻度线上。

他没动。右手不自觉地摸向背包侧兜。

兜里的表还在。他把它取出来，并排放在窗台上。两块表搁在路灯的黄光里，表盘大小一致，刻度样式一致，表带材质一致。但窗台上这块更旧，表壳边缘的氧化层已经发暗红，像渗过血又干透的颜色。

他翻过第二块表，凑到窗边。

背壳上，0317那串划痕旁边，多出一行极浅的刻字。他借着路灯光辨认，一个字一个字地认。

已。偿。

后面还跟了一下。

木字旁。

林。

指尖按在“林”字上，刻痕边缘有毛刺，蹭着皮肤。他认得这种刻法，父亲在剪报册第三十八页背面写过“代价已偿：林建国”，笔画走势和这个“林”字一模一样，都是先竖后撇，末笔往右下带一点钩。

他从内兜掏出铜扣，边缘卡进表壳底部的缝隙。第一下没撬动，金属滑了，蹭出一道白痕。第二下他把掌根压上去猛推，表壳弹开。

机芯暴露在路灯的黄光下。摆轮停在正中，像一颗冻住的心脏。齿轮上覆着一层薄锈。

摆轮旁边，塞着一卷纸。

比火柴棍还细，卷得很紧，塞在机芯和内壁之间的缝里。他用指甲尖一点点挑，纸筒落在掌心，轻得几乎没有重量。

展开。纸条极薄，半透明，对光能看见背面。上面是铅笔字，一笔一划往右上斜，父亲的手笔。

“别信拿表的人。”

下一行。

“陈默，离开老屋。今天。”

他翻到背面。空白。纸边有撕口，锯齿走向不齐，但形状眼熟。他从钱包夹层抽出父亲遗书的第三页，把两张纸并到路灯下。缺口对缺口。严丝合缝。

他把纸条凑近灯，字迹边缘的铅笔屑还在，没有被摩擦过的痕迹。写完到塞进表壳，中间或许没人碰过。

今天。他摸出手机看日期。3月16日。

表上是3月17日。

明天。

他捏着纸条准备塞进内兜。掌心里的表动了一下。

不是他的肌肉在抖。是表盘里边的机械在运转。秒针跳了一格，逆着走，从九与十之间跳回八与九之间，停住。日期窗口闪了一下，数字从17跳回16，又跳回17。像有人从里面拨了一下，没拨准。

他合拢手掌，把表扣在掌心。抬头看窗帘。

窗帘没动。窗外，街对面三楼那扇窗，昨晚他看见戴帽男人站在后面的那扇，灯亮着。

有人站在窗前。

隔着两层玻璃和一道街，看不清脸，只能看出一个肩宽偏窄的轮廓，没动。他不知道对方看不看得见他，但他现在站在书房正中央，窗台的路灯光把他的影子拉在身后的墙上。

他把两块表塞进内兜，纸条折好夹进手机壳，拉死背包拉链。退出书房时没回头。

跳下楼梯。石膏磕在台阶棱角上，闷响一声接一声，从三楼一直滚到二楼。声控灯始终没亮。二楼拐角有一滩水，他脚底一滑，扶墙撑住，墙面湿冷，水从三楼方向往下滴，带着铁锈味。他没停，继续往下跳。

冲出单元门，夜风灌进领口。他扶住路灯杆喘气，回头望老屋三楼。

窗台空了。

金属反光没了。水泥边缘剩一道弧形压痕，像什么东西被拿走，或者被换了个位置。他站在路灯底下看那道压痕看了十几秒。弧度、长度，和兜里那块表的表壳一模一样。

他低下头。

右手手腕上一圈白痕。不宽不窄，恰好是表带的宽度。晒痕一样的颜色，比周围皮肤浅一号，边缘发灰。

他从未戴过表。

夜风从袖口灌进去，白痕边缘泛起细密的痒。他拉起袖子盖住白痕，转身往巷口走。书包里两块表贴着后背，硬邦邦的。铜扣还在左手掌心，他没松开。

走到巷口路灯下，他停住。身后老屋方向没有动静。对面那栋楼三层的灯已经灭了。

他从裤兜里摸出手机，想确认时间。屏幕亮起来的时候，锁屏上又跳出一条备忘录：

标题没变。内容多了一行。

“表归你了。别信我。”

创建设备栏，尾号0317亮着。
