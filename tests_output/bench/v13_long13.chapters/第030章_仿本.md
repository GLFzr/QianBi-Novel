# 第30章 仿本

垃圾通道的铁门内把手硌着掌心那道口子，血珠还没干。陈默背贴潮墙，把纸卷从左手换到右手，用牙咬住纸缘，慢慢捻开。

铅笔字。字瘦，起笔收笔都带一点抖。周师傅的字。

纸卷不长，写着一个地址城南槐树巷13号后院。后面跟着一行警告。改运互助，假书收了七个人的本子。三一七之前别去。末尾还有半行，被蹭得很淡，他把纸凑到手机屏的光上才认出。那本仿的，是不对的。

侧门方向传来门轴的一声轻响。

陈默停住，把纸卷往内兜塞。门缝那边，一道人形把光挡断又让开，搭在门把手上的那只右手收进去。人影侧身进门。门缝里透出的光在地面拉长，又收短。侧门轻轻合上。

他抓住这一瞬，往垃圾通道另一头退。通道尽头有出口，铁栅门卡着，他用肩顶开，侧身挤出去，落在后墙外的窄巷。石膏撞在排水管上闷响一声。他没回头，贴着墙根往东走，绕开主路，穿过两条没有路灯的巷子。

回到出租屋时天还黑着。他换了件干净外套，把脏的那件反过来搭在椅背上。

灯管有点闪。他把纸卷在床沿上摊平，用两只手指压住两头。周师傅的字看第二遍更清楚：城南，槐树巷，13号后院。改运互助。假书收了七个人的本子。三一七之前别去。

他数了一遍七个人这三个字的笔画。铅笔芯在七字上断过一次，留下一个针尖大的灰点。

他掏出手机，把纸卷拍了两张。一张全景，一张末行。末行那半句被蹭淡的字拍不清楚，他侧着灯又拍了一张。然后他翻到备忘录。顶部还是那行尾号0317的创建设备。侧门钥匙开过的锁，会锁两次。他盯着看了一会儿，切到地图，搜槐树巷。

一条。老城区，离这里不到六公里。

窗外的环卫车咔地响了一声，又停。天边刚有一线灰。他决定先走纸卷上这一条。把纸卷折成四折，夹进钱包内层，出门。

槐树巷比地图上窄。两边是低矮的平房，墙根长着青苔，晾衣绳横跨巷顶，挂着没收的衣物，潮气重。13号是一扇旧木门，门对着巷，半掩着。门楣上钉了一块褪色的小木牌，牌子上的字被雨淋得起皮，只认得出互助两个字。

他推门。

院里比外面干净。青砖地扫过了。摆着两张方桌，藤椅三四把，桌上一只紫砂壶，壶嘴正冒着白汽。壶旁边倒扣着两只玻璃杯。

桌后坐着一个中年男人，四十来岁。穿一件深灰夹克，袖口没挽，手搭在桌沿。见陈默进门，目光先落下来。

“你手上那道墨。”男人开口。声音不高，字咬得很实。“肥皂搓不掉。”

陈默没答。拉开对面的藤椅，坐下。椅腿在砖地上刮了一声。

男人看了他两秒。伸手到桌下，提出一只布包，放在膝上解开结。布包里又是一层油纸。他把油纸摊平，取出一本书，放在桌上，推过来。

深灰硬壳。磨白的边角。跟种子书放在一起，像一对。

页角写着一串手写数字。案：0317。

陈默没有立刻碰。他先看封皮的色。灰里带一点蓝，和父亲那本几乎一样。然后他伸手，翻开封皮。

手指触上去的瞬间就知道了。纸面太滑。父亲那本的内页，纸边都是氧化的毛口，摸上去像细砂。这一本很整，边角齐，没有毛边，也没有泛黄起翘的地方。

他翻到内页。字写了两页，格式模仿得像。名字、时刻、地点、动作，都照抄。但墨色不对。父亲用的是蓝黑墨水，干了之后边缘会泛一层极淡的青。这一本的字是碳素黑，直，不透纸，纸背没有洇。

他再翻回页角，看那串编号。0317。

笔画是横平竖直。每一笔都收得齐，没有顿笔。父亲写数字习惯往右上斜，收笔往下压一点。手记的字虽然工整，横折起手处也带一点小小的钩。这串编号什么都没有。

他合上仿本，推到桌子中间。没有说破。

“这本书谁给你的。”

男人没有立刻答。他伸手把桌上的紫砂壶拿起来，把两只玻璃杯翻正，斟了一杯，推给陈默，又斟一杯自己端在手里。壶盖放回去的时候磕了一下壶沿。

“你爸当年那本，我们也有过一个抄本。”

陈默的手指在仿本封皮上收紧了一瞬。他松开。没有追问。

他站起来。

男人没有拦，也没有送。只把杯子送到嘴边，喝了一口。陈默转身走向木门，推门出去。身后传来壶盖轻磕紫砂壶沿的声音，一下，很短。

巷子里比来时亮了一点。他走到巷口回头。

那扇木门已经合拢。门缝里没有光。整扇门像一面剥了漆的旧墙，安安静静长在那里，刚才那间茶社本来就只是茶社。

他站在巷口，从内兜摸出真书。翻到页角。案：0317。蓝黑墨，边角磨白。

他从外套内兜抽出纸巾，展开，把周师傅那截纸卷重新摊平。末行被蹭淡的半句下面，还有两笔他没看清的。他把手机灯斜着打上去。

那本仿的，是不对的。

不对两个字后面，铅笔芯断过一次，留下一个针尖大的坑。

他把纸卷折回钱包。手机在口袋里震了一下。

陌生号码。一行字。

“七个人的本子里，有一本是你的。”

他盯着这行字，拇指按住屏幕，没有回。号码归属地显示本地，后面几位他认得。和之前“别去建设路”那条短信，末尾四位相同。

他把手机塞回口袋，抬起头。

茶社那扇合拢的木门，门缝底下，透出一条极淡的红光。宽度不到半指。像什么地方的倒车灯，或者别的什么颜色从里面打出来。

他退后半步，转身往巷外走。

石膏腿在砖地上拖出一道痕。
