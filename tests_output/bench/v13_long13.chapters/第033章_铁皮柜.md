# 第33章 铁皮柜

出租屋窗帘缝刚透出灰白，陈默坐在床沿，手机贴在耳边。嘟声响到第四下，无人接。再拨，关机。周师傅的号码像被人从另一头按灭了。

他把手机搁下，从床头拿过昨夜整理的照片袋。仿本末页、圆章拓印、铁皮箱分装编号、头目原话、阿莲的染血纸巾，五张，一张一张过目。相册最后是备忘录截图，还差一天，创建时间停在三点四十七分。他把照片袋收进背包，掌心那道旧墨痕蹭过布面，凉。

手机在掌心震起来，号码是阿莲的。

“陈默。”她语气比平时快，声音压着，“周师傅出事了。昨夜在殡仪馆后门，被人从背后推倒。右臂骨折，额头上缝了针。现在市二院骨科，住院部六楼。”

“谁干的。”

“他不肯细说。”阿莲那边有推车的响动，“只让护士转告一句话，来找我的人，手里有本子。”

陈默握手机的手指收紧。他问清床号，挂了电话。穿衣出门，石膏腿撑楼梯扶手，一级一级往下跳，腓骨中段那处钝痛从脚踝返上来。拦下出租车，报市二院。

车过桥时手机又响。程雨的短信，三条一起进来。他点开。后巷堵住两个搬箱子的，七本仿本扣了。头目从暗门跑掉，在河堤被截。口供里说，仿本模板是从城西殡仪馆一个姓周的老头那儿拿的。

他回了一个收到。抬眼看窗外，河面的灯影被水切成一条一条，往车尾退去。周师傅被袭，和这条口供，前后差不到十小时。

市二院骨科走廊的灯管有一段在闪。六楼靠窗床位，周师傅仰面躺着，右臂架在石膏支架上，额角贴一块纱布，边缘渗着淡黄。监护仪在床头柜上方亮着绿线。

陈默走到床尾站住。

周师傅眼皮动了动，睁开。浑浊的眼神在他脸上停了两秒，认出来。右手打了石膏动不了，他用左手抬起来，抓陈默的手腕，把陈默的掌心翻向上，用指腹贴上去。

第一笔，横，带个弧。他停了一下。第二笔。陈默看懂了，是三。他接着写，一竖，一折，一横。十六。

写完，他手指松开，嘴唇动了几次，声音很轻，像从气管深处挤出来的。

“柜子。不要让他们先到。”

说完又闭眼。监护仪绿线平直地走。

阿莲从水房回来，手里拎着暖水瓶和一只塑料袋。看见陈默站在床边，她把暖水瓶放在床头柜上，走到对面。

“你手上有灰。”她看了他一眼。

陈默低头看掌心，墙皮灰蹭在掌纹里。他把周师傅在他掌心写的两个笔画用手机拍下来，收好。他看着阿莲：“你守着，别离开病房。他一醒，发消息。”

阿莲点头，没问去哪儿。她把塑料袋放在椅子上，里面两盒粥。陈默转身走出走廊。电梯门合拢前，他回头看了一眼，阿莲已经走到床边，替周师傅把被角掖平。

出租车在殡仪馆门外一个街口停下。陈默付钱下车，绕到后门侧墙。外墙贴着灰白瓷砖，缝隙里的白灰干裂。侧门锁着，门框边接了一段铁皮通风管，管口蒙着滤网，滤网角的一颗卡扣松了。

他左右看，巷子空。钥匙串摸出来，齿尖撬开卡扣，滤网掀到一侧。管口比想象中窄。他把背包先塞进去，再侧身，石膏腿先探，肩蹭着管壁滑进去，落在档案室地面，一层白灰腾起来，呛得他咳了两声，又压住。

灯管在头顶闪灰光。一排铁皮柜靠墙立着，编号白漆写的，从001排到3开头。墙角堆着几只塑料筐，筐里是散页。地上有拖痕，从门口拖到316号柜前，又被抹了一下，没抹干净。

316号柜的抽屉被拉开一半。

陈默走过去，蹲下。手指搭在抽屉边缘，纸页边角齐整，但中间有一段被往后推过，页间距不匀。他拉开抽屉。里面的记录按编号排，每一页都有手写批注、日期、时段。他翻到末页位置。

撕口齐根。被撕走的纸一张不剩，只剩页根留在装订线的胶里，边缘发白毛糙。他用指腹摸了一下页根，胶已经干透，撕的时间不短，至少几个小时。

他把抽屉里的纸翻回原位，手指探到最里侧的夹层。夹层是抽屉底和外壳之间的一道薄缝，平时塞不上东西。他指尖碰到一小片纸，比指甲盖大一点，折叠着，塞得很深，像故意留在那儿。

他捏出来。极薄半透明，铅笔字。展开在膝盖上，起笔往右上斜，横画压得重。他只看得清先一行半截。

若我不改，此事无解。

父亲的笔迹。和薄纸清单、遗书同一只手。夹层再往里摸，摸到一小卷胶带，纸卷末端缠着，绕了两圈，没撕开。

走廊传来脚步声。

一步一步，近。陈默把残页和胶带塞进内兜，合上抽屉，退到最边上一排铁皮柜后面，蹲下，手机屏幕按灭，石膏腿收拢。铜扣攥在掌心，扣面压在指腹上。

脚步声停在档案室门口。

门把手转了一下。金属声很轻，转到底，停住。陈默贴着铁皮柜侧面，屏住呼吸。门没有推开。把手转回原位，脚步声沿走廊往另一头去了，一下，一下，慢慢远。

他蹲着没动，数到自己心跳了四十下才起身。侧耳听，走廊安静。他回到316号柜前，把抽屉推回半开的位置，跟来时一样，又从兜里掏出一枚硬币，垫在抽屉侧面底缝里，薄薄一片，卡住。以后谁再拉这个抽屉，硬币会滑一下。

他记下柜号，退出通风管，卡扣复位，落在殡仪馆外墙的阴影里。远处火化炉烟囱亮着一点红光。天光发灰，还没全亮。

陈默贴着墙根站住，喘了两口气。内兜的残页硌着肋骨，铜扣贴着掌纹。他刚抬手想把滤网再按平，巷口阴影里有人。

身形不高，肩比常人窄。穿深色夹克，帽檐压着。不是周师傅被袭那晚戴帽男人站的位置，但站姿像一个人练出来的，脚跟不落地，随时能转身。

对方没动，也没说话。抬手把帽檐往下压了压。

陈默没有跑，也没有掏手机。他左手按住内兜的残页，右手垂在体侧，看着那个人。

两个人隔着一条巷子，谁都没先动。
