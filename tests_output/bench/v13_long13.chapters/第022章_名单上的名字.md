# 第22章 名单上的名字

台灯底座压着第三页，折痕没有回弹，拱起的纸脊投出一道细影。

陈默在黑暗里坐了很久，久到石膏外面的绷带被小腿焐出一层薄汗。他拧亮台灯，光从底座边缘漫上去，照在那三行字上。建设路173号302室。找沈照。别查0317，别找收账的人。

他摸出手机，屏幕的光刺得眼睛发酸。搜索栏里先敲“沈照”，后面跟了一个空格，指尖停住。滨河区。

搜索结果前五条都是同名的人。他往下划，第三条是一个本地交通事故信息聚合页，页面做得粗糙，蓝底白字的分类表，事故时间、路段、定损方，一列一列排。标题挂着半年前的日期。沈照。这个名字在定损方那一栏出现。陈默把页面往下拉，又一条。再往下，再一条。近一年，四起夜间事故，最晚的凌晨两点十一分，最早二十三点。沈照经手了其中两起。

他退回去，把这个名字和四起事故的路段抄在便签上。桩号、路名、方向。这四个路段有两个共同点：都在二环外，都靠近货运通道。时间全在深夜。

他把手机切到备忘录，翻出前几天从互助群截下来的路线信息。群主每周推一次“夜间高价单”，比普通单贵三到五倍。一条一条比过去。他往下翻，看到上周三那条。建设路。

手指停住。

建设路出现在群主推送里。而沈照经手的事故中，有一段就在建设路与货运通道的交叉口。时间段也对得上，凌晨一点前后。

他靠在椅背上，把便签翻过来，用蓝黑笔在“建设路”下面画了一道线。笔尖落在纸上，石膏腿在桌下磕了一下，骨裂处从深处往上返了一线酸。

他盯着那两道交叉的线看了几秒，合上便签，摸起手机。通讯录翻到程雨，拨出去。响了一声就通了。

“喂。”程雨声音清醒，不像刚被吵醒。背景里有翻纸的响动。

“是我。这么晚打给你。”

“在整理我爸的东西。”翻纸声停了一下。“你说。”

陈默把便签展开。“你爸那堆卷宗里，有没有建设路相关的司机单。上个月到现在就行。”

“你等一下。”

电话那头，纸摞被一页一页翻过去，哗啦，哗啦，间或夹着几句低声念编号的碎语。陈默站起来，走到窗边。楼下路灯照着十字路口，空的。

“有了。”程雨的声音拉回来。“上周三。接单司机姓方，路线从梧桐里走建设路往北，原定十一点出发。”

“原定？”

“群主把出车时间往后推了两个小时，改成一点。备注里写的是‘避开检查’。”程雨翻了一下纸，“路线绕得奇怪，不走直路，拐到货运通道那边再掉头回来。”

陈默把手机换了个耳朵。“编号多少。”

“你等一下，我找封皮。”

翻纸声又响起来。他站在窗边，石膏腿的重心压在前脚掌，小腿外侧有点胀。楼下路口有一辆电动车经过，没停。路灯在路面上铺开一片惨白。

“找到了。卷宗编号是——”

敲门声。

三下。停。两下。

陈默握着手机的手收紧了。这个节奏。三下停两下。跟殡仪馆后门那个晚上一样的拍法。

程雨那边没声音了。过了两秒，她压低了声音说：“等一下。”话筒搁在桌面上的闷响传过来，接着是脚步声，往门口去。

他站着没动。耳朵里只剩电话那头的底噪，空调在嗡，还有他自己的呼吸，压得很浅。

脚步声停了。门开的声音很轻。他听不清外面的人说了什么，只听到程雨回了一句什么，语气平稳，像在闲聊。

然后什么声音都没了。

陈默低头看自己的手。左手小鱼际那道墨痕还是老样子，边缘淡了，轮廓在。他从外套口袋里摸出一样东西，攥在掌心。铜扣。阿莲塞给他的那枚，扣面刻着“林”字，铜绿咬掉了半边笔画。金属边缘压进指腹，留下一道浅浅的印。

电话没有挂。他等。

窗外的路灯闪了一下，明灭之间，十字路口空荡荡的。对面楼有一扇窗亮着，有人影晃过去，又暗了。

程雨的脚步声回来了。比刚才快，鞋底在地砖上敲得密。她拿起话筒，喘了一口气，声音压得很低。

“陈默。你别来。”

他刚要开口，她接着说：“有人在敲隔壁的门。”

电话那头传来两下敲门声。比刚才那次重。程雨没再说话，但话筒也没搁下，他能听见她呼吸贴着听筒，又轻又急。

他把铜扣攥得更紧，指腹上那道金属边缘陷进去的印子慢慢变白。

“你锁门了没有。”他问。

“锁了。”她的声音很稳，尾音在抖。

楼下的路口，路灯又闪了一下。有人从拐角走出来，穿深色外套，走得不快，经过路口时偏了一下头，没有停，继续往东走了。

陈默站在窗边看着那个背影消失在街角。手心里的铜扣被体温捂得发黏，他低头看了一眼，扣面上的“林”字铜绿泛着暗光，指腹压在上面，粘了一层薄薄的汗。

电话那头，程雨的呼吸还在，像一根绷紧的弦，没有断，也没有松开。

“隔壁住的是谁。”他问。

“一对老夫妻。上周才搬来。”程雨的声音从听筒里挤出来，“我不认识。”

又两下，比刚才更重。门板震动的闷响顺着信号传过来。陈默听见她往后退了一步，拖鞋蹭着地砖。

“你手机开免提，放桌上。”他说，“别挂。”

“你要干什么。”

“听。听清楚他们敲的是哪扇门。”

电话那头安静了两秒。然后她的呼吸声变得开阔，混进了一点房间的回响。他把手机贴紧耳朵，听见自己出租屋里压缩机的嗡鸣，和听筒里那种空旷的杂音叠在一起。

敲门声停了。走廊里响起一串脚步声，不紧不慢，从程雨门口经过，停在隔壁。然后是钥匙插进锁孔转动的声音，门开了，又合上。一句含混的男声说了什么，听不清。

“是隔壁的人回来了。”程雨的声音重新贴近话筒，气还没顺下来，“不是敲我的门。”

陈默没接话。他盯着楼下那个空路口，刚才穿深色外套的人已经走远，但拐角另一侧，还有一道影子贴着墙根站着，没动。

“卷宗编号。”他说，“建设路那条，发我。”

“现在？”

“现在。发完锁门，别开窗，别应声。”

电话那头传来按键的嘀嗒声。他听见她念了一遍编号，又重复一遍，确认他记下。然后她说：“陈默。”

“嗯。”

“刚才那个人，是不是跟着你来的。”

他没回答。掌心里铜扣的边缘硌进指腹，那道印子从白转红。楼下的影子还贴着墙，像一段没写完的笔画，等着谁去落笔。

“发过来。”他说，“我等你。”
