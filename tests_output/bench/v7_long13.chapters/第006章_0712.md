# 第6章 07:12

陈默惊醒时后脑勺是空的，像被人从里面挖走了什么。他摸手机想确认时间，屏幕停在拨号记录页面。昨晚18点42分有一通拨给父亲旧号码的通话，时长42秒。他不记得自己拨过这通电话。

他翻相册，最新一张照片是一块旧手表，表盘指向22点47分，放在老屋窗台上。他环顾窗外，窗台空荡荡的，连表影都没有。昨晚18点到19点这一个小时，在他记忆里彻底断了档。被子还搭在沙发扶手上，屋里没有人来过的痕迹。

6点50分，他骑车到东门街路口。车流已经密起来，修鞋摊的老周正在支遮阳棚，见了他只点了下头。陈默站在摊位西侧，那个刚好能看见路口西北角的位置。他抬头确认信号灯配时，绿灯约38秒，红灯约52秒。跟昨天记的数字一致。

7点11分，林果果从路口西北角出现。背书包，左手腕红绳还在，身边没有大人。她走到斑马线前站定，低头看了一眼自己的鞋带。鞋带系得紧紧的。陈默的呼吸卡了一下，他昨天写的是07:12鞋带松开，可她的鞋带好好的，没有要散的迹象。他往前迈出半步，又收了回来。

绿灯亮了。林果果起步，走了两步。左脚鞋带的结突然自己松开，绳头甩到脚面。她停下来，蹲下身，把鞋带重新系好，又检查了一遍，系紧。她起身的时候，信号灯刚跳红。旁边一个小学生越过她先跑了过去。

同一秒，东侧直行道上一辆白色轿车驶来。刹车灯亮了一下，又灭了。车没有减速，顶着护栏滑行出数米。金属护栏在轮胎碾压下弯折变形，弯折段的起点，离林果果刚才站过的路肩不到半米。碎砾飞溅开来，有人喊了一声。

林果果往后退两步，低头看裤脚。灰白校服裤上蹭了一道灰痕。她没哭，蹲下去拍了两下，站起来，跟着人流绕过事故段走了。

白色轿车司机趴在方向盘上没动。有人举着手机拍照，有人去敲驾驶室的窗。陈默站在马路对岸，把外套拉链拉到顶。林果果混在人群里越走越远，她不知道自己刚站过的位置被一截弯折的护栏占了。她以为那只是鞋带松了。

11点40分，陈默回到老屋，翻开种子书。页角的压痕叠出一行他没写过的小字：多次改写致第二人擦伤。路人，男性，左臂轻微剐蹭。

他盯着那行字看了很久。落笔时他写的是“林果果，07:12，东门街路口，因鞋带散开蹲下系鞋带，停滞至绿灯转红后第3秒才起身”。没有第二个人，没有擦伤，没有左臂。他把今天车祸现场在脑子里过了一遍。那辆白车冲过来时右前灯下方有一片斑驳的擦痕，像刚蹭过什么。可车顶着护栏滑行时，他清楚地看见护栏没有被撞过的旧痕。那个擦伤的路人是从哪来的？

他合上书页，又打开，那行字还在。墨色跟四周的压痕一样深，像是本来就在那里。他把种子书塞进外套内袋，走出老屋，在台阶上站了一会儿。手机在兜里震了一下，是一条话费账单提醒。他顺势点开通话记录，那通42秒的录音还挂在列表里，文件名是一串自动生成的日期数字，状态显示未播放。

他拇指停在播放键上方。昨晚18点到19点的记忆被抽走了，那段空白里他拨了一通电话，说了42秒的话。对面接听的人是谁，他说了什么，他完全不记得。唯二能证明这段空白存在过的，是相册里那张旧手表照片和这通未播放的录音。

他按下播放键。

录音先是一段杂音，电流声里混着远处隐约的车流声。然后他自己的声音响起来，很轻，呼吸很重：“爸，距离0317还剩13天。林果果的事……是我写的。这是第一次没告诉你的账。如果这就是你说的代价的样子，那我已经付了。”

杂音里有一个男人的声音回了一句什么。声音太矮，隔着电流断在半截。录音到这里结束。

陈默握着手机，屏幕显示录音已播完。他确定，电话那头接听的，根本不是父亲的旧语音信箱。

他重新听了一遍。这一次他把手机贴到耳边，音量推到最大，想从那段杂音里捞回那个男人的半句话。电流声像砂纸，刮过耳膜，还是断的。那个声音太矮，矮得像是从很远的地方隔着墙递过来的。他反复听了三遍，第四遍的时候，他听见了杂音里一段极轻的底噪，像翻动纸页的声音。

他愣住。纸页。

他把种子书从外套内袋里抽出来，摊在膝盖上，又按下播放键。录音里翻纸声响起的位置，他手指压住书页，指尖传来粗糙的纸纹。他翻到页脚，0319那行编号还趴在纸角。录音里，那个男人的声音在纸页声之后又回了一句什么，这次他听清了一个字，尾音上扬，像在问话。

“……谁？”

他自己的声音没有回答。录音到这里彻底断了，42秒结束，屏幕跳回通话记录界面。

他盯着那串日期数字文件名，拇指又移到播放键上。这一次他没有按下去，而是把手机屏幕扣在膝盖上，翻开种子书，一页一页地翻。他不知道自己想找什么，只是机械地翻着，直到翻到昨晚落笔的那一页。页角的墨痕在晨光里干透了，压痕深处却有一道极浅的折痕，像有人在他落笔之前，已经翻过这一页。

他想起凌晨三点，他坐在老屋台灯前反复翻页的时候，有没有一个瞬间，他翻到了这一页，看见了什么，然后合上了书。

记忆里只有一片空白。

他合上种子书，塞回外套内袋，站起身。晨光已经铺满台阶，远处传来早班公交的刹车声。手机屏幕亮了，是林兰发来的微信：“果果到学校了，说路上鞋带松了蹲下系了一下，没别的事。你昨晚说的那个，我当没听见。”

他盯着那条消息看了很久，没有回复。屏幕暗下去，又亮起来，通话记录里那通42秒的录音还挂在列表顶部，文件名下方多了一行小字。

“已播放。”

他锁了屏。台阶下的水泥地上，一只烟头还在冒烟，像是刚被人踩灭的。他抬头环顾四周，巷口空荡荡的，一个人影也没有。
