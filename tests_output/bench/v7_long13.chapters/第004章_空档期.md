# 第4章 空档期

陈默在物流网点前台填入职表时，墙上的片区配送图先撞进眼睛。图是A3纸打印的，网格线，每个片区用不同颜色标着配送范围。东门街那一块，出口位置被红笔反复画了三道叉，叉线粗重，把那个路口圈成了一个小团。

老调度坐在柜台后头，腿上摊着一本翻旧的路单，抬眼看他盯着图看：“别看了，那条口子咬人。”

“什么？”

“东门街出口。连续两年有配送员在那儿出事，上个月才撞过一个。”老调度用笔杆敲了敲图上的叉，“你要跟车，明天倒是有趟去东门街的件。”

“我考虑一下。”陈默把填好的表推过去，手机在裤兜里震了一下。房东的催租短信，这个月第三次了。他把手机翻个面扣在台上。

走出网点，他站在台阶上，背包里那本种子书贴着他的后背。他本该直接回家，腿却往东门街的方向转。只是去吃碗面。他这样对自己解释。早上出门到现在还没吃口热乎的，东门街有家面馆，前天路过时见过。

东门街路口比他想的窄。路是一道斜的，车流从弯道下来，转到直道时有一块被公交站牌挡住的盲区。他扫了一圈，把信号灯位置和路口宽度记下来，像记一笔账。地面有一道白漆重新画过的裂缝，漆是新刷的，底下开裂的路面还没干透。修鞋摊在站牌旁边，摊主是个戴老花镜的大爷，姓周。陈默要了杯水，在摊边的小马扎上坐下来。

老周头也不抬，手里敲着一只鞋掌：“你不是这片的。”

“路过。”

“这个路口的孩子，过马路都蹦着来。”老周说，“不看车。去年一个送外卖的就在那儿，弯道下来，刹不住。”

电话响了，林兰打来的。陈默接起来，林兰的声音带着楼道里的风。

“果果的科创营挪到下午了，今天不用送。我跟你一声。”

“嗯。”

“你昨天怎么还拿着那本子？”林兰顿了一下，“我爸以前也总翻一本旧本子，后来他走了。”

陈默握着手机，等了三秒才问：“他后来什么时候走的？”

“忘了。”林兰说，“都是老早的事了。”

电话挂断。陈默把手机放回兜里，在摊边又坐了一会儿。老周已经敲完那只鞋掌，换了一只鞋底，没再说话。

下午4点17分，东门街社区学校放学。陈默站在马路对面，孩子们三三两两从校门涌出来。他在人群里看见林果果。她扎马尾，左手腕缠着一根褪色的红绳，书包带子斜挎着，和另一个女孩说着话走出来。同伴拐进巷子后，她一个人往路口走。过街时她没看车，一辆电动车从她身边擦过去，按了喇叭。保安在门口喊了一嗓子，她才跳回斑马线边。

她蹲下来系鞋带。蹲在路缘石边上，鞋带缠了两圈，她低头捣鼓了大约十二秒。陈默拿手机按下计时器，又锁屏。

黄昏，陈默坐在便利店落地窗前，关东煮的杯子搁在桌上，凉了。他把手机里拍的页痕照片放大，怼在眼前。页角那半行字不再是“14:07 东门街路口”。它变成了另一行：

停留：138秒。

没有“林果果”三个字。纸页上没有她的名字，但他硬是从那行字里读出了她。

晚上他回到出租屋，给林兰发了一条微信：明天果果有人送吗？

林兰秒回：你关心她干嘛？

陈默打了两行字，又全删了。锁屏。手机还没放回桌上，屏幕亮了一下：本地新闻推送，东门街路口近日将进行人行道检修，临时调整信号灯配时。配图里一辆白色轿车正驶过路口。

他盯着那张图看了几秒，想起那行“停留：138秒”，想起页角那道毛糙的撕纸残余。窗外东门街方向的路灯已经亮成一小片橙光。他在窗边站了一会儿，没开灯。

手机又震了一下。林兰发来一张照片。照片是木头桌角，老屋墙角那张书桌的桌角，陈默认得那是父亲屋子里的东西。桌角刻着一串数字：0317。

林兰只发来一句话：你是不是也在查这本？

陈默握着手机，屏幕的光映在他脸上。窗外，东门街方向的路灯闪了一下，又亮回来。

他盯着那张照片看了很久，久到屏幕自动暗了又亮。0317。这个数字今天已经出现过太多次，多到他已经没法把它当作巧合。他想起页角那串钢笔编号，想起外卖单底联，想起表壳背面的划痕。它们像同一条线在不同位置露出的线头，而他手里攥着的，是其中一根。

他打字：这本是什么？

林兰那边显示“对方正在输入”，跳了三次，最后发来一段语音，十二秒。陈默点开，声音压得很低，像怕隔墙有人听：“你爸走之前，在我家放了一个纸箱。他说要是有一天你回来翻老屋，就把箱子给你。我没打开过，但箱子角上贴着一张纸条，写的也是0317。”

语音结束。陈默把手机贴在耳边，又听了一遍。父亲留了东西给林兰，却要等他“回来翻老屋”才给。这意味着父亲早就知道他会回来，甚至知道他会翻到什么。

他问：箱子现在在哪？

林兰隔了快一分钟才回：地垫底下压着把旧门禁卡，你拿它去城东仓库，103号柜。你爸说，柜子钥匙在书桌抽屉夹层里。

陈默放下手机，看了一眼抽屉。种子书躺在最里层，页角那串“案：0317”在台灯下泛着暗蓝。他拉开书桌抽屉，指尖探进夹层，碰到一把冰凉的钥匙。钥匙齿上缠着一截蓝色尼龙绳，和表链接缝里卡着的那截一模一样。

窗外，东门街方向的路灯又闪了一下。这次没再亮回来。
