# 第3章 水渍在延伸

窗外雨停之前，手机闹钟先响了。雨声还在，只是变成屋檐滴水的节奏。陈默睁眼，床头柜上摊着那张外卖单底联，单号0317。他看了几秒，不记得自己什么时候把它从包里翻出来放平的。单边角有一道折痕，是昨天从外卖员手里接过来时留下的。

手机上两条未读。房东那条他直接划掉。另一条来自林兰，一条语音留言，时长十二秒。他点开，林兰的声音带着楼道里的回声："一楼走廊渗水了，你老屋的水管是不是没关？昨天看你拉总闸，我怕你拧反了方向。"

陈默把手机揣回兜里。他套上外套，钥匙串从桌面扫进裤兜，蓝色尼龙绳垂在口袋外头。凌晨的雨把巷子浇透了，楼道口的感应灯还是坏的。他踩下去时，那滩旧水渍还在地砖缝里，边缘漫开了一圈新潮。

老屋门推开，潮气顶上来。厨房台面上一列水渍正沿着台边往下滴，昨日那摞没洗的碗还搁在原处，碗底积了一小汪。水龙头是拧紧的。水从台面缝隙里渗出来，沿着瓷砖缝，绕过一只缺口的碗，再往墙角淌下去。他拧紧总阀，水流慢慢变小，最后停住。停住的那一瞬间，他发现自己想不起昨天午饭吃的什么。

这种空不是遗忘的模糊，像一页被撕走的时间。前后都连着，中间断掉了。他站在台前，拧过阀门的手还没松，指腹上压着一道阀门棱角的红痕。

他翻包找物业缴费单。手指在笔袋底部碰到一张对折的纸。展开，是他自己的笔迹：3月17日必须联系小周。字迹用力，笔尖划破纸面一处。他不记得写过这张便签，不记得"小周"是谁，也不记得3月17日要联系这个人做什么。他把便签对折，塞进胸口口袋，手指碰到那截蓝色尼龙绳。绳子末端湿了一小截，是刚才沾上的。

锁门下楼。楼道口的光线比昨天亮，雨后的台阶泛着水色，地砖缝隙里积着水。一个穿黄色工服的外卖员正从车筐里拎出泡沫箱，抬脚要踩上那级湿台阶。昨天也是这身衣服，误闯进来问"3门317是这栋不"。

陈默叫住他："欸。"

外卖员回头。一张年轻的脸，头盔带子没系，垂在领口。

"你叫什么名字？"

"周航。"他把泡沫箱换到另一只手上，补了一句："昨天那单尾号0317的，是我送的。"

0317。陈默的手指在背包带子上收紧。他退到楼道阴影里，翻开种子书。翻到空白页，蓝黑笔尖抵上去。楼上传来电视声，有人冲水的管道声从墙里碾过。他看了一眼手机屏幕：9时52分。周航脚上是一双磨损的板鞋，鞋底花纹几乎磨平。这种鞋底踩上那级松动的湿砖，不用试也知道会滑。

他落笔：周航，3月11日9时52分，滨河道12号一楼台阶，右手握紧扶手，停住半步。

纸面干净，墨迹渗进纸里，跟写别的字一样。他合上书页，心跳撞着肋骨，他数了两秒。

楼道口传来一声闷响。陈默探出身。周航半跪在台阶上，右手死死攥着扶手栏杆。人还杵在那级台阶上。泡沫箱从车筐里甩出去，倒扣在台阶边，汤水哗啦溢出来，顺着地砖缝流成一道细线。那道细线沿着地砖缝延伸，停在昨日那滩旧水渍的延长线上，像接上了半截断掉的笔画。周航骂了一句，爬起来拍膝盖，又弯腰去捞泡沫箱。他看了看那道水迹，抬头冲陈默笑了笑："这台阶真滑，回头我得跟房东说一声。"

陈默站在原地。手心里的种子书贴着掌纹，不烫，不响。他嗯了一声，把书合上，翻到封面内页。那行"不可贪"的铅笔字还横在斜角，他看了两秒，把书收进背包。

中午他回了出租屋。推开门，灶台上三只空泡面碗，调料包残渣贴在碗底，已经干了。其中一只碗里的塑料叉子还插在痕迹中间，面条残渣粘在叉齿上，凉透了。他不记得自己吃过其中任何一碗。他拉开抽屉，种子书还在最里层。他抽出来，翻到上午写字的页面。那行字还在，蓝黑色，趴在横格线上。周航，3月11日9时52分。他合上书，又翻出手机通话记录。最近一通是凌晨2点17分，时长11秒，号码备注"爸（老宅）"。末尾四位0317跳进眼睛。他看了几秒，把手机扣在桌上。

下午他给物业打了个电话，物业说维修师傅傍晚到。他把手机放回兜里，在老屋门口的长条石阶上坐了一会儿。雨停了又下，细得像雾。种子书躺在背包里，压着拉链的位置。

傍晚，雨又细密地落下来。陈默在老屋门口翻开种子书，借着手电白光的斜角，页角压出一道极淡的压痕。像铅笔描过又被蹭掉一层，只余半行：14:07 东门街路口。

他指尖蹭过纸面，压痕不变。他不认识东门街。他合上书，钥匙串刚放进兜里，隔壁门开了。

林兰撑一把滴水的伞走出来，身后跟着扎马尾的小女孩。她把手里的钥匙串递过来："昨天你落在我家的。"

陈默接过。林兰没收伞，语气平常："果果明天七点要去东门街那边上科创营，我本来还愁下雨怎么送。"

陈默低头。书页边沿，半行压痕在灯光下发灰。他问："你说哪里？"

"东门街路口呀。"林兰答，"滨河道那头，有个红绿灯的。"

"几点到那边？"

"七点。"林兰说，"她爸顺路送。"

陈默看了一眼书页。14:07。早上七点，纸上是下午两点七分。他问："她平时也走那边？"

林兰奇怪地看他一眼："今天不去，明早要去东门街路口那个红绿灯，她爸送。"

林果果仰头看了他一眼，又转回去。林兰牵着她的手往回走，门关上了。

陈默站在走廊里，重新翻开种子书。手电白光照着页角，那半行字还是"14:07 东门街路口"。但隔着一道纸纹的距离，有一笔正在浮出来。很淡，像水渍渗过纸背。他看不出那是什么字。

楼道尽头，老屋的门缝里传出滴水声。一下，又一下。他今天早上明明拧紧了总阀。
