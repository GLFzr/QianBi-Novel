# 第2章 单号

车到站，陈默下了公交，走回出租屋。楼道感应灯坏了，他跺了一下脚，灯没亮。脚底踩到一滩黏腻的东西，鞋底带起一串声响。他低头，那滩外卖汤渍反射着楼道里仅存的冷光，像一行被水泡烂的字。他蹲下来看了两秒，没看出所以然，跨过去走了。

身后那滩汤渍里，浮着一截蓝色尼龙绳的碎头，跟父亲账本封皮一个颜色。

开门，进屋。他把背包放在桌上，纸箱摊在地板上，遗物一样样归位。木工工具他留了一套，其余明天装进回收袋。分类快，不需要想。唯独那本蓝皮笔记本，他抽出来，单独放进抽屉最里层。不上锁。手在抽屉边沿顿了一下，然后推上。

手机弹出消息。房东发来一条：“周六前再不转，别怪我直接换锁。”他摁掉，顺手翻到通讯录，父亲的号码躺在最底下。备注：爸（老宅）。他本来想办销号，这个号留着没有意义。

拨过去。听筒里钻出机械女声：“您拨打的电话已关机。”他正要挂断，屏幕上弹出一行小字：“有一条未播放的通话录音。”他愣住了。录音是语音信箱留下的，存了三个月。点开。

前十秒是窸窣声，布料和纸质摩擦，像有人在整理什么。中段，父亲的声音压低着，语速比平常慢，含混不清：“……这个放下面，那个收好。这本子留给陈默。告诉他，账，命运收不走，会有人来——”

门铃响了。录音断了。

陈默把手机握在手里，拇指悬在屏幕上方。他又点了一遍播放。听到“留给陈默”时，指节收紧。他把录音倒回去，第三遍。这一遍他听清了：父亲声音停住的那段底噪里，有一个电子女声在播报：“您有新的外卖订单，编号0317。”

外卖。编号。0317。

他站起来，翻背包。外兜里除了那张“陈默”纸条，还有一张卷边的外卖单底联。今天在楼道口，外卖员举着单票问他路，弯腰去捡掉落的底纸时，他鬼使神差地接住了，顺手揣进兜里。他当时只想着别让风刮走。单号区印着三个数字：0317。

一天之内。页角，单票，播报。同一个编号，出现三次。他先前还说服自己，纸角页码和单号撞车只是巧合。巧合不会在录音里再冒一次头。

他从抽屉最里层取出种子书，翻开。页角那行钢笔字还压着纸，案：0317。他把笔尖抵住那串数字，没动。纸面被压出一个浅浅的凹痕，没落墨。呼吸放慢，像怕惊动什么。本子封皮翘着的角贴着指腹，手感粗糙。他合上书，关灯躺下，把种子书压在枕头底下。

夜里，他翻了个身，肋骨碰到枕头下硬硬的直角。手机屏幕自动亮起来。他摸过来，又拨出那个号码。这一次听筒里传出父亲自己的声音，语速缓缓地，像在留什么话：“您拨打的用户已在服务区外。留言请按——”

忙音。

屏幕停在通讯录页面。备注栏下有一行小字，创建于三年前：“0317，他生日。”

他拿着手机看了很久。拇指悬在屏幕上方的删除键附近，没按下去。他点开备忘录，往下翻。父亲失踪前一天，他的手机里多了一条记事，他不记得自己存过。“3月17日22:47，去东门街路口。”

他抬头，窗外的路灯底下，一个外卖骑手的头盔反光一闪，停在巷口。骑手没进任何一栋楼门。手机屏幕顶端弹出一条推送：“您有新的通话录音已保存。”他还没点开，屏幕上的时间跳到2点18分。楼下，那辆外卖电动车启动，引擎声缠着，迟迟没有驶离。

楼下那辆电动车引擎声低低地缠着，像有人捏着油门不撒手。陈默盯着屏幕顶端那条推送，拇指悬在通知栏上方，没有点下去。通话录音已保存。他今天没录过任何通话，这个号码拨出去只有忙音，忙音不会生成录音。

窗外那顶头盔又闪了一下。路灯底下，骑手跨在车上，一条腿撑着地，低头看手机。头盔面罩压得很低，看不见脸。电动车没熄火，尾灯红彤彤地亮着，像嵌在夜里的一只眼睛。

陈默把窗帘拉上一半，退回床边坐下。手机屏幕还亮着，那条推送挂在顶端，不消失。他点开通讯录，手指停在“爸（老宅）”那一行的编辑键上。备注栏下方那行字又跳出来：“0317，他生日。”他生日。他爸的手机里存着他的生日，用一串编号的格式，跟种子书页角那个“案：0317”一模一样。他从来没告诉过父亲自己习惯用这个数字当密码，但父亲存了三年。

楼下引擎声突然拔高，又低下去，像骑手拧了两下油门，还是没走。

陈默把手机扣在床上，走到窗边，从窗帘缝里往下看。骑手还在路灯底下，头盔微微偏着，像在朝这栋楼的方向看。他看不见骑手的脸，但能看见那辆电动车后座绑着的保温箱，箱体侧面有一道很长的白色划痕。

他退回床边，重新拿起手机。那条推送还在。他点了下去。

录音播放界面跳出来，时长四十七秒。进度条从零开始走，前段是沙沙的底噪，像风灌进话筒。中段有布料摩擦的声音，然后是父亲的声音，比刚才彩铃里那句更轻，更像在跟很近的人说话：“……东门街路口，你替我去看一眼。要是看到有人蹲在路灯底下数烟头，就别往前走了。”

录音到这里停住。进度条走完，界面自动退回通知栏。

陈默站在原地，手机屏幕的光映着他半张脸。父亲失踪前一天，备忘录里那条记事是“3月17日22:47，去东门街路口”。录音里父亲说的是“你替我去看一眼”。他爸在给拿到手机的人留一句话。

楼下那辆电动车终于动了。引擎声拖长，骑手拧着油门往巷口方向滑出去，尾灯在拐角处闪了两下，熄了。

陈默低头看手机。录音文件的名字是一串乱码，保存时间显示为今晚，2点17分。他点开文件详情，底部有一行小字：由来电录音生成，通话时长零秒。

他没有拨出去过任何一通能接通电话。
