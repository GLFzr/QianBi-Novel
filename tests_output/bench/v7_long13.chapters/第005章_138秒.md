# 第5章 138秒

凌晨三点，陈默坐在老屋底楼的台灯前。种子书摊在桌面，页角那行“停留：138秒”趴在纸纹里，跟傍晚看到时一模一样。他把页面翻了过去，隔了几秒又翻回来。没有变化。他关了台灯，黑暗里那行字还烙在视网膜上。重新开灯，它还在那里，一笔没多，一笔没少。

他这样反复了三次。

第三次合上书本时，他的手指压在封皮上，指节发白。门外楼道里没有声音，楼板上偶尔传来水管里的咕噜声。台灯的光晕在纸面上切出一个扇形，他盯着页角那行字，眼皮发沉。

3点47分，页角的空白处多了一行字。

他确定自己刚才没有碰过笔。台灯下，那行字像从纸里渗出来的一样，墨色比“停留：138秒”浅了一号，字体却他一眼就认得出来。他父亲的笔迹，横画收得急，竖画带一点往左的斜。他看了十几秒才读懂那行字的意思：

明 07:12 停留处有车刹不住。

笔尖没有落过墨。这一页上没有任何新鲜的笔痕，但字在那里，安静地趴在横格线上，像早就该出现的一样。

他翻到封面内页，把脸凑近那行不可贪。铅笔字，瘦瘦的，斜在页角。内衬纸边有一道折痕，他先前翻过，以为只是陈旧的压痕。这时他顺着折痕揭起来，内衬里贴着一张薄纸，边缘被浆糊糊住，只露出一角。

他抽出铅笔，用笔尖在不可贪三个字上轻轻描了一遍。笔压透进纸背，背面透出一行更浅的字，像水渍干透后留下的痕迹：

改写是替人挡，不是替天改。

他把纸放回内衬，手指捏着纸缘，抖了一下。他父亲写下过一行批注，专门贴在内衬里，让后来者用铅笔拓才能看见。这不是使用说明。这是警告。

他拿起手机，拨林兰的号码。响了三声，机械女声提示关机。他看了一眼时间，4点26分。离07:12还有不到三小时。他放下手机，重新翻开种子书，翻到周航那一页。

周航，3月11日9时52分，滨河道12号一楼台阶，右手握紧扶手，停住半步。

那笔他写得短。几乎只是一个动作，不涉及时间长度，不涉及停顿，更不涉及让谁避开什么。他当时以为改写得越少，代价就越小。现在他盯着那行字，想起自己落笔时心里那股掂量：写得越少，是因为不想多拿走自己。

他翻到新的一页。蓝黑墨水笔尖抵在纸面上，悬停了三秒。

5点12分，他落笔。

林果果，07:12，东门街路口，因鞋带散开蹲下系鞋带，停滞至绿灯转红后第3秒才起身。

墨渗进纸里，跟写别的字没有区别。他合上书页，同一瞬间，太阳穴一抽，像有什么东西从后脑被抽走，抽得很轻，轻得像一根线被慢慢拽出线轴。他按住太阳穴，低头看见自己的左手。小鱼际处多了一道墨痕，墨水还没干透，在皮肤纹路里洇成一小片暗色。他没有碰过墨水。

他静坐了几分钟，不敢翻本子。他想回忆昨天午饭吃的什么，脑子里出现一只碗，碗里是什么，一片空白。那一段记忆正在变稀，像墨水被水泡开，边界一点点模糊。

页脚无声地多出一行字。他起先以为是灯光反光，凑近了才看清。0319。

0317旁边的新编号，像同一本账的下一行。他盯着那串数字，呼吸停了一拍。

门外楼道里传来脚步声。一步一步，没有迟疑，走到他门口，停住了。他等了十秒。脚步声没有离开，也没有敲门。

门外传来一个压低的女声：“陈默，我知道你醒着。”

他认出那个声音。林兰。

他站起身，椅子腿刮过水泥地，发出一声短促的尖响。台灯的光把门缝照成一条细线，门外的人没有动，影子压在光缝里，矮矮的一截。

“你女儿明早七点要去东门街。”他说。声音比他预想的哑。

门外的影子顿了一下。“你知道。”

“我知道。”他低头看了一眼左手，墨痕还在，暗沉沉地嵌在皮肉里，“我也知道那个路口有问题。我改了她的时间。”

门外安静了很长一段时间。他几乎以为人走了，脚步声才重新响起来，很轻，像踩在棉花上。“你爸当年也这么说过。”林兰的声音隔着门板，闷闷的，“他说有些事不能靠本子，本子只能让你晚一点知道后果。”

“你见过他写？”

“见过。”她说，“他走之前，把本子烧了。在我家后院烧的。灰我替他扫的。他说这种东西不该传下去。”

陈默攥着门把手，指节发白。烧了。父亲烧了自己的本子，却留下一本新的给他。他忽然想起那行批注：改写是替人挡，不是替天改。他替林果果挡了这一下，可明天早上那辆车还会不会来，会撞上谁，他不知道。

“你走吧。”他说，“明天要是果果没事，我再跟你解释。”

门外的影子站了一会儿，然后脚步声顺着楼道往下走，一层，两层，消失了。

他回到桌前，翻开种子书。页脚那行0319已经干了，墨色沉进纸里，像生来就在那儿。他盯着那串数字，想起父亲页角那行0317。同一本账的下一行。他合上书页，把左手小鱼际贴在封面内页那行字上：记人未长成的事。

窗外，东门街方向的天际线开始泛白。他看了一眼时间。5点41分。距离07:12，还有一小时三十一分钟。

他关上台灯，坐在黑暗里，等天亮。
