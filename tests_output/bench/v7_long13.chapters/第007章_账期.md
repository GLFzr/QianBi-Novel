# 第7章 账期

他弯腰把烟头收进塑料袋时，指腹蹭到地砖缝里一小截硬东西。抠出来，是蓝色尼龙绳头，绳结处有一道被反复捻磨出的凹痕，像有人长时间用指尖搓过同一个位置。他从裤兜摸出那把钥匙，齿上缠着另一截同样颜色的绳。两截对在一起，凹痕的方向不一样。他顺着磨损的方向比划了一下，不是他惯用的角度，也不是父亲惯用右手的指腹方向。

有人在这截绳子上捻了很久，用他不知道的一只手。

他把绳头也塞进塑料袋，扎紧口，上楼。

林兰开的门。她穿着一件旧毛衣，手上还沾着肥皂水，看见他，脸上的客气顿了一拍。陈默没进屋，从肩上卸下背包，拉开拉链，把种子书取出来，直接放在楼道的水泥窗台上。封面朝上，压住半张旧报纸。

“我爸留给你的箱子，什么条件给我。”

林兰的视线在那本书上停了一下。她没看内页，只看了封面，然后抬眼看他：“我答应过不说全。”

“我今天早上在东门街路口，看到一个孩子鞋带散开，蹲下去躲了一辆车。”陈默说，“那孩子是你女儿。”

林兰的手在毛衣下摆上攥了一下。肥皂水洇出一小片深色。她沉默了很长一段时间，楼道里的声控灯灭了一次，他跺了一下脚，灯又亮起来。

“3月17日。”她说，“如果有人敲门，箱子直接烧掉，书不给你。”

陈默没有追问。他把种子书收进背包，拉链拉好，转身下楼。林兰在身后没有关门，他走出几步，听见那扇门轻轻合上。

城东仓库在货运站背后，一排铁皮顶的矮房，门牌泡过水，字洇成一团。103号柜在走廊尽头，锁孔边缘有一圈磨亮的痕迹，像是常被人打开。他把钥匙插进去，齿上那截蓝绳蹭过锁孔边缘，发出一声细微的咯吱。锁芯转开。

柜子里一只纸箱，箱角贴着一张纸条，写着0317，是他父亲的字迹。他剪开胶带。箱子里只有一盒录像带，标签是手写的：陈默，3.17。带身缠着一圈蓝色尼龙绳，和钥匙、表链、地砖缝里那三截同一个颜色。他拆线圈时手指碰到磁带脊，摸到一道细裂痕，像被摔过一次又粘了回去。

他没放。把录像带装进背包，锁好柜门，走出仓库。风灌进衣领，他停下来，伸手进外套内袋摸种子书，指腹碰到封面时顿了一下。书壳比早晨厚了一点，像有什么东西夹进了封皮夹层。

他在路灯下翻开。封面与内衬之间鼓着半张纸。他抽出来，一行钢笔字，蓝黑墨水：不要看3月17日的录像带。

字迹是他自己的。

他盯着那行字看了很久。笔锋收尾的方式，横画起笔的习惯，墨水颜色，甚至纸边撕下的形状，都在告诉他这是他自己写的。但今天早晨翻种子书时，夹层里还没有这张纸。他摸出手机看时间，屏幕上是傍晚6点40分，距离他最后一次翻开种子书，过了七个小时。

他不知道自己什么时候写过这行字。他也不知道自己是什么时候把它放进夹层的。他只知道，这行字是在他打开103号柜之前写的，还是之后。

他没有再翻开那半张纸，原样把它塞回封皮夹层，合上书。路灯的光从楼房间切下来，把书壳裁成一道窄窄的蓝色。

他走回出租屋，楼道里的感应灯亮了。他摸出钥匙，插进锁孔，还没拧，听见房间里传出一阵沙沙声。像电视机没有信号时那种雪花音。他站住，耳朵贴着门板。沙沙声没有停，均匀地，持续地，滚动在门板后面。他确定自己出门前拔了电视的电源插头。连插头都拔了。

他拧开门。

电视柜上，那盒录像带平放着，标签朝上。陈默，3.17。电视机屏幕亮着，雪花纹在屏幕上翻涌，一阵一阵，像有人在画面里走动。他站在门口，背着装有种子书的包，看着那台他自己拔掉电源的电视机，屏幕的光在他脸上明灭不定。雪花纹里，有一个影子，停住了，正对着屏幕外。

他的目光钉在那个影子上。屏幕的雪花纹一层层翻涌，影子的轮廓也跟着一明一暗。他认出那个姿势。低头，垂肩，一只手撑着电视柜边缘，像在等什么人开口。

他往前迈了一步。影子没动。他又迈了一步。沙沙声忽然矮下去，像有人把音量拧小了一格。他停在电视柜前，伸手去够那盒录像带。指尖刚碰到标签，屏幕上的影子抬了一下头。

他缩回手。沙沙声又涨回来。

“谁放的。”他听见自己的声音，干得像砂纸。没有人回答。他绕到电视机侧面，伸手摸到电源线。插头确实不在插座上，线头垂在柜子后面，悬空。他蹲下去，顺着线摸了一遍。线是完好的，插头是拔下来的，但屏幕亮着。

他站起来，重新看那盒录像带。标签上的字是他父亲的笔迹，蓝黑墨水，和种子书封面那行字一个颜色。带身缠着的蓝尼龙绳已经被他拆开，现在松垮垮地搭在带壳上。他想起103号柜里那个纸箱，箱角贴的纸条，0317。他父亲把这一切留好，锁在仓库里，等着他有一天用那把缠着蓝绳的钥匙打开。

他伸手拿起录像带。带壳冰凉，磁脊那道细裂痕在指腹下硌了一下。他翻转带身，背面贴着一张白色标签，被人用圆珠笔写过又划掉，只剩几个残字。他把带子凑到灯下，辨认那行被划掉的笔迹，像是“别让她”两个字。后面还有字，但被划得太重，看不清了。

电视机里，那个影子又动了一下。这一次它偏过头，像在侧耳听什么。陈默握着录像带，站在屏幕前。沙沙声里有一道极细的底噪，像有谁在很远的地方翻动纸页。

他低头看了一眼手里的带子。标签上，他父亲写的那行字被屏幕光照得发蓝。陈默，3.17。

他抬起头，看向屏幕里的影子。那个影子也看着他。
