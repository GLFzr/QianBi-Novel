# 第8章 第二人

屏幕里的影子还看着他。他先把录像带退出来，塞进背包，再弯腰去拆电视的接线口。

电视背板上的螺丝有点滑，他拧了两下才松开。面板揭开，天线口内侧的卡簧断了半截，一根细铜片从信号线接头处绕出去，插进一台落满灰的旧信号转换器里。转换器的电源线是断的，插头垂在地板上，金属触点没有任何通电的痕迹。但屏幕亮着。

他把铜片拔下来。屏幕闪了一下，雪花纹变纯，影子消失了。没有信号源，屏幕却一直亮着，说明刚才进到画面里的东西，不是靠电进来的。他重新插好电视电源线，把屏幕关掉，确认它彻底灭了。铜片放进抽屉，录像带用外套裹住，塞进行李箱最底层。锁好箱子之后，他把钥匙从锁孔里拔出来，又站在原地听了几秒，房间里只剩下他自己的呼吸声。

凌晨一点多，他坐在床边，翻开种子书。页角那句小字还在：多次改写致第二人擦伤。路人，男性，左臂轻微剐蹭。他看了很久，指腹蹭过纸面，那几个字没有变化。合上书，他躺下，眼睛睁着，天花板上的裂纹被路灯照出一道细长的影子。

清晨他去物流网点。老调度从窗口递出一块工牌，塑料壳上有道裂缝：“东门街那片，你自己当心。”陈默把工牌挂上，走出网点，脚步没停，顺着人行道往东门街方向去。

修鞋摊在收摊。遮阳棚已经塌下来一半，棚布耷拉在支架上，一个穿灰外套的老人正往三轮车上搬工具。钉子盒，锤子，一罐鞋油，一样一样放进侧兜。他左手臂缠着纱布，纱布边缘有一小块泛黄的旧血渍。陈默站在路对面，脚定住了。那个位置，那条手臂，和种子书页角那行字对齐了。

他站在原地没有动。老人推着三轮车转过来，往路口方向走。侧兜里垂出一截蓝色尼龙绳头，随着车身晃，颜色和钥匙上那截、表接缝里那截、地砖缝里那截，是同一个蓝。

7点48分，白色轿车从东门街方向驶出。车头保险杠右侧有一处凹痕，蹭着灰漆。它没有打转向灯，也没有减速，直直冲向三轮车的侧后方。

推车的老人正好走到斑马线中间，三轮车前轮卡进一道隆起的沥青裂缝，他低头去弄车把。白车撞上来。一声钝响，三轮车被顶出去两米多，工具从侧兜里甩出来，撒了一地。老人倒在地上，左臂压在碎砾上，袖子被划开一条长口，血顺着小臂流下来，浸透了腕上的纱布。

陈默跑起来。白车顶住三轮车后斗才停下，司机趴在方向盘上，半天没动。陈默双手抓住三轮车车帮，把车尾往上抬，鞋油罐滚到他脚边，黑色的油淌进地缝。他把车抬稳，蹲下去，老人侧卧着，左臂那道口子从肘弯拉到小臂，新血覆在旧伤纱布上。

救护车来得很快。老人被抬上担架时偏过头，看着蹲在旁边的陈默，嘴唇翕动，声音很低，几乎压进救护车的引擎声里。

“你说的那个路，我天天走。”

陈默没有听懂。他没有对老人说过任何一条路。他张了张嘴，担架已经推进车厢，车门关上，警笛切进路口的车流里，越来越远。

他蹲在原地，手心发麻。低头时发现自己手里握着一本旧笔记本，封皮发黑，边角磨圆，沾着灰和一小块油渍。他不记得自己什么时候捡起来的，可能是抬车那会，也可能是救护车停在路边时，他弯腰去挪工具，从三轮车侧兜掉出来的东西。

他翻开封面。边缘贴着一枚红色标签，印着“案：0317”。第一页是父亲的笔迹，蓝黑墨水，横画收得急，竖画带一点往左的斜。第一行写的是他自己的生日：陈默，3月17日。

后面是空白页。他把笔记本翻转过去，纸页间掉出半张快递单。收件人写着“陈默”，墨迹被水晕开一点，寄件地址栏只填了一个字：“爸”。

路口那边的车流开始动了。有人把三轮车推到路边，工具还没收拾完。陈默把快递单夹回笔记本里，合上封面，装进外套内袋。起身的时候，他摸到胸前那个位置，硬硬的，贴着心脏。

他站起身，路口的风把快递单的边角吹得翻起来，又被他按回去。他想起父亲打电话那天的声音，想起录音里那句“这本子留给陈默”，想起录像带背面被划掉的“别让她”。这些事像一串珠子，他手里捏着线头，却不知道另一头拴着什么。

他往回走了两步，又停下来。三轮车还在路边，侧兜里滑出来的那截蓝尼龙绳垂在挡泥板上，风一吹，轻轻拍着车架。他走过去，把绳子捡起来，绳头那道磨损的凹痕在指腹下硌了一下。和钥匙上那截、表链里那截，同一个方向。

他把绳子缠在笔记本上，绕了两圈，打了个死结。

手机在口袋里震了。他摸出来，是物流网点的老调度发来的消息：“工牌给你办好了，明天早上八点，东门街片区，你自己当心。”他盯着“东门街”三个字看了两秒，锁屏，把手机塞回兜里。

路口对面的修鞋摊还支着半块油布，凳子翻倒在人行道上，一只拖鞋孤零零地留在原地。陈默绕过三轮车，弯腰把凳子扶起来。油布底下压着一张报纸，露出一角，日期是三个月前。他抽出报纸，头版右下角有一则简短的社会新闻，标题被油渍洇了一半，只剩几个字：“城西老宅失火，一人……”后半截字被撕掉了。他翻过报纸，背面是一张照片，黑白，拍的是东门街路口，路灯底下蹲着一个人，看不清脸，手里夹着烟。

风把报纸从他手里卷走，贴在不远处的护栏上。陈默没有去追。他看着那张报纸在风里抖了抖，翻了个面，又翻回来，最后从护栏的缝隙里滑下去，落进水沟。

他低下头，看了一眼胸口的笔记本，蓝尼龙绳的绳头从衣领边沿露出一点，被风轻轻吹动。
