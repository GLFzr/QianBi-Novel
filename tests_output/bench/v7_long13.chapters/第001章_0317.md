# 第1章 0317

周六午后，老筒子楼底层过道里，水泥返潮的气味往鼻子里顶。陈默站在楼梯口，钥匙扣上拴着一截旧蓝色尼龙绳，绳头磨出了毛，颜色和父亲那本账本封皮一样。这根绳子父亲用了七年，拴单车钥匙用的，后来单车卖了，绳子没有摘。

手机在裤兜里震了一下。房东上周五催租的消息还没回，这次直接换了说法：“这月再不交就收房。”他摁掉屏幕。中介的回复躺在消息栏里：老破小动迁观望，先挂上，别抱期望。

楼道门从里面推开，林兰走出来，手背上沾着面粉，身边跟着女儿林果果。她把钥匙递过来，抬眼看了看四楼窗户：“你爸走前说，有样东西要留给你。我按他说的，没碰。”

陈默把钥匙收进裤兜。林兰也没等他应话，又补了一句：“别的，等我哪天有空再跟你说。”林果果扯她的袖子：“妈，锅还开着。”林兰朝他点了下头，牵着女儿退回门里。铁门合上，过道里重新只剩那股返潮味。

他爸会留下的东西，无非是没做完的账，外加一屋子灰。父亲替人做了半辈子账，走的时候床头还码着两箱单据。半句话不值得他站在这儿等完。

锁芯发涩，他拧了两下才开。门推开，一股潮霉气迎面扑来。客厅桌上搁着一杯凉透的茶，水面浮着灰。旧报纸摊在桌面，日期停在三个月前。他推开窗，风灌进来，窗帘角一起一伏。

他把冰箱里的东西兜进垃圾袋，旧家电约了明天回收，电瓶车昨天脱手，换了六百块。剩下的东西一周内清完，房子挂出去，房租缺口就补上了。

木工工具归进工具箱，被褥塞进废纸箱，空白收据册理成整齐的一叠。他分这些东西分得很快，一个物件该留该卖，扫一眼就有答案。这是账目里泡出来的本事：先归类，再对账，错不过三行。

手指按在钥匙扣那截绳子上，有一处被常年攥出来的弧度，刚好嵌进指腹。这是他的习惯动作还是父亲的，分不清。旧衣服里有一件灰色棉袄，袖口磨得发白。他拎起来，没有停，直接放进废纸箱。这类东西不能多看，一看就走不动。

床头柜最底下那个抽屉卡死了，抽屉底板牵出几根杂线，他用力一抽，线绷断，整个抽屉脱出来。底板底下压着一个牛皮纸袋。

纸袋里躺着一本薄薄的旧笔记本，硬壳蓝色封皮，翘着角。他翻开封面内页，上面是他父亲的笔迹，写得很慢，墨水在横格线上洇开：种子书。记人未长成的事。

斜角一行铅笔小字，笔迹瘦削：不可贪。

页角有个钢笔编号，压得很重，收笔带顿：案：0317。这写法不是他爸的习惯。

他往后翻了几页，全是空白。纸页边沿留着一道毛糙的撕纸残余，那一页不在书里。

这不是账本。他的手在封皮上顿了顿。一个浸在账目里大半辈子的人，单凭装订和胶水痕迹就能把它跟账本分开。他把本子合上，塞进背包夹层。细究下去，他可能得在这屋里多留好几天。

拉电闸时他在开关前站了片刻。走到门口，又折回去。窗台上那盆花早枯死了，花盆底下压着半张纸条。他抽出来，断口被水渍咬出毛边，上面是两个字的墨迹：陈默。他爸的笔迹。花盆土干得裂了缝，盆沿一碰就掉渣。纸条折了两折，压在盆底和托盘之间，不翻动花盆根本看不见。他爸把这样一张纸条藏在这儿，像是怕人找到，又像是怕没人找到。

他把纸条对折，塞进背包外兜，锁上门，背包带子上肩。头迈出楼道口时，头顶的声控灯灭了，咔嗒一声。

楼道口有声音喊：“3门317是这栋不？”

一个戴黄色头盔的外卖员骑在电动车上，半只脚撑地，车尾的餐箱歪着，轮胎碾过门前一摊水。箱底漏出的饮料渍在日光下亮成一小片。他摘下一只手套擦汗，手套是灰色棉线的，指腹开了线。他举着手机，屏幕上一角碎得发白，导航的红点在巷子里转圈。

“317不在这栋。”陈默说。

外卖员偏头，把垂下来的单票拎起来。单票边角印着一串取件码：0317。

陈默的手在单票边角停了一息。掌心里还攥着那张写着“陈默”的纸条角，风把它吹得卷了边。他把纸条角压平，塞回外兜，走下台阶。

走了二十来步，他摸到外兜里多了一个硬东西。

纸条是软的。这不是纸条。

他掏出来，一块旧手表。表盘上围着一圈细裂痕，指针停住，短针压在十和十一之间，长针斜在四十七格的位置。表链是旧金属，链节接缝处有被磨亮的痕迹。他翻过表来，表壳背面被人用硬物划出一串数字：0317。划痕里嵌着灰，像存了很多年。

他今天碰过的地方，窗台、床头柜、花盆，没有一处能带出这块表来。

背包里那本蓝皮笔记本贴着他的背，不塌，不响。巷口有公交车进站，刹车声拖着尾音。陈默把那只表攥得更紧，迈步走过去。

他上了车，在后排坐下。窗外的老筒子楼缩成一小团灰影。

表壳背面那串划痕他看了三遍。0317，和种子书页角的编号一样，和外卖单上的取件码一样。一天之内，三个地方出现同一串数字。他找不到一个合理的解释，把这三件事串成巧合。

车过两站，他把表翻回正面。表盘玻璃内侧有一层薄雾，像水汽凝在里面散不去。他用指腹蹭了蹭，擦不掉。表链的接缝处卡着一小截蓝色尼龙绳，跟钥匙扣上那截一模一样，只是更旧，颜色褪得发白。

他想起父亲用那截绳子系账本的样子。那根绳穿了七个年头，磨得发亮，父亲舍不得换。

车窗外街灯一盏盏亮起来。陈默把表放回外兜，手指碰到那截纸条角，又缩回来。他低头翻背包，把那本蓝皮笔记本抽出来，翻开封面内页，父亲的字迹还伏在纸上。他看了很久，合上，把表和纸条一起夹进本子里。

车到站。他站起来，那本笔记本贴着他的手臂，有点沉。
