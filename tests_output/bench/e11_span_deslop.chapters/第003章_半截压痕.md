# 第3章 半截压痕

他回老屋时，雨刚停。钥匙在锁孔里拧了两圈，门推开，门缝底下拖出一道深色湿痕，漫到走廊的水泥地面上。

厨房台面上汪着一片水，正顺着台边往下滴，落在那摞没洗的碗旁边。他伸手去拧水龙头，拧不动。龙头是关紧的。水从台面和后墙的接缝里渗出来。

他先关了总阀，再端那摞碗去水池。碗底结了隔夜的油，热水一冲，油花浮起来，水声灌满整间屋子。等最后一个碗扣进沥水架，水声停了，屋里静得能听见楼道某处也在滴水。

他握着沥水架的铁杆，整个人顿住。他不记得昨天中午吃过什么。

他握着沥水架的铁杆，站着没动。十二点到一点半之间像被撕掉了一页，只剩带毛边的断口。他站在水池前，手指泡得发白，撑着台面愣了几秒，没找出任何画面。连一口饭的味道都想不起来，昨天这时候他到底在哪儿，在干什么，像有人用橡皮把那段时间擦得干干净净，连底下的铅笔印都没留。

他关了水，把手在裤子上擦干。找物业缴费单时，指头在包底碰上一个硬角。他摸出来，是张对折的便签。展开，自己的笔迹，落笔很快，有个字拖出了纸面：“3月17日必须联系小周。”

他不记得写过这张纸。不记得小周是谁。更不记得三月十七日要联系这个人做什么。他把便签重新对折，没放回包里，塞进左边胸口的口袋。隔着衬衫按了按，能感觉到纸的折痕硌在肋骨上。

下楼时楼道口传来闷响，泡沫箱的角磕上楼梯扶手。一个穿黄色工服的外卖员正弯腰把箱子往台阶上挪，肩头的雨迹深一块浅一块。他看到陈默，点头招呼：“滨河道12号，是这儿吧？昨天那单尾号0317的，是我送的。”

“你叫什么？”陈默问。

“周航。”对方拍了拍泡沫箱上的胶带，“怎么了？”

“随口问问。”

周航又弯腰去拎车筐里的塑料袋。陈默退到拐角的阴影里，目光落在他脚下那级台阶上。地砖松了一道缝，雨水积在缝里，整块砖泛着暗光，鞋底踩上去必然打滑。周航两手都腾不出来，蹲下去抱箱时，脚尖在砖面蹭了一下，蹭掉一小块青苔，露出底下更滑的水泥面。

陈默翻开包。

种子书放在夹层最底下。他拿起蓝黑钢笔，笔尖抵住空白页，停了片刻。笔尖在纸面上压出一个小凹点，墨水洇开半粒米大，他没落笔。走廊那头传来周航挪箱子的声音，还有他朝楼上喊了一嗓子，像是问几楼有人接。没人应。

陈默又等了两秒，笔尖移开那个洇开的墨点，在旁边重新落笔。他写：“周航，3月11日9时52分，滨河道12号一楼台阶，右手握紧扶手，停住半步。”

纸面平平的，没有渗墨，纸也不烫手，安安静静像一本普通笔记本。他盯着那行字看了半秒，合上本子。心跳撞着肋骨，一下一下，砸得实。他靠在墙上，把种子书攥在手里，指节发白。外面一辆电动车碾水过去，水声溅开。

楼道里传上一声闷响。他冲下去，看见周航半跪在台阶上，右手死死攥着扶手。泡沫箱甩飞出去，扣在墙根，箱盖裂开，汤水顺着砖缝淌成一道细线，从旧水渍的断口处接上去，往前爬了小半块砖，停在一条裂缝前。周航的右膝磕在台阶棱上，裤腿蹭破一小块，没见血。

周航爬起来拍了拍膝盖：“这台阶真滑，好悬。”他回头冲陈默咧嘴，“没泼着你吧？”

陈默摇头。周航弯腰去扶箱子，又看他一眼：“你脸色不太好，没事吧？”

“没事。”

周航把箱子扶正，又蹲下去捡散出来的餐盒，嘴里骂了句脏话，说这单怕是赔了。他抬头冲陈默摆摆手：“得，走了，您当心这台阶。”他跨上电动车，车灯闪了一下，消失在巷口拐角。

陈默在台阶上蹲了一会儿。汤水线沿着砖缝伸出去，正好接在昨天那道旧水渍上，像同一条线被人从昨天描到了今天。他伸手想碰，指头悬在半空，又收回来。他摸到口袋里的便签，隔着衬衫按了一下。那行字还硌在那儿。

午后他坐在窗边，不知道什么时候睡着了。醒时窗外又灰下来，灶台上有三只空泡面碗，筷子还搁在碗沿上，其中一只的汤底已经干在碗壁。他不记得自己吃过其中任何一碗。

他站起来，膝盖发麻，扶着桌沿站了一会儿。他拿起其中一只碗，凑近闻了闻，红烧牛肉的油味，很浓。他翻手机想找昨晚的通话记录，屏幕显示凌晨两点十七分拨出一个号码，通话时长十一秒。号码尾号是0317。他不记得自己拨过这个电话。

他把手机放下，把三只碗叠在一起收进垃圾桶。塑料袋系口的时候，他顿了一下，又松开，把袋子搁在门口，没拎下楼。

傍晚，林兰来还钥匙串。门开时陈默正站在窗边翻种子书，页角对着外面的灰光斜过去，显出几道极浅的压痕。他起初以为是自己的指纹，换了个角度才看清，是字。像铅笔写过又被人擦净，留下半行：“14:07 东门街路口”。

他不认识东门街。他抬头，看见林兰站在门口，一手撑伞，一手举着一串钥匙：“你爸那屋的钥匙串，落在水台边上了，我给你送来。”

她身后跟着个扎马尾的小女孩，怯生生叫了声哥哥。陈默认出是昨天在楼前差点被三轮车撞到的那个孩子，林果果。林兰把钥匙放在门边鞋柜上，收伞抖了抖水，伞尖在地上磕了两下，甩出一串水珠：“果果明早七点要去东门街那边上科创营，我本来还发愁下雨怎么送。”

陈默把页角按在指腹下：“你说哪里？”

“东门街路口呀，滨河道那头，有个红绿灯的。”林兰看他，“怎么了？”

“果果明天几点到那个路口？”

“七点，她爸送。”林兰奇怪地看他，“你问这个干什么？”

陈默没回答。他低头，页角那半行字在灰光里发淡。纸上是十四点零七分。她爸送她走的是早上七点。他隔了两秒又开口：“她平时也那个点走那边吗？”

林兰更疑惑了：“今天不去，明早去东门街路口那个红绿灯，她爸顺路送。”

门关上。陈默站在门口没动，纸页上那半行字下面，隔着一道纸纹的距离，有一道更浅的印子刚显出轮廓，短，横折，认不出是什么字。他拇指按上去，那道印子没有温度，也没有别的反应，只是纸面上凹下去的一道细痕。走廊尽头的老厨房里，某根管子里的积水正往下坠，一滴，又一滴。
