# 第2章 编号重叠

半夜雨声大了一阵，把窗框敲得哐哐响。陈默没睡踏实，翻了个身，胳膊压到枕头底下那本硬壳本子，他往床沿挪了半寸，拉开些距离。合眼时脑子里还转着0317，那三个数字不知怎么拼成了一种读音。他翻到另一侧，把被子拉到耳根，又翻回来。枕头下的本子硌人，隔着枕巾也压得慌。他索性坐起来，在黑暗里把本子摸出来放在床头柜上，离自己远一臂，才重新躺下。这一觉睡得很浅，每次翻身都先探一探柜面上那本子还在不在。

醒来时雨停了。出租屋的天花板泛黄，墙角一道水痕从灯座边上弯下去，是老楼渗雨的旧症。他坐起来，手按在床头柜上，空的。心口跟着空了一拍，随即想起来，昨夜睡前他把本子放进了抽屉。拉开抽屉，本子还在，压在几件旧T恤底下，布壳一角露在外面。抽出来，深蓝布壳搁在白天光线下和夜里不一样，旧得发闷。页角的案：0317今天看着比昨日颜色沉了一些，他用指腹蹭了蹭，没掉色，是写进纸里的那种黑。纸皱了一道边，昨夜翻来覆去摩挲出来的。

手机提示音在枕头边响了一声。他拿起来，屏幕上是话费账单的推送。鬼使神差，他没锁屏，在拨号键盘上按出记忆里那个号码。父亲那串手机号他背得熟，用不着翻通讯录。听筒里机械女声报完最后一句，顿了顿。下一秒，系统跳出一条通知：“您有一条通话录音文件于23:17保存。”

他愣住。上个月他根本没打过这个号码。他点开文件，进度条起步的瞬间，背景噪音先灌了出来。旧PVC袋子的窸窣声，有人在一叠叠理顺塑料袋。随后是翻纸页的声音，响了几下，停了。

然后是父亲的声音。很轻。“这本子不能按常理使。”慢半拍，继续翻纸的声响，“记任何事都要写全，年，月，日，时辰，地点。缺一项就白记了。”录音底下又响了一声哗啦。父亲把什么东西放进抽屉里，金属扣磕在木板上。“给小默说的时候，只讲三样：旧账，旧笔，旧路。别的他自己会试出来。”停顿片刻，“钱放他那个账本的夹层里了，密码还是他的生日。”

陈默捏着手机的手指紧了一下。他父亲做事从来不留话，修车铺里那些工具，哪把扳手配哪个型号的螺帽，他爸都记在脑子里，从不写下来。如今这段录音里，他爸把话说得这么碎，怕漏掉一个字。录音里忽然传来门铃声，隔得远，又在近处响起来。父亲那边椅子蹭了地面一下，他应当是把听筒撂在床上，脚步声往外走。门轴响过后，录音到头了。

自动播放回到起点，他又按了一遍播放。这次他听见了背景里一个本不该在的东西。第一遍被父亲的声音盖过去的，一段极轻的老式门铃，那门铃响完两声后，又有人按了一下。电话那头的门铃，和录音里父亲走过去的门铃方向相反。陈默退回去重听。门铃响的同时，父亲说旧笔两个字的口型刚收住，背景里另有一声金属拨动的脆响，钥匙碰锁舌的动静。那扇门没等父亲走到就自己开了一条缝。

录音在这时结束。陈默听着文件末端那个微不可察的尾音，指头悬在屏幕上方没动。他忽然想起一件事，昨天在老屋收拾时，床头柜抽屉里有一卷没用完的胶带，旁边搁着一支圆珠笔，笔帽上夹着一片纸角。当时他没在意，现在想起来，那纸角的颜色和种子书里页边撕下来的那个缺口接近。他当时把纸角丢进了背包夹层，和本子挨着放。

他拉开背包，夹层里纸角还在，边缘的毛茬和案字旁的缺口严丝合缝。他把纸角放在页角旁边比了比，缺口边缘对得上，纸角上残留的半截3和页角的0正好拼成一个完整的0317。有人从这页上撕走了一部分，撕得很急，边都没裁齐。

窗外又开始落雨。他起身走到窗边，楼下的路灯亮着，照出一片湿漉漉的水泥地。对面楼门口停着一辆外卖电动车，车灯没熄，黄制服的外卖员坐在车上低头看手机，头盔面罩推上去，露出一截下巴。陈默多看了一眼。那车停的位置，正好在路灯底下，车牌号末尾三个数字是317。他看了两秒，那外卖员抬头朝这边扫了一眼，又低下头去，拧了下油门，车往前挪了半米，仍没走。陈默把窗帘拉上，退回屋里。

他翻开种子书，第一页空白处有一道极浅的压痕，有人用指甲在纸上划过。他把本子侧过来就着光看，压痕断断续续，拼不出完整的字，只在纸角处留下一个笔画的末端，横折钩，像是记字的最后一笔。他合上本子，把它放回抽屉里，这次没压T恤底下，就搁在抽屉正中间，拉开一半，又推回去。

他需要想清楚一件事。那段录音里父亲说旧账，旧笔，旧路，三样东西，他手里只有这本种子书。旧账本在哪，旧笔又是什么。他父亲在录音里提到账本的夹层，可他翻过那叠旧账本，封皮都是纸的，没有夹层。他忽然想起昨夜翻遗物时，有一本暗红色软皮的账本搁在箱底，封面空白，当时他以为是空白的，没细看就放回去了。那本账本，他没带回来。

他抓起钥匙，在门口顿住，看了一眼窗外的雨，雨不大，他拉开门走了出去。楼道里的声控灯亮了一盏，他踩着一级一级台阶往下走，走到二楼拐角时，手机在口袋里震了一下。他摸出来，屏幕上是一条新通知：“您有新的通话录音已保存。”他没有停下脚步，把手机按灭，塞回兜里，继续往楼下走。
