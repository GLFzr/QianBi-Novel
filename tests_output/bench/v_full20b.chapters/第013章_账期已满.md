# 第13章 账期已满

凌晨两点，出租屋的灯还亮着。陈默把收据联、剪报册夹层便签、三条表对时了的短信截图、烟头滤嘴在桌面上排成一条直线。收据联右下角那个手写数字11，和便签上的座机号末四位，和烟头滤嘴上的0317，指向同一个日期。他把四样东西来回看了三遍，用整理旧账的习惯顺了一遍顺序：日期相同，金额相同，单号却有两联。一联是白条，在程师傅手里；一联是收据联，在他手里。中间隔着一行账期已结算。这说明第一联已经被人取走了，他手里的是存底联。

他把收据联翻过来，对着台灯看背面的压纹，纸面纹路里嵌着一道极淡的折痕，被人反复折过又展开过。他把四样东西按时间顺序重新排了一遍，收据联、便签、烟头、短信截图，每一件都指向同一个日期，但中间缺一个收件人的名字。

他拿起手机，拨通便签上的座机号。听筒里传来一段自动语音：城西修表铺，营业时间下午两点至晚十点。他挂断，把手机放回桌面。凌晨四点，他把种子书从背包里拿出来，翻开到页脚0319那一张。墨水笔抵住纸面，他想到维修工那句账期到了，想到程师傅后脑磕在路缘石上的声音。他合上笔帽，把种子书放回背包夹层。这一次他什么都没有写。他把种子书压在枕头下面，躺下去，盯着天花板那道细裂纹，一直到天亮。裂纹的走向像一条干涸的河床，他想起大连西路站牌背面那道油性笔的划痕，想起老屋书桌桌角刻着的0317。它们都指向同一个日期，而他正躺在这个日期的前夜。

天蒙蒙亮。陈默带着收据联出门，街面上只有一家早点摊冒热气。他走到城西修表铺门口，卷帘门落着，门牌上贴了一张拆迁待迁的告示，边缘已经卷起，露出底下旧门牌的一角。他蹲下来，从卷帘门缝往里看。柜台上一只挂钟停着，指针停在22:47。柜台后面的墙上钉着一排挂钩，其中一只空着，旁边落了一层灰，像什么东西被取走不久。他起身，转身要走，路对面停着一辆电动车，发动机没有熄火。黄色头盔的骑手跨在车上，镜片没有放下来，正面朝着他。

两人隔着马路对视了三秒。骑手拧动油门，电动车擦着他身边过去，经过时往他外套口袋里塞了一张纸条。没有减速，也没有停。陈默站在原地看着车尾灯拐进巷口，发动机声扯远，巷口恢复空荡。他低头，风把外套下摆吹起来，口袋里的纸条边角露出一截。

他掏出纸条。无落款，蓝黑墨水，字迹的收笔顿挫和种子书页角的案：0317是同一只手。他读了三遍：0317账期已满。下一次不是记忆。他把纸条折好，没有放回口袋，捏在手里。纸面是凉的，墨迹已经干透。他把纸条凑近鼻尖闻了一下，没有墨水味，只有一股旧纸的潮气，像在什么地方压了很久。

手机震动。林兰来电，声音压得很低："两个穿深灰夹克的男人，在我楼下打听陈建国。问'那本本子还在不在'。"

"你锁好门。"陈默挂断，拦了一辆出租车回老屋。车窗外的街景往后掠，他把纸条又展开看了一遍，蓝黑墨水的笔压透过纸背，在背面凸起一道痕。他把纸条折回原样，塞进外套内袋，和台历页贴在一起。出租车经过东门街路口时他往外看了一眼，护栏已经换成了新的，白漆裂缝被重新补过。那辆白色轿车撞过的地方，现在看不出痕迹。

老屋门锁完好。他直奔书房，推开门的瞬间，动作停住。台历翻开着，3月17日那一页被红笔圈了三遍，圈线交叠，纸面快被划穿。旁边歪斜地写着两个字，笔画带着压感的钝，像写的人用力摁着笔尖往下拖：收账日。他把台历翻回3月1日，逐页往上翻，每一页右上角都有一个极淡的铅笔点，轻得几乎看不出。从1号到16号，十六个点，排成一条线。他想起程师傅白条背面那串铅笔写的22:47，笔顺的同源性像一根细针扎进指腹。有人一直在数日子。数到今天。他把台历举起来对着窗外的光，那些铅笔点透光后更清晰了，每一个点都落在右上角同一位置，间距均匀，像用尺子比着画的。他数了一遍，十六个，没有缺号。

他合上台历，指腹按住收账日三个字。手机亮起，第四条短信，备注名还是那个三天前已注销的号码：表对时了。

他把台历那页撕下来，折好，收进外套内袋，转身出屋。门合上时，楼道拐角传来滴水声，一滴，停两秒，又一滴，砸在水泥台阶上。他停住脚，没有回头，把内袋拉链拉好，继续下了半层楼。滴水声跟在身后，间隔均匀，像在数他下台阶的步数。

走出楼门，太阳刚升起来，光落在台阶上。他低头看手机，屏幕还亮着表对时了。屏幕上方弹出一条新消息，备注名是父亲，只有两个字：

"去查。"
