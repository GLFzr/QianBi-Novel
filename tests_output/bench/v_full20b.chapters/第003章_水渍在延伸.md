# 第3章 水渍在延伸

闹钟响的时候，窗外的雨刚停。陈默睁开眼，床头柜上摊着一张外卖单底联，单号区印着0317。他不记得自己什么时候把它从包里翻出来放平的。手机屏幕亮着，一条林兰的语音留言，凌晨六点发的：“一楼走廊渗水了，可能是你家厨房水管没关紧，你过来看看。”他坐起来，喉咙干得发紧，把底联折了两折塞进裤兜。

到老屋时走廊已经积了一片水。他开门进厨房，台面上的水渍正沿着边沿往下滴，昨日那摞没洗的碗还搁在原处。水龙头是关紧的，水是从台面缝隙里渗出来的。他拧紧总阀，把那摞碗洗了。水流声停下来时，他忽然意识到一件事：他不记得自己昨天午饭吃过什么。那里空了一块，像一页被撕掉的时间。他站在水池前，手还搭在碗沿上，水珠顺着指尖滴回池底。他试着回想昨天中午的餐桌，出租屋那张折叠桌，桌角压着没扔的快递盒，然后什么都没有了。他记得自己上午在做什么，记得下午出门去老屋，中午那一段像被人用橡皮擦过，纸还在，字没了。

他翻包找物业缴费单，指尖在笔袋底部碰到一张对折的便签。展开，上面是自己的笔迹：“3月17日必须联系小周。”他盯着这行字，手指发凉。他不记得写过它，不记得小周是谁，更不记得3月17日要联系这个人做什么。字迹是他的，这个错不了，他写“必须”两个字的时候习惯把“必”字最后一笔拖得长一点，这行字上那个“必”也是这么写的。他把便签对折，塞进胸口口袋。贴身收着。

拿着缴费单下楼时，楼道口站着一个人。黄色工服，电动车歪在台阶边，泡沫箱刚从车筐里拎出来。正是昨天那个问“3门317”的外卖员。雨后的台阶泛着水光，地砖松动，缝里积着水，踩上去必滑。陈默看见他脚上那双运动鞋，鞋底已经磨平了花纹，踩上那级台阶的时候，鞋尖先着地，试探了一下。

陈默叫住他：“你叫什么名字？”外卖员抬头：“周航。昨天那单尾号0317的，是我送的。”说完把泡沫箱往手臂上一托，脚尖已经迈上那级湿台阶。

陈默退到楼道阴影里，翻开种子书。蓝黑笔尖抵在空白页上，他知道规则吗？不，他只知道昨夜录音里那句没说完的话。犹豫三秒。他写下：周航，3月11日9时52分，滨河道12号一楼台阶，右手握紧扶手，停住半步。

落墨。纸面安静得像一本普通笔记本。他合上书页，心跳撞着肋骨。他在心里数秒，数到十的时候，楼道口还没有动静。数到十五，一声闷响传过来。

他几步冲出去，看见周航半跪在台阶上，右手死死攥着扶手栏杆。没摔。泡沫箱从臂弯里甩脱出去，倒扣在台阶边，箱沿裂开一道口子，汤水溢出来，顺着地砖缝流成一道细线，不偏不倚接在昨日那滩旧水渍的延长线上，然后停住。周航骂了句脏话，爬起来拍了拍膝盖上的水，弯腰去捡泡沫箱，回头冲他笑了一下：“这台阶真滑。”

陈默站在原地。手心里的种子书不烫、不响，像一件死物。但他知道它刚才动过一次。周航把泡沫箱扶正，箱角还在淌水，他拿手抹了一把，甩了甩：“得，这单得赔了。”他跨上电动车，拧了油门又松开，回头补了一句：“谢了啊，刚才那下要不是扶住，我后脑勺得磕台阶上。”陈默没接话。周航也没等他接，电动车碾过水渍冲出了巷口。

午后回到出租屋，灶台上摞着三只空泡面碗。他不记得自己吃过其中任何一碗。他拿起最上面那只，碗壁上还挂着没干透的汤渍，筷子上沾着面渣。他放下碗，翻手机想找昨晚的通话记录，屏幕还停在通讯录页面，最上面是一通凌晨2点17分拨出的电话，时长11秒，号码尾号0317。他想不起那通电话里自己说过什么。他拨回去，听筒里是忙音。再拨，还是忙音。号码不在他的通讯录里，通话记录里也没有备注。

傍晚，雨又下起来。陈默在老屋门口重新翻开种子书，就着楼道口的白光照向页角。纸面干净。他把书斜了斜，一道极淡的压痕在光下显形，像铅笔描过又被擦掉，只留半行字：“14:07 东门街路口。”纸是凉的，字像被水泡过又干透的旧痕。

他不认识东门街。他把书合上，又拉开。压痕还在。

隔壁门开了，林兰撑着一把滴水的伞出来，手里捏着一串钥匙：“昨天落你家门口台阶上了。”她身后跟着一个扎马尾的小女孩，五六岁，正低头系鞋带。林兰收了伞，随口说：“果果明天七点要去东门街那边上科创营，我本来还愁下雨怎么送。”

陈默的拇指压住页角那半行字，没把纸给她看：“你说哪里？”

林兰把伞往墙边靠了靠，语气平常：“东门街路口呀，滨河道那头，有个红绿灯的。”

陈默低头。页角的压痕在灯下发灰。他问：“果果几点到那个路口？”林兰答：“七点，她爸送。”陈默看着纸上那半行字，早上七点，纸上写着下午两点七分。他问：“她平时不走那边吧？”林兰奇怪地看了他一眼：“今天不去，明早要去东门街路口那个红绿灯，她爸顺路送。”说完她牵着果果转身进门，门在身后带上了。

陈默站在走廊里，把种子书重新翻开到页角。白光底下，那半行压痕下面，隔着一道纸纹的距离，正慢慢浮出第二笔。笔画极淡，像是没写完就被按了回去。他看不清那是什么字。

楼道尽头，老屋里传出一声滴水。水龙头已经拧紧了，他没有再动。那滴水声一下，又一下，不紧不慢地落着。
