# 第5章 138秒

凌晨三点，老屋楼下的台灯还亮着。陈默坐在藤椅里，膝盖上摊着种子书。页角那行字在灯下发灰：停留：138秒。

他合上书，又翻开。合上。再翻开。纸面没有变化，那行字还是那行字。他站起来走到窗边，巷子里的路灯隔一盏亮一盏。又坐回藤椅，把书压在大腿上，一个字一个字重新看过去。他关灯躺下，两分钟后重新拉亮，把书页翻到同一面。字还在原处。他不知道自己在怕什么。怕它变多，也怕它不变。

凌晨三点四十七分。他正要再次把台灯拧暗，目光落回页角时，那行字下面多了一行小字。墨色与父亲留在封面内页的字一样，沉进纸纹深处，不是刚写的浮墨。写的是：明 07:12 停留处有车刹不住。

陈默的手停在纸缘。笔在桌上，笔帽盖着，墨水瓶昨夜拧紧后就没打开过。他很久没有动，直到台灯的热度烫到指背。那行字的笔迹他认得。收笔带一点往下压的顿势，是周珩的字。他已经不在了，可他的笔迹刚从纸上多出来。

他合上书，又猛地掀开，那行字还在。指腹摸过去，纸面有轻微的凹痕，这行字像是早已存在，此刻才被光线显出来。他想起父亲录音里那句没说完的话。账不由命运收。那这行字算谁写的？

他起身，从老屋抽屉里翻出一张折成小方块的旧纸。边缘起了毛，折痕深得发白。展开，父亲铅笔字写在纸页斜角：不可贪。下午收拾遗物时他见过这张纸，当时只当作父亲随手记的备忘。他取来铅笔，顺着字迹轻轻描了一遍。纸背透出一道淡影，不凑近根本看不见。他把纸翻过来对着台灯，又翻回正面。浅字从纸纹里浮出来：

“改写是替人挡，不是替天改。”

他读了三遍。那行字先写“挡”，又划掉，改成“替人挡”。下笔的人改过两遍，像不知该把话说多重。他想起页角那道批注“不可贪”，想起父亲留在册子里的每一处铅笔字。他一直以为那是日记，现在才明白那全是警告，一句比一句轻，也一句比一句重。挡一次摔，挡一次撞，挡一个孩子在一辆刹不住的车前多停的那几秒。可替人挡了之后呢，那笔账记在谁头上？页脚那个还没出现的编号，就是答案。

凌晨四点二十六分，他拨林兰的电话。响到第四声，机械女声接起来，提示对方已关机。他放下手机，按亮屏幕又按灭，离早上七点还有两个半小时。林兰手机上的未接来电会在一早出现。假如她早起看见，可能来得及换条路送果果。也可能来不及。

他又拨了一遍，还是关机。他盯着通话记录里那个名字，拇指悬在重拨键上，最终把手机扣在桌上。他试过用普通的方式解决。电话打不通，凌晨四点半他总不能去敲一个单亲妈妈的门，告诉她你女儿明天早上七点十二分会在一辆刹不住的车前面站一百三十八秒。

他翻出父亲贴在册子内衬的那页纸。背面边缘还有一行更小的字，下午读时被他略过了。他重新对着台灯，铅笔轻轻扫过纸面，那行字从阴影里浮出来：“字有多长，醒着的时间就还多长。”

他停住笔尖。原来写下去不只是落一个字，是要从脑子里抽走什么去换。周航那回他只写了一句话，代价是三碗记不得的泡面。这回要写一整行，抽走的会是什么？他不敢想，但笔已经握在手里了。

凌晨四点五十分。他把种子书翻到空白页，对照父亲留下的两行格式记录重新读。上一回改写周航，他只写了一个动作，一句话。这一回，要让一个孩子在那个路口多停一百三十八秒，句子会更长。他试着在草稿纸上先写了一遍，又划掉。太长了。字越多，抽走的记忆就越多。他删掉“因鞋带散开”的前因，只保留动作本身。想了想，又加回去。没有前因的改写像悬空的梯子，他不敢赌它能不能落地。

五点十二分，他拧开墨水瓶，钢笔尖探进瓶口，吸满。他把空白页摊在台灯正下方，纸面干净，能看清纸纹的走向。他落笔，没有停顿：“林果果，07:12，东门街路口，因鞋带散开蹲下系鞋带，停滞至绿灯转红后第3秒才起身。”

合上本子时，太阳穴像被什么从侧面敲了一下。钝痛从耳后蔓到眼眶底，他伸手扶住桌沿，低头，左手小鱼际上多了一道墨痕。短促的斜线，像谁用笔尖在皮肉上快速划过。他擦了擦，擦不掉。墨痕渗在皮肤纹理里，跟纸页上的字一个颜色。

他坐在藤椅里，很长时间没有翻那本册子。他想试着回忆昨天午饭吃了什么。那一段记忆正从内部融化，像隔一层水看水底，轮廓还在，细节捞不上来。他攥了攥拳，指节发白。越是想抓住那一块，它就越模糊，直至只剩一片深灰。他想起周航那回，灶台上三只泡面碗。这一次抽走的是哪一段，他暂时还不知道。

五点三十一分。他重新摊开种子书，没有看正文，只翻到页脚。那里无声地多出一行数字。0319。

他看了很久。上次改写周航，页脚没有增加任何东西。这一次，编号出现了。0319。父亲页角留下的是0317。两个数字隔一行，像同一本账簿的上下两笔，中间还缺着一行空白。他想起父亲批注页背面那行字。改写是替人挡，不是替天改。页脚的数字或许就是挡的次数。他替周航挡了一次，没有编号。这一次挡了林果果，编号出现了。为什么？因为他挡的是一辆车，还是因为他挡的是一个孩子？

门外忽然传来脚步声。皮鞋落在水泥地上，一步一步，不快不慢。凌晨五点半，这条老楼里不该有人走动。声音在他门口停住了。他坐在藤椅里，台灯的光圈把他钉在原地。脚步声没有离开，也没有继续往前。

过了十秒。

门缝底下挤进来一个压低的女声，几乎是贴着地面说的：

“陈默，我知道你醒着。”
