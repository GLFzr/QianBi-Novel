# 第24章 折痕底下那一角

陈默把信封举到窗前时，窗玻璃映出他自己身后走廊尽头一截深色衣角，比病房门口的位置更远，但角度恰好正对他手中的信封。

他没有回头。隔着两层玻璃，那截衣角静止了约两秒，像在确认他还没有拆开封口，然后朝防火梯的方向退走，消失在反光的边缘。陈默压住呼吸，把信封放低，等了两拍，才重新抬起手。他没有立刻拆，先让心跳落回正常的速度，再确认那截衣角没有重新出现在反光里。

他合上门，走到窗边，背对门站着，把信封再次举到光下。走廊的灯管在身后闪了一下，窗外的月光透过磨砂玻璃铺进来，两层光在纸面上交叠，把信封里的内容照出一个模糊的轮廓。里面的纸确实被折过，折痕的走向与他内袋里那张航空信纸一致，纸张的颜色和质地也相同，但比内袋那张小一圈。他把信封换了个角度，让月光从侧面打进来，纸面上透出一行行字迹的压痕，但没有一处是完整的，全被折痕截断。

他隔着纸捏了一下厚度，里面叠着两张纸。上层那张薄，下层那张稍厚，像是一张写过的纸垫在一张空白的纸上。他用指甲尖顺着封口的边缘挑起，封口的胶痕已经被手指抹平过，边缘留着一道很浅的指甲印。他没有撕，让封口自然张开。

倒出来的纸叠得更小，只有内袋航空信纸的四分之一大小，折痕压得极深，纸张在展开时发出细碎的响声。他展开第一折，露出父亲笔迹的开头：三年前3月17日22点47分，东门街路口，补写。字迹比内袋那版更小，行距更密，像是写下这行字的时候，落笔的人知道纸不够用。他数了一下行数，比内袋那版多出三行。

他展开第二折。事件细节的中间段比内袋那版多出两个字，写在补写与白色轿车之间。那两个字很小，笔压比周围的字重了一度，像是后来补上去的。他认出那两个字是另一种更急的写法，收笔时没有顿点。

他没有继续往下展开。后半段被折痕压住，纸页在那一处折得特别死，像是有意不让它被打开。他把纸翻到背面，背面没有字，只有一道蓝黑色的墨渍划痕，从纸的左上角拉到右下角，力道很重，划破了纸面。划痕的弧线和他刚才在空信封内侧看到的那个偿字轮廓首笔同向。

程师傅在病床上翻了个身，被子窸窣作响。陈默停住，把纸按在信封上没动，等那阵声响落定，程师傅的呼吸重新拉长。他把纸原样折回去，塞进信封，压进封口，放回床头柜台灯旁原来的位置。封口保持敞开，纸角露出的朝向与发现时一致。

他掏出手机，屏幕亮度调到最低，快门声关掉，把展开的信纸正反面各拍了一张。先正面，再背面，拍完立刻锁屏。他没有把纸带走，把信封的角度旋回自己刚拿起时那个位置，退到门口，最后一次用余光核对。信封角度与刚才一致，封口敞开的角度也与刚才一致。

他退出病房，带上门。护士站的灯管还在闪。他没有走电梯，推开防火梯的门，在楼梯间半层平台站住。

从外套内袋取出种子书，翻开页脚。

撕纸残余旁，“廿二，与阿莲同车”那行字的边缘，发毛的痕迹比昨晚更宽，像被水汽洇过，笔画的轮廓变得模糊。他翻到下一页，页脚外缘渗入一枚极淡的轮廓，那是一个字的起笔，撇的弧线，与空信封内侧那道偿字轮廓的首笔同向。他用指腹擦了一下，擦不掉，墨迹在纸面以下。

他合上种子书，攥在手里。楼梯间的声控灯灭了。他站了三秒没有动。

黑暗里，楼下防火门被推开又合上，铁门框撞上门框，发出一声闷响。那个声音很快，是有人出去了。他往楼下快走两步，到转弯处探身往下看，防火门还在轻轻晃动。

楼梯间没人。他站在原地，手机在口袋里震了一下。

他低头看，不是代驾号码。是程师傅的号码发来一条短信，只有五个字：“你从我抽屉里。”落款是程师傅的名字。

发信时间显示为23:52，比陈默退出病房早了四分钟。
