# 第14章 事务所的旧纸

陈默蹲在单元门口，背靠水泥门垛，膝盖上摊着那张纸条。天还没亮透，东边一层灰白压着楼顶线。纸条被他翻了一整夜，边角起毛，折痕泛着细纹。字确实是他的，从起笔到收锋都是他平时写字的习惯，但他从来没写过这一行：3月17日22:47，我会去东门街路口。

我会去三个字用的是现在时。

他试着回想写下这行字的那个晚上，手指悬在纸上、笔尖落下去的触感，脑子里却只有一片光滑的空白，像刚擦干净的黑板。他把纸条翻过来，正面朝下压在膝盖上，过了一会儿又翻回去。每翻一次，那行字都在，一滴墨都没少。

天亮到六成时，他把纸条对折收进里袋，和牛皮纸信封、手机贴在一起。摸出手机拨出父亲的号码，听筒里彩铃响了整一圈，无人接听。他挂断，把手机收回兜里，没有留话。

早班公交六点一刻到站，车厢里只有三个乘客，一个在打盹，一个在看窗外，他坐最后一排靠窗。窗玻璃上蒙着一层夜里的灰尘，他用袖子擦出一块。数过从老屋到出租屋的站台：城西、机械厂、纺织路口、中医院、文昌阁、南门桥、农贸市场、毛巾厂、金桂苑、东站新村、终点站，一共十一站。每一站的站名他都记得很清楚，站牌底下是瓷砖还是水泥地，也在脑子里排成一条线。今晚会忘掉其中几个，他说不准。

车过纺织路口时，乔一宁发来微信：“那个虚拟号我托人查过，实名是个空壳。别回拨，照片别删。”他回了一个字，嗯。手指在发送键上停了一下，又补了一句：“程师傅醒了。”那边隔了半分钟才回：“他记得多少？”

“被撞那段是空的。”

乔一宁没有追问，只回了三个字：那正好。

他看了这三个字几秒，锁了屏。

出租屋楼下，程师傅的电话先进来。

小默。

程师傅的声音被砂纸磨过，沙哑。陈默想起前天夜里观察区那扇门推开时，老人躺在白被单里，嘴唇干裂的样子。

“我醒了。人醒了脑子没醒。有一段是空的，不记得怎么到的东门街，不记得谁打的电话。”程师傅停了一下，陈默听见电话那头氧气瓶推过地面的咕噜声，然后老人接着说，“只记得有个女声，说有人会找你。”

陈默没接话。时隔两天，同样的六个字换了一个人说出来，他没想好该问哪一个。他问出口的是另一句：“事务所里有多少卷宗？”

“十几个案子，都是没结的。眼下我在医院里，我一个人也翻不动那些纸。”程师傅咳了两声，“有两份是意外死亡。我想着，你脑子清楚，又能沉住气，替我把台面上的东西理一理，等我出院。”他顿了顿，没等陈默开口又补了一句，“你爸以前也帮我理过卷宗。”

陈默攥着手机没接话。话头落到父亲身上，他没顺着往下接，只说：“我下午过去。”

“钥匙在门楣上，左边第三块砖后面。”

挂断电话，他把录音里那句“这本子留给陈默”又听了一遍，才回拨过去。他报了名字，说了句我去，挂了。

下午两点，城西事务所。门脸夹在五金店和彩票站中间，卷帘门拉上去一半，露出被遮了大半天的昏暗。屋里一股纸和灰尘混出来的气味，像旧书铺子在梅雨季节闷过头了。阳光从门顶缝斜下来，照在门内地板上一道白线，白线那边，纸箱子摞到齐腰高，边缘翘边的文件袋从缝隙里探出头。桌角压着半杯凉透的茶，茶水表面浮着一层细灰，杯壁上留着一圈干了的茶渍。

卷宗堆在办公桌上，摞了三层。最上面一份是人损案，第二份是合同纠纷，翻到第三份才是网约车司机碰撞案。牛皮纸卷宗，边角磨得发白，封面上用圆珠笔写着编号，前几页是报警记录和问询笔录。死者男性，四十一岁，凌晨三点收车回家，撞上护栏，车头起火，人没能出来。报案人一栏填着路人，目击者一栏空白。

他一页一页翻。事故认定书，尸检报告，家属谈话记录。翻到认定书那一页时，页脚露出一张比普通纸薄许多的纸片，边角泛黄。如果不是纸的质感不对，很容易被当成卷宗自带的一页隔纸。上面是打印体：案：0316。这四个字是打出来的，与种子书页角的编号格式几乎一致，案字后空一格，四位数字。

他翻到背面，空白。纸片边缘平整，没有胶痕，订书机钉孔也没有，像是有人用它当过书签，一夹就是很久。他又翻了一遍事故认定书前后的页数，纸片的位置夹在认定书和尸检报告之间，这个位置像是有人刻意选的，翻开就看见。

后面两份卷宗翻完，页脚干干净净。他蹲在卷宗堆旁，把那片薄纸夹在食指和中指之间，摩挲了一下边缘，最后把纸片对折，放进外套内袋，与那张纸片的照片隔了一个口袋。

傍晚从城西出来，他没坐车，顺路走到东门街。路口修路，围挡遮住半条人行道，切割机在远处作响，空气里一股烧焦的沥青味。站牌底下的裂缝还在，白漆被鞋底磨掉一圈边，露出底下灰黑色的铁皮。他没动种子书，只站在路肩上，站在和那天早晨同样的位置。绿灯亮起，行人走过，尾巴上一个人加快了步子，小跑着穿过斑马线。他站着，一直看到红灯再次亮起，才转身往出租屋的方向走。

回到出租屋，他摊开种子书，搓掉指尖在纸页上停留过的一层灰。页脚0319与0320并排，下方干干净净，没有第三个编号。但页边压痕处多了一行极淡的铅笔字。笔迹不是他的，也不像父亲的，写着：第三个连接点：东门街仓库，老赵。

连接点三个字，上一次出现在第7章页痕里，指的是老周。这次换成了老赵。他没有问自己这两个姓之间隔着多远，先想到的是：页痕从来没有给过连接点后面的具体地址，这次给了仓库和名字。

他盯着老赵两个字看了很久。修鞋摊的老周，页脚成形的航字，程师傅病历单上的程字，再添上这一个姓，四个人名排成一条他没有主动选择的路。他拿起笔，笔尖悬在页面上方，墨水聚成一滴，又被他挪开。笔始终没有落下去。

他把种子书合上，压到枕头底下，又翻出外套内袋里的0316纸片，放在书旁。最后是牛皮纸信封。林兰交给他时说了句第一期付款。他掂了掂，很轻，像没装东西。他把三样东西排成一行，在枕边摆平。

灯关了。窗外路灯光斜着切进来一小块，落在地板砖缝上。他翻了个身，枕头边有什么东西硌了一下。他摸到牛皮纸信封的毛边，拆开的念头从脑子里冒出来，这次他没往下压。他坐起身，就着手机屏幕的光，撕开封口。

里面只有一张纸质发硬的收据。没有现金，没有单据，纸对折过，压得平平整整，边角带着潮气捂过的黄。抬头是城西一家早就停运的货运站。日期，三年前的3月17日。金额栏填着一个数字，没有商品名。他盯着那个金额看了一会儿，才明白第一期付款指的就是这张纸。

收据背面，圆珠笔两行字。字迹不是父亲的，也不是林兰的，写着：3月17日22:47，你的表在仓库里。
