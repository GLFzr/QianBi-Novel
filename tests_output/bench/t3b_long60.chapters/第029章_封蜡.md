# 第29章 封蜡

路灯下，陈默低头看自己内袋鼓出的硬纸筒轮廓，筒口蜡壳上那个缠胶布的指印，在橙黄灯光下现出一道极淡的绒毛边。他捏住筒身一端，蜡没有碎。这蜡封了很多年，刚在门缝里滚落一时，蜡壳边缘还带着殡仪馆走廊那股消毒水味，隔着衣料直透进肋骨。

他站在原地没有动，隔着外套按住纸筒，先判断了一件事：不能在这里开筒。蜡壳上的指印太清楚，等的人可能就在门缝后。他转身，不回头，步行绕过正门监控区，沿着路灯照不到的墙根走，走出两百米，在一家还亮着灯的24小时便利店门口停下来。

他面对玻璃橱窗站定。玻璃映出身后马路空无一人，只有一辆熄火的灰色面包车停在街对面树影下，车头朝老屋方向。他看了两秒，推门进店，走到靠玻璃的货架边，背对马路，拆蜡壳。

蜡壳在指尖裂开一条缝，没有碎，沿着封口完整地断开。筒内掉出一张折成四折的航空信纸，和一枚断笔芯。他先捏起笔芯，对着店内日光灯比了一下，断位与程师傅抽屉隔层那枚、昨夜档案盒底那枚，三枚同型同墨，笔杆粗细一致，断口角度一致。他把笔芯放在货架边缘，展开信纸。

折成四折的航空信纸，纸色与他内袋那张一样发黄。信纸上记录了一次改写，开头格式与父亲手写完全一致，改写对象名字被同色墨水涂死，只留半个厂字边角。事件细节指向三年前3月17日22点47分，地点栏被一道折痕压住，他展平后，看清事件细节栏后半段写着一个地址：城西老屋。

就是他自己刚离开的那间。

他停住，没有继续往下看。指腹压在地址下方的批注上，父亲笔迹：“这笔账，还差一次。”批注边角有一道极淡的划痕，弧线走向，与档案盒底偿字首笔同向。

他翻出种子书，页脚偿字新墨还在，页痕以北被一道更细的新痕划掉，改写为以南。他拿起货架边缘那枚断笔芯，笔尖断口沾着一粒墨渣，与改痕同色。页痕方向被外部改写者动过，第一次以南改以北，第二次以北改回以南，两笔改痕方向不同。筒内这支断笔芯，是其中的一支。

他用掌心里那截透明胶带头把蜡壳原样封回筒口，买了一张明信片裹住纸筒，走到便利店门口，投进邮筒。转身时，手机亮起一条网约车推送：起点城西殡仪馆，终点老屋，行程时长与他在便利店停留的时长重合。他回头扫过马路对面，灰色面包车已不在原位。

手机又震了一下。锁屏界面上，推送下面多出一行备注：行程已规划，接驾司机将于23:04抵达，请保持手机畅通。

他看了一眼锁屏时间，22:59。距离那辆预设他回老屋的车到来，还有五分钟。
