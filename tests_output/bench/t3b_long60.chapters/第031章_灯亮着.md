# 第31章 灯亮着

信纸压着门槛与门之间。第一行是父亲笔迹。第二行他没看全。

陈默蹲在门槛前，指尖夹住纸角，借路灯余光照见第一行字。他没有继续抽。松开纸角，让信纸落回原位，起身推门进屋。屋里没开灯，他先用手机屏幕微光照了一遍地面，确认鞋底没有带进泥，才迈过门槛。门轴发出很轻的响声，在安静的夜里被放大，他停下来等那声响落定，才继续往里走。

窗台积灰上有一处指印，无名指和中指间距比常人大，像是戴过戒指的压痕。他没有碰窗台，用衬衫下摆垫着指腹擦了一下边缘，确认灰不是新落的，指印边缘已经结了一层薄壳，留下至少半天以上。他蹲下来，把手机屏幕的光侧着打过去，指印的纹路在斜光下显出几道平行的细线，是织物压痕。戴手套按的。

他站起来，没有继续看窗台。书桌抽屉的闭合位比昨天多出一指宽。他拉开，拉手内侧有一道新痕，胶带撕除后留下的黏痕，边缘卷起一点白边。抽屉里的文件被翻动过，但一件没少。最上层压着一张白纸，没有写字。他把抽屉推回去，没有关严，留着那道一指宽的缝，和发现时一致。

他退出屋，没有关窗灯。灯亮着是信号，他判断它该继续亮着。他站在门槛外，回看了一眼窗灯，光从旧窗帘的缝隙里漏出来，落在地面上，像一条被压扁的线。

他绕到屋外，蹲下，从门缝侧面用钥匙柄挑出信纸一角。这一次他看到了第二行的开头：一个时间，十五点零七，比手机备忘录里那个二十二点四十七更早。第三行露出一半，纸边是米色的，有细条纹，酒店便签纸的纸质，和父亲桌上那叠便签不一样。他把纸角原样塞回门缝，没有抽完，站直，在门槛前等了几秒，确认没有脚步声。然后他转身沿巷子往外走，不回头看。

走出巷口，他在路灯下站定。路灯的光把他影子拉长，斜斜地落在柏油路面上。他掏出手机，屏幕亮起，备忘录里那条“3月17日22:47，去东门街路口”旁边，多出一行字：“往北走，有一个修表的人见过那只表。”

他没有打字。他盯着那行字看了三秒，锁屏。手机屏幕暗下去，路灯的光重新落回路面，他站在原地，没有动。巷子深处，老屋的窗灯还亮着。

他想起窗台指印的无名指间距，和老赵手里那只烧痕表带上的勒痕宽度对得上。烧痕表是老赵在王开志遗物里找到的，表带内侧的勒痕宽度他比对过，两指间距几乎一致。他把这个联想压下去，没有继续往下想，因为现在不是想这个的时候。他需要先确认一件事：那行字是什么时候出现在备忘录里的。

他重新解锁手机，打开备忘录，查看那条记录的编辑历史。没有编辑记录。他退出备忘录，打开相册，翻到白天拍的照片，确认自己在白天没有打过这行字。他又检查了一遍键盘记录，空白。那行字不是他打的。

他把手机锁屏，塞回口袋。巷子深处，老屋的窗灯还亮着。他转过身，朝巷口外走，没有回头。
