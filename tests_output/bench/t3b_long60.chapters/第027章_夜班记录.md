# 第27章 夜班记录

他没有回复那条短信，把手机装进裤兜，弯腰把饼干盒推回原位。铁皮与木槽卡紧时，他闻到一股很淡的消毒水味，从自己外套袖口窜上来，殡仪馆那种。

他把种子书、平面图、借阅单残角装进外套内袋，锁门时指尖沾到饼干盒铁皮划痕的灰，没擦就直接出了门。

凌晨两点的城西，路灯间隔着灭了两盏。他没有叫车，步行绕过正门监控灯，从殡仪车通道侧门进去。两米宽的灰白内墙，灯管发出低频的嗡声，消毒水味从墙缝里涌出来，和袖口上那股味道叠在一起。走廊地面铺着深灰色防滑砖，砖缝里嵌着陈年的灰，鞋底踩上去没有声音。他贴着墙根走，避开头顶那盏亮得发白的灯，在它照不到的阴影里停了一步，确认走廊尽头没有人才继续往前。

走廊尽头夜班值班室亮着白灯。老周坐在里面翻报纸，听见脚步声抬起头，目光先落在他外套内袋鼓出的形状上，又移回他脸上。“办遗物手续的，夜班记账那屋。”陈默说。

老周放下报纸，打量他几秒：“你爸以前说，这里的东西别碰。”他把钥匙从抽屉里取出来，推过桌面，“前些天，有人拿你爸工号来问过档案室。”

陈默伸手去接钥匙，老周没有松手。“两小时后来锁门。”他说完，松开钥匙，重新拿起报纸。陈默把钥匙攥在手里，钥匙圈上挂着一块旧铁牌，牌面磨得发亮，上面刻着一串编号。他没有多看，转身往走廊深处走。

档案室在西北角，门没有锁，锁舌缩在门框里。他推门进去，反手把门带上，没有开灯，先站在门口等眼睛适应黑暗。月光从高处一扇窄窗漏进来，照在档案柜的金属边上，拉出一道细长的白线。他借着那道白线走到西北角，蹲下来，用手电筒的光照柜架侧面的编号标签。标签是印刷体，灰底黑字，一排排扫过去，在F-17的位置停住。

他拉开柜门。金属摩擦声在空旷档案室里被放大，他用脚尖垫住门框减小响动。柜内档案盒印刷体“F-17”，盒面落灰，边角被反复开合磨得发白。他抽出档案盒，放在膝盖上，翻开盒盖。盒内是一叠夜班记账，纸张发黄，边缘卷起，按日期排列。他翻到中间，夹着一张正式借阅单。编号“0316”开头，借阅日期是他生日前一天，借阅人栏写着“陈国平”。他把残角从内袋里取出来，压上去。水渍弧线与断口严丝合缝，编号拼成一个完整的整组。残角的水渍与正式单的水渍，是同一条水流洇开的。

他手指顿了一下。借阅人栏“陈国平”三个字里，“国”字的笔画有轻微颤抖，笔压在收尾处陡然变轻。这不是父亲的习惯笔迹。

他继续往后翻。记账单中间夹着一张对折的白纸，没有抬头，只写着一行字，字迹不是父亲的：“你在找的东西，不在这个盒子里。”他没有碰那张纸，用手机拍了照，把纸按原样夹回记账单中间。

盒底露出那截断笔芯。他捏起来，笔杆上刻着“偿”字，与程师傅抽屉隔层那截同型同墨。朝向是尖朝外、杆朝里，递到眼前人一眼就能看到的方向。他拍了照，把笔芯放回原位，角度全无偏移。

他合上档案盒时，门缝被从外带住。门把手转了一半不再动，像是有人从走廊那边按住。他停住，抵住柜门，隔着门缝看到走廊灯光下一双灰色鞋尖，鞋面朝门。

他后退两步，墙柜暗格滑出一张旧照片，只露出一角。父亲和一个陌生男人的合影，背面半行字被水渍浸掉。他没有抽出照片，把暗格推回原位。

档案室外传来金属推车刹停的声音，轮子碾过水泥地，停在门口。灰色鞋尖退后半步，露出裤腿边缘一小截白布，像缠在手指上那种。推车又往前推了一寸，响声停在他右手边那块地砖上。
