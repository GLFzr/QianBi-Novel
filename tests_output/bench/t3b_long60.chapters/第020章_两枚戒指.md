# 第20章 两枚戒指

窗外男子敲完第二下玻璃之后，没有等陈默回应，自己先开了口：“我知道你有一张巡更表。表不表的不重要，我想看看表上那个签名钉在哪个时刻。”

他说话的语速不快，手指在玻璃上划了一条线，正好是巡更表上22:47那一栏的横线位置。他说这句话时的语气像在核对自己的记忆，而不是征求同意。他事先知道那张表的内容。陈默站在灯下，没有动。他把手从外套内袋里抽出来，空着手，垂在身侧。隔着那块落灰的玻璃，两个人之间只隔着一层光。

男子从外套内袋摸出一张照片，折了一下，从玻璃和门框的缝隙里塞进来，半张露在外面。陈默没有伸手接，退后半步，让台灯光落在照片边缘。照片上老赵站在白车旁，低头看手机。天色是傍晚，车尾灯亮着，地上的影子被拉得很长。拍摄角度不高，是从路对面某个固定位置拍的，像是蹲在马路牙子上等人时顺手举起手机的那种角度。

“你找的人还活着。”男子说，“但你也看到了，他旁边那辆车，你认识。”

陈默不接照片，不接话。他的视线从照片上移到男子脸上，又移回照片上。老赵的衣领立着，下巴缩进领口里，像在等人，又像在躲人。照片右下角的日期水印被裁掉了，只留半截像素点。那种裁法很熟练，像是用什么工具切过的。

两个人隔着一块玻璃，灯光把中间那道灰痕照得分明。

男子说，表换人。“你手上那张表，是我老板想要的东西。你把表从门缝递出来，我告诉你老赵晚上去了哪。”

陈默退回抽屉前，拉开，从旧文件夹里抽出一张空白巡更表。他把外套套上去，夹在指间，在灯下晃了一下，又收回来。隔窗看，看不见内页，只看得见表套子上的横格和纸色。男子的瞳孔在那一瞬收了一下。陈默抓住这个间隙，开口：“表可以给。你先告诉我，三年前3月17日22点47分，你在不在这个仓库里。”

男子沉默了几秒。灯管发出细碎的电流声。陈默握着那张假表套，手没有动。窗外的人影在玻璃上定住了两三息，然后他忽然笑了一声。

“你爸不是第一个，也不是最后一个。”男子说，“你以为你拿着笔是在救人，他不知道他拿着笔是在记账。”

他说完这句话，身体微微前倾，手掌贴上玻璃。陈默看见他右手腕内侧有一条横向的烧伤疤痕，颜色暗红，像被什么东西烫过，不是旧伤，边缘还泛着细碎的白皮。那条疤横过腕骨，正好被袖口盖住一半，如果不是他这个姿势，不会露出来。

陈默没有后退。他低头看了一眼脚边。值班室角落半截松动的砖块边滚着一颗小石子，他脚尖一拨，石子滑出去撞在门框上，发出一声脆响。男子的眼神下意识朝声源偏了半寸。陈默借着这个瞬间，把空白表套扔回抽屉，合上，站起来。

男子看回来，脸上的笑收了。他在窗外站了片刻，左手从口袋里抽出来，捏着那半张照片的边角，又塞回内袋。他隔着玻璃看了陈默一眼，那一眼比刚才长了一息，留下一句：“表你留着，看你能留到几号。”转身朝白车走去。驾驶座门打开，他坐进去，倒车灯亮起，引擎低响，车尾灯沿着仓库区出口的方向慢慢驶远，消失在灰雾里。

陈默站在窗边等了三秒。车没有折返。他低头翻开种子书，页脚新增了一行极小的铅笔字，墨迹还没干透：廿二，与阿莲同车。

他念了一遍。这个数和日期、编号对不上。页脚从来没有给过这种写法。他翻了一页，确认后面没有补充。

手机屏幕亮了。网约车平台弹出一条接单提醒。乘客确认用名只有两个字：阿莲。起点，城西殡仪馆正门。下单时间显示十分钟后。

他念出这个名字时，不知道为什么，和页脚那个廿二放在一起，像一个被对折过的号码。

陈默把种子书合上，攥在手里，关灯。值班室暗下来，摄像头屏幕上的画面切换成夜视模式，一个轮廓站在暗处，是他自己。他推开值班室门，朝仓库区出口走去。

走到大门外，路灯下他重新看了一眼订单详情。阿莲的下车备注是手打的，只有一句话：师傅，去东门街路口，到地方等我十分钟，不用催。

东门街路口。他今天刚从那片地方走过，那是林果果没有出事的路口，也是程师傅被撞伤的路口。同一个地点，再次出现在一个陌生乘客的备注里。他抬头，路灯照见马路对面停着一辆黑色车，引擎没熄。
