# 第25章 抽屉里的东西

防火梯间声控灯灭，手机屏幕亮起，程师傅的号码发来短信“你从我抽屉里”，发信时间23:52，比陈默退出病房早了四分钟。

陈默没有立刻回拨。他先盯着那个时间看了三秒，把时间线在脑子里过了一遍。他退出病房是23:56，短信时间是23:52，比他早了四分钟。也就是说，这条短信发出的时候，他还在病房里。程师傅当时躺在床上，呼吸匀长，没有动过手机。他低头看了一眼短信落款，程师傅的名字，三个字，和他通讯录里存的一致。但程师傅本人不会在睡梦中发短信。

他按了回拨。听筒里响了七声，无人接听。他挂断，又拨了一次，响了两声后变成忙音。程师傅的手机没有关机，但没有人接。如果是程师傅自己发的短信，他不会不接电话。这条短信发出时，手机在另一个人手里。

他收起手机，推开防火梯的门，往病房走。走廊的灯管还在闪，护士站台面上没有人，推车靠墙停着，橡胶轮压着一道深色的水痕。病房门半开着，程师傅仍靠床头，眼睛闭着，呼吸匀长。他站在门口，先确认程师傅的胸口在起伏，才走进去。

他先看床头柜上的信封。封口角度与他离开时一致，封口胶痕没有被重新粘过的痕迹，边缘那道指甲印还在原位。他犹豫了两秒，拆开封口。

信封内不再是那张折痕极深的完整改写记录纸页。里面平躺着一张空白旧信封，比原来的信封小一号，封口合拢，没有落款。他抽出来，对着窗户光看，内衬透出一道蓝黑色的墨渍划痕，从左下角斜向右上角，弧线与页脚偿字轮廓首笔同向。他用指尖在信封内衬上抹了一下，墨渍是干的，没有湿气。他把信封翻过来，背面也没有落款。他把空白信封原样放回折痕里，合上封口，压回床头柜台灯旁的原来位置。封口角度与之前一致。

程师傅在睡梦中翻了个身，半睁开眼，含混地说了一句：“他说，你抽屉里的东西，本来就是你的。”

陈默问是谁说的。

程师傅没有回答。他的眼皮落下去，呼吸又恢复匀长，像刚才那句话是从水里浮起来的气泡，冒了一下就没了。陈默站在原地等了一会儿，确认他不会再说第二句，才拉开床头柜抽屉。

最上层那沓单据还在，橡皮筋滚在角落没有归位。他翻到最底层隔板，指尖探进去，摸到一根硬物。抽出来，是一截断掉的圆珠笔芯，笔尖残余蓝黑色的墨渍，与种子书所用墨水同色。他把笔芯举到窗前对光，笔杆上有一道极浅的刻痕，是一个偿字的起笔，撇的弧线。与页脚洇入的轮廓同向，与空信封内侧的轮廓同向。他把笔芯横过来，对着光再看了一眼，刻痕的深度比页脚轮廓浅得多，像是很久以前刻下的，边缘已经被磨平了一层。

他掏出手机，屏幕亮度调到最低，快门声关掉，拍下笔芯正反两面，又拍了一张抽屉隔层的位置照片。他把笔芯放回原处，把隔板按回原位，合上抽屉。

退出病房，带上门。护士站灯管还在闪。他走到防火梯间，翻开种子书页脚，偿字轮廓比刚才更深了一分，边缘的墨色更实，像有人用指腹按过一遍。他合上书，攥在手里。

楼梯间声控灯灭了。黑暗里，手机又震了一下。

这次不是程师傅的号码。一个陌生号码发来的短信，只有一行字：“你拿走的不是纸，是笔。”
