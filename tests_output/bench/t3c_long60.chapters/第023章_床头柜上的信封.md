# 第23章 床头柜上的信封

床头柜上那截纸角，颜色和他内袋里那张一模一样。但走近了才看见，信封鼓着，里面装着东西。

陈默在病房门口站了约十秒。程师傅的呼吸声隔着门缝传出来，匀称，带着上了年纪的人睡觉时喉间轻微的呼噜。他把门推开一条缝，确认房间里没有第二个人，才侧身进去，反手带上门。门锁舌咬进锁扣的声音很轻，在安静的病房里还是响了一下。

床头柜上那只信封压在台灯底座旁边，纸角翘起来，鼓出一个小弧度。他没有先动正面，绕到床头另一侧，从背面看。信封背面没有落款，封口处的胶痕被手指抹平过，有人用指腹顺着封口压了一遍，压得很慢，不急。他注意到封口的胶痕边缘有一道极浅的指甲印，像是压完后顺手掐了一下，试胶干没干。

他拆开封口，里面不是航空信纸。

一张折了两折的小纸条，纸角有水渍浸过的痕迹，边缘发硬。纸条上只有一行圆珠笔字：东西在抽屉里。

字迹横平竖直，收笔没有顿点，像左手写的。他见过右手写的字，笔锋会往一个方向偏，写横的时候起笔重、收笔轻。这行字没有这种偏斜，每一笔都落在正中间，像写字的人刻意控制着不让笔尖歪出去。

他捏着纸条，在灯光下转了一个角度，对比自己内袋里那张航空信纸的纸质。手感不同，航空信纸更薄更硬，这张纸条更接近普通便签纸。但信封本身，纸色与纹理和他那只一致，是同一批纸。他把纸条放回信封，没有合上封口，转身拉开床头柜抽屉。

抽屉里被翻动过。最上层的一沓单据位置偏了，原本压在上面的橡皮筋滚到角落。单据上面压着一只没写字的旧信封，封口是开的，里面什么都没有。

陈默把空信封拿起来，先看正面，空白。翻到背面，也是空白。他把信封对着窗户的方向举起来，借着走廊透过磨砂玻璃漏进来的光，看见信封内侧有一道被反复折过的折痕。折痕处透出极淡的蓝黑色，是一点墨水渍，被水洗过，只剩下一个轮廓。

轮廓的形状像半个偿字。

他摸了一下外套内袋，航空信纸还在。他隔着布料按了按那张纸的位置，确认没有移动过。内袋的布料压出一个固定的折角，那张纸在里面待了几个小时，已经留出形状了。

程师傅在病床上翻了个身，喉咙里发出一声含糊的声响。陈默把空信封扣在掌心里，没有放回抽屉，站在原地等。

程师傅睁开半只眼，目光在台灯的光圈外转了一圈，落在陈默身上，又落回自己搭在被子上的手。他的嘴唇动了两下，声音哑得像砂纸蹭过铁皮：“刚才那个人，说他是来还东西的。”

陈默没有接话，等他说完。

“我问他还什么，”程师傅闭着眼，声音越来越低，“他说，你抽屉里的。”

“他长什么样。”

程师傅的手在被子边缘摸了一下，像在找什么东西，没找到，缩了回去：“右手三根指头都包着，白的。”

“他还说别的吗。”

程师傅没有再回答。他的呼吸重新变长，呼噜声又起来了，半张着嘴，睡沉了。陈默站在原地，又等了十几秒，确认他没有再醒过来的迹象，才低头看着手里那只空信封。

内衬那道折痕在灯光下比刚才清楚了一点，蓝黑色的轮廓断成两截，上半截依稀像偿字的起笔，下半截被水渍冲得只剩一点尾巴。他把信封放到窗户边，换了一个角度再看，那半个字没有变得更清楚，但也没有消失。他伸手碰了一下折痕处的纸面。墨渍是干的，没有湿气。

他把空信封放回抽屉最上层，压在单据上面，把单据推回原来的位置，合上抽屉，转身往外走。

走出病房门，他停了一步，站在门边。走廊尽头，护士推车的橡胶轮碾过地砖的声音由远及近，从电梯口方向滚过来。他靠墙站着，等车过去。走廊的灯管有一根在闪，光线一明一暗地落在他脚边，他没有抬头看。

车没有过去。推车在病房门口停住。

护士敲了敲门，说查房。

陈默从墙边侧开一步，迎上去，说他刚睡。

护士点头，推门进来，先看了一眼程师傅的呼吸，又低头看了一眼床头柜，目光落在台灯旁边那只信封上。她伸手把信封往边上推了推，说：“这谁的，怎么放这儿。”

陈默站在她侧后方，看见封口在她指尖下敞开，里面露出一角纸边，和航空信纸一样的颜色。

他内袋里那张纸还在。他隔着布料按了一下，确认它的位置没有变。那另一张纸，从那道张开的封口里露出来，颜色一样，纸质一样，折痕的方向也一样。

护士没有注意到那道封口里露出的纸角，她推完信封就把手收回去，在护理记录板上勾了一笔，退出病房。车轮的声音继续往前滚。

陈默站在床头柜前，看着那只信封。封口在他刚才放回时是合上的，现在敞着，角度比刚才转了约十五度。他伸手，把信封拿起来，没有拆，对着窗户的方向看。

折痕处的偿字轮廓还在。纸角露出的那一角，颜色和他内袋里那张一模一样的纸，被折进信封里，压在那道折痕底下。
