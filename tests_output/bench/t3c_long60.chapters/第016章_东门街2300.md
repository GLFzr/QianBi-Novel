# 第16章 东门街23:00

白车驾驶座的门从里面推开一条缝，动作很慢，像怕惊动什么。陈默站在原地没动，看那只手按住门框边缘，骨节分明，腕上露出一截表带。

穿浅色薄外套的年轻男人下了车，没有关车门，径直走到他面前，开口第一句是：“你接过快递了。”

陈默没接话。他认出这人右手腕上的表盘，老式，同型同刻位，和他内袋里那两块出自同一道工序。宋姓男子从外套内袋抽出一张纸，折了两折，展开是旧货运站收据的复印件。线条一致，但纸面比陈默那张更黄，像是原件在他身上揣了很久。

“你是谁。”

“王开志出事前最后一单的乘客。”宋姓男子说话时视线朝仓库值班室方向偏了一下，“那晚他送我到旧货运站。我在路灯底下看了两次表，等的人没来。”他停了停，“烧痕表上停的22:47，是我最后一次校表时看到的时间。”

风从卸货区灌进来，卷起地上一层烟灰。宋姓男子说：“今晚23:00，有人会来取王开志的表。”他停在陈默面前半步远的地方，“你替我拦下他，我告诉你三年前3月17号晚上，货运站里装的是谁的东西。”

陈默没有立刻答。他注意到值班室的门从里面开了条缝，老赵的保温杯沿露出来，又缩了回去。他把视线从门缝上收回来，问：“你为什么不自己拦。”

宋姓男子沉默了几秒，侧过头去看仓库对面旧货运站的方向：“因为我不能在23:00以后出现在这条街上。拿了不该拿的东西的人，会被记进账本。”他转回脸来，“你已经接过自己的信封了。你没发现吗？从那天起，你每晚有几分钟，会不知道自己刚才在做什么。”

陈默的手在外套口袋里攥了一下。那几分钟确实存在，但他从来没有抓住过，总是在事后才意识到，中间有一段是空的，像被人从底片上剪掉了几格。他闭了一下嘴。

值班室的门完全开了。老赵攥着保温杯走出来，看到宋姓男子时脚下一顿。他的目光在对方脸上停了两秒，干巴巴说了一句：“昨晚来问表的，不是你。”

宋姓男子没有否认，也没有承认。他偏过头：“穿深色外套的人不是我。”

老赵没接话，站在原地，手里的保温杯盖子也没拧紧，冒出一缕白气。他看看宋姓男子，又看看陈默，像是要把两个人从里到外看穿。冷风把他外套的下摆吹得掀起来一角，他没有去压，目光也没从宋姓男子脸上挪开。

陈默打断三个人之间那截僵住的沉默。他把0316纸片的事扣在口袋里，没有提。他只对宋姓男子说：“表在老赵那里，不是我的，也不是你的。今晚之前，它不会离开这个仓库。”他停了一下，“你让我拦人，你为什么不自己拦。”

宋姓男子的嘴角动了一下，像笑又不像笑。他没有回答，退后两步，站在路灯和值班室灯光的交界处，从外套内袋里掏出一块表。表盘边缘一道细裂痕，和陈默继承了的那块旧表一模一样。他对着路灯校了一下时间，拧了半圈表冠，又塞了回去。

陈默盯着那道裂痕看了好几秒。他把手伸进外套内袋，指尖碰到种子书封皮，没有抽出来，只在里面翻开了一页。页脚处，今晚东门街23:00的下方，多了一行极小的字：21:40前把老赵支走。

他合上书。这几个字不会是今天才写上去的，墨色已经干透，压痕嵌进纸面深处，像是写了很多天。他想起一件事，页痕上一次主动给他具体时间，是林果果那天的7:12。那一次他照做了，结果保住了她的命。这一次他还没决定要不要照做，页痕已经把动作写好了。

他把书放回内袋，转身走进值班室。侧门的钥匙从挂钩上取下，他把钥匙递到老赵面前：“21:40前，走侧门离开。去哪都行，别留在仓库。”

老赵没接钥匙，先问了一句：“为什么。”

“页痕写了。”

老赵盯着他看了约莫三秒。他把钥匙从陈默手里接过去，攥在手心里，没有再多问，转身往侧门走。走到门口时他停了一步，头也没回，只说：“仓库后门的风向不好，你等风转了再走。”

门在身后关上，锁舌咬合的声音轧过一阵风。陈默站在仓库中间，侧门外的脚步声朝远处去，越来越短，最后被风吞掉了。他走回门口，站在门廊下，看着宋姓男子在对面旧货运站门廊里坐下来，背靠着墙，膝盖曲着，手搭在膝盖上，没有走，也没有再看他。

夜色把两个人隔开。仓库这边一盏白灯，旧货运站那边一盏黄灯，中间的沥青地面上裂着一条旧缝。

23:00还没到。值班室的灯光从门缝里漏出来，在他身后拖出一道影子。他又翻了一次种子书，页脚那行字底下，多了一个竖写的字。不是今天写的，像是从纸里面渗上来的。三。

三。第三块表。第三个取表的人。还是这一页上第三个名字。他盯着那个字看了一会儿，指腹压在页边的旧折痕上，竖画笔直，没有钩，收笔处留着一点没提起来的重压。这个字的写法他没有见过。不是父亲的，也不是他自己任何一个字的收笔习惯。

他合上书，站回仓库门口。对面门廊下，宋姓男子坐姿没变，手里的表盘在路灯下反射出一线冷光。风又灌进来一次，侧门没带实的门锁在风里咔嚓响了一声。
