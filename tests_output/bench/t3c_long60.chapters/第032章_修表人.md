# 第32章 修表人

那行字不是他打的。他确认了三遍。既然不是他打的，那就是有人替他打的。替他用手机打出这行字的人，想让他去北边找修表人。他没有往北走。他往物流网点走。

路灯在他身后拉出一道长影子，他沿着墙根走，避开正门监控的照射范围。凌晨的街道空无一人，只有远处一辆洒水车缓慢驶过，水雾在路灯下泛着白光。他拐进物流网点侧巷，从后门进，没有开灯，借着手机屏幕的光摸到柜台。柜台台面上压着几张未归位的回执单，他扫了一眼日期，都是昨天的。他把回执单推到一边，腾出桌面。

夜班柜台没人。他出示工牌，绕到柜台后，打开铁皮档案柜。柜门铰链发出很轻的吱呀声，在安静的屋里被放大。他停了一下，等那声响落定，才继续拉开。柜子里码着近几年夜班配送存根册，按年份排，册脊上的年份标签被磨损大半，2022那本最旧，纸边发毛。他抽出2022年那一册，手指沿着纸张边缘滑到3月17日，翻到22:47前后的三张存根：一张南向，两张北向。

其中一张北向送货单的收货地址，指向修表铺巷口的便利店。签收人是代收，收货人栏写着一个姓氏，和父亲工号卡上的姓一样。他记下那个姓，合上存根册，没有多看一眼。他把存根册放回原处时，手指在册脊上停了一瞬，确认它落回的位置和刚才一致。

归位时他顺手翻了一下同批次的夜班排班表，本意是确认存根册放回的位置对不对。排班表夹在存根册和柜壁之间，纸质不同，颜色泛新，与其他旧表放一起显得扎眼。他抽出来。表头印着“城西第三殡仪馆夜班记账员排班表”，名字栏填着父亲的名字，排班日期是本周四，精确到分钟。

这张表不该出现在这里。他捏着表格停了几秒，先看纸边，裁切整齐，没有折痕，不像被随手塞进来的。他看表格底部，调度人签名栏是空白的。他又看了一遍排班时刻，周四晚十点四十七分，和他备忘录里那个时间一致。他掏出手机拍了一张，把表按原夹层位置放回，合上柜门，用指尖抹平柜面浮灰。他做完这些动作后没有立刻走，站在原地等了几秒，确认没有声音从柜台方向传来。

柜台电话响了一声就断。他抬头，挂钟停在22:47。上周换挂钟电池的人是他自己。他没有去检查挂钟，转身往门口走。手搭上门把时，背后电话又响了一声就断。他没有回头，拉开门走出去，把门带上。

他站在网点门口的路灯下，翻出刚拍的排班表照片。照片角落曝光过度，有一道白条。他放大白条，是档案柜内壁的一行刻痕，字迹很浅。他认出那笔迹，是他自己的。他盯着那行刻痕看了三秒，锁屏。心里有两件事待确认：那张今年排班表是谁放进档案柜的，刻痕他什么时候写过。他朝北看了一眼，决定明天白天先去修表铺，再回来查监控。他转身走入巷子里。

走出三步，手机在口袋里震了一下。他没有掏出来看，继续走，直到拐进巷口才停住。他摸出手机，屏幕上是一条短信，寄件人是父亲的号码，只有六个字：“明天别去修表铺。”

他盯着那六个字看了很久。父亲的号码他拨过无数次，每一次都是彩铃，从来没有接通过。现在这个号码发来一条短信，内容指向他刚刚决定要去的方向。他没有回拨，把手机锁屏，继续走。巷子深处，老屋的窗灯还亮着。
