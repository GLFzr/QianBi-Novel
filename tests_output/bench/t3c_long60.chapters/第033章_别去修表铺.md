# 第33章 别去修表铺

短信还亮着。屏幕的光照得他虎口发白。“明天别去修表铺”六个字是父亲号码发来的。他站在巷口，没有回拨，而是先看了一眼手机顶部的时间。23:58。距他决定去修表铺，过去十七分钟。

他拨了回去。听筒里是那句逐字一致的提示音，“您拨打的用户已在服务区外”，但这次他没挂，继续按住免提。第三秒时，一声极短的嘟音提前跳了出来，比平时早了一秒。他挂断，把那个“早一秒的间隔”记在心里，收好手机，朝老屋走。

路灯在他身后拉出一道长影子，他沿着墙根走，避开正门监控的照射范围。凌晨的街道空无一人，只有远处一辆洒水车缓慢驶过，水雾在路灯下泛着白光。他拐进物流网点侧巷，从后门进，没有开灯，借着手机屏幕的光摸到柜台。柜台台面上压着几张未归位的回执单，他扫了一眼日期，都是昨天的。他把回执单推到一边，腾出桌面。

储物间的灯管比走廊暗一半，他把排班表照片导出原图，和今晨巡更记录本背面的照片叠放对位。放大到百分之四十时，排班表存根照片的缝线同侧有一处白斑，与改动墨色的拉痕走向一致。他用圆珠笔描出白斑轮廓，和巡更本封面封底的旧痕比了比，确认这是纸面物理损伤。他把两张照片并排放好，又调出页痕以北改回以南的那张特写，三者放在同一屏幕上，白斑、拉痕、改痕的走向在放大后指向同一个方向。

他拉开铁皮柜，取出旧布套。内衬有一道透明胶带撕扯后留下的余胶，边缘卷起，和掌心里那截断口同源。有人曾经用胶带把什么东西固定在这本巡更记录本里，后来撕走了。他翻出修表铺巷口便利店存根的照片，背面朝上，发现一行圆珠笔字：“北边第三个灯柱，有根表带卡在缝里。懂的人去找，用的上次那只。”

字迹不是他的，也不是偿字收笔那一手的顿点习惯。他放大照片，字迹末端正对上次那只四个字的位置，有一枚极浅的指纹捺印。他调出巡更本背面自己刚压下的指纹对比，两枚指纹的方向刚好镜像。他把存根照片和巡更本背面并排放在灯下，指纹的纹路走向在斜光下显出清晰的弧线，一左一右，像同一个动作在镜子里留下的两个影子。

他把手机放下，没有立刻去修表铺。他打开公共浏览器，输入“北环辅道旧修表铺”，锁定了那间2022年停止营业的街角铺面。他记下坐标，抄在巡更记录本背面，在字迹旁边用干净指尖压下一枚指纹。合上本子，套好旧布套，放回铁皮柜最上层，位置与原先完全一致。他做完这些动作后没有立刻走，站在原地等了几秒，确认柜门闭合的声音没有引起任何回应。

他关灯锁门，朝修表铺方向走。走到巷口时，老屋窗灯在他背后亮了一下，亮起时间不足一秒，随即熄灭。他没有回头。巷口地面有一颗刚熄灭的烟头，烟灰还是白的，边缘没有风干的痕迹。他没有停，继续走。身后那盏窗灯又亮起一秒，亮起时正好照亮他手里的手机屏幕，屏幕上是刚拍的存根照片背面。

他走到第二盏路灯下停住，把手机举到眼前，重新看了一遍存根照片背面那行字。北边第三个灯柱，有根表带卡在缝里。懂的人去找，用的上次那只。他默念了一遍上次那只，想起老赵手里烧痕表表带内侧那道勒痕，宽度和窗台指印的无名指间距对得上。他把这个联想压下去，没有继续往下想，因为现在不是想这个的时候。他需要先确认一件事：这行字是什么时候写上去的。

他重新解锁手机，打开相册，翻到白天拍的存根照片，确认自己在白天没有见过这行字。他又检查了一遍拍摄时间，照片是今晚拍的，但字迹的墨色已经干透，边缘没有新写的湿润反光。这行字不是他今晚写的，也不是刚才在便利店灯光下新出现的。他收起手机，继续走。巷子深处，老屋的窗灯又亮了一下，这次亮起的时间比上次长了一点，像有人站在窗前，把灯开关按住了半秒。他没有回头，脚步不停。
