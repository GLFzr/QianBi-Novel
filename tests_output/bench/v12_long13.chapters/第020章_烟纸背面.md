# 第20章 烟纸背面

殡仪馆后门的铁栅栏上挂着一串铜铃，风从西边来的时候响了三声。

陈默站在台阶下，石膏腿撑在第二级，脚底能感觉到台阶边沿被雨水泡酥的那层石屑。他一点四十到的，比约定早了二十分钟。侧廊里有风吹出来，夹着一股消毒水味混着别的什么，冷，甜，像隔夜的花。

铁栅栏从里面被推开一条缝。阿莲从侧廊阴影里走出来，白色工服外面套了件灰蓝夹克，工牌反扣在胸前，金属边缘露出编号的后半段。她看见他腿上的石膏，没问，只侧了侧头。

跟我走。

她带他穿过侧廊，绕过一排停着推车的空地。走廊尽头传来压缩机低频的嗡鸣，闷在墙里，从脚底往上震。值班室的门是铁皮包边的，漆掉了几块，门框边钉着一块小铝牌，磨得看不清字，末尾两个数字倒是清晰，03-17。

阿莲进去后反手把门推上，锁舌咔哒落进扣槽。十平米不到的房间，一张铁皮桌，两把椅子，墙角立着一排掉了漆的铁皮柜，柜门缝里塞着泛黄的标签。桌上一只搪瓷缸，缸沿磕掉一块瓷，里面泡着半缸冷茶。

0317。阿莲站在桌对面，没有坐。是不是你爸。

陈默看着她。她眼睛里没有绕弯的意思，嘴角抿成一条直线，手插在夹克口袋里。

是。

阿莲从口袋里摸出一样东西，放在桌面正中。烟盒锡纸内衬，折成四折，边缘发毛。她用手掌压平，锡纸背面那半句蓝黑墨水字露出来，和她上次给他看的那张照片一样。

陈默掏出手机，翻出页痕照片，推到锡纸旁边。两样东西并排搁在铁皮桌面上，冷白灯管照下来，墨色比肉眼看着更沉。一样的蓝黑，一样的笔压，起笔的顿挫方向一致。

阿莲从夹克内侧又取出一小片锡纸碎角，边缘的锯齿纹和桌上那半张完全吻合。她把碎片推过去。

我哥撕的。他说上半句被血洇了，下半句他另撕了一片留着。

陈默捏起碎片，对准断口，齿纹咬合，中间没有空隙。上下两半拼回原样，完整的一句话浮出来。

账，命运收不走，是人记得收。

他的后颈一阵发麻。父亲录音里那句卡在门铃里的半句话，和这半句拼在一起，闭环了。账不是命运收的。是人记得收。两句话，一个人说了一半，一个人写了后半，中间隔着一扇门铃、一场车祸、三年。

阿俊什么时候写的。

出事前三天。阿莲的声音低下去，他那天回来，右手使不上劲，用左手写的。潦草，但认得出。

陈默把碎片轻轻放回桌上。他想起名单上阿俊的名字和日期，2019.06.14。出事前三天，就是6月11号前后。父亲录音里的门铃，是敲在哪一天的门。

还有东西。

阿莲转身拉开角落一只铁皮柜的抽屉，从里面抽出一本旧记事本。黑色硬皮，边角磨圆了，橡皮筋箍着。她翻到末三页，摊在桌上。

密密麻麻的手抄编号，字迹杂乱但能辨。0317写了好几行，旁边画着歪斜的圈。最末一行，笔画比前面都重，像是换了一支笔、加了力气写下的。

0317 东门街 22:47 替

陈默的手指停在那个替字上。走之底的写法，起笔往内收，收笔往右上挑，横折的转角带一个极小的弧度。父亲的笔迹。他在薄纸三行记录上见过这个替字，在台历反向压痕收账日三个字上见过同样的收笔习惯。

这个字不是你哥写的。

阿莲凑过来看。她的呼吸在灯下变成一小片白雾。

是。她说，这一行，我哥说是别人写的。那个人上门找他那天，他在本子上记了这一行，让对方自己落笔。

陈默抬起眼看她。

你爸找过我哥。阿莲收回记事本，手指按在封皮上，就在出事前一周。他走的时候留了一句话给我哥，说三月十七号之前会有人来找，手上带墨的那个人。

值班室静了几秒。压缩机嗡鸣从墙根渗进来，像有人在隔壁低声说话。陈默的手插进口袋，指尖碰到种子书硬壳边角，没掏。他选择了另一条路。

他有留东西给我吗。

阿莲没回答。她把记事本收回抽屉，蹲下去，从铁皮柜最底层摸出一只牛皮纸信封，边角发黄，封口没有粘，只是折了两折压平。她把信封搁在桌上，正面朝上。

陈默收。

三个字，父亲笔迹。蓝黑墨水，收笔的顿点深入纸纹，和种子书封面内页的字同一个人。信封右下角有一行小字，铅笔，很淡。

2019.06.07

陈默盯着那个日期。阿俊死亡前七天。也是台历一月页被划掉的7.14 海堤三号脚手架 林前一个多月。

阿莲退开半步，给他让出桌前的空间。

我哥让我等手上带墨的人来拿。她低头看了一眼他的左手，小鱼际那道旧墨痕在灯下显出浅青灰的轮廓。前天在留观室门口我就看见了。

陈默伸手。指尖碰到信封边缘，纸面粗糙，樟脑味顺着指腹爬上来。他没有拆。拇指在陈默两个字上停了一瞬，纸的温度比铁皮桌面高一点，像是刚从谁的口袋里拿出来。

走廊尽头传来喊声，隔着一道墙，闷。

阿莲，三号柜要复位。

阿莲应了一声，转头看他。她的目光落在信封和他的手指之间。

三号柜等我复位，十分钟。她把搪瓷缸往旁边挪了挪，腾出桌面的位置。够你看里面的东西吗。

她没有等他回答。推开门，侧廊的冷风灌进来，消毒水味又浓了一层。她出去，门重新合上，锁舌没有落回来。

陈默站在铁皮柜旁，桌面一张锡纸碎片，一本记事本，一只牛皮纸信封。压缩机在墙根嗡嗡地走，像远处有人在数数。

信封正面，陈默收三个字压着他的视线。他低头看了一眼自己左手的墨痕，颜色在灯管下比今早深了一层。

他拉开椅子，坐下，把信封锁在两掌之间。没有拆。
