# 第26章 夜档

路灯从他脚底往前铺了十几米，就断了，再往前是一段没装灯的偏街。陈默走出了巷口，回头看两次。头一次身后什么都没有，第二次看见一辆共享单车斜靠在便利店墙根，车锁亮着一小点蓝光，不是人。

他掏手机，在备忘录里敲：老屋撤出，无尾随，0317设备仍活跃。

便利店灯牌亮着，白光从玻璃门里溢出来，落在地上一块方方正正。收银台后面没人，货架尽头有个店员蹲着理纸箱。陈默站到冷柜旁边的灯下，把右袖口撸上去。

白痕还在。边缘起了一层细屑，像晒脱皮，又不像。

他用手机微距拍了两张，存进相册。新建的相册名字他打了一个字：证。白痕底下那种痒又起来了，一阵一阵的，像有极细的砂在皮肉之间走。

他在窗边的高脚凳上坐下。玻璃窗外对着偏街，对面一排卷帘门都关着，最远那盏路灯忽明忽暗。他从内兜摸出两块表，没有并排摆开，只翻到背面。一块背面划着0317，一块刻着已偿林。灯管的白光打上去，铜绿和划痕都吃得很深。

他给阿莲发消息：老屋出了点事，人在外面，平安。

两分钟后手机震了。

她说：殡仪馆这边周师傅今天翻了一下午旧档，有个生人来找过他。你小心。

陈默盯着“周师傅”那三个字看了一会儿。这个名字他以前没往心里去，此刻像一枚刚从水底浮上来的铁钉，锈迹一层。

他拨程师傅的号码。

响到第四声才接。

“这么晚。”程师傅的声音哑，背景里有电视新闻在播。

“你认识周师傅吗。”

那边静了。过了三秒，电视声被按掉，接着是一阵布料擦过沙发的响动，像有人从躺着的姿势坐直，换了个房间。

“你是不是碰了老屋的东西。”程师傅先问。他没答陈默的问题。

“碰了。”

又是一段静。程师傅的呼吸压得很低，再开口时离话筒更近了。

“那老头只认你爸的字，不认人。”他停了一下，“他要是肯接你电话，说明你爸的东西真到你手上了。”

“你怎么知道的。”

“我出事第二天他来过医院。站走廊口看了一眼，没进来，走了。”程师傅顿了顿，“他的记性比谁都好，你爸的本子上有多少笔，他数得过来。”

陈默没接话。窗外那盏忽明忽暗的路灯又亮了。

“把号码给我。”

程师傅报了一串数字。临挂断前他开口：“陈默，你爸当年。”

后半句没出来，电话断了。听筒里只剩忙音。

他握着手机在窗边坐了一会儿，起身去收银台拿了一瓶矿泉水。店员扫码时他透过玻璃柜门的反光看街对面。一辆车都没有。他拧开瓶盖喝了一口，重新坐下。

电话没多久就响了。

来电号码正是程师傅报的那一串。

接起来，对面先是一阵持续不断的翻纸声，一页一页往下掀，中间夹着老式座机按键的嘀嗒。然后一个老人的声音响起来，念稿子一样平，没有起伏。

“夜班登记簿，第316次。一起夜间事故。目标对象姓名已涂。页脚原批四个字，不可贪。涂改时间距事发不到四小时。”

陈默的手扣紧矿泉水瓶。水从瓶口盈出来一点，顺着他的指节淌下去，滴在窗台上。

“是他自己涂的。”

“他自己。”

“为什么涂。”

“页角有编号，编号跟涂改是一回事。”周师傅没直接答，“316是累计。你自己来数。”

陈默咽下那口水。“数字从什么年代起算的。”

“你爸接手那一年。”

翻纸声又响起来了，比刚才快。

“我能见你吗。”

“不能。”

陈默没有追问原因。他把瓶子搁在窗台上，玻璃凉。他先开口问了一句。

“钥匙是哪一把。”

翻纸声停了。

“你怎么知道有钥匙。”

“程师傅说的。”

电话那头沉默了几秒。老人的语气没有变：“后门消防栓箱，夹层。齿槽编号0317-侧。”又顿了一下，“那把钥匙开的是侧门，正门有人盯。0317之后经手过这本簿子的人，有人一笔一笔在记。”

“是谁在记。”

“你爸当年也接过这个电话。”

周师傅说完这句就挂了。听筒里传来挂断的忙音，很短，像被人按掉。

陈默从内兜摸出林兰给的那把生锈钥匙，搁在窗台上。钥匙柄的“兰”字旁边那道极细的刻痕，他凑到灯下辨认，是一个“侧”字的左半边，底下那半截被铜绿咬掉了。齿槽编号的走向和老屋书桌抽屉那把对不上。

不是同一把锁。

但齿的方向，起手的深浅，铣出来的槽宽，是同一只手做的。

他把两把钥匙并在一起，在灯下看。老屋抽屉那把开的是书房，这把开的是殡仪馆档案室侧门。编号都是四个字。0317。一个前缀。一个后缀。

他把矿泉水瓶盖拧上。从收银台抽了一张小票，展开，用铜扣的边缘在纸背上刻字。侧门消防栓。四个字刻得很浅，对着灯才看得见。他把小票折了三折，塞进鞋垫底下。两把钥匙一起收进内兜。两块表叠好放进背包侧兜。

手机他没有再翻。

推门出去。

对面街角停着一辆黑色网约车，双闪灯亮着，一下一下地跳。车灯没关，远光打在偏街的水泥地上，照出一条白。驾驶位上没有人。

陈默停在便利店台阶上，没有走过去。风从街口过来，卷起地上一角塑料袋。他从车尾的角度看过去。后视镜上挂着一根蓝色尼龙绳，绳头被风吹起来，撞了玻璃一下，又落回去。

褪成灰蓝的旧色。林兰那天递钥匙的时候，钥匙环上也缠着一截这样的绳。颜色一样，编法也一样。

双闪又跳了一下。

陈默没有走近，也没有往原路退回。他退下台阶，绕进便利店旁边那条更窄的巷子，走了十几步，回头。

那辆车还停在原处。双闪亮着，驾驶位空着。

巷口的夜风把河道的湿腥气送过来。他站在暗处，把手机调成静音，屏幕扣在掌心。手腕上的白痕又开始痒了，一层一层往上走，沿着表带那一圈，绕了小臂半圈。
