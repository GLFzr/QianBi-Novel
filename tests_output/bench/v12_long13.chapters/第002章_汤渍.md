# 第2章 汤渍

共享单车停在小区门口，锁车时手机在裤兜里震了一下。房租催缴短信，倒数第三天。陈默按灭屏幕，拎着背包往楼道里走。楼道灯坏了一盏，剩下那盏感应迟钝，他跺了两下脚才亮。

第三步踩上去，鞋底一声黏腻的响。

汤渍。外卖袋漏的那种，黄褐色，沿台阶往下淌了半级。他低头，汤渍表面浮着感应灯的白光，光的边缘碎成几块，里面泡着一小截蓝色尼龙绳，绳头磨得起毛。跟今天林兰手里那截，颜色一样。

他蹲下来看了两秒。汤渍里没别的。他跨过去，上楼。

开门，开灯。出租屋十平米出头，床、桌、一个两门的旧衣柜。他把背包放桌上，先掏出种子书，拿在手里掂了掂。然后拉开衣柜下的抽屉，把两件旧T恤拨到一边，把本子塞进最里层，抽屉推上，没上锁。

手在抽屉边沿顿了一下。

他直起身，把遗物纸箱里的东西一样样摊在地板上。父亲的老花镜、半盒名片、两本银行流水、一沓缴费单，还有一个牛皮纸信封，里面装着旧钥匙和三张外卖底联。底联是那种打印小票，油墨发灰，一张压着一张，最早那张日期是两年前。

他正要归进没用的那堆，手指停住。最上面那张底联的订单号区印着四个数字：0317。

翻过来，背面干净。再翻回来。0317。跟背包里种子书页角的编号一样，跟那块旧手表背面被刀尖划出来的数字一样。

他把底联放回信封。巧合。一天里看到同一个数字三次，不等于它有意义。外卖平台的订单号是四位流水，一天几万单，撞上不稀奇。

他掏出手机，翻到通讯录，停在一个备注上：爸（老宅）。这号父亲用了五年，老宅拆了之后应该早欠费停机。他打算拨过去，听到已停机就销号，手机里清干净。

拨号。

“您好，您拨打的电话已关机。”

机械女声说完，他拇指已经按在挂断键上。听筒里忽然进了提示音：“您有一条新的通话录音，请按1收听。”

通话录音。打了没接通的电话，对方如果在语音信箱里留过话，会顶到拨出方手机里。他按了1。

录音开始。前几秒是杂音，布料摩擦，什么东西被拖了一下。然后是父亲的呼吸声，很浅。背景里有个电器在低低地响，嗡嗡的。

“默。”父亲的声音，有点哑。

陈默的手指在手机边缘收紧。

“这本子留给陈默。告诉他，账不是命运收的，是。”

门铃响了。一声，两声。父亲那边呼吸停住。咔的一声，录音断了。时长四十一秒。

陈默把手机放下，又拿起来。倒回开头，听第二遍。这次他注意底噪。电器声，布料声，父亲呼吸。到那句账不是命运收的时，背景里多了一个声音，被压在门铃响之后、录音断掉之前。

一个电子女声：“您有新的外卖订单，编号，零三一七。”

他倒回第三遍。还是那句。外卖播报，标准女声，数字读得平平的。

他从桌上抓起那张外卖底联，又听了一遍。零三一七。单号区。零三一七。

同一天里，这个数字出现了四次。种子书页角。旧手表背面。外卖底联。父亲录音里的播报声。

他坐在床沿，把底联折好塞进口袋，从衣柜抽屉最里层把种子书拿出来。

封面磨得起毛，边角翘起。他翻到内页，那行案：0317在纸角，蓝黑墨水，平直笔画。他摸出笔袋，抽了那支蓝黑笔，笔尖抵在纸页上。

纸面粗糙，笔尖按下去，没出墨。

他看着那个数字，停了一会儿。笔尖在纸上留了个浅浅的压痕，看不太出来。

合上书。关灯，躺下，把本子塞到枕头底下。

夜里两点十七分，翻身时后脑勺碰到枕头下一个硬角。手机屏幕自己亮了。一条推送浮在锁屏上：“您有新的通话录音已保存。”

他没点开。拇指往上一划，翻到通讯录。备注还停在那个位置：爸（老宅）。他点进详情，创建时间三年前。备注栏底下有一行小字：0317，他生日。

三年前的备注。那会儿父亲还在。

他又拨了一遍那个号。等待音响了两声，接起来的是彩铃。父亲自己录的，声音比录音里清楚些：“您拨打的用户已在服务区外。留言请按。”

他按了挂断。

屏幕暗下去，又亮起来。时间跳到两点十八。

窗外楼下，路灯底下停着一辆外卖电动车。车没熄火，尾灯照着湿地，红了一小片。骑手坐在车上，头盔面罩推上去，发动机响了一下，又静下去。

没走。

他把手机翻扣在床单上，屏幕的光从边缘漏出来，在枕头上切了一道窄缝。楼下那辆电动车的尾灯还亮着，红色的光映在湿地的水膜上，像一小滩没干的血。发动机又响了一下，这次比刚才长，拧了油门又松开，车没动。

陈默坐起来，光脚踩到地板上。凉。他走到窗边，隔着纱窗往下看。骑手还坐在车上，一只脚撑着地，脸朝着这栋楼。看不清表情，那个姿势像在等一个具体的门牌号。

他拉上窗帘，布边没合严，留了一道指头宽的缝。

回到床边，手机又亮了一次。推送还挂着，那条通话录音的标题是一串陌生号码，没有备注。他没点开。拇指悬在屏幕上方，悬了几秒，退出来，翻到备忘录。父亲留的那条记事还在：3月17日22:47，去东门街路口。

他盯着这行字。22:47。今天那块旧手表停的时间。明天就是3月17。

他退出备忘录，又翻回通讯录。爸（老宅）那行备注底下，“0317，他生日”五个字安安静静地躺着。他看了很久，久到屏幕自动暗下去。再点亮，那行字还在。

手机第三次亮起来的时候，他点了那条录音。

加载条转了两圈，播放键亮起。他没按。把手机贴在耳边，听筒里先是一阵极轻的电流底噪，像老式收音机没调准频道时的沙沙声。然后，父亲的声音传出来，比上一条清楚，只有一句，很短，像是对着话筒说的：

“别在3月17号动笔。”

录音结束。播放条走到头，自动跳回列表。那条录音的时长显示为三秒，接收时间：两分钟前。

陈默把手机从耳边拿下来。屏幕的光映在他脸上，瞳孔缩了一下。他转头看向窗帘缝。楼下，那辆电动车的尾灯终于灭了。发动机声彻底消失。他听见一个脚步声，不急，不快，从单元门口经过，沿着巷子往外走，踩在湿地上，一步，一步，越来越远。

他掀开枕头，把种子书抽出来。封面在手机余光里泛着旧纸的黄。他翻到内页，借着那点光看封面里那行字。父亲写的：种子书。记人未长成的事。

他合上本子，没放回枕头底下。攥在手里，坐到床沿。脚底的地板还是凉的。

手机屏幕彻底暗下去。屋里只剩窗帘缝漏进来的路灯光，斜斜一道，落在他脚背上。他低头看着那道光的边界，拇指压在种子书的封面上，没动。

楼下巷口，那个脚步声停了。停了两秒，又响起来，这次是往回走，朝单元门的方向。
