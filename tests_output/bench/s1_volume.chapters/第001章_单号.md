# 第1章 单号

钥匙串从锁孔里拔出来时，陈默的指腹蹭到一截毛边。

蓝色尼龙绳。旧了，颜色发灰，一头系在钥匙圈上，一头磨出细密的毛刺。他认得这截绳子。父亲系了七年，每年入冬前换一根新的，蓝的。去年冬天那根他系上时还说过一句蓝的经脏。陈默当时没接话，现在想起来，那是父亲最后一次跟他说起这根绳子。

这屋子现在归他处置了。

下午两点四十，城西老筒子楼底层的过道里堆着别人家不要的沙发和一辆缺了轮子的儿童车。光从楼道口斜进来，照见灰尘在半空浮着。墙皮剥落处露出里面的红砖，有人用粉笔在砖上画过一个圈，圈里写了个拆字，又被雨水冲得只剩半边。陈默把钥匙塞进兜里，对面住户的门开了一道缝。

林兰探出半个身子，手里攥着一个塑料袋。她看了他一眼，又把门带上一半，像在犹豫什么。

“你爸那几天说，有东西要留给你。”她递钥匙时等他先伸手，“我按着他说的，没碰。”

“什么东西？”

“他让我……”林兰说到这里，低头。她女儿果果从门缝里钻出来，扯她的衣角。林兰把后半截话咽回去，拍拍女孩的背，“你先进去。”

果果没进，仰着头看陈默：“叔叔，你爸是不是不会回来了？”

楼道里安静了一瞬。声控灯没亮，光从两人之间的缝隙里漏过去。林兰的脸绷紧了，拽着果果回了屋。门关上前她说了一句：“东西你进去自己找。话我没带到，对不住。”

门合拢，楼道又静下来。陈默站了两秒，钥匙在手心硌着。他没敲回去。父亲的东西他本来就打算清空，多一句少一句，不影响他要做的事。

他开门进屋。

一股灰味，混着旧木头和凉透的茶气。凉茶在桌面还剩半杯，杯口一圈茶渍早干了，茶叶沉在杯底，结了层膜。旧报纸摊着，日期停在三月初。父亲是四月走的，这一个月里，没人动过这张桌子。窗台上一盆绿萝干透了，叶子蜷成褐色的小卷，一碰就碎。

陈默摸出手机拨了中介的号。响了三声，对方接了：“陈先生是吧，我跟你说实话，那片老破小在动迁观望里挂着，先挂上，别指望太快。”

“挂吧。”

“行，回头我传个电子协议——”

陈默挂了电话。

房东上周五的催租消息还趴在消息列表里。他划掉红点，把手机扣在桌上，开始分类遗物。

衣物归进废纸箱，木工工具挪到窗台左侧。角磨机的把手上还有一层干透的木屑和汗渍，他没多看，放进回收袋。账本和票据摞成一叠，用橡皮筋箍好。他做这行当快，收得也快。哪个该留哪个该扔，扫一眼就有数。父亲攒了一辈子的旧物，在他手里十秒分一边。工具归工具，纸归纸，没有一样让他多停两秒。

他蹲到床头柜前，拉开最底下的抽屉时卡了一下，有什么东西把它拖住了。抽屉在滑轨上歪着，伸手进去探，指头碰到一个硬角的薄物件，卡在抽屉底板和柜体之间，像被人塞进去后就没再动过。

他把它抽出来。

一个旧笔记本，封皮是深灰的。比账本薄，大小也不规矩，像自己裁过的纸订的，边角磨得发白。他翻开封面，看到扉页上停着一行字。

父亲的笔迹。钢笔，蓝黑墨水，笔画按得很实，收笔处有顿挫：

“种子书。记人未长成的事。”

他翻到斜角。一行铅笔小字，是父亲的字但写得很轻，像犹豫过才落下去，笔画比正文淡了一截：

“不可贪。”

页角。一个编号，墨色不一样，蓝得更深些：“案：0317”。笔画的收势往下压得重，不像父亲捺笔的习惯。父亲写字收尾是平的，这个编号的最后一笔却往下戳，像写的人用了多余的力。

他翻了几页，都是空白。页边有一道毛糙的撕纸残余，有人撕掉了什么，撕得急，留下一截锯齿状的边。他盯着那处毛边看了两秒，合上本子。

这不是账。

陈默清楚账本长什么样。父亲记了三十年的工账，每一页都写满数字和日期，页脚总要画一道横线封底。这本子没有横线，页脚也没有封底。只有一行不像记账的话。他把种子书放进随身的背包夹层，拉链拉到头。转身去关窗台边那盏旧电扇时，花盆底下露出一角白纸。

他拨开土和枯叶，抽出来。纸条潮了一角，字洇开了大半，纸面发黄发脆，边缘卷着：

“陈默。”

只有这两个字。父亲的笔迹。余下的字被水渍咬断，能看出还有一行，但只剩下几个洇成团的墨点，笔画全糊在一起，认不出原本的内容。他把纸条合进一个旧塑封袋里，压在背包最底部。

电闸关了。他背起包走到门口，把手搭上门把时，楼下一声车刹。

外卖员在楼道口停了车，黄色头盔，脚踏着一地湿。他刚碾过门外那片湿泥，后轮甩了一下。箱子底渗出来一摊冷饮渍，在日光下亮着，淌到过道里映出一片晃眼的白。他捏着手机，探进半截身子：“3门317是这栋不？”

“这栋没有317。”陈默说，“门牌从301到312。”

外卖员低头看单，把单票举起来对着光，嘟囔了一句“导航又瞎带”。边角垂下来，露出一截印花：取件码，尾号0317。油墨印得齐整，在日光下清清楚楚。

陈默没说话。他没跟出来，站在门框里，手里还攥着那张纸角。纸角从种子书里露出来，风吹着它翻卷。他没动。

外卖员没等他再答，拧着油门碾过那摊水渍冲出了巷口。白水映着天光，慢慢收窄成一条浅痕。

陈默低头，把手里的旧纸角按回本子里。锁门。钥匙在锁孔里拧了两圈。他把钥匙串抽出来时，那截蓝色尼龙绳在掌心里擦了一下。

他走到公交站台，摸兜找零钱时，碰到一样硬物。外层不知道什么时候多出来的，他没往那个兜里放过东西。他掏出来。

一块旧表。钢壳上有磨痕，表盘一圈细裂纹，指针钉死在22点47分。他捏着表链，指腹在表壳背面刮到一道划痕。翻过来看，有人在背面刻了一串数字，字形浅，但很工整。

0317。

他反复转了两次表壳，让光落上去。那串数字是拿硬物一道一道划出来的，槽口里留着金属屑。他抬头，巷口那摊水渍已经干了。他摸到背包里种子书的位置，隔着帆布按了按。

公交车来了，他没上。
