# 第5章 138秒

林兰那条消息在屏幕上亮了很久。他读了四遍，拇指悬在输入框上方，最终什么也没写。他不知道怎么回。他还没想清楚自己到底在做什么。一点多的时候他穿上外套，把种子书塞进内袋，出了门，往老屋方向走。

夜里起了风，吹得电线呜呜响。楼道口那盏感应灯坏了，他跺了一下脚，灯没亮，只有回声在楼梯间里滚了一圈。他摸着墙上去，开门，蹲下看了一眼门槛边的地砖。水线断在干地砖前，摸上去冰凉干燥。通往走廊的细痕已经完全干了，像从来没有人洒过东西在那里。他蹲了一会儿，指腹贴着砖面，那块砖的温度比旁边的低。他把手收回来，没有再想。

他进里屋，拧开台灯。光在桌面上压出一圈圆，四面都是暗的。他翻到页痕所在的位置。

停留：138秒。

字还在，深浅不变。他往前翻一页，往后翻一页，都是空白。纸面上没有新墨，页角没有新编号。他把书合上又翻开，那行字钉在纸里一样停着。他坐着等。他不知道自己在等什么，只是觉得它还会变。

手表指针爬得很慢。三点过了一刻，他撑不住，伏在桌沿合了一会儿眼。惊醒时台灯还亮着，光线刺进眼底。他低头看了一眼时间，三点四十七分，又低头看书页。

在那行字下方，隔着一段空白，多出一行小字。蓝黑墨水，笔画收得平实，和父亲留在扉页上的字出自同一只手：

明 07:12 停留处有车刹不住。

他盯着那行字，读了进去。车刹不住。他没看到任何车，但那行字已经告诉他明天的某个片刻，会有东西以很高的速度抵达这个路口。他没有写它。它自己出现在两行空白中间，墨迹干透，像早就存在，只是等他翻开。

他迟疑着摸了一下字迹。纸面平滑，墨水已经吃进纤维里。他翻开内衬，抽出那张父亲贴在封面内侧的旧纸片。铅笔字已经淡得只剩一道影子：“不可贪。”他找了支硬笔，用笔尖蘸了极少的水，沿着字痕轻轻描过。铅笔的沟壑比肉眼看到的深。他把纸片翻过来，对着台灯，背面透出另一行字。极浅，像写了很久之后被磨去大半：

“改写是替人挡，不能替天改。”

他的手停在纸上。房间里很静，能听见自己的脉搏跳了一下又一下。他想起父亲扉页上那句话，想起“不可贪”三个字写在斜角的位置，像一个人侧着身给自己留的提醒。他把纸片放回内衬，抚平边角，合上封面。纸片贴着书脊的位置，旧得发脆，他不敢用力压。

他拿起手机，拨了林兰的号码。听筒里传来机械女声：“您拨打的电话已关机。”

凌晨四点二十六分。距离七点十二分不到三个小时。他挂断，又拨了一遍。同样的提示音。他盯着屏幕上那个号码看了几秒，把手机扣在桌上。

他重新打开种子书，翻到前几页。周航那条记录还留在原处：“周航，3月11日9时52分，滨河道12号一楼台阶，右手握紧扶手，停住半步。”他写得很少，少到几乎成一条备注。那一天他丢掉了午饭的记忆，三个空碗留在了灶台上。

这一次他要写的比那多。他知道几个字会换走什么，但他已经把林果果看进眼里。那条歪着的书包带。褪色的红绳。她蹲在路边系鞋带的背影。她在过马路前不会抬起头，也不会发现车刹不住。

凌晨五点十二分。他把种子书翻到空白页，蓝黑墨水笔尖抵住纸面。落笔前他停顿了一个呼吸的时长。他想起周航那次，笔尖落下去的时候几乎没有犹豫，因为那只是一个握扶手的动作。这一次不一样。这一次他写的是一个孩子的秒数。

他写：“林果果，07:12，东门街路口，因鞋带散开蹲下系鞋带，停滞至绿灯转红后第3秒才起身。”

合上书的瞬间，太阳穴抽了一下。有一根很细的线从后脑被拉走，拉到一半突然绷断。他撑着桌沿等那阵晕眩过去，后脑勺里嗡嗡地响，像空房间里的回音。他把手掌平摊在桌面上，低头看见自己左手掌根靠近小指那一侧的肉上，横着一道没来由的墨痕。他没碰过墨水。他抬手想擦，指腹蹭过那道痕，颜色没有沾开。墨痕是干的，长在皮肤底下。

他坐了很久，不敢翻开那本书。他努力回想自己刚才写了什么，每一个字都还在，但记忆的边缘已经开始起毛。他回想锁门时的动作。门锁转了几圈，他把钥匙插进锁孔的方向靠左还是靠右，那个画面正在变淡，被水浸透的纸一样一碰就碎。他试图去确认自己写下的时刻到底对不对，脑子里却浮起一片嗡嗡声。

四点半到五点之间的那段时间正在离开他。

他伸手，把种子书重新翻到写着林果果名字的那一页。字迹立在纸面上，工整，干燥。页脚的空白里，无声地站着一个新的编号。

0319。

他想起首页那条“案：0317”。两个数字隔着几十页纸相望，像同一本账册上被先后记下的两笔。他呼吸滞了一下。胸口口袋里的便签“3月17日必须联系小周”隔着棉布硌着他的心口。

他盯着那片页脚没有动。楼道里忽然传来脚步声，一阶一阶往上，到他门口停住。没有敲门声。那脚步声像是专门为他停下来的。他屏住呼吸，等那脚步声继续往上走，它没有动。

他等了十秒。门口没有人离开的动静。风从窗缝里灌进来，台灯的光晃了晃。门外传来一个压低的女声，隔着旧木门，像怕吵醒别人又怕他听不见：“陈默，我知道你醒着。”
