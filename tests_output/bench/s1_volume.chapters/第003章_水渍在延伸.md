# 第3章 水渍在延伸

闹钟在雨声里响了三声。他伸手按掉，雨声重新灌满窗户。床头柜上摊着一张外卖单底联，单号区印着0317，纸面被人抹平过，边角没有折痕。他看了五秒，不记得自己什么时候把它从包里翻出来放平的。

林兰的语音留言：“陈默啊，一楼走廊渗水了，你家厨房那根管子是不是没关？”他回拨过去，响了四声没人接。他套上外套，把外卖单折了塞进内袋，那把钥匙串在兜里硌着，蓝尼龙绳绕在钥匙圈上，绳头发毛。

雨停了，空气里一股土腥味。楼道墙根洇出一大片暗色水痕，踢脚线吸饱了水，一按一个印。他上二楼开锁进门。

水声在空屋里响，滴答滴答。厨房台面一长条水渍沿边沿淌，几股细流落在瓷砖上。他伸手去拧水龙头。龙头是关紧的，拧不动。水从台面和墙砖的接缝里渗出来，玻璃胶裂了一道口子，水沿着裂口往下爬。

他退到门厅，关了总阀。水声矮下去，停住。屋子静下来，能听见楼下过道里人走过的脚步。

他在水池前把碗洗了。碗沿磕着水池边沿，脆响。倒扣在沥水架上，关水龙头。水声停住的一瞬，他忽然意识到：他不记得昨天中午吃过什么。那个位置空了一块，像一页被撕掉的时间。

他甩了甩手上的水，进里屋翻包找物业缴费单。手指在笔袋底层碰到一个硬折角。掏出来，一张对折的便签，字迹是自己的，蓝黑墨水，笔画收得利落：“3月17日必须联系小周。”指腹按在字迹上，墨干了很久。他不记得写过这张便签，不记得小周是谁，更想不起3月17日需要联系这个人做什么。他把便签对折两下，塞进胸口内袋。

下楼时，楼道口停着一辆电动车。黄色工服，车筐里搁着一只泡沫箱。正是昨天误闯进来问“3门317”的那个外卖员。雨后台阶泛着水光，松动那块地砖翘起一角，砖缝里汪着水。他弯腰去拎泡沫箱，箱里汤水晃荡，分量不轻。

陈默在楼梯上停住：“你叫什么名字？”

“周航。”他答得干脆，“昨儿那单尾号0317的，是我送的。”

陈默点头，退进楼道阴影里，翻开种子书。他抽出圆珠笔，笔尖悬在纸面上方。楼道外，周航已拎起泡沫箱，鞋尖正对翘起的地砖。箱子把重心往左拽，台阶上的水光白晃晃一片。

他落笔。“周航，3月11日9时52分，滨河道12号一楼台阶，右手握紧扶手，停住半步。”

合上书页，心跳撞着肋骨。

十五秒后，楼道口一声闷响。周航半跪在台阶上，右手死死攥着扶手栏杆。他没摔下去。泡沫箱脱手倒扣在台阶边，汤汁从箱沿溢出来，顺地砖缝流成一道细线，淌到墙根。那里有一道昨天的旧水渍。细线接在旧痕的延长方向上，往前多爬了两指宽，停在一个砖缝处。

周航骂了句脏话，撑着扶手站起来，膝盖上的灰也没拍。“这台阶真滑。”他回头冲陈默笑了笑，“谢了啊。”他扶起泡沫箱绑回后座，跨上车拧了油门，车尾在湿路面上摆了一下，拐出巷口。

陈默站在台阶上，手里的种子书合拢着。纸面冰凉，没有动静。他刚才在上面写了一句话，那句话应了。

中午他回到出租屋，进厨房倒水。灶台上三只空泡面碗叠成一摞，筷子搁在碗沿，摆放角度是他自己的习惯。碗底还温着，余温透过纸壁传到掌心。他在脑子里翻找上午的画面，找不到任何一段自己坐在灶台边吃面的记忆。三只碗摞得整整齐齐，他连第一口汤的味道都想不起来。

傍晚，雨又下起来。他揣着种子书去老屋，楼道里那摊水渍已被踩乱。汤汁和雨水混在一起顺着砖缝漫开，分不出新旧。他蹲在门口翻开种子书，用电筒照向页角。下午落笔那页没有变化。往前翻两页，纸面上有一道极淡的压痕，像被橡皮擦过的铅笔字，凹下去一层，只剩半行字：“14:07 东门街路口。”

他不认识东门街。

隔壁门开了。林兰撑伞出来，手里攥一串钥匙，蓝尼龙绳湿了一截。“你的钥匙吧？昨儿落我家门口了。我听见楼道响了一声，出来看就搁在门槛边。”

陈默接过钥匙。那截蓝尼龙绳触手冰凉，末梢的毛刺跟他兜里那串的如出一辙。他不记得自己去过她家门口。

林兰身后转出一个小女孩，扎马尾，书包带歪在肩上。林兰抬手帮她正了正书包：“果果明早七点要去东门街那边上科创营，我先去认个路。”

陈默的拇指按在书页边缘：“你说哪里？”

“东门街路口呀。”林兰把伞重新撑开，“滨河道那头，有个红绿灯的。”

女孩拽她袖子：“妈妈，走了。”

林兰转身要走。陈默在屋檐下站定：“她几点到那边？”

“七点。她爸送。”她回过头，“你问这个做什么？”

“没什么，顺路。”

他低头看那半行压痕在路灯光下发灰：14:07。早上七点。纸上写的是下午两点七分。

“她平时也那个点走那边？”

林兰在雨里站住了，歪了歪伞：“果果今早还跟我说不认得路。你以前去过东门街？”

楼道里滴水声不断。陈默把书页合拢，什么也没说。林兰领了果果回屋，门在走廊里合拢。

他转身要走，脚边响起一声水响。台阶边沿的积水正缓缓漫过一道细痕，往墙根的方向延伸。那方向和周航今天洒的汤汁朝着同一个去处，两股水在砖缝处汇到一起。

他身后，老屋的门缝里传来一声滴水。嗒。嗒。他下午关紧了总阀。
