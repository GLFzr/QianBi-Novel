# 第2章 断线的录音

车锁反弹的脆响在楼道里回声很重。陈默把共享单车支好，鞋底踩进一滩汤渍。汤汁还温着，沿砖缝淌了半米。他用鞋尖蹭了一下，里面卷出一截蓝尼龙绳头，磨着毛边，半指长，和他爸捆账本的绳子同一种蓝。他在绳头上停了不到两秒，跨过去上楼。

单间门锁照旧别一下才开。灯管闪两回才亮，中午攒下的潮味扑了一脸。他把纸箱拖进屋，把旧衣物和工具摊在地板上分堆。一件灰夹克，三把起子，一盒锈死的膨胀螺丝，半包没抽完的烟。他爸的东西不多，摊开也就占了两块地砖。他把那包烟拿起来看了看牌子，又放回去，归进“不要”那堆。

从箱子最底下抽出那本灰蓝封面的册子时，他的手指在封皮上停了一下，指腹沿着那道捆绳压出的凹痕抹过去。单独放进抽屉最里层。抽屉没有上锁。他的手在拉手上停了一阵，最后还是推了回去。

他给中介发去一条回复，只有两个字：再挂。发完把手机扔到桌上，手机立刻又亮了。房东第二条催租短信顶了上来，比第一条多一个感叹号，像纸单贴在门缝上不肯走。他盯着那个到期的数字看了一会儿，没按下转账，退出付款页，想起还有一件拖了很久的事。

父亲那个老号，每个月还从卡里扣套餐钱。人没了，号也该销。

他在通讯录里找到“爸（老宅）”，按下拨出键。听筒里传来机械女声：“您拨打的电话已关机。”他正要挂断，屏幕上浮出一行字，他从来没有在上面见过：有一条未播放的通话录音。

他点开了它。

前十几秒全是杂音。布料摊开的声响，拉链齿一粒粒咬开，纸张铺上桌面又被拖走。谁在一个屋子里来回走动，怕踩到地雷似的。然后父亲的声音进来了，压得很低，像在喉咙里含着一口沙：“……保单不算数。要紧的是包里的行车记录仪，我放进一个想不到的地方了。”

停顿了几息，父亲又开口，气流声明显更短：

“这本子留给陈默。”

停住，很长的空白，像决定什么也没决定好。

“告诉他。账，有人收。”

门铃声音在句尾炸开。录音在那里断掉。

陈默把拇指压在播放键上，又放了一遍，第三遍还是一样。最后半句总共被截断三次，回回都断在同一个地方。他改了改心思，把音量推到最大，回头去听铃声底下那一段底噪。门铃长音的末尾，有一个电子女声平板地咬进来：“您有新的外卖订单，编号0317。”

他坐直了，再放了一遍。一模一样的播报。

他从外衣口袋里摸出一张卷了边的白色单纸，是下午在老屋楼道前，那个黄色头盔的外卖员捏着对光看过的那张底联。风把它吹到他脚边，他随手拾了一下，后来不知怎么就跟上了他自己的外衣口袋。底单边角印着四位数取件码，0317。他又把手机屏幕转了个角度，让那串底噪里听来的号码和纸上的数字并排躺在同一片光里。同一个数字。他的目光在手机屏幕和白纸单之间走了两个来回，身上有些发紧。

他拉开抽屉，将那本灰蓝册子又取出来，在台灯下翻到页角。那一页留着一行编号，老式钢笔的墨迹收笔很重。“案：0317”，和他爸的字迹对不上。台灯光从侧面打过来，他凑近去看，编号底下的纸面有一道很浅的划痕，像是有人曾经用笔尖抵在这里，犹豫过，又收走了。

他顺手从笔筒取出一支水笔，笔帽拔了一半，笔尖悬在编号上方，在纸面压出一个很浅的坑。窗外的风灌进来，把窗帘鼓成一道弧，又落下。他维持着那个姿势，指节发酸，最后把笔帽重新盖回去，合上册子，关了灯。册子被他塞到枕头最底下，硬的一个角顶出枕套的形状。

凌晨两点多，他翻身，肋骨硌到枕下那个硬角。意识回来时手机屏幕正亮着光，他摸过来看，是刚才那通电话的详情页。他无意间又碰了拨出键。听筒没有传来已关机的提示，顿了一息，然后一串低沉的留言放了出来。是他父亲的声音，隔着纸一样厚的底噪，一句一字录得极慢：“您拨打的用户，已在服务区外。留言请按”

忙音。

陈默的拇指悬在挂断键上，又收回去，把页面往上一推，停在这个号的信息栏。号码是旧号，备注名是“爸（老宅）”。备注栏底下还有一行小字，标注着创建时间，是三年前加的。备注的内容只有一行，“0317，他生日”。

三月十七日。他忽然意识到，那是他爸的生日。三年前的某一天，他坐在哪张桌子前，把这一行字敲进通讯录里，怕自己忘。他爸的生日他记了三十来年，可那行备注一直在那儿，像他爸的手机号一样，每个月还在扣着套餐钱。

他盯着那行字没有删，也没有退出界面。屏幕还没暗下去，上方推出一条新通知。一条新的通话录音，已保存到本机。他还没有点开。

楼下传来电动车发动机的低响，车没有熄火，停着一阵，又移了个位置，仍然没有开走。跟着楼下声控灯亮了，自动灭了，刚刚停下的引擎又响起来，像等着什么还没有到的时间。
