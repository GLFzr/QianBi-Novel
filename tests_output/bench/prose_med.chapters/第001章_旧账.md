# 第1章 旧账

钥匙扣上系着一截蓝色尼龙绳，颜色旧得发灰，打结处磨出毛边。陈默记得这根绳子。父亲用它捆账本捆了七年，捆完还要用指甲压一压绳结，怕账页散开。

他把钥匙捅进锁孔，又拔出来，退后半步望了一眼四楼窗户。外墙刷着白“拆”字，红漆顺着墙皮流下几道泪痕。周六下午两点，巷子里没有外卖车进得来，也没有中介愿意往里走。手机里躺着房东上周五的催租消息，中介专员半小时前回了四个字：“先挂着吧。”

“陈默。”身后有人叫他。

邻居林兰站在楼梯口，系一件褪色围裙，举着串钥匙。林果果缩在她腿边啃玉米。

“你爸托我保管的。”林兰把钥匙递过来，“那几天他说，有东西要留给你，我按着他说的，没碰。”

陈默接钥匙，冰凉的齿痕硌进掌心。

“我还……”林兰话到一半，低头看了一眼女儿，“算了，你先进去吧。回头有空再说。”

她拽着女儿往回走，脚步快得像怕被追问。林果果扭过头，嘴里含着玉米问了一句什么，被林兰按回了脑袋。

陈默没追。他爸干活的人，能留多少东西。一屋子旧账和工具，清空卖废铁，一周够了。

推开门，落灰混着隔夜凉茶的味扑过来。桌面摊着半个月前的旧报纸，干在碗底的凉茶结了层褐壳。他推开卡住的老窗，潮气和尾气一起灌进来。

陈默放下手机，开始干活。衣物毯子归一堆，木工工具归一堆，锅碗瓢盆归一堆。他爸做了一辈子装修散工，工具比衣物值钱。电瓶车挂网上卖，旧家电约了周一回收，其余见一件清一件。他速度很快，干完客厅就进了里屋，把床头柜抽屉一个个抽出来往地上倒。

第三个抽屉到底时，手指碰到个不对劲的东西。

一卷薄薄的、外包牛皮纸的旧本子，贴在抽屉最深处底板边缝里，像是放的时候就存了心不打算让它露出来。他抽出来掂了掂，牛皮纸已经脆了，一动就掉渣，里面的本子却还板正。

不是账本。

他翻开封面。内页是父亲的蓝黑墨水笔迹，字写得慢，横平竖直：“种子书。记人未长成的事。”

他认出父亲的字，又不完全像父亲的字。父亲记账时字急，尾巴爱甩。这里头的字每个都收住了，纸背都压出了痕。

斜角还有一行更小的字：“不可贪。”

再往后翻，页页空白。只在中间一页纸角上留着一条毛糙的撕纸残余。有人从这页上撕走了什么。

底页贴近书脊处压着一串数字，老式钢笔，收笔重得几乎划破纸：“案：0317”。那个“案”字和数字隔得有点远。父亲写编号从不用前面那个字。

陈默把本子搁在膝头，对着空白页停了几秒。他爸记了三十年账，每本都记得满满当当。一个做了一辈子账的人，怎么留下一本什么也没记的。“不可贪”。贪什么？账目里哪一笔能贪。他把本子合上，封面是粗纹牛皮纸，没有印字。这薄薄一本，比那一抽屉账本都沉。

他把本子塞进桌边双肩包的夹层。不打算细看。一细看，就得在这里多留好几天。

收完里屋，他去关窗。窗台花盆底下压着一张纸，边缘发黄卷起。他抠出来展开，上面只有两个字：“陈默”。他爸的字。名字后头有断开的笔痕，像接着写了很长一段话，余下的被水渍咬得稀烂，糊成一团褐色污迹。

他捏着纸条看了两秒，喉咙里像堵了个物件，又咽回去。他找出一个旧塑封袋把纸放进去，仍塞回花盆底下。父亲要藏的东西，他替父亲留好。他背上包，反手替父亲拉了电闸。楼道声控灯闪两下，灭了。

锁门的时候，身后一道刹车声扫过来。电动车碾上门前湿泥，车尾一偏，差点撞上门框。骑手戴黄色头盔，个子瘦，车后座绑着半透明外卖箱，箱底漏出一摊褐黄色饮料渍，反着光。

“师傅，”外卖员没下车，单脚撑地，捏着手机问，“3门317是这栋不？”

“317在这栋不存在。”陈默锁好门，“这栋是3门，只有3层，门牌到三零七为止。”

外卖员低头看单，又把手机屏幕侧过去对光：“不对啊，您看这写的三栋三门……”他话头一断。下垂的单票边角被风掀起，露出一段印花。取件码后四位“0317”。

陈默的目光落在那四个数字上，后背像被一根线绷住。外卖员浑然不觉，把单票按回去，拧油门：“行，我再往里头找找。”电动车碾过水渍，颠了一下，冲出巷口，留一地湿痕慢慢变干。

陈默低头，看见自己右手还攥着那截旧纸角，不记得什么时候把它带了出来。风一吹，纸片在他指间打了个卷。他把纸角夹进背包里种子书的页缝，锁好门，没回头。

往公交站走，手插进外兜，指尖碰到一个圆形、硬的物件。他不记得兜里装过这东西。

掏出来。一块旧表，表带断了，表盘上一圈细裂痕，指针停在22点47分。他今天在父亲屋里没碰过表。床头柜没有，窗台没有，父亲遗物里一块表都没有。

他把表翻过来。表壳背面划痕很乱，刻得深，指痕发黑，能认出是一串数字。

0317。

他再摸了一遍外兜。空的。干净的。唯一放进去过的只有自己的手，这表怎么进的兜，他说不上来。

一辆公交车刹站，门开了一下又关上。司机从车窗探出头：“走不走？”

陈默把表握在掌心，指腹抵住表壳背面那串划痕的凹陷，背着装有那本册子的包，上了车。
