# 第3章 水渍延伸

雨还没停，手机闹钟先响了。

陈默伸手去按，指尖先碰到床头柜上一张摊开的外卖单底联。单号印得模糊，尾号三一七。他盯着那个数字看了五六秒，想不起自己什么时候把这东西从包里翻出来，还压得这样平整。枕下的种子书硌着肩胛，他挪了挪，摸过手机。一条语音留言，来自“邻居林姐”：“小陈，你爸那屋走廊渗水了，一楼墙根湿了一大片。你看看是不是二楼厨房水管没关紧。”

他把外卖单对折塞进外套口袋，套了件卫衣出门。老屋那栋筒子楼立在巷子深处，墙皮鼓起一片一片水泡。他用钥匙捅开单元门，还没上楼，先看见墙根的水印一路爬到一米高，白灰起壳，指甲一抠就掉粉。上到二楼推开厨房门，台面上横着一道水渍，沿台边往下滴，挂出细亮的线。水龙头是关紧的。那排没洗的碗摞在水池边，和昨天他离开时摆成一模一样的角度。他拧紧总阀，顺手把那摞碗洗了。

水声停住的那一刻，他才发现一件事。他不记得昨天午饭吃过什么。

那个位置空了一块。他记得上午在办什么，记得下午怎么进的屋，前前后后都有画面，偏在午饭前后那一截，什么都没有。像一本书被翻过去几页，中间的页码灰蒙蒙。

他翻包想找物业缴费单，指尖在笔袋底碰到一张叠成四方块的便签。展开，自己的笔迹，蓝黑墨水：“3月17日必须联系小周。”

字写得有点急，最后一个“周”字的钩拖得很长。他不记得写过它。不记得小周是谁。不记得三月十七日要和这个人联系什么。便签边缘磨得发毛，不像新写的。他把便签对折塞进胸口内袋，贴身收着。

下楼的时候，楼道口站着一个人。

黄色工服，头盔夹在腋下，正弯腰往车筐里拎泡沫箱。陈默认出那张脸，昨天误闯进老屋，递给他一张外卖单底联的那个年轻人。年轻人听见脚步声抬头，咧嘴一笑：“哥，你也住这？”

“你叫什么名字？”陈默问。

年轻人愣了一下：“周航。昨天那单尾号0317的，是我送的。”

雨后楼梯的水泥台面泛着暗光。最底下那级台阶的地砖裂了一角，砖缝里积着水，踩上去就是整只鞋底的滑。周航拎着泡沫箱正往那级台阶上踏。

“你等下。”陈默往楼层阴影里退了一步，从怀里抽出那本灰蓝册子，拔开笔帽。他不知道种子书能不能用。他只知道他爸留过的那句话：记人未长成的事。那页“案：0317”编号底下的浅划痕他现在还记得，有人曾经把笔尖抵在那个位置，犹豫过。

他写下：周航，3月11日9时52分，滨河道12号一楼台阶，右手握紧扶手，停住半步。

墨迹落定，纸面安静。册子不烫，不响，死物一样贴着掌心的汗。陈默合上它，心跳一下一下撞着肋骨。他听见楼道那头周航又迈动了脚步。

十五秒后，一声闷响。

周航半跪在台阶下，右手死死攥着扶手栏杆，手背青筋暴起，没摔到底。泡沫箱从车筐里甩脱，倒扣在台阶边，箱沿崩开一道缝。汤水从缝里漫出来，沿地砖缝爬成一条细线，爬过小半米，正接在昨天那滩旧水渍的长尾巴上，停住。

周航骂了句脏话，拍拍膝盖站起来，弯腰抱起泡沫箱，回头冲他笑：“这台阶真滑。哥你当心。”

陈默站在原地没应声。手里的册子贴着掌心的汗，凉意慢慢透上来。但他知道它动过了。

午后他回到出租屋，灶台上三只空泡面碗并列放着，筷子横插在汤底泡胀。他不记得自己吃过任何一碗。

他摸出手机翻通话记录，屏幕拉到最底下，看到一条今早就忽略的记录：凌晨2:17，拨出，号码是他父亲那张旧号的套餐号，时长11秒，对方尾号0317。他盯着那行记录，胸口口袋里的便签纸硌着。他按下回拨，忙音响到第三声又掐了。

傍晚，雨又下起来，比早晨密。

他回老屋拿总阀的扳手。那本种子书不知什么时候被他带了出来，又不知什么时候被攥在手心。他在走廊风口翻到页角，手电白光亮起，纸面上有一道极浅的压痕，浅得像铅笔画上去又被人用橡皮擦过，只残下半行字：

“14:07 东门街路口”。

东门街。他没听过这个街名。压痕底下的纸是凉的，字痕边缘发灰，像水泡过又干透的旧渍。正看着，隔壁门开了。

林兰撑一把滴水的黑伞，另一只手捏着一串钥匙，昨天他父亲窗台上落下的那串。她身后跟着个扎马尾的小女孩，书包带子拖到膝弯。林兰收了伞：“果果明天七点要去东门街那边上科创营，我本来还愁下雨怎么送。”

陈默的拇指停在纸面上，按住那半行字。他抬头：“你说哪里？”

“东门街路口呀。”林兰把钥匙圈套进他手指，“滨河道那头，有个红绿灯的。”

楼道尽头一盏灯昏黄，正好照在钥匙串的铜齿上。陈默捏着那串钥匙，没动。明早七点。纸上写的是下午两点七分。

“她平时，也走那个红绿灯吗？”他听见自己问。

林兰奇怪地看他：“今天又不走。明早她爸顺路送，就过那一个路口。”

说完她领着果果回屋。门锁咔哒落上，走廊重新蹲回雨声里。

陈默关了手电，站在门框的影子下，老屋里滴水的龙头一下一下敲着水池。他又把书翻回页角，手电的光重新亮起。

那半行“14:07 东门街路口”还是原来的样子。可就在它隔着一道纸纹的下面，一道极淡的笔画正从纸面上浮出来。

只有一笔。横着起笔，细得几乎看不见。

陈默不知道那是什么字。他只知道，它已经开始写了。
