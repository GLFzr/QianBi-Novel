# 第21章 东门街路口

陈默拉开驾驶座门坐进车里，双手握方向盘。车没有熄火。透过前挡风玻璃，马路对面那辆黑色车的灯灭了一盏。

他把手机屏幕又按亮了一次，阿莲的订单还在上面。起点城西殡仪馆正门，下单时间显示十分钟后，已经过了一小半。他踩下离合，车头刚往前提了半米，那盏灭掉的灯又亮了，黑色车没有动，像在等他先开。

陈默把车停回原地。他熄了火，双手从方向盘上松下来，等着。

两分钟后，黑色车的倒车灯亮起，向后退出半个车身，并线，掉头，朝反方向驶走。尾灯在路口拐了一个弯，很快看不见了。它停的位置空出一片柏油路面，什么也没留下。

那辆车退走的方式，是要亲眼看见他坐在驾驶座里才肯离开。陈默把车重新点着，中控屏上导航的路线已经画好，城西殡仪馆，全程十一公里。

他挂挡起步，车汇入凌晨的夜路。收音机没有开，车窗没有落，他左手搭在方向盘上，把三块碎片在脑子里摆了一次。页脚那行“廿二，与阿莲同车”，页脚上方并排的0317与0320，阿莲这个名字的陌生性。同车两个字像一枚钉子，把名字和编号钉在同一行。

廿二这个数，不像日期，倒像编号。如果它不是日期，那它和0317、0320、0316这一排竖写的数字就属于同一套序列，只是这一条以汉字写成，不按阿拉伯数字排。他没有办法从自己现有的信息里判断这套序列的规则，但至少他确认了一件事：廿二第一次出现时，阿莲的名字跟它绑在一起。

导航女声报出殡仪馆的地址时，他回想了一下自己走这条路的前几次。载林果果去科创营，林兰在副驾上一直看着窗外。程师傅出事后从东门街路口赶去市三院，那天的救护车尾灯在车流里一闪一闪。殡仪馆在这条路的中段偏南，离旧仓库群隔了一个工业区的纵深，再往前开几百米，路边开始出现花圈的铁架和打折的凭吊用品招牌。

凌晨的城西殡仪馆正门，路灯坏了一盏，剩下的一盏照着门牌和台阶的半边，另外半边陷进暗影里。陈默把车减速靠边，看见暗半侧的台阶下站着一个人。

深灰短外套，没打伞，也没有提包。她站在台阶下第二级的位置，面向来车方向，一直到陈默的车停稳，才从台阶上走下来。她走路的步子不快，鞋跟在台阶上磕了两声，停下来，确认车牌号。

她拉开后门，没有马上坐进来。弯腰探进半个身，先问了一句：“车上还有别人吗。”

陈默说没有。

她这才坐进来，关上门，报了一声：“东门街路口。”说完就没有再开口。

陈默调整了一下后视镜，余光扫过后座。阿莲的头发遮着半张脸，左手搭在膝盖上，右手收在身侧。她坐得离门很近，像随时可以打开车门退出去。他收回视线的瞬间，看见她右手无名指上有一枚窄银戒。款式不花哨，戴在无名指上很小一圈。他在三小时前见过差不多的指圈弧度，在戴两枚戒指那个人的食指和无名指上。

只是阿莲这枚少了一对，只有一枚，而且没有那层用旧了的暗色。是新的，比那人指上的干净，像是最近才戴上的。

他踩下油门，车朝东门街方向驶去。全程阿莲没有再说话，他也没有问。车载空调风口吹出一点轻微的声响，剩下的只有路噪。他透过内后视镜看了两次，阿莲一直在看窗外，目光落在路边掠过的路灯和围墙上，没有固定的落点，一间一间数着过去。

车到东门街路口，阿莲在一家还亮着灯的便利店前说：“等我十分钟。”

陈默把车停在路边，熄了火，留在驾驶座。他从前排储物格里摸出种子书，翻开页脚，那行“廿二，与阿莲同车”还在原处，墨迹已经干了。他没有合上书，手指沿着字迹的笔划捋了一遍。没有被接触者靠近而加深的迹象，字迹保持原样。

他把书合上放回储物格，靠在椅背上，隔着前挡风玻璃看那家便利店的灯箱。灯管有一截暗了，剩下半截把门口的地砖照得发白。阿莲没有出现在那截光里。他看了一眼手机，从她下车到现在，过了四分半。储物格里的种子书安静地压着那截黄纸角。

十分钟后，阿莲从便利店侧面的方向走回来，手里空着。她拉开后门，坐了进来，朝副驾座上放下一只牛皮纸信封，没有封口。

“去市三院。”她说，“这张纸你现在不要看，到了再看。”

陈默捏了一下信封边缘，透过纸面能感觉到里面是一张硬纸片，边缘平整。不是照片的厚度，比照片薄，比普通书写纸硬。他没有当场翻看，把信封留在副驾座上，踩下离合，车汇入东门街路口的车流。

侧过头，信封露出一截纸角，颜色偏黄，是旧纸。

手机屏幕弹出一条系统提示，自营平台的行程结束通知，费用已支付。他趁红灯低头，看见阿莲的评价栏打出一行字：师傅，下次还叫你。

下次两个字在屏幕上停了很久。他想起页脚那行字，“同车”已经发生了，阿莲说下次，页痕说同车，两句话像在绕着同一个圈。

手机又震了一下。他低头，通信录里备注代驾的号码弹出一条短信，只有两个数字：22。
