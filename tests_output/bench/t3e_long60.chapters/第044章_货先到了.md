# 第44章 货先到了

第三秒，车灯已经把桥洞地面照白。

陈默没有逃向手表。他侧身朝引道排水缺口的方向斜跨两步，让出光圈中央，同时左手抄起路边半块碎砖，反手拍在面包车右侧翼子板上。金属闷响顺着车身传进驾驶室，车头朝响声的方向偏了半尺。

他赌的就是这一偏。车要撞的是桥洞里站到点的人，他不站，车就只能去撞水泥。

车头擦着第二、第三桥墩之间的空当斜插过去，右前角撞上桥墩侧面护栏，一声闷响，引擎盖拱起，车滑出两米停住。水箱里的水滋滋往外冒，白汽贴着地面爬，橡胶的焦味混在里头。桥灯的光圈被车头切掉一角，地上那格亮区歪了。

陈默冲过去拉侧门。门变形了，他用脚蹬开半扇，探进手去摸颈侧。有呼吸，慢，但匀。驾驶座上的人侧歪着，安全带勒进肩肉里，锁骨的位置顶起一个棱。他解开卡扣，把人往外拖，五十来公斤的重量压在小臂上，他咬着牙拖到灯光格里，膝盖跪在碎石上，硌得生疼。袖子被车门边缘刮开一道口子，小臂上渗出一道红。

程师傅。脸颊上有擦伤，血已经半凝，眉骨上一道口子翻着肉。陈默蹲下去，从兜里翻出手机里存的档案照片，把屏幕凑到车头跟前。右前灯罩裂着一道纹，裂纹发白，和照片里那道，走向一致，长度一致。灰色面包车，同一辆。

他撕下外套内衬垫过程师傅的头，把人摆成侧卧。程师傅外套口袋敞着，一截透明胶带头滑出来，落在灯光格里。断口是撕扯的，边缘积灰，和档案室现场那截同款。陈默用纸巾垫着捏起来，翻到背面，胶带残胶里压着半截手写体字母的压痕，笔画连着绕。登记卡照片还在他手机里，经手人栏那个字母，起笔方向对得上。

程师傅的手机摔在挡把底下，屏幕亮着，通话界面没挂断。号码陈默认得，高价单的号，父亲号码末位差一的那个。通话时长停在四十一分钟。他调出通话记录，线路归属一栏，与父亲号码同段。张若虚借的旧线路，拨的这通电话，把人引到桥下。

接单记录最后一单，派单方备注一栏：老周介绍的业务关系。

陈默蹲在车头旁，把三问便签摊在膝盖上。第一问已经划掉，他用笔尖在下面添了一行：谁把程师傅交到老周那条线上。写完他把便签折起，塞回兜里。四条线，胶带、号码、老周、登记卡，此刻全压在他一个人手里。

水箱的白汽漫过来，带着烫过的橡胶味。他起身想找水源，程师傅的手指忽然动了。

那只手攥住他的袖口，攥得很紧。程师傅的眼皮颤了颤，没睁开，嘴唇动着，吐出含混的两个字。

“站住。”

陈默蹲回原位，没挣袖口。“程叔，是我，陈默。你撞了车，别动。”

程师傅的手指又收紧了一下，然后松了半分，人重新沉进昏迷里。呼吸还在，比刚才沉。

桥灯的电流声里，阴影的方向传来一句话。

“货提前到了。”张若虚的声音贴着水泥面滚过来，听不出远近，“可登记卡的栏，还空着。”

陈默循声转头。第三根桥墩的阴影里，轮廓都没给。他没出声，先看了一眼手表的方向，那枚表还在粉笔杠下面，没动。

“今晚不算。”阴影里的声音继续，“栏要填在3月17日，晚八点过一分。到点的人，得是站着的。”

“程师傅的伤，算谁的账。”陈默问。

阴影里静了两秒。“车是我安排的。撞没撞上你，是他开偏的。”声音顿了顿，“这笔，我认一半。”

“另一半呢。”

“另一半，等栏填了再算。”张若虚说，“你有二十多天。物证你捡走了，我不拦。3月17日，你带着它们来，或者不带，都行。”

“你打算让程师傅醒着看见这一栏。”陈默说。

“他接的单，他有权看完。”阴影里的声音说，“这单从派出去那天起，就没打算瞒他。”

脚步声贴着桥墩走远，这次连碾石子的声音都没有，像直接退进了墙里。

陈默蹲回程师傅身边，先拨了急救电话，报了桥的位置，又报了伤情，侧卧位，有呼吸，眉骨出血。接线员让他别挂，他照做了，把手机搁在程师傅肩膀旁边，开着免提。然后他把胶带头、程师傅的手机并排摆在灯光格里，掏出自己另一部手机逐一拍照，正面一张，侧面一张，胶带残胶的字母压痕单独一张。拍完，他把外套脱下来盖过程师傅上半身，领口掖好。

救护车的声音从远处过来，先是一点，再是一线。桥灯把两道影子投在第三道杠旁边，一道长，一道短，长的盖着短的。程师傅的手还搭在他袖口边，指节微微曲着，保持着攥过的形状。
