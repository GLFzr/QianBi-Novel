# 第42章 就差一位

天蒙蒙亮，陈默把三问便签在桌面上摆正，压平翘起的纸角。桌上还摊着昨晚的物证，登记卡照片、底联、蜡圈卡纸，一样没收。浓茶凉透了，杯底一圈茶垢。他一夜没怎么合眼，眼眶发涩，第一问在最上头：程师傅在哪。

他从手机里调出事务所转来的接单截图，高价单的来电号码排在页面顶上。他拿笔逐位抄在便签背面，抄一位，核一位，抄完，又翻开通讯录，找到父亲那格。两个号码并排写在纸上，他从首位对起，一位一位往下走，笔尖点着纸面移动。前十一位，全同。末位，一个4，一个5。

就差一位。修车铺老板转述的那句嘟囔，从比喻落成了实指。程师傅接电话时听出的耳熟，记的就是这个号。

他捏着手机拨过去。响了四声，听筒里响起彩铃。您拨打的用户已在服务区外。留言请按。父亲自录的那段声音，三年没换过，尾音还是那个尾音。陈默握着手机听完一整遍，挂断，屏幕上跳出关机提示。他没留言，把号码末位的5抄进便签，笔尖在那个数字上顿出一个墨点，纸背都透了。

三年前父亲失踪，这个号就再没人接过。现在它接走了一单高价活，把程师傅领进了夜里。他盯着那行号码看了半分钟，把便签翻回正面。

九点，阿莲来电：“登记卡查到了，录入终端在馆内前台那台机，但账号是公共的，几个人共用，查不出人。”

“别查了。”陈默说，“录入时间昨晚十一点过，那会儿你在馆里，再往深了追，线就引到你身上。”

“你怕连累我？”

“我怕账本多记一个名字。”他说，“登记卡的事到此为止，剩下的我来。”

电话那头静了两秒。“行，剩下的归你。查到了记得告诉我，别又瞒。”

“给你留一半。”他说完就挂了。挂完他把手机扣在桌上，指腹在便签第一问上按了按。

出门时天阴着，屋檐滴水，程师傅所属的事务所在一条窄巷里，门口停着两辆待派的面包车，雨刮都立着。值班调度趴在柜台上翻派车本，指头蘸着口水捻页角，柜台上摆着半盒烟和一个缺角的搪瓷缸。陈默报了程师傅的名字，调度抬头打量他一眼：“你不是他同事？”

“他家属托我来问的。”

调度把本子翻到昨夜那页，念出高价单的备注：“建设路跨线桥下货运点，3月17日晚八点交货。哟，这单备注写得真全，连钟点都定了。老程接单从不挑，这单他倒是问了两遍地址。”

“问的两遍，都是这句？”

“都是这句。”调度用铅笔敲了敲本子，“一个字不差。”

陈默把这句原样抄下，道了谢出门。回程车上，他摊开便签，划掉第一问，划痕很重，把纸都划毛了。划完他盯着剩下的一问半，经手人是谁，3月17日要我写什么。程师傅被引去的地方有了，钟点有了，人还关在哪一格，不知道。

到家，他翻开种子书页角，在案：0317旁边添了一行铅笔字：建设路跨线桥，晚八点。两行字并排贴着，日期是同一个。他先用“他先填”，后写的是他。顺序被人排好了，他把笔帽按紧，合上书。

傍晚天色沉下来，风里带潮气，他驱车往建设路。跨线桥横在货运区边上，桥身是老式的双墩结构，桥下水洼结着薄薄一层油膜，映着桥灯，颜色发乌。他把车停在两百米外的路侧，熄了火，步行过去，背包换到胸前。

踩点按他惯常的法子来。先数灯：桥下六盏，两盏不亮，亮着的四盏把桥洞切成明暗相间的格子。再找盲区：第三根桥墩背后有一片灯照不进的死角，宽度够停一辆车，车头朝里，从桥南方向看不见。出口只有一个，桥南匝道，北头是隔离带。上引道是段下坡，坡顶到桥洞口约一百二十米，他走了个来回，用步子量的，刹车距离拉长，路面没有监控杆。他蹲在桥洞口看车流方向，晚高峰的车从坡上下来，都带速，没人在这个位置减速。

他在纸上勾出两条可能的事故路线：一条从下坡直插桥洞，收口在第三根桥墩的死角前；一条借匝道横切，把正常车流拦腰截断。两条路线的收口，都在桥洞正下方。他画完，在两条线外圈了个圈，又添了三个小方格，桥洞里能站人的位置，一共三处。

对方选这座桥，选得省心。下坡，死角，单出口。把人摆进去，剩下的只需要等一个钟点。晚八点，车流最密的时候。

他收笔，抬头核对桥墩编号。第三根桥墩的水泥面上，齐腰的高度，有三道粉笔短杠。间距不等，第一道和第二道隔得近，第二道和第三道隔得远，杠头都朝同一个方向斜。粉笔是新画的，白得发亮，蹭都没蹭过。

三道。他往前走了两步，伸手比了比高度，齐腰，画的人站着画的。三个方格，三道杠，他心里的数对不上，但数目先记下了。

桥洞阴影里，有人站着。

深色外套，右手垂在身侧，三根指头缠着白胶布。那人离他七八米，站进第三根桥墩的影子里，脸隐在暗处。他没出声，也没退，右手慢慢抬起来，白胶布在桥灯光边上亮了一下，掌心朝着陈默，像打招呼，也像示意他过去。

陈默站在光暗交界处，种子书隔着背包贴在后背上。那只手悬在半空，不放下，也不靠近，等着他迈出下一步。
