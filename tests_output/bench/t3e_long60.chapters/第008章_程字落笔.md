# 第8章 程字落笔

手机在口袋里震了第二下。周航那头风很大，声音被刮得断断续续：“程师傅出事了，东门街路口，被白色轿车挂倒，救护车刚走，你过来看看吧。”

陈默站在东门街口，低头，路肩上有一道新的水泥刮痕，卷口发亮。他蹲下去看了一眼。十分钟前这里还没有这道印子。他站起来，把手机换到左手，没让屏幕暗下去，林兰发来的那张锡皮盒照片还摊在上面，蓝黑墨水的笔尖从盒盖缝隙里探出来。两样东西在他视线里叠了一下，刮痕和笔尖，同一种颜色。

他赶到市三院急诊科时，走廊里已经排到第三张担架。程师傅躺在靠墙的一张，左腿裤管被剪开，小腿外侧一条长口，皮肉翻着，血渗到床单上。护士正往伤口上压纱布。陈默在门口站住，隔着一排输液架看着那张脸，晒得黝黑，眼角全是褶子，他不确定自己在东门街见过这个人。他见过那辆电动车，后座绑着的泡沫箱，但没见过骑车的人。他们之间的距离最近的时候，大概只有那道旧水渍的两指宽。

程师傅先看见他。他半撑起身子，目光在陈默脸上停了两秒，开口：“你叔叔让你来的？”

陈默顺着话头接住：“他让我来看看你。”

“他这人就这样，见不得别人出事。”程师傅躺回去，呼了一口气，“跟他说我没事，皮肉伤，养几天就好。”他低头看了一眼自己那条被剪开的裤腿，又把目光移回陈默脸上，“你回去跟他说，上回那事我还没谢他。他要是得空，来店里坐坐。”

陈默没接这句。护士走过来推他的床，他摆摆手，没再说话。床轮碾过走廊地面，往拍片室去了。陈默站在原地，看着那辆床拐过弯，帘子拉上。

他低头翻了翻种子书页脚，0319和0320并排躺在纸角，底下多出半行极浅的铅笔痕，一个姓：程。那笔画跟他今天下午在医院台阶上看到的人形标记出自同一种痕迹。他合上书，塞回背包内层，没有翻页落笔。

缴费窗口排着队。陈默替程师傅挂急诊骨科号，掏钱夹时指腹擦到那张别拆的信纸边角。他没打开信封，把信封放回内袋。窗口里头的收费员报了个数，他刷卡时想起来，自己连程师傅的全名还没来得及问。挂号单上打出来的名字是程国栋，年纪一栏写着五十二。他把单子折好收进口袋，转头看见程师傅的电动车钥匙和手机被护士装在一只透明袋子里，搁在缝合室外的台面上。

缝合室外，陈默帮着护士把程师傅的随身物品整理进一个塑料袋。钱包掉在地上，翻开，一张纸片滑出半截。边角发黄，对折过很多次，折痕深得发白。陈默捏着纸边抽出来，上面写着“案：0317”，下面一行小字：“本子留给陈默。告诉他，账不是命运收的。”

他盯着那行字看了很久，久到护士走过来问他要不要帮忙。字迹是父亲的，起笔重，收笔拖，和种子书内页那行“种子书。记人未长成的事”出自同一只手。但墨水颜色比账本内页淡，像放了很多年。他把纸片平放在掌心，纸的硬度在指尖压出一点弧度。他不知道这张纸在程师傅的钱包里躺了多久，但折痕的深度不像近几年的东西。

他只拍了正反面照片，纸片和钱包一起装进塑料袋，递给从护士站走出来的乔一宁。“帮我封个档，暂时放你那儿。”

乔一宁接过袋子，往里看了一眼，手指在纸片边上多停了两秒。她抬起头，没问纸片是什么，只说：“下午那个左臂缝四针的冷藏运输员，没留名就走了。我记住他那口音，东北的，说话带儿化音。”她顿了顿，“还有一件事，昨晚十二点我在前台交接，登记台上压着一张纸条，写‘账还在门外’，没落款，也没写收信人。没人看见谁放的。”

陈默接过那张纸条。纸是普通A4纸裁的，字是用黑笔写的，笔画很正，像是刻意放慢了速度。他把纸条翻过来，背面空白。

“放多久了？”

“我早上接班才看见。”乔一宁说，“保洁说昨晚十一点半开始打扫，那时候还没有。十二点我就在前台，没人靠近过。”

“监控呢？”

“前台那个摄像头上周坏了，维修单还挂在后勤那边。”她看了他一眼，“你最近在查什么？连着两天跑医院。”

“没查什么。”陈默把纸条对折，塞进外套内袋，“一个朋友出了点事，我过来看看。”

乔一宁没追问。她转身回护士站，走了两步又停下，侧过头：“表哥，你爸的事过去那么多年了。有些东西，别往里翻太深。”

陈默捏着纸条退回走廊，站在窗边。路灯亮着，底下救护车泊位空着，台阶上只有一只被风刮歪的纸杯。他看了一会儿，纸杯没动，风也没停。他把纸条又掏出来看了一眼，“账还在门外”四个字在黑笔线条里显得格外规整，像有人一笔一画写下来，怕他认不清。

程师傅缝合完，被推进观察区。陈默隔着玻璃看他。他躺在床上，输液管垂到床沿，牛仔裤从剪开的裤管里露出一截石膏的边。他半睡半醒，嘴唇动了动，声音隔着玻璃听不真切。陈默凑近些，才听见那句含混的话：“你爸说，这本子不能再让第三个人碰。”

陈默站在玻璃外面，手里还攥着那张“账还在门外”的纸条。观察区的门被护士从里面掩上。他低头，把无主纸条和纸片放在一起拍照，拍到纸片背面时，他愣住。

背面还有一行铅笔字，笔画比正面那行要细，不是父亲的字：“本子不能碰。但你已经碰了。第三个人会替你付账。”

走廊灯光白得晃眼。陈默把照片放大，那行字最末一个账字收笔处有个很轻的顿点，跟老屋书桌上那串刻痕的收笔方式一模一样。他站在原地，手机屏幕的光映在脸上。乔一宁在护士站那头探出半个身子，喊他：“程师傅醒了，说想见你。”
