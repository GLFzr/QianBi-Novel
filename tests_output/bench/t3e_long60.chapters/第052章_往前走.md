# 第52章 往前走

清晨醒来，屋里安静得没有要查的东西。窗帘缝里那条窄亮还落在地板上，位置比昨晚挪了半掌。陈默躺着听了一会儿，楼下有收废品的三轮车过去，铃铛响了两声，又远了。他起身，苹果袋还系着那两个结，他解开一个，拿了一个苹果，剩下的重新系上，放进冰箱。冰箱门关上的时候，箱底的方向他看了一眼，床单垂着，盖住箱角。

出门时楼道里碰见对门的阿姨倒垃圾，阿姨看了他一眼，说小伙子最近回来得早了。他说工作调了，白班。阿姨点点头，拎着垃圾袋下楼，塑料袋蹭着墙，一路响到拐角。

网点上午忙而不乱。分拣线转着，扫码枪的滴滴声连成一片，纸箱从传送带上下来，摞成整齐的几垛，胶带撕开的声音此起彼伏。老调度蹲在垛边核对单号，看见他进来，抬了抬下巴：“来了。”

“来了。”

“吃早饭没。”

“吃了。”其实没吃，苹果在包里。他没提。

上午的活是扫件和分拣，他做得比上月熟了，手上有了准头，错件率低下来。有一件地址写反的，他核了三遍才挑出来，放回待改区。旁边分拣的小伙子探过头：“默哥，你挑错件怎么比机器还准。”

“核三遍。”陈默说，“一遍看字，一遍看数，一遍看地址对不对得上。”

“学到了。”小伙子缩回去，扫码枪又滴滴响起来。

中午交接班的时候，老调度把一张新线的单子递给他：“城东这条线，站点多，路杂，你跑得熟，接不接。”

“接。”

“这条线跑顺了，旺季我给你报转正。”老调度说，“你打算干多久。”

“长期。”

老调度看了他两秒，把单子塞进他手里，又从兜里摸出一副线手套扔过来。“行。旺季的事，我记着。手套拿着，城东那边有段路在修，扬灰。”

“谢了。”

“谢什么，干活的手得护着。”老调度说完转身去点下一批件，背影比上月弯得厉害些。

午休他绕去东门街。老周的摊支着，帆布上晒着几双换底的鞋，胶水味混着日头味，街口的梧桐影子挪到了摊边。老周坐在马扎上纳鞋底，抬头看见他，把锥子插回线团。

“来了。”

“来了。”陈默把包里的苹果拿出来一个，递过去，“林兰家树上摘的。”

老周接了，在袖子上蹭了蹭，咬了一口，嚼了两下。“甜。”他说，“你爸以前也爱吃这个。”

“他常来你这儿？”

“常来。”老周说，“不修鞋，就坐这条凳，坐一会儿就走。有时候带俩苹果，跟我下两盘棋，输了也不恼。”他顿了顿，“后来他不来了，凳子空着，我就没再让坐。”

陈默看着那条凳。凳面磨得发亮，比周围的地面浅一色，边角磕掉一块漆，露出底下的木色。

“现在呢。”他问。

“现在你坐。”老周说，“坐吧，凳子闲着也是闲着。”

陈默坐下了。凳面被日头晒得温热。他坐了一会儿，没说话，老周也没说话，各自看着街口。一辆公交车过去，带起一阵风，帆布上的鞋晃了晃，又停住。

“他下棋什么路数。”陈默问。

“慢。”老周说，“落子慢，想得久，可一旦落了就不悔。跟他的脾气一个样。”老周把苹果核丢进脚边的纸盒，“你要学棋，就学他这个，别学我，我落子快，悔得也快。”

“周叔，”陈默起身时说，“改天我来陪你下棋。”

“行。”老周说，“带苹果。”

下午过得很平。手机在兜里一次没响，屏幕亮起来的时候全是派单提醒。他跑了两趟城东的新线，站点位置在地图上标了七处，有两处门牌号对不上，他记下来，打算明天去核。第三趟回来，电动车的电剩一格，他换了电池，把车推进棚里。下班前他把新线的站点在地图上标完，标完抬头，天已经擦黑，网点门口的灯箱亮了。

沈照倚着护栏站着，便装，没戴帽子，手里拎着个塑料袋，袋里两瓶汽水，瓶身上挂着水珠。

“你挑地方，我查了附近有家面馆。”沈照说，“牛肉面，汤头老，开了十几年。”

“你怎么找过来的。”

“案卷里有你网点的地址。”沈照说，“案子结了，地址就从案卷挪进了通讯录。”

陈默看了他一眼。“你这算约饭还是查岗。”

“约饭。”沈照把塑料袋晃了晃，“汽水我带了，面馆不管外带。”

两人往面馆走。晚高峰刚过，街面上人稀了些，面馆的灯箱亮着，蒸汽从后厨的门缝里冒出来，牛肉汤的香味隔着半条街就到了。店里六张桌，坐了三桌，靠窗那桌空着。沈照先坐下，把汽水放在桌上，一瓶推给陈默。

“两碗牛肉面，一碗不要香菜。”沈照冲后厨喊，然后回头，“你要香菜吗。”

“要。”

“改口。”沈照又喊，“一碗要香菜。”

面还没上来，沈照把菜单合上，推到一边。

“不谈案子。”他说，“谈点别的。”

“谈什么。”

“谈你下个月跑城东那条线，谈老周家的棋，谈苹果甜不甜。”沈照说，“案子归卷宗，日子归日子。”

“行。”陈默说。

热汤端上桌，白气腾起来，糊在窗玻璃上。窗外路灯亮了，光从糊住的玻璃外透进来，成了一团模糊的黄。沈照把筷子递过来，陈默接住。

两人对坐，面在中间，汽水在旁边，热气往上走。
