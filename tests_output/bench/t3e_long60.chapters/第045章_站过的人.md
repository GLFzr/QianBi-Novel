# 第45章 站过的人

救护车的灯扫进桥洞，蓝白两色把桥墩上的粉笔杠轮流照亮。急救员跳下车，先掰过程师傅攥着陈默袖口的手。那手指节还曲着，保持着攥过的形状，松开后慢慢垂回担架边。

“生命体征报一下。”急救员冲陈默喊。

“呼吸有，一直有，昏迷，眉骨出血。”陈默答，“我是他接单的同事，跟车。”

“你叫什么。”

“陈默。物流网点的。”他把工牌从胸前摘下来递过去。工牌是入职那天发的，照片上的他比现在精神。急救员扫了一眼，登记在单子上。

交警随后到，拉了警戒带，对着车头拍照。闪光灯一下一下，把水箱的白汽照成一小片白雾。对讲机里响了一阵，一个穿制服的男人从车后绕出来，三十多岁，帽檐压得低，先看车，再看人，最后落在陈默脸上。

“桥洞里报警的是你？”

“是。”

“档案室那晚的电力巡检记录，签的是你名字的拼音缩写。”男人说，“我姓沈，沈照。”

陈默的手在兜里停了半秒。沈照没等他解释，转身指挥抬人上车。担架推过第三根桥墩时，轮子碾过一道粉笔杠的白粉，杠痕缺了一角。两人对视的那一眼里，谁都没先提档案室。车门合拢，警灯还在车顶转，把桥洞口照得一阵红一阵蓝。

救护车上，程师傅扣着吸氧面罩，胸口起伏。装胶带头的物证袋被贴上标签，搁在担架旁的设备架上，随着车身晃动。陈默盯着那个袋子看了一路，没伸手。车厢里飘着消毒水的味道，混着一点血腥气。程师傅的面罩里积了一层白雾，随呼吸鼓起又瘪下去。陈默伸手把滑到下巴的绑带往上推了推，程师傅没醒，眉骨上的纱布却渗出一小点红。

医院走廊，灯白得发青。沈照换了便装外套，在缴费机旁边等他，手里捏着一支没水的圆珠笔，笔帽咬出了牙印。走廊里醒着的人不多，保洁的拖把在远端一下一下推，水迹拖出一条亮线。

“物证副本。”陈默把照片拷贝和胶带头原物递过去，“原物你们收，我留照片。”

“胶带残胶里的压痕，物证科初判是笔迹压痕，起笔方向和馆里某份登记文书的样本对得上。”沈照接过袋子，掂了掂，“蜡圈成分，和你们档案室那圈封蜡同类。两条线在往同一个本子上合。”

“正式结果什么时候出。”

“走流程，快不了。”沈照把袋子收进包里，抬眼看他，“我查过你。三起事故，你都在场，每次记录都干净得挑不出毛病。干净过头了。”

“你想说什么。”

“你在替谁兜着。”沈照说，“号码那一块，你今晚一个字没提。通话记录你自己截掉了。”

陈默没接。他看着走廊尽头病房的灯，说：“号码进了卷宗，会多牵一个不相干的人。等我能给你的时候，我给。”

“不相干的人。”沈照重复了一遍这五个字，把笔帽按上，“行。我等你能给的那天。但你要是等到案子结了还没给，我就当你在毁证。”

“到那天，你收着。”

沈照转身走了两步，又停下，没回头：“桥墩上那三道杠，我拍下来了。粉笔的成分，物证科也送检了。你要是知道那是什么，最好先想清楚，进不进你的证词。”

值班护士过来递缴费单，陈默垫付了，报程师傅事务所电话时停顿两秒，报了前台座机，没报老周那条线。单子上的数字他扫了一眼，从裤兜里数钱，指尖还沾着桥洞碎石的灰。

病房里，程师傅的手在被子外头动了。陈默凑近，程师傅睁开一条缝，一把抓住他的手腕，力气不大，但抓得很实。病房另一头是张空床，床头柜上摆着别人没带走的保温杯，监护仪每隔几秒响一声，绿线在屏幕上走。

“我站到点没有。”程师傅的声音从面罩里漏出来，含混。

“没有。你撞了车，在医院。”

程师傅的眼珠转了转，像在辨认这句话。陈默俯低身子，压着声音问：“程叔，你见过站着的人吗。”

程师傅的呼吸顿了一下。监护仪的曲线平了两拍。他盯着天花板看了很久，久到陈默以为他又沉下去了，嘴唇才重新动起来。

“见过。”他说，“好些年前，桥洞里站过一个人。车下来，他不躲。车自己让的，贴着他拐过去。”手指在陈默腕上收紧，“我那晚接单，电话里那声音跟我说，照那样子走就行。我是照着那样子接的活。我喊站住，是喊给那个人听的，我想问他，站到点，是不是就不疼了。”

话到这里断了。程师傅的手从陈默腕上滑下去，眼皮合拢，呼吸重新拉长。值班护士进来换了吊瓶，看了眼监护仪，说体征平稳，让他别再逗病人说话。

陈默出了医院，在门口台阶上摸出烟，没点，夹在指间。夜班公交从高架上一串灯滑过去。风从台阶底下灌上来，他把外套拉链拉到顶，袖子上那道被车门刮开的口子漏风，凉意贴着小臂走。三道杠，站桩，不躲车，车自己让的。他爸站过。他此刻站在光圈里没让车撞上，用的也是让车偏头的法子。两件事隔着年头，摆成了一列。他把那支没点的烟别回烟盒，下台阶。

深夜到家，他把种子书摊在台灯下。桌上还摊着白天没收的物证照片，他把它们拢到一边，腾出半张桌面。页角那行铅笔小字比昨夜清楚了，笔画沉进了纸里。

他先填，你后写。

接尸簿预登栏，签的是他的名字。登记卡死因栏，空着等现场。张若虚填的是货，空出来的栏，排给他落笔。账本没打算让他站着挨撞，账本要的是他的字。

他用指腹压住“你后写”三个字。指腹底下的纸面微微发潮，像有墨正从纸的背面往上渗。他抬起手，指腹上没沾墨。台灯的光圈里，那行字比周围纸面暗了半度，像吸过水又干掉的痕迹。他翻开手机，登记卡照片调出来，死因栏那格空白，在屏幕上亮着。
