# 第38章 后半张我看完了

门缝外那道影子横了三秒才移开。陈默知道对方在确认他是否还活着。

影子移开后，脚步声往走廊尽头走了七步才停下。陈默在原地再数二十下呼吸，确认门缝外影子没再折返，才缓步走到门边。他先后做两件低风险事：第一先听门缝外走廊动静，第二拨动闸锁确认断钥匙嵌死，右旋一圈后被外力拧断。锁孔断键柄上蓝色尼龙绳的编法，他借着袖口手机灯看了一眼：与父亲钥匙串上那截同色但钢丝更硬，是新做旧的仿制品。他把前半张底稿对折两下，塞进内袋贴胸处，拉链拉死。

走廊尽头传来皮鞋跟声，七步后停下，再没有下一步。陈默原地站着，不逼近门缝去确认对方是否还在。他判断对方不会推门回来，因为断钥匙已封死门锁，只需等巡夜时间。他用拨号键盲打一段加密短消息发给阿莲，只在末尾加0，让她回拨。发完锁屏，他退回档案柜侧夹缝，又把绿植往自己这边拨了半寸。门缝外那道光由亮转暗再转亮，是一台电瓶巡逻车经过的间隔。他知道夜巡记录每四十分钟一轮，下一轮倒计时还有二十六分钟。

他在夹缝里又数了十四下呼吸，把绿植叶子拨回原位，确认从外面看不出来有人翻过。他掏出手机，把监控截图再放大一遍，深色外套人右手胶布中段那道新痕，和他贴在台灯底座上的胶带断口，弧度吻合。他把截图锁屏，等着。

电力巡检保安用备用卡开安全门，在工具间拿梯子，顺口说"档案室门锁下午刚报修过"。陈默借绿植和文件箱的阴影，在保安视线死角里半蹲着挪到后门，等门一开带风的一瞬贴门侧闪出。他没拿硬纸筒。出门那一刻他摸了一下内袋，前半张底稿还在，监控截图卷在袖口里。他贴着墙根往东侧消防楼梯走，到一楼才直起身。他算的是开门时序。他走过保安身边时，保安正拿梯子往工具间搬，没看他。他出了消防通道，站在殡仪馆后门外，夜风灌进领口，他拉了一下外套拉链，把底稿的边角按了按，确认没有折损。

回到住处，床头灯亮着，他摊开前半张底稿，先读背面那行圆珠笔字"这一账偿过了，换一个人来记"。笔锋横平竖直，与排班表表头不是同一支笔。再翻正面，父亲笔迹三行半："3月17日22:47。东门街路口。补写：白色轿车减速让行，未撞护栏"，第二行中间两字被涂死。他用指腹摸那处涂痕，表面微凸，是同色墨水补涂后未干透时留下的颗粒感。背面那句不要写的顿笔，压在他能认出的父亲旧笔记本其他页的笔锋同向。

他接下来才去翻那半张A4打印纸。城西旧机动车登记代办业务抬头，黑色帕萨特车主张若虚。右下角圆珠笔补记"右手三指旧绷带，中指指甲缝有油泥"。监控截图放大，深色外套人右手胶布中段与透明胶带断口纹理吻合。他写下时间线：张若虚进修表铺、他在柜台底部发现父亲笔迹、监控确认张若虚到过物流网点、档案室对方取走后半张。这条线所有物证的同一指向，都是同一双手。

他在纸边空处写下"张若虚3月17日22:47在东门街路口有没有出现过"这个问句。把车钥匙环明细单对折两下，压在种子书第44页页脚，偿字边缘新墨在灯下比昨夜又深了一点。他伸手去碰那处墨迹边缘，指腹触到浮末，凉到指尖。他忽然明白一件事：他长时间不落笔，页脚的新墨并不会停止叠加，代价在不写的选择里也在累积。不写，账也在动。他按灭灯。

被子没掀开，他穿着外套躺下去，把那半张底稿一直压在胸口，轻声说了一句"后半张，我看完了"。指尖按在胸口那半张底稿上，睁眼望着天花板那面没光的天花板。

手机屏幕在枕边亮了一瞬。阿莲回拨，通话接通后她没有先开口，背景里是弹珠落地的声音，清脆，像从好几层楼高的地方掉下来。她低声说，档案室那边她在想办法明天重进。话音末了她停了两秒，加了一句：我这边替你查到一个东西，你先别问。
