# 第28章 封存

推车刹停声落地后，门缝里的灰色鞋尖没有动。陈默退到档案柜侧面，用手背抵住门，听见走廊那头传来铁皮桶被踢翻的声音，紧接着是老周的脚步声和一句“谁在那”。

鞋尖退后半步，露出裤腿边缘那一小截白布，但没有走开。陈默屏住呼吸，数了两秒，鞋尖的位置没有变化。他判断门外的人在等他自己开门。对方站得那么近，却不动手，说明耐心比他长。他不动，让门外的人先动。

铁皮桶翻倒的声音是从走廊深处传来的，离档案室隔了大约三扇门。老周的脚步声由远及近，鞋底碾过水泥地，每一步都踩实，不快不慢，是巡夜人特有的走法。他喊了一声“谁在那”之后没有再出声，脚步声继续朝档案室方向移动。

门缝外，鞋尖又退了一点，露出更多裤腿边缘的白布，但仍没有离开。陈默抵住柜门的手背感觉到门板传来极轻的震动，是有人把身体重心从一只脚移到另一只脚。对方在犹豫。

老周的脚步声停在档案室门口。他拍了一下门板，声音在空旷走廊里显得格外响：“侄辈，你还在里面？”

陈默没有立刻回答。他先把档案盒从膝盖上放回柜内，盒盖合拢时发出一声轻响，他用指尖顺着盒边压了一遍，确认没有夹住纸页。然后他站起来，用袖口擦掉柜门侧面自己刚才扶过的位置，压痕被布料抹平。他走到门边，拧动把手，门开了。

走廊灯光灌进来，老周站在门口，手里拎着一只铁皮桶，桶底沾着灰。他看了一眼陈默，又看了一眼陈默身后开着的档案柜，目光停了一瞬，没问。“前些天，有人拿你爸工号来问过档案室。”老周把钥匙从锁孔里抽出来，顺口说，“三十出头，右手三根指头缠着白胶布。”

陈默握住钥匙，指节收紧。他正要追问，余光瞥见走廊尽头防火梯门的玻璃上映出一截人影。鞋尖没走，只是退到防火梯间，隔着玻璃观察。他没有追。他走出正门，绕到后门台阶蹲下，翻开种子书。页脚偿字边缘多了一滴干透的墨色，像有人在他离开后用指腹按过。页痕上“下一张纸，在水泥厂以南”的以南被一道新痕划掉，改写为以北。

他合上本子站起来。殡仪馆后门正对水泥厂烟囱方向，路灯照一条向北延伸的土路。他摊开手掌，掌心里是刚才擦柜门时袖口勾下的灰，灰里有一小截断掉的透明胶带头。

他走出十步远，身后殡仪馆后门铁皮门被推开一道缝又合上，门缝里滚出一截硬纸筒，外面套着与档案盒同色灰，筒口封蜡，蜡上压出一个指印，指印中段有压痕，像缠着胶布。陈默站在路灯下回头，门已经关严。
