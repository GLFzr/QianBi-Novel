# 第15章 仓库里的表

收据那行字压了他一整夜。天亮前陈默从床上坐起来，没开灯，把收据叠进外套内袋。枕边种子书的位置他摸了两次，最后空着手出门，只带了0316纸片和两块旧表。

头班公交六点整到东门街站。仓库区还没醒，装卸区的白灯亮成一排，灯泡上凝着隔夜的霜。他沿着铁皮围墙走到值班室门口，门虚掩着，暖气混着柴油味从门缝挤出来。门轴坏过，推门时发出一声拖长的锈响。

屋里坐着一个五十来岁的男人，正往保温杯里倒热水。桌上两副旧手套，皮面磨得发亮，指节处有长时间攥方向盘磨出的硬壳，边上压着一本翻烂的登记簿。墙上挂着一块白板，记着几行车次和号码，最底下有一行被擦掉大半的字，只剩一个"表"字还认得出来。

“程师傅的账我认得你的姓。”老赵头也没抬，“你姓陈。”

陈默在桌对面坐下，把收据推过去。老赵扫了一眼，没碰：“货运站早停了，这张票根比我的班表都老。”他把保温杯放到桌角，杯底在桌面上磕出很轻一声，“你是替程师傅跑腿，还是替你自己跑。”

“程师傅让我来理的卷宗里有王开志的案子。”陈默把0316纸片放在收据旁边，“这个编号，你见过没有。”

老赵的目光在纸片上停了片刻。他合上保温杯盖，拧到卡紧的位置，才开口：“昨晚有人来问过同一块表。”

“谁。”

“不知道。穿深色外套，没进门，在窗口站了一分钟就走了。”老赵看向窗外，玻璃上凝着水汽，他伸手抹了一下，窗外什么也没有，“他问的是王开志的遗物，说想看看那块表。我说证物都交上去了，他就走了。”

“你告诉他了？”

“没有。”老赵转过头来，陈默看见他眼角的皱纹在灯光下叠成几道深沟，“你是第几个找王开志的。”

陈默没有回答这个问题，把0316纸片推近了一寸：“王开志出事前，有什么异常。”

老赵沉默了很久。屋里暖气片发出一声闷响，像什么东西在管子里翻了个身。他弯腰从储物柜底层取出一个透明证物袋，袋口封着白色标签，标签边角卷起，日期栏用圆珠笔填过，数字已经被水渍洇得认不全。

里面是一块烧痕表。表盘被火燎得变形，玻璃面裂成蛛网纹，指针卡在一处。表壳边缘有一圈焦黑色，像被什么东西舔过一遍。

“他出事那晚，凌晨两点五十在仓库门口接的客。”老赵把证物袋放在桌上，手指隔着塑料膜按了一下表盘的位置，“穿浅色薄外套，右手表盘老式，上车前在路灯底下抬腕看过一次时间。王开志回来说，那人下了车，没走，站在路边又看了一次表，像在等什么。”

“接单后不能受客服线跟踪，”老赵说，“他原话是这么讲的。王开志当时还笑了一下，说那客人神神叨叨的，大半夜站在路灯底下看表，像在等一个准点。”

“哪一个准点？”

“他没说。王开志没问，他也不爱打听客人的私事。跑夜班的人都知道，不该问的别问，问多了这一趟就不干净了。”老赵顿了一下，“后来王开志出事，我去派出所问过，人家说车上没找到第二个人坐过的痕迹。副驾脚垫底下就这一块表，连个指纹都没有。”

陈默盯着证物袋里的表。指针停的位置他不用凑近就认得出来。

“这块表不是事故物件。”老赵说，“是有人放在那的。”

陈默从自己内袋里取出那两块旧表，隔着证物袋的塑料膜并排比对。同一块表盘，同一处停产的编号刻位，连表耳内侧的磨损纹路都从一个模子里出来。唯一不同的是表带，他手上这两块表带经手方向相反，烧痕表没有表带，只剩一对断耳。他把旧表翻过来，表壳背面的划痕在日光灯下泛着光。两块表背面的压痕隔着塑料膜和烧痕表背面的刻位对在一起，形制一致，深浅接近，像同一个工具在同一个工序里留下的。

他指节压住烧痕表背面。塑料膜底下有一道斜向压痕，划痕的弧度和旧表背面刻位的走向几乎吻合。他收回手，注意到自己右手指节上有一点蓝黑墨渍，不知道什么时候蹭上的。

“这两块表，你从哪来的。”老赵的声音从桌对面压过来。

陈默把旧表收回内袋，没接话。

老赵盯了他片刻，把证物袋从桌上收回，在手里握了一会儿，又放回原处：“王开志死前留过一句话。他说，天亮前，如果有人来问表，什么也不要告诉他。”

“他什么时候说的这句话？”

“出事前一天晚上。他收车回来，在值班室坐了一会儿，突然说了这么一句。我当时问他什么意思，他没解释，只说记着就行。”老赵拧开保温杯喝了一口水，“第二天他就没了。”

陈默没接话。他把0316纸片从桌上拿起，折好放回原处。老赵看着他做这些动作，没有拦，但目光一直落在他放纸片的那只手。

“你和他不一样。”老赵说，“他来这里，先问的是表在哪。你从头到尾没问过这块表一次。”

陈默走到门口时回头。仓库出口方向的卸货区尽头，一辆白色轿车停在照明范围外的阴影里，车头朝向值班室，没有熄火。排气管口有一层极薄的白雾，在冷空气里时隐时现。

他低头翻开种子书页脚。0319与0320并排，下方多出一行竖写铅笔字：今晚东门街23:00。

笔尖悬在页面上方，没有落下去。

白车仍停在原地，右前翼子板内侧有一道旧刮痕，泛白无锈，像很久以前留下的。驾驶座上的轮廓被反光吞掉，看不清有没有人。
