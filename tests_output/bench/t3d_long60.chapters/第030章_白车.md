# 第30章 白车

锁屏时间跳到23:01。马路对面路口，一辆引擎没熄的白色网约车打着左转向灯靠过来，车牌尾号与他手机订单推送上的“行程已规划”一致。

陈默把手机锁屏塞回口袋，没有立刻过去。他站在原地等那辆车停稳，驾驶座车门没开，车窗降了一条缝，露出一只戴白手套的手搭在方向盘上。他绕到副驾一侧，拉开车门坐下，系安全带时顺手摸了一把坐垫缝隙。指尖干净，没有毛发，也没有碎屑。这辆车被人彻底清洁过，清洁得像没人坐过。

司机三十岁上下，穿深灰夹克，双手戴白手套握方向盘，目光平视前方。车起步，他没问陈默去哪，也没说欢迎语，只说了一句：“您地址我这边自动带的。”声音干涩，像很久没跟人说过话。

陈默应了一声，没接话。他看了一眼窗外，车影从便利店的玻璃橱窗前划过，拐上一条他不常走的新路。他认出路牌，滨河路。这条路绕开了东门街路口，比常规路线多出七八分钟车程。他没问为什么绕路，只是记下这个细节。车窗外的路灯一根接一根往后退，光在柏油路面上拉出长短不一的影子，他注意到司机在每一个路口都提前打了转向灯，动作标准得像培训录像里放出来的。

车开过水泥厂旧址南门段时，司机看了一眼右后视镜，说了一句：“这条路我再熟不过了。”陈默顺着话头问：“师傅您平时跑夜班多吗？”

“多。”司机说，“三年前跑得最勤。”

陈默没让表情动。他低头假装看手机，实际在记这个时间点。窗外路牌写着“水泥厂路”，路灯光从路灯杆上依次滑过，车影在柏油路面上时短时长。他注意到司机说这句话时，右手食指在方向盘上轻轻敲了一下，像在确认某个节奏。他没有接话，等司机自己往下说。

司机没有往下说。车拐过水泥厂旧址的围墙，路灯暗了一截，墙根处堆着几根锈蚀的钢管，影子横在路面上。陈默的目光从窗外收回来，落在副驾靠背的置物袋上。袋口微微敞着，露出一角深色纸边。他伸手去够，指尖探进去，碰到一本薄册子。封皮无字，厚度像一本旧登记簿。他抽出来，翻开第一页，内页第一行印着一行打印体：“案：0317”。字迹不是父亲的，也不像手写，更像机器印刷，笔画均匀，没有墨迹深浅变化。

他手指一压，册子里掉出一张收费站票据。日期，三年前3月17日22:47。通行路段，水泥厂以南。他捏住票据一角，让它在指腹下转了一个角度，确认纸质和印刷格式后，把它轻轻塞回册子。册子放回置物袋，用手掌压平袋口折痕。他做完这些动作只用了几秒，呼吸没有变化。他注意到册子的封皮边缘有一道极浅的压痕，像是被人反复翻开又合上留下的，位置在封皮右下角。他没有再碰它。

司机在红灯前踩下刹车，看了一眼右后视镜，说：“这条路我再熟不过了。”

陈默听见自己接了一句：“熟到什么时候？”

司机愣了一下，像是没想到他会反问。红灯转绿，车重新起步，他开口时声音比刚才低了些：“三年前3月17号，我拉过一单。半夜十点四十多，东门街路口上车，终点是这儿往北那片仓库。”他顿了一下，“那时候这条路人少，晚上更少。我记得清楚。”

陈默没接话。他低头，假装在看手机屏幕，实际在消化这句话。三年前3月17日22:47，东门街路口上车，终点水泥厂以北仓库区。同一个时间，同一个路口，被改写的记录里写着“白色轿车减速让行”。他握住手机的手指收紧了一下，又松开。他没有追问那个乘客长什么样，因为问了也不会有答案。司机记得的是路，他记的是时间。

车在老屋巷口停稳。司机没熄火，说：“您到了。”

陈默推开车门时回头看了司机一眼。对方没有看他，只是盯着前风挡玻璃上自己呼出的白气。他关上车门，走出三步，又停下来。他折返回去，敲了一下副驾车窗。司机降下窗，露出半张脸。

“师傅，您刚才说的那单，”陈默问，“乘客下车后，往北走了多远？”

司机眨了一下眼，像在想：“他下车就往北走了，没回头。我掉头时候看了一眼，他拐进仓库群那片路灯下，就没影了。”他说完，等着陈默的下文。陈默说谢谢，转身走进巷子。

走出几步，他听见身后的车没有倒车，也没有熄火。他没有回头看，脚步没停。

老屋门口，他从兜里摸出钥匙时顿住。窗灯亮着。林兰搬走时他亲手锁的门，走前关的灯。他隔着门缝看到一张纸角，压在门槛与门之间，只露出一小截。他蹲下，用指尖夹住纸角往外抽，纸身发硬，是航空信纸的触感。他抽出一半，看到第一行字是父亲笔迹。

“3月17日22:47，我在这里写过一次。他们让我不要写。我没听。”

纸的下半截还压在门缝下。他没有继续抽。他抬头看了一眼窗灯，灯还亮着，窗后没有人影。信纸第一行父亲笔迹旁，有一道没擦干净的灰痕，像是有人用指腹按过。
