# 第34章 修表铺没有表

陈默站在修表铺门口，手电筒扫过橱窗玻璃，看见里面一排挂钟，指针全部停在22点47分。橱窗下方贴着一张褪色的纸，写着"修表"二字，第二个字被油渍洇掉一半。他先关掉手电筒，让眼睛适应巷子里的暗光，再重新打量这扇门。门板是深棕色的，漆皮剥落大半，门把手被磨得发亮，像无数只手在同一个位置握过。门缝里透出一股陈旧机油和金属混合的气味，不刺鼻，但很重，像这间屋子已经很多年没有开过窗。

他没有立刻推门。先沿墙根摸到侧窗，借手电筒的光从窗缝里扫进去，确认铺内无人。柜台后面的椅子上搭着一件灰外套，桌面却干净，没有工具摊开，不像有人正在干活。他回到正门，推门。门没锁，铰链发出一声短促的吱呀，像是很久没有被推开过。

他站在门内，没有往里走。柜台上方挂着一排挂钟，七只，全部停在同一时刻，22点47分。秒针也停在47秒的位置，像一整排时间被同时冻住。他往前走了一步，鞋底在磨砂地砖上蹭出一声轻响，铺内没有其他回应。他环顾四周，墙面挂着几副旧眼镜，镜腿都断了，用细铁丝缠着。墙角堆着一摞木盒，盒盖半开，露出里面的游丝和齿轮，零件上蒙着一层均匀的灰，像是很久没有被人碰过。他想起林兰说过，修表的老头不让人进柜台，怕有人偷零件。他说不清这句话是什么时候说的，但它确实在脑子里，而且让他做出一个判断：铺内没有监控，否则"不让人进柜台"这个习惯没有意义。

他绕过柜台，发现柜台后靠墙的工作台底下，有一只锁着的抽屉。锁是老式弹子锁，锁孔边缘磨得发亮。他掏出钥匙串，试了货运站收据背面父亲画过的那个号码，数字不是钥匙，但他把那串数字按在锁壳上时，锁芯自己弹开，像是被磨损到某个特定角度就能解锁。抽屉滑开一道缝，他拉开来。

五只旧表并排躺着。表盘大小，表冠磨损位置，玻璃裂纹走向，全部一致。他掏出自己那只背面划着0317的旧手表，与第一只表并排放在一起。表盘的碎纹在灯光下交错咬合，像是从同一块原料上裁下来的。他翻过第二只表，表带内侧有一道勒痕，宽度与他之前在窗台指印上量的无名指间距合得上。他拿起第三只表，表壳背面有一道极浅的划痕，弧线走向和种子书页脚那个"偿"字起笔一致。他没有继续翻下去，把第三只表放回原位。

他没有把所有表都捞出来。只拍了一张照片，把第一只表放回原处，抽屉角度旋回刚打开时的位置。抽屉底部垫着一张对折的纸，他抽出来，展开。纸面是种子书同款的纸质，泛黄发硬。上面的字迹是父亲的，蓝黑墨水，收笔习惯和种子书页角的批注一模一样："上次写的就是修表铺。这笔账，还差一次。"字迹旁边页角处，有三个极淡的铅笔字，几乎看不清："案：0317"。

他把纸放回抽屉底部，合上抽屉，按原样压好。他没有撕走那行批注，因为批注留在原地，等修表人回来看到它被翻动过，对方会来找他。他站起来，用手电筒扫了一圈铺内，确认自己没留下什么明显的痕迹，才往柜台边走。

巷口传来脚步声。由远及近，走得很慢，鞋底碾过水泥地面的声音很均匀。他快速扫了一眼铺内，确认没有后门，退到柜台边，翻上窗台。翻窗外跳时，余光瞥见工作台上那只挂钟的秒针动了一下，从47分的位置滑向48分。他没有看第二眼，人已经落入巷子拐角的暗影里。

他走到第二盏路灯下停住，掏出种子书翻到页脚。页痕"以北"被新墨划掉，改回"以南"。下方新出现一行极小的字，像是指腹按上去的："下次来，别翻窗。铺里有人。"他把种子书合上，攥在手里，回头看向巷子深处。修表铺的橱窗里，那些挂钟的指针仍然停在22点47分。他走回铺子正面，橱窗玻璃内侧多了一张纸，浅黄色，边缘带撕纸的毛边，是新的。纸上有六个字，圆珠笔，横平竖直似左手写："表在抽屉里等你。"
