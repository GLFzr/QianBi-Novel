# 第3章 水渍在延伸

雨水在半夜停了。陈默被枕头下顶醒，眯着眼摸到手机，屏幕光线里先冒出的是床头柜边缘的一张纸。外卖单底联，单号末尾三个数字朝上。0317。

他不记得自己什么时候把它从包里翻出来放平的。

手机里有一条未读语音留言，来自林兰，老屋隔壁的邻居。声音压得低：“陈默，一楼走廊墙根渗水，可能从你家厨房管子出来的。你过来看看。”留了两遍。

他在出租屋的洗手间用冷水扑了把脸，骑车往滨河道去。雨后的街面浮着一层水汽，共享单车拐进巷子时，后轮碾起的水珠溅上裤脚。

老屋的门一推开，先闻到一股潮气。厨房台面上汪着一层水，正沿着台边往下滴，顺着柜门缝流到地面。那摞碗还立在灶台边，跟他昨天离开时一个位置，一个没动。

他伸手去拧水龙头，是关紧的。锈水从台面跟墙砖的接缝里渗出来，源头不在这里。他弯腰拧紧墙角的进水总阀，水声渐渐弱了，最后只剩管道里咕咚一声闷响。

他把那摞碗洗了。碗底油腻，结着隔夜的硬痂。热水流过指缝时他忽地停住，想昨天中午自己吃的什么。想不起来。那种空白像手伸进悬空的楼梯，踏下去才发觉没有台阶。

昨天的早饭记得，他在老屋门口买了豆浆。午饭之后那一整段全是空的。他只能靠找见的物件推断：回过出租屋，分类过纸箱，拨过父亲的电话。这些事他记得结果，不记得经过。

他蹲下去翻背包找物业缴费单，指尖触到包底折成硬角的东西。摸出来是张对折便签，他的笔迹，蓝黑墨水，写得很急：“3月17日，必须联系小周。”

便签上没有落款，也没写号码。他不记得自己写过它，更不记得小周是谁。翻通讯录，没有存过叫小周的人。他把便签对折塞进胸口口袋。

下楼。楼道口的水泥台阶反着薄光，积在地砖缝里的水还没干。一辆外卖电动车横在台阶下，车筐里搁着一只白色泡沫箱，压得车头微微下沉。穿黄色工服的骑手正弯腰往箱角塞餐盒。

昨天在巷口问他路的人，坐姿一样，头盔一样，后座的保温箱也是这只。骑手抬头的刹那，陈默开口：“你昨天来过滨河道，单号尾号是不是0317？”

“周航。”骑手拍了拍车座，“昨天那单是我送的，尾号0317，怎么，漏了东西？”

“没。”陈默的目光扫过他脚下的台阶，湿痕正顺着松动的地砖缝洇过去。

周航说话时已经把泡沫箱从车筐里拎了出来，腾出右手在上衣下摆蹭了蹭，准备上楼。台阶最湿的地方恰恰在拐角那块松动地砖上，鞋底踩上去没有声音，滑得厉害。

陈默退进门洞的阴影里。他从夹克内袋摸出那本旧笔记本，翻开空白页的瞬间，指尖停了半秒。

他只知道一件事。父亲在封面内页写过：记人未长成的事。

他落笔时手很稳：“周航，3月11日9时52分，滨河道12号一楼台阶，右手握紧扶手，停住半步。”

墨迹干了，纸面没有半点动静，不热不凉。他合上本子塞回内袋，心跳敲在肋骨上。他写下的东西会不会有结果，他连规则是什么也说不清。

楼道口那声闷响来得比他预想的更快。泡沫箱砸在台阶上，盖子弹飞，裹着红油的汤水泼了一地。周航半跪在地，右手死死攥着扶手，膝盖撞在台阶边棱上，脸色白了一瞬。

他没摔下去。箱角那道裂口正对着地砖缝，汤水顺着砖缝往前走，在旧水渍的痕迹尽头又漫出半块砖的距离，堪堪停住。

周航骂了一声，撑着扶手站起来，朝陈默咧了咧嘴：“这台阶真滑。回头得跟物业说说，砖都松了。”

陈默站在门洞阴影里没有接话。周航今天穿的鞋底纹路很深，踩湿砖不至于滑倒，坏的是那块砖本身。他弯腰帮周航捡起箱盖，指尖碰到汤水，温的。

午后回出租屋，灶台上叠着三只空泡面碗。出门前还没有这些碗。他拿起最上面那只，碗底的红油没凝透。他把三只碗摞进水池。手机屏幕亮着，通话记录顶端是凌晨拨给父亲的那通电话，时长十一秒。

傍晚又落起雨。他回老屋拧进水总阀的外圈垫圈，才拧了两圈，雨声已经密起来。他蹲在廊檐下翻开种子书，想确认那道压痕还在不在。书页角落泛起一片极淡的灰，像被水汽洇过又干透的旧痕，压着半行字，缩在页角边缘：

“14:07 东门街路口。”

他不认识东门街。可这几个字昨夜刚在父亲手机的备忘里出现过：3月17日22:47，去东门街路口。他指腹摩挲过纸面，粗糙的纹路里带着一点潮意。

隔壁的门开了。林兰撑着一把滴水的黑伞过来，食指勾着一串钥匙，递到他面前：“昨天你落在我桌上的。”

陈默接过钥匙没动。林兰身后跟着个扎马尾的女孩，背着粉色的书包，正偏头看屋檐滴水。林兰顺着他的目光看了女孩一眼：“果果明天七点要去东门街那边上科创营，我本来还愁下雨怎么送。”

陈默低头看纸页。那半行压痕在伞下的阴影里发灰。他问：“你说哪里？”

“东门街路口呀。”林兰收了伞，甩了甩水，“滨河道那头，过个红绿灯就到了。”马尾辫的女孩已经踮着脚去够门框上的雨水，指尖一点，又缩回去。

陈默把纸页合上，拇指无意识地压住页角“14:07”那几个字的位置。雨声密下来，楼道里那盏声控灯熄了。他拧亮手机手电，重新照向纸面。页边有一粒细水珠正顺着纸纤维往前洇，在那行字的末梢拖出一道极淡的灰痕，像第二行字的起笔，还没有干透，正沿着纸的空白一寸一寸延过去。
