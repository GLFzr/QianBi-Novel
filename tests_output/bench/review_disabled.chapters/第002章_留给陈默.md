# 第2章 留给陈默

共享单车在路口撞上一串红灯，陈默单脚撑地，手机在口袋里震了两下。房东的语音条，说房租自动扣款失败，已逾期两天，限期明天处理。

他逐条听完，退出之前扫到通话记录。父亲的号码排在最顶，下午他从老屋出来时误拨过一回，标记成未接。那四个数字就缩在号码栏底下，他看了一瞬，锁了屏。

共享单车拐进巷子时，后轮碾过一道浅水洼，溅起的水星子落在裤脚上。他低头看了一眼，灰白色的泥点，跟下午在老屋门口溅的那道位置几乎重合。他甩了甩脚踝，没停。

楼道感应灯坏了一盏，他在半黑里摸到三楼，跺脚跺亮剩下那盏，开门把两只纸箱搁在玄关。蹲下，将父亲的东西一样样摊开。旧衣服归成一摞，账本票据归成一摞，铁皮文具盒和生锈图钉另放。种子书被单独拿出来，放进书桌最底层抽屉，推到最里侧，没上锁。

他手在抽屉沿上停了一下，又拉开，把那本子再往里推了一寸，才合上。指尖在抽屉木纹上蹭了蹭，留下一道浅印。他盯着那印子看了两秒，拿拇指抹掉。

房东第二条语音条追过来。他拧开水龙头烧水，顺手翻开手机找营业厅号码，打算明天停了父亲那张卡的套餐。手指划到“爸（老宅）”这栏，停了停。屏幕上的备注名是他自己三年前填的，那时候父亲还隔周给他打一次电话，问他吃饭没有。最近一次通话记录停在上个月十四号，来电，时长一分零二秒。他没接。

陈默把拇指移到拨号键上，按了下去。

听筒里机械女声报了一遍“您拨打的电话已关机”。陈默正要挂断，提示音接上来：“您有一条通话录音尚未收听。”

语音留言。父亲那个老套餐开卡时自带的功能，十几年没关过。

他按了收听。

录音约四十秒。前十几秒全是杂物碰撞的动静，像一个人腾不出手，把许多东西从包里掏出来又放回去。没有话声，只有那些声响。铁皮磕在木面上，拉链被拉开，纸页翻动，一角压着一角。隔着电流，那些声音像从很深的地方传上来。隔了一阵，父亲的声音才进来，压得很碎：“这个铁盒，别当垃圾。里头那个，放抽斗里。”

停了片刻，声音又矮下去半截：“本子……留给陈默。”

陈默把手机换到另一只耳朵，攥机的手在膝盖上慢慢捏成拳。水壶在灶上烧开了，鸣笛声尖而长，他伸手把火拧灭，屋子静下来，只剩录音里那道呼吸声。父亲的声音到这儿突然清楚了，像有人把嘴凑近了收声的地方，一个字一个字放慢吐出来：“告诉他。账是有人来收的，收的人……”

门铃在这时候响了。

录音断在句尾，后头只剩两三秒底噪。陈默听完一遍，倒回去再听，把音量推到最大，终于从那段底噪里辨出一道电子女声，隔了许多层，像某部手机在报外送订单：“您有新的外卖订单，编号0317。”

他听了第三遍，确认没有听错。水壶的余温把灶台烤得发烫，他手肘蹭过去，皮肤上一层潮热，没有挪开。

陈默放下手机，从外套内侧袋摸出白天那张外卖小票。底联折过两折，边角渗着褐色汤渍，单号区压了一串数字，看清前他已经认得那形状。他又从背包侧袋摸出那块表，表壳背面的刻痕带锈，棱角被磨圆，唯独四位数清清楚楚。

0317。纸片、取件码、表壳、录音底噪。同一天，四种出处，同一串数字。下午他还能告诉自己，纸片和取件码撞号是巧合，一个老旧的编号，一个外送流水号，基数大了总会碰上一次。可表壳上的刻痕是多年前就锈进去的，录音里那道女声更不可能预先知道他会听见。巧合的壳裂开一条缝，缝里透出来的东西他没有名字。

他起身去拿种子书，在书桌灯下翻开，页角边立着四个字：案：0317。他用指腹蹭过那行墨，干得发脆，像是许多年前落的笔。陈默拿起桌上的签字笔，笔尖抵住“案”字右侧的空白纸面。写下一个名字，一段走向，一件会在明天发生的小事，这笔就落成另一端。但写谁，写什么，写下之后会从自己身上抽走什么，他全无概念。

笔尖在纸面硌起一道浅痕，压得久了，那痕显出一种深度。没墨水。

他合上书，关了灯，把本子压在枕头底下。躺下去，楼下便利店门铃每隔一阵响一声。他睁着眼躺到后半夜，被枕头底下的硬角硌醒。手机不知什么时候滑进枕头和本子之间，屏幕亮着，是通话记录页面，父亲的号码那栏显示着凌晨两点的已拨时间。他从床头柜摸过老花镜盒，又放下，用不着那个。他重新拨了那个号码。

这回占线的提示声不同。听筒里传来一段他自己录的彩铃，还没有停机，一字一字咬得清楚：“您拨打的用户暂时不在服务区。留言请按……”

录音结束后是一段忙音。陈默把手机拿远了些，屏幕上映出通讯录备注：“爸（老宅）”，底下压缩着一行小字，是三年前哪次他顺手填的归属：“0317，他生日。”

0317，指的是3月17日。备忘那页自动关联出一条老设备同步来的旧记录，日期栏空着，正文只有一句话：

“3月17日22:47，去东门街路口。”

他指腹按在那行字上。表盘永远停的正是二十二点四十七分。父亲留给他的本子，父亲自己录的彩铃，父亲手机里一条指向未来某天的备忘。这些东西没有一件是巧合，它们被人预先排过序，一件叠一件，等着他今晚拨出那通电话。

楼下响起电瓶车启动的声音，闷闷的，带一点没松手刹的摩擦。陈默走到窗边，路灯下停着一辆外卖电动车，车上的人戴着头盔，脸隐在暗处，车头朝东，没有熄火。

手机又震了一下，屏幕上方浮出新提示：“您有新的通话录音已保存。”他没点，视线压在楼下那人身上。

时间跳到2点18分。电瓶车的引擎声低低响着，像随时要走，却迟迟没有驶离。
