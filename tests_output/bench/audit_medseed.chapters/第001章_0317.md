# 第1章 0317

钥匙扣上系着一截蓝色尼龙绳，和父亲账本封皮一个色。这截绳子系了七年，磨出毛边。

陈默站在四单元楼下，手机在兜里震。房东的消息停在上周五，一行数字，9千8。他按灭屏幕，抬头看四楼那扇窗。窗帘没拉。周六下午两点多，城西这条待拆的老筒子楼巷子，外卖和中介的车都不愿意拐进来。巷口堆着半车废砖，砖缝里钻出几蓬干草。

林兰从楼道口出来，手心里攥着钥匙。“你爸那几天说，有东西要留给你。”她抬起下巴朝四楼点了点，“我按着他说的，屋里的纸片一张没碰。”

陈默伸手接钥匙。林兰没有松手。

“有句话我没带到。”她的手指在钥匙上停了一秒，又松开。钥匙落进他掌心，还带着她手心的温度。“你上去吧。”

林果果从她身后探出半个头，拽她的衣角。林兰弯腰牵起女儿，往巷口走。走了几步，回头看他一眼，又转回去。她的步子快起来，林果果小跑着跟。

陈默没追。父亲留下的，大概只是没做完的账。

门锁涩，钥匙转了两圈才开。灰和凉茶混成的气味往外压，像有人刚走。桌上半杯凉茶，茶面浮着一层干缩的膜。旧报纸摊开在桌角，日期停在6月9日。

他先给中介挂电话。“动迁有消息没？”

“观望的人多，看房的没有。我先挂上，等通知。”

他挂了，开始分。

工具归一侧。衣物进废纸箱。空白收据册理成一叠。每样东西经手一下，留或不留，他判断得很快。父亲在账目上教他的事，到底成了他唯一熟练的东西。电瓶车的钥匙压在鞋盒里，他单独放到门口，明天推去二手市场。旧家电贴了张纸，写“回收”。他做这些事的时候没怎么停，弯腰，起身，归位，像在清点一笔早就该平的账。

床头柜底下的抽屉最深处，卡着一本薄旧笔记本。他抽出来，封面是深灰硬壳，没写字。翻到内页，一行蓝黑墨水，父亲的字：

“种子书。记人未长成的事。”

斜角两个小字，铅笔写的：“不可贪。”

纸角一串数字，钢笔，下笔重：“案：0317”。

陈默的手指停在页角。

这不是账。账本不会留空页，不会在封面上练这种话。这本子哪个分类都塞不进去。他翻了几页，空白。页边有一道毛糙的撕痕，有人撕走了什么东西。撕口很旧，纸茬已经软了。

他合上本子，放进背包夹层。

他告诉自己只是懒得上楼再跑一趟扔废品。走到门口，他折回来。窗台的花盆底下，他指尖探出一张纸条。水渍咬掉大半，只剩两个字：“陈默”。纸的右下角有半枚折痕，像被人反复打开又合上过。

他把纸条放进父亲留下的旧塑封袋，拉上封口，塞进背包。电闸在门后，他顺手拉下。

锁门时，背后有人喊：“3门317！”

陈默转过身。一个黄色头盔的外卖员拎着餐盒冲进楼道口，前轮碾过门前的湿泥，车尾一偏。地面一摊饮料渍，不知从哪个箱底漏出来，日光下反着光。

外卖员捏着手机，抬头看门牌。“3门317，是这栋不？”

陈默说：“这栋没有317。”

对方低头看单。下垂的单票边角露出一段印花，取件码尾号：0317。日光正好切在那一行，数字清清楚楚。

陈默没跟出去。外卖员骂了一声，跨上车拧油门，后轮带起泥水，冲出巷口。白亮的水渍横在路中间。

陈默低头。指缝里夹着一张旧纸角，卷了边，是从种子书页边带下来的，不知什么时候夹在了指间。他把它夹回本子。背包外兜鼓起一块。

他摸进去。

一块旧手表。表盘上一圈细裂纹，指针停在22点47分。表带发硬，粘着灰。这块表不在遗物清点里，他今天只碰过窗台和床头柜。

他把表翻过来。

表壳背面划着一串数字，刻痕很细，边角磨圆了：0317。

风从巷口灌进来，卷起地上那张外卖单。纸单滚过他的鞋面，取件码冲上，尾号0317，停在水渍边。陈默站着，表和本子都攥在手里。
