# 第3章 水渍在延伸

手机闹钟响之前，雨先停了。

陈默睁眼，天花板上的裂缝还没看清，目光先落在床头柜上。一张摊平的外卖单底联压在他昨晚搁手机的充电器底下，纸边卷着，沾了点褐色的干渍。单号栏印着0317。印刷字。他看了五秒，不记得自己什么时候把它从包里翻出来放平的。

手机又震了一下，是林兰的语音留言。她的声音压得很低，像是怕吵醒谁：“陈默，一楼走廊渗水了，湿到我家储藏室门口。可能是你家厨房水管没关紧，你过来看看？”

他坐起来，后颈一层薄汗，枕头芯里那本硬皮书硌着肩胛。他抽出来放到桌上，套上外套就出了门。

老屋厨房的水声比他想象的清楚。台面上的水渍从墙角一路延伸到台边，正一滴一滴往下坠，落在昨夜的旧碗叠上。他拧开水槽下面的总阀，关死，手摸着管子是干的。水龙头是关紧的。水是从台面缝隙里渗出来的，沿着瓷砖釉面的裂口，像一条深色的细线，正在朝插座方向走。

他顺手把那摞碗洗了。水声停下的时候，屋里突然安静下来，他发现自己站了一会儿，想不起昨天午饭吃过什么。那里空了一块，一页纸被人齐边撕掉，连毛茬都没留。

他蹲身去翻茶几底下的包，找物业缴费单。手指在笔袋底部碰到一张折成四方块的便签，纸面被他自己的汗泅软了一点。展开，是他的笔迹：“3月17日必须联系小周。”他盯着那行字，指头有点僵。他不记得写过这张便签，不记得小周是谁，更不知道3月17日为什么要联系这个人。字迹是他自己的，收笔的力气、横折的角度，他认得。可他对写字那一刻没有任何记忆。

他把便签对折，贴身收进胸口口袋，拉上外套拉链，下楼。

楼道口的水泥台阶让雨水泡了一夜，地砖缝里积着水，走在上面能听见鞋底打滑的声响。他刚要拐过一楼走廊的转角，一辆电动车急停在单元门外。穿黄色工服的外卖员从车座上翻身下来，车筐里蹲着一只白色泡沫箱，他正弯腰去拎。

陈默叫住他：“师傅，你送几楼？”

外卖员抬头，是个年轻人，雨衣帽子滑下来，露出半张被雨水冲得泛红的脸：“三单元，317。”他顿了一下，自己笑了，“你住这儿？我昨天跑错一单，就这栋。四栋，对，四栋。”

陈默认出来了。昨天那个误闯进老屋楼道、给他塞过一张外卖底联的年轻人，单号尾号0317。

“你叫什么？”

“周航。”外卖员答得干脆，弯腰拎起泡沫箱，往台阶边走，“昨天那单尾号0317的，是我送的。”

台阶最底下那级地砖明显松了，半边翘起，雨水积在凹槽里，黑亮黑亮的。周航穿着运动鞋，鞋底磨得看不出纹路，踩上去必滑。

陈默退到楼道阴影里，背过身去，从外套内袋里掏出种子书，翻开封面。内页上那页还留着撕纸的残余，他翻过不可贪的铅笔字，翻到一张干净的白页。蓝黑钢笔拔开笔帽，笔尖抵上去，压出一个浅浅的凹。他听见自己的心跳，像在胸腔里撞一台老水泵。

他写下：周航，3月11日9时52分，滨河道12号一楼台阶，右手握紧扶手，停住半步。

落墨。纸面安静。笔尖留下的墨痕慢慢干透，颜色从亮蓝沉成暗青，再没有其他变化。

他把书合上，塞回内袋，心跳没降，反而更响了。

十五秒后，楼道口传来一声闷响。他冲出去。

周航半跪在台阶上，右手死死攥着那根锈铁扶手，泡沫箱从车筐里甩出去，倒扣在台阶边沿。箱盖弹开，汤水溢出来，顺着地砖缝流成一道细线，在旧水渍的延长线上拐了个弯，停住了。他没摔。

周航骂了一句，爬起来拍了拍膝盖，把泡沫箱扶正，回头冲他咧嘴：“这台阶真滑。”他弯腰把散出来的汤盒塞回箱子里，扶稳车把，一脚蹬地，电动车碾过积水，拐出院门。

陈默站在台阶下，手伸进内袋，碰了碰种子书的封面。布面是凉的，像一本旧账本搁久了的那种凉。但他知道，它刚动过一次。

午后雨又下起来。他回到出租屋，灶台上摞着三只空泡面碗，筷子还插在第二只碗沿上，汤底凝了一层白油。他不记得自己吃过其中任何一碗。他摸出手机，翻昨天晚上的通话记录。凌晨2:17拨出，通话时长11秒，号码尾号0317。那个号码是他爸的。他盯着那行记录，胃里像被什么东西轻轻拽了一下。

傍晚雨停了。他绕回老屋，在门口翻种子书的内页，借着楼道声控灯的白光，看见页角压出一道极淡的凹痕。像铅笔描过又被擦掉，只留下半行字，在光的斜照下隐隐发灰：“14:07 东门街路口。”

纸是凉的。字像被水泡过又干透的旧痕，边缘是毛的，透进纸纹里。

他不认识东门街。

隔壁的门开了。林兰撑着一把滴水的伞出来，弯腰在门口的地垫上蹭了蹭鞋底，手里捏着一串钥匙。“陈默，你昨天钥匙落门口了。”她身后跟着一个扎马尾的小女孩，抱着只蓝色书包，仰头看了他一眼。

林兰把伞收拢，随口说了句：“果果明天七点要去东门街那边上科创营，我本来还愁下雨怎么送。”

陈默低头。页角那半行压痕在袖口的阴影里，发灰的浅。他听见自己的声音：“你说哪里？”

“东门街路口呀。”林兰把伞挂到门边，弯腰替果果整了整书包带，“滨河道那头，有个红绿灯的，他爸顺路送。”

陈默的拇指无意识地压住纸面上“14:07”那半行字。他没把页痕给她看，也没提纸上那摊字。他把种子书合上，后背抵住门框。

声控灯灭了，楼道里暗下来。走廊尽头，老屋没关严的门缝里，传出一声水分坠落，厨房台面上那道水渍又多走了一格，滴在旧碗叠上，一下，又一下。
