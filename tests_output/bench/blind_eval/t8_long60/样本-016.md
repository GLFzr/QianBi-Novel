# 第4章 空档期

周一早上，陈默把种子书塞进背包夹层，去了物流网点。兼职入职手续上周就该办完，他拖了三天。填表的时候，前台老调度正在墙上贴一张新的片区配送图。陈默抬头扫了一眼，东门街出口的位置被红笔反复划了三个叉，笔迹叠在一起，像一道结痂的伤口。

“那地方怎么了？”

老调度头也没回：“最容易出事的弯口。连续两年有配送员在那儿出事，上个月才撞过一个，膝盖骨裂。”

陈默没接话。他低头继续填表，写完最后一个格子，笔尖在纸上停了两秒。他脑子里那一页，种子书上那半行字正压着“14:07 东门街路口”，和墙上那三个红叉叠在一起。

走出网点，房东催租短信又弹出来。他没回，把手机锁屏，站在台阶上想了一会儿。然后他骑了一辆共享单车，往东门街方向拐。他想好了说辞：只去吃碗面，然后回。

东门街路口比他想的宽。街角有个修鞋摊，摊主老周正拿锤子敲一只鞋底。陈默把车停在摊边，蹲下来假装看鞋。他先看地面，路面有一条被白漆重新画过的裂缝，漆是新补的，白得刺眼。旁边的公交站牌也是新的，车流从东往西拐弯时，有一截视线盲区正好被站牌挡住。老周顺着他的目光看了一眼：“那条口子咬人，上个月才啃了一个骑车的。”

“怎么个咬法？”

“车从那边过来，看不见站牌底下的人。站牌后面的人，也看不见车。”老周敲完鞋底，翻过来看了眼，“你住这边？”

陈默没接茬。他在街角站了十分钟，数了信号灯的秒数，记下了拐弯车辆的提速点，把那截盲区的位置在心里画了个十字。然后他走回路边，买了一份报纸，坐在修鞋摊旁边的塑料凳上。

快十二点的时候手机响了。林兰打来的。

“喂，陈默，你今天在东门街那边吗？”她声音有点急，“果果的科创营调到下午了，临时通知，我这会儿走不开，她爸又出差，你帮我看一眼她到学校没，行吗？”

陈默握手机的手收紧了。他听见自己问：“几点到？”

“两点多吧，具体我也没问清。她手机关机了，打不通。”

他挂断电话，站起来，走到路口对面一家便利店门口，买了一瓶水。他站在遮阳棚底下，把水拧开，喝了一口，又拧上。他盯着校门的方向，手里的瓶子被他转了三圈。他本来只打算看一眼路口就走，现在得留到下午。他给林兰回了个好字，然后把手机揣回兜里，掌心有一层薄汗。

下午两点出头，东门街社区学校的门开了。学生三三两两往外走。陈默站在马路对面，隔着一条车流的距离，看见林果果背着书包从门里出来，左手腕缠着一截褪色的红绳。她和另一个女孩说了几句话，那女孩往左拐走了，她一个人往路口走。

她走到斑马线边上，没有看车。一辆电动车从她身后擦过去，她没躲。保安在门卫室窗户里喊了一嗓子，她才跳回白线后面。绿灯亮了，她跟着人流过街，走到马路中间，鞋带松了。她蹲下来，就蹲在斑马线上，背对着来车的方向，低头系鞋带。

陈默掏出手机，按下计时器。他数着她的动作：拉鞋带，绕圈，打结，再拉紧。大约十二秒。她站起来，蹦着跑了两步，被一个穿环卫服的大叔喊住，退回路边。陈默看了一眼计时器，锁屏，把手机放回兜里。她蹲下的十二秒里，有三辆车从她身后绕过，最近的一辆，后视镜离她的书包带不到一臂远。

黄昏的时候，陈默坐在便利店落地窗前，面前摆着一盒凉了的关东煮。他把种子书从包里拿出来，翻到那一页。灯光下，页角的压痕比早上深了一些，“14:07 东门街路口”那行字下面，多了一行更淡的新字。他凑近看，是五个字加一个冒号：“将停留：138秒。”

他放下书，又拿起来，指腹蹭过那行字。纸是凉的，字陷在纹路里。他把页痕放大拍了照，对着屏幕看了很久。138秒。他今天亲眼看到她蹲了十二秒。一个是现实里他看见的，一个是纸页上告诉他未来的。他记得下午那辆车的后视镜离她的书包带有多近。

晚上他回到出租屋，给林兰发了条消息。“明天果果有人送吗？”他打完，删掉。又打了一遍“东门街口这两天在修路，早上送她的话绕一下”，又删掉。他锁屏，把手机放在桌边，拿起种子书，翻到父亲内页那行字。

“种子书。记人未长成的事。”

他盯着未长成三个字，忽然觉得冷。手机在桌边震了一下。他拿起来看，是本地新闻推送：东门街路口即日起进行人行道检修，施工期间临时调整信号灯配时，请过往车辆与行人注意安全。配图是一张白色轿车正驶过路口的照片，车头切着斑马线的边缘。

他还在看那张图，屏幕上又跳出一条微信。林兰发的。一张照片：老屋墙角那张木头书桌，桌腿和桌面连接处，被人用硬物刻了一串数字，刻痕深得发黑。

0317。

林兰只发了六个字：“你是不是也在查这本？”
