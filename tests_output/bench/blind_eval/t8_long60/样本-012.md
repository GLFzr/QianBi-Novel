# 第7章 第三连接点

陈默在公交站台上看完事故推送的后续：东门街路口单车碰撞，伤者已自行离开，未留联系信息。他把手机揣回兜里，车来了，他没上。那行字在页角上待了一上午，像一根刺横在念头里：第二人擦伤。他从口袋里摸出烟，又塞回去。出租屋门锁还是那样，一拧就开。

他翻开种子书，页痕的“第二人擦伤”后面，多出一行新墨。

“第三连接点：老周。若未对应改写，代价自动延至时空最近的下一个名字。”

页脚，0319下面，浮现0320。他盯着那行字看了很久，把本子合上，又翻开，字还在。他第一次看到连接点这个说法，但意思不难懂：他写的每一笔，都在把某个人和另一个人拴在一起。他想起昨天页角那行“第二人擦伤”时自己心里冒出来的第一个念头：要是我不写那一笔，那辆车会撞上谁。现在答案贴在他眼前：要是不写，代价就会顺着时间线，滑到下一个离那个路口最近的人身上。老周坐在修鞋摊后面，离林果果蹲下的地方不到十米。

手机响了。林兰打来的。

“果果回家一直好好的，没惊吓。”她顿了顿，“物业说老屋楼梯间渗水，有可能是你爸那间书房的墙根返潮。你要不要回来看看？”

“好。”他握着手机，问了一句，“老周今天收摊没有？”

“修鞋那个？下午四点收吧，路修完他就搬了。你问他干嘛？”

“路过想修个鞋跟。”

挂了电话，他把种子书塞进内袋，出门。

市三院门诊大厅的消毒水味在空气里压着。陈默在急诊窗口前停住，对值班护士说是东门街事故的目击者，想找那个左臂擦伤的路人，确认一下人没事。护士翻了翻登记本，头也没抬：“缝了四针。左臂剐蹭，皮肉外翻，没留名就走了。”护士把登记单转过来给他看：职业一栏写着“冷藏运输员”，年龄约四十岁。

陈默看着那两行字。他在东门街见过的人里，没有这一位。老周、林果果、白车司机，都不是。这笔擦伤落到了他从没打过照面的人身上。他想起自己改写林果果时写的那一行字，短短几句，纸上甚至没有出现过“左臂”两个字。可那道缝了四针的伤口，一样不少地落在了某个人的身上。那个人姓什么，住在哪，家里有没有人等他回去，他全不知道。页脚0319还在，他合上书时想到一个词：账本上又多了一行。

他走出门诊楼，在台阶上停下来，翻开种子书。页痕在“第二人擦伤”和“第三连接点”之间，多出一幅画：一辆白色轿车的轮廓被几根简笔画线条勾出来，线穿过一个站在栏杆边的人形。人形旁边，用极小的字标着一个姓：程。

他想起周航说过的话：“东门街跑配送的程师傅。”那天周航的汤水沿旧渍延长线流出去时，他看见过一辆电动车停在台阶下。他当时没在意。页痕在提前标记下一个收账对象。他试着回想那个姓程的人的脸，想不起来。只记得电动车后座绑着的泡沫箱，和汤水沿地砖缝淌成一道细线的下午。

下午四点，东门街的修鞋摊收了半摊。老周正往三轮车上搬木箱，看见他，没说话，弯腰从工具箱底层抽出一个牛皮纸信封，递过来。信封没有封口，封面用蓝黑墨水写着两个字的字迹，和种子书里父亲的字，有七分像。

“下午出车回来自行车筐里就多了这个。”老周说，“没见着人。”

“筐里就多了一个信封？”

“就多了这个。”老周靠在三轮车斗沿上，难得地停下手里的活，“我寻思是有人放错车了，本来想扔了，后来拆开看了一眼，上头写的是你的名。”他顿了顿，目光在陈默脸上停了一下，“你认识写字的人？”

陈默说不认识。老周没再问，转身把最后一箱工具码上三轮车。陈默拆开信封，抽出一张对折的纸。纸上只有一行手写字：

“案：0320已配送成功。旧账有第三连接点，别拆。”

他抬头想再问老周，老周已经蹬上三轮车，往巷口去了，头也没回。信纸叠好塞进内袋时，他的指腹擦过纸边，纸很厚，像办公用的那种。

陈默站在东门街口，手里攥着信封。风灌进领口，他把拉链拉到头。种子书页脚里，0319和0320并排，像同一串账目的两行。远处救护车笛声由远及近，停在他身后的人行道上。他转头，一个穿外卖服的人瘫坐在地，左臂缠着纱布，帽檐压得低，被两个急救员扶着往担架上挪。救护车顶灯的光在他脸上转了一下，陈默的脚钉在原地。

那个人他认得。楼下，二楼楼道口，路灯底下，一顶头盔反光一闪。他站在外面看了一会儿，没进任何楼门，就离开了。那是夜里两点十八分，他窗前那辆没有驶离的电动车。

外卖员被推进救护车，车门关上，笛声往市三院方向去。陈默把信封塞进内袋，低头看信纸上那行字：“旧账有第三连接点，别拆。”又抬头，救护车尾灯已经拐过长街，看不到了。他在路口站了一会儿，老周的三轮车已经没了影，修鞋摊的位置只剩一块油布铺在地上的轮廓。

手机震动。林兰发来一张照片，配文：“水是从书房地板下渗上来的，师傅把板撬了，露出一个锡皮盒子，盒盖有点变形，你回来看看吧。”

照片里，泡涨的木地板撬开一片，底下的灰泥里埋着一只锡皮盒，盖子微微翘起，缝隙里探出半截蓝黑墨水的笔尖。
