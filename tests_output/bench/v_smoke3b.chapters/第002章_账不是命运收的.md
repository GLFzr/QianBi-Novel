# 第2章 账不是命运收的

陈默把共享单车停在楼门口时，前轮碾进一摊汤渍，鞋底带起一串黏腻的声响。楼道的感应灯亮了，那滩汤渍反着冷白的光，边缘浮着一截细短的东西。他低头看了一眼。是一截蓝色尼龙绳的碎头，泡胀了，颜色发暗，跟他下午攥过的那截旧绳圈同色。

蹲下来看了两秒，什么名堂也没看出来。他站起来，跨过那滩水，摸出钥匙上楼。这事他没往心里去，今天装回来的东西已经够多了。

出租屋在四楼。钥匙转开门，灯亮，纸箱还摊在地板上。他把背包卸到桌上，拉开拉链，把种子书单独抽出来，走到书桌前，拉开抽屉，把本子放进最里层，没有上锁。抽屉推回去的瞬间，手在边沿顿了一下。他收回手，转身去拿外卖单。

手机在这时候震了。房东发来消息，说房租这周内得交，不然按合同办。他回了一个字：行。然后点开通讯录，翻到“爸（老宅）”。他本来想办销号，省下那笔话费。号码拨出去，听筒里机械女声说：“您拨打的电话已关机。”

他正要挂断，屏幕上方弹出一行小字：有一条未播放的通话录音。

手指悬住。三息后，他点了一下。

录音开始。前十几息是细碎的杂音，纸页翻动声，抽屉合上，什么东西被放到桌面。然后椅子腿刮过地面，脚步声由远及近。父亲清了清嗓子，声音压得很低，怕被隔墙的人听去。

“这本子留给陈默。告诉他，账不由命收，收账的另有其人——”

门铃在这时响了，录音断掉。

陈默握着手机，等了几息才把手臂放下来。他倒回去，又听了一遍。第二遍，他听见录音更深处有金属物件碰落在地的脆响，还有父亲翻动纸页的节奏，翻得很慢，在找某一页。第三遍，他听完了整段录音，在断掉之前那几息的底噪里，有一个电子女声在远处播报。

他又倒回去，把那几息放慢。电子女声清晰了很多：“您有新的外卖订单，编号0317。”

手机屏幕的光映着陈默的脸。他放下手机，解开背包侧袋的扣子，手指伸进去，摸到一张折过的纸。他不记得自己什么时候往里放过纸。展开，是一张外卖单票的底联，边角沾着干涸的汤渍，中间印着一行字。

取件码：0317。

页角的“案：0317”，录音底噪里的“编号0317”，加上这张不知怎么进了他背包的底联。同一个数字，今天第三次叠在一起。他把底联平摊在桌上，手指又往侧袋深处探了一下，摸到那块旧表。表盘还是停在22点47分，和下午一样。两块东西并排放在桌面上，一个是指头带回来的，一个是不知何时塞进去的，都没有解释。

手机屏幕的光熄了。屋里只剩茶几上一盏台灯亮着。他拉开抽屉，把种子书取出来，翻到页角写着“案：0317”的那一页。钢笔字的压痕很深，透过纸背。他找了支圆珠笔，笔尖抵在编号旁边的一块空白上。

屋里很静。笔尖抵着纸面，迟迟没有落下。

父亲的话还在耳朵里。“账不由命收，收账的另有其人”他第一次听到父亲用这种语气说话，弯腰低语，声音压得极低。那句话的形状就在舌尖上，差一个门铃就能说出来。

笔尖在纸面留下一个很浅的压痕。他看了那个压痕一会儿，把笔放下，合上本子，塞回抽屉最里层。关灯，躺下。躺了不到半刻，他又翻身起来，把本子从抽屉里摸出来，压到枕头底下。

夜里两点十七分，他翻身，胳膊肘抵着枕头下的硬角，醒了。手机屏幕自动亮起，最近通话停在“爸（老宅）”。他盯着那行字看了几息，又按了一次拨打。

这一次没有关机提示。听筒里传来一段录音，是父亲的声音，自己对着手机录的日常问候：“您拨打的用户已在服务区外。请在提示音后留言。”随后一阵忙音。

陈默握着手机没有松。他点开通讯录，翻到那个号码。备注“爸（老宅）”下面还有一行小字，创建时间是三年前。

“0317，他生日。”

他拇指停在屏幕上方，始终没按下去。屏幕暗下去之前，他又点多了一下，进了备忘录。父亲的手机号关联着一个账号，里面只有一条记事。

“3月17日22:47，去东门街路口。”

22:47。陈默把枕头底下那块表摸出来，表针还停在原处。备忘录里的时间，跟表盘上是同一个数字。后颈像被什么东西轻轻按住。他抬头看向窗外。楼下路灯底下，一个戴头盔的外卖骑手跨坐在电动车上，车没熄火，面罩反了一道白光。骑手没进任何一栋楼门。

枕边手机又震了一下。屏幕亮起来，弹出一条新推送。

“您有新的通话录音已保存。”

屏幕上方的时间跳到两点十八分。楼下传来电动车引擎的声音，低低地响着，迟迟没有驶离。

他盯着那行推送，拇指悬在屏幕上方。录音已保存。谁保存的？他今天下午才第一次拨通这个号码，之前从没听过这段录音。系统提示的措辞像是它一直躺在那里，等他来取。他点了一下，录音开始播放。又是那段杂音，纸页翻动，抽屉合上，父亲的脚步声。他快进到后半段，停在那半句话之前。

“账不由命收，收账的另有其人”

门铃响，录音断。他再点一次，再断一次。每次都在同一个位置断掉，被人专门剪过。

他放下手机，把枕头底下的种子书摸出来，翻到“案：0317”那一页。台灯的光照在纸面上，他看了很久。刚才笔尖压出的那道浅痕还在，没有变深，也没有消失。他合上书，重新压回枕头下。

楼下的电动车引擎还在响。他走到窗边，掀开窗帘一角。骑手还跨在车上，头盔没摘，低头看着手机屏幕，在等什么消息。他看了半刻，把窗帘放下。

回到床上，他没有立刻躺下。手机屏幕又亮了一次，是那条推送的提醒。他没有点开，也没有清除。屏幕暗下去之前，他看见备忘录里那行字还亮着。

“3月17日22:47，去东门街路口。”

他躺下来，盯着天花板。3月17日。今天几号来着？他摸过手机看了一眼。星期六，三月十五。两天之后。表盘停在22点47分，备忘录写着22:47。同一个时间，一个在表上，一个在纸上。

他把表拿到眼前，裂痕从十二点方向爬过表盘。表针停在原处，没有走。他翻过表壳，背面那串数字在台灯下反着光。0317。他忽然想到一个念头，手指顿了一下。表盘上22点47分，加上日期3月17日，如果把日期和时间排在一起，就是0317，2247。他不知道自己为什么这么想，但这个念头落下去之后，他再也没能把它从脑子里赶走。

楼下电动车引擎的声音低低地响着。他握着表，没有松手。
