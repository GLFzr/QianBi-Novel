# 第2章 半句话

楼道口那摊汤渍还在，颜色比上午深了些，边沿结了一层薄壳。陈默鞋底踩上去，带起一串发黏的声响。他低头，汤渍表面反着感应灯的冷光，一行被水泡烂的字躺在里面。他蹲下看了两秒，没看出什么，跨过去走了。身后那摊水里浮着一截蓝色的尼龙绳碎头，跟他钥匙扣上那根一个色。

他没有回头去捡。

共享单车推出巷口，车座是凉的。红灯亮起时他掏手机，房东的消息躺在通知栏里：本月房租，最迟周五。他回了收到，字打得很快，手指在屏幕上多停了半秒才熄屏。

楼里没电梯。六层走上去，钥匙在锁孔里转了一圈，咔。

十平米的出租屋，一张床占了大半，墙上一道水渍从上漫到下。他把背包甩在床上，拉开拉链，先把那本旧笔记拿出来，捏在手里掂了掂。封面磨得发白，边角卷着。

然后他拉开床头柜最下面那格抽屉。里面是充电器、过期药盒、一张没撕干净的快递面单。他把笔记放进去，推到最里，合上抽屉，没有上锁。

遗物纸箱倒在地上，他一件一件往外拿。旧工牌、缠成团的耳机线、半盒没拆封的降压药。最后翻出一张外卖单，是从外套内袋里掉出来的，纸已经揉皱，是今天误闯楼道那个外卖哥塞给他的底联。

他没细看，随手搁在桌角。

房东那条消息下面还压着一条运营商提示：您办理的号码将于三日内停机，请办理后续手续。是父亲的号。

陈默翻进通讯录，点开备注爸（老宅），按下拨号。他没指望接通。销号手续要本人确认，他只是想听听系统会报什么。

“您拨打的用户已关机。”

机械女声，一句，干净。他准备挂断，听筒里却顿了一下，跟着跳出一条串音提示。冰冷的电子音念：您有一条新的通话录音已保存。播放请按一。

他的拇指悬在屏幕上方。

父亲走了三年，这个号是家里的座机转过来的，从来没听说过有录音功能。他按下了一。

开头十秒是杂音。塑料袋被翻动的窸窣声，什么东西磕在桌面上，一下，又一下。背景里很空，像在一间没放家具的屋子。陈默听着，把手机贴紧了耳朵。

中段，父亲的声音进来了，很低，贴着话筒说的那种低。

“这本子留给陈默。”

陈默的手指收紧了，指节抵住床沿的木板。

父亲停顿了几秒，像在确认外面有没有人。然后声音往下压了半度，语速比平时慢：

“告诉他，账不是命运收的，是。”

门铃响了。

录音到这里断掉。一声短促的电流杂音，往后全是空的。

陈默盯着屏幕上的进度条走完，归零。他倒回去，从头再放。第二遍他闭着眼听。第三遍他把外放打开，凑近听筒底噪。

前段的杂音里，有一层更细的底噪，录音时收音设备旁边还有另一台机器在工作。第三遍听到末段时，那层底噪里钻出一句被压扁的电子播报女声，快、轻，混在门铃的余响里：

“您有新的外卖订单，编号0317。”

陈默把录音停在那一帧，坐了十几秒。

他起身，走到桌角，拿起那张揉皱的外卖底联，摊平。单号区印着一行小字。取件码尾号，0317。

一天之内，第三次。

纸角上是它，外卖单上是它，现在连父亲的录音里都夹着它。

他拉开抽屉，把那本旧笔记重新拿出来，坐到床上翻开。翻到夹着那张写着陈默的纸条的地方，往后再翻两页，纸角那串手写数字还压在那里。

案：0317。

他从笔袋里抽出一支蓝黑墨水的笔，把笔尖抵在那串数字旁边的空白处。

纸上什么都没有发生。他的呼吸慢下去。笔尖在纸面停留了很久，压出一个小小的凹点，没有墨水渗出去。

他合上本子。笔帽扣回。

“巧合。”他说，“全是巧合。”

声音在空屋子里散开，没有人接。

关灯。躺下。他把笔记塞到枕头底下，硬角硌着后脑一侧，翻了两次身，没挪开。

半夜两点十七分，他翻身时太阳穴撞到那个硬角，醒了。手机屏幕自己亮了一下，是运营商发来的夜间维护提醒。他顺手点开备忘录，翻通讯录，又按下了那个号码。

这次没有关机提示。听筒里响起了彩铃，一段人声，父亲的声音，很平，录音棚里才有的那种距离。他一句一句报：

“您拨打的用户已在服务区外。留言请按。”

忙音。

陈默没按。他把手机从耳边拿下来，屏幕光映在脸上。通讯录那一栏，备注是爸（老宅）。备注底下还压着一行更小的字，创建于三年前，是他自己当年敲进去的备忘：

0317，他生日。

他看着那三个字，拇指停在屏幕右侧的删除键上，没有按下去。

屏幕暗下去之前，他点开了父亲留在这部手机云端的唯一一条记事。只有一行，时间是三年前的三月。

3月17日22:47，去东门街路口。

窗外楼下，路灯底下，一个外卖骑手的头盔反光一闪而过。那辆车没进任何一栋楼门，也没熄火，引擎声闷在楼底下，迟迟没有开走。

他盯着那行字看了很久。备忘录的创建时间比父亲走失还早半年，可父亲从来没提过东门街。他把手机扣在胸口，屏幕的光从指缝里漏出来，在天花板上投出一小块灰白。楼下那辆电动车还在响，怠速不稳，一高一低，排气管里堵着什么似的。

他掀开被子坐起来，把枕头底下的种子书抽出来，搁在膝盖上。没开灯。窗外路灯的光斜进来，勉强照见封面那层磨旧的布纹。他翻开，翻到案：0317那页，指尖按在纸面上，停了两秒，又翻回前一页。父亲的字，那句不可贪斜在页角，笔画压得极重，纸背凸起一道棱。

他拿手机对着那行字拍了张照。闪光灯亮的一瞬，纸面上似乎有什么反光，细看又没了。他把照片放大，页角数字0317旁边，好像还有一点极淡的铅笔痕，蹭得几乎看不见。他把屏幕凑到眼前，那痕迹像半个字，又像只是纸的纹路。

楼下引擎声忽然断了。

陈默停住动作，侧耳听。静了几秒，一阵脚步声从单元门方向传来，不急，一步一步踩在楼道的水泥台阶上。走得不快，但每一步都踩实了。他这栋楼一共六层，他住四楼。脚步声到三楼停了一下，又继续往上。

他把种子书合上，塞回枕头底下。手机屏幕自动熄了，屋里只剩路灯那点黄光。脚步声到了四楼，停在他门口。

门缝底下，一道影子晃了一下，又定住。
