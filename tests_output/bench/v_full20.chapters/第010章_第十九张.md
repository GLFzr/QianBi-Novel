# 第10章 第十九张

医院走廊尽头的电视在播午间新闻。陈默靠在窗边，手机贴在耳边，拇指按着重播键。语音留言那条只有十几秒，那个男声说到"是我留给你的第"就被嘈杂盖住。他第一次听的时候以为那阵嘈杂是风噪，第二次听觉得像车流，第三次他意识到那可能是地铁进站的声音。第四第五次，他把听筒紧紧压住耳朵，背景音里有一个字被碾碎又拼起来。第六次，他听清了。

"第十九张。"

他放下手机，指尖发麻。剪报册，他今天翻过，一共十九页。他锁屏，快步走出医院。经过前台时他停了一下，跟护士要了张便签，写了"程师傅转病房请通知我"和手机号，压在登记台上。护士问他跟病人什么关系，他说朋友，护士多看了他一眼，没再问。他走出大门时手机响了。林兰。

"果果今天没去上学，早上赖在床上不肯起来，问她什么也不说，就攥着那条红绳。刚才冒了一句'陈叔叔昨天在路口看着我'。"林兰的声音压得很低，"你昨天去过东门街？"

陈默握着手机没有立刻回答。昨天他在永宁路口，不在东门街。但林果果看到他了，或者说，她感知到某种东西。"没有。"他说，"我昨天没去东门街。"

林兰沉默了几秒，挂了电话。陈默站在原地，太阳穴那根筋跳了一下。他想起页痕上那句"多次改写致第二人擦伤"，想起改写后维修工左臂的纱布。果果记住了不该记住的东西，而那不是他落笔的内容。他以前以为代价只会落在身体上，擦伤、撞伤、磕破。现在他发现代价还会落在记忆里，被改写的人会留下一道他自己都说不清的印子。他想起程师傅把他误认为陈建国时的笃定眼神，想起那句"你上次说账还没结清，怎么就走了"。被改写的人记不住具体的事，但会记住一个轮廓，一个影子。他骑上共享单车，回老屋。

剪报册摊在桌面上时已经过了下午三点，日光斜着从窗户挤进来。他一页一页翻过，编号0311到0316的记录集中在前面几页，后面全是空白的旧纸。他翻了三遍，没有第十九张纸。他几乎要把册子合上，手指停在封边，忽然把整本册子垂直立起来，侧着看。第十九页与第十八页之间，露出一条极细的纸缝，压在页脊方向，被人折过又压平。他伸进指甲，轻轻揭出一张手掌大的薄纸。纸很薄，几乎是半透明的，边缘被压得发亮，像在册子里躺了很多年。

纸上两行字。父亲的字。"3月17日22:47，大连西路站牌下，有人等核销。别让书知道。"背面是一个座机号，末四位他眼熟，和他备忘录里那条记事创建时间相差不到一小时。他把纸翻过来又翻回去，确认纸上没有第三个字。他把便签折好，放进外套内袋，和那张收据贴在一起。他把剪报册重新立起来，又看了一遍页脊那道纸缝，确认没有第二张夹层。没有。他把册子合上，放回桌面。

他拨过去。三声后接通。没有人说话。背景里有地铁自动报站声，清晰得很："开往……方向列车即将进站，请退到黄线以外。"他屏住呼吸等第二个报站声。几秒后，那个声音穿透听筒："东门街站，到了。"对面挂断。

他再拨。已关机。他查了这个座机号的开户地址，跳出一个名字：城西修表铺。离老屋两条街。他把手机放下来，窗外天已经暗了一半。他低头，旧手表就放在桌角，表针停在22:47。他伸手拿起表，表壳背面那串数字在台灯下发灰，他指腹摩过刻痕，揣进外套内袋，出门。

楼道口，一个人站在对面台阶上。周航。他手里捏着一个牛皮纸信封，没有寄件人。看到陈默出来，他往前递了一下："有人说，今天傍晚前必须送到你手上。"

"谁说的？"

周航摇头："一个穿深蓝工装的人，左臂缠着纱布。他让我别问，说你知道。"周航说完没有立刻走，站在台阶上，像是还有话要说。他张了张嘴，最后只补了一句："他说你知道是什么意思。"

陈默接过，拆开。一把铁钥匙，钥匙柄缠着一圈胶布，上面用圆珠笔写着五个字：阁楼衣柜顶层。他抬起头。二楼老屋的阁楼灯，亮着。他出门前没有开过那盏灯。他低头看手里的钥匙，铁质，钥匙齿磨得发亮，是一把用了很多年的旧钥匙。他想起维修工深夜还表时说的那句"账期到了，表先还你"，想起那个无寄件人信封里缠着胶布的钥匙。有人知道他会拿走剪报册，有人知道他会翻到第十九张，有人算准了周航会在傍晚前把钥匙递到他手里。阁楼的灯亮着，是这一步的确认信号。
