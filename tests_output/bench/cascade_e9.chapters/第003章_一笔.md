# 第3章 一笔

雨停之前，手机闹钟先响了。陈默睁眼，床头柜上摊着一张外卖单底联，单号0317。他不记得自己什么时候把它从包里翻出来放平的。

手机压在枕头下，屏幕亮着。林兰的语音留言跳出来，声音带喘：“陈默，一楼楼道口又渗水了，水管是不是你爸这边没关严，你回来看看吧。”

他坐起来，后脑勺发木。种子书还在枕头底下，他抽出来装进包里。出门前他把外卖单底联塞进裤袋，手碰到那张底联时，他记不清昨晚睡前碰没碰过它。他把那张纸从裤袋里又抽出来，展开看了一眼，单号边角被雨水洇过，数字有些发胀。他重新折好，放回原处。

回老屋骑了二十多分钟。云没散透，路面湿黑。他推开单元门，一股潮气从楼梯间压下来，墙缝里渗着水珠。二楼门口那滩旧水渍还在，比昨天宽出一截。他进门，厨房台面一列水渍正沿台边往下滴，那摞碗还泡在水里，水龙头是拧紧的。水是从台面缝隙里渗出来的，他蹲下看了眼，总阀在柜角，他拧紧，滴声跟着断掉。

他把碗一只只洗了。洗洁精挤在第三只碗沿，泡沫泛白。洗到第五只时，他停住。

他不记得自己昨天午饭吃过什么。不是想不起来，是那里空了一块，像一页被撕掉的时间。他甩干手，翻包找物业缴费单。笔袋底部有一张对折的便签。他展开，上面是自己的笔迹：3月17日必须联系小周。

字是蓝黑墨水，最后一竖拖得有些长。他不记得写过它，不记得小周是谁。

陈默把便签折好，塞进胸口口袋，贴着肉。下楼时他掏出手机准备打给林兰，楼道口传来电动车支架落地的声响。

一个黄色工服的外卖员正从车筐里拎泡沫箱。那人抬头，愣了一下，冲陈默点头：“哥，昨天那单尾号0317的，是我送的。”

陈默看着他：“你叫什么。”

“周航。”他把泡沫箱夹在腋下，腾出一只手提打包袋，“滨河道12号，这栋没错吧。”

陈默没答。他看了眼周航脚下那级台阶，地砖松动，雨水积在缝里，鞋底踩上去必滑。周航的鞋已经往那级台阶上迈了，鞋尖离缝里的水只有半掌。

“等一下。”陈默说。

周航停住，回头看他。

陈默退进楼道阴影，从包里抽出种子书。纸页干爽，没有异样。他拧开笔帽，蓝黑笔尖抵在空白页上，犹豫了三秒。雨后的穿堂风从楼门口灌进来，吹得纸角轻颤。他写下：

周航，3月11日9时52分，滨河道12号一楼台阶，右手握紧扶手，停住半步。

落墨无声。纸面安静得像一本普通笔记本，没有发烫，没有震动，没有字迹自现。陈默合上书页，心跳撞着肋骨。

十五秒后，楼道口传来一声闷响。他冲出去。

周航半跪在台阶上，右手死死攥着扶手栏杆。泡沫箱从车筐甩出去，倒扣在台阶下，汤水从箱沿溢出来，顺着地砖缝流成一道细线。那道线不偏不倚，接在昨天那滩旧水渍的延长线上，停住。

周航骂了句脏话，爬起来拍了拍膝盖，弯腰去捡泡沫箱，回头冲陈默笑了笑：“这台阶真滑。”

陈默站在楼门口，手里的种子书不烫、不响，像一本死物。但他知道，它刚动过一次。

“你没事吧。”陈默问。

“没事，就膝盖磕了一下。”周航把泡沫箱扶正，箱底还在往外沥汤，“这楼物业也不修修，都松了多久了。”

陈默没接话。周航把打包袋重新挎到肩上，朝楼上走，走了两步又回头：“哥，你昨天那单是不是有东西漏拿了？”

陈默摇头。

“行。”周航没再问，脚步声往楼上去了。

陈默低头看台阶。那道汤水线停在旧水渍的延长线上，像有人拿尺子比着画过去的。他站了几秒，转身进门。

午后他回了出租屋。灶台上有三只空泡面碗，整齐码着。他不记得自己吃过其中任何一碗。他拿起手机翻昨晚的通话记录，屏幕显示有一通凌晨2点17分拨出的号码，时长11秒，尾号是0317。那下面还挂着未点开的通话录音提示。

肠胃翻了一下。他冲进卫生间，扶着马桶干呕，没吐出东西。

傍晚雨又下起来。陈默坐在老屋门口翻种子书。白光从门缝切进来，页角静躺着。他慢慢翻到刚才写过的那一页，纸还是干的。他把书侧过来，借着光看见页角处有一道极淡的压痕，像铅笔描过又被擦掉，只留半行：14:07 东门街路口。

纸是凉的，字像被水泡过又干透的旧痕。陈默用拇指反复蹭了蹭，那笔迹不晕染，不加深。

隔壁门开了。

林兰撑着一把滴水的伞过来，身后跟着个扎马尾的小女孩。林兰把伞收了，从口袋里掏出一串钥匙递过来：“昨天你落在我这儿的。还有，果果明天七点要去东门街那边上科创营，我还愁下雨怎么送。”

陈默站起来，没接钥匙。他低头看纸面，页角那半行字在暗处发灰：“14:07”。

“你说哪里。”他问。

林兰又把钥匙往前递了递：“东门街路口呀，滨河道那头，有个红绿灯的。”

果果从母亲身后探出半张脸，马尾辫上沾着雨珠。她拉了一下林兰的衣角，小声说：“妈妈，我鞋湿了。”

林兰低头看了眼，催她先回屋：“先回去换鞋，别感冒。”

果果跑回隔壁。门没关严，从里面漏出一小片暖黄的灯光。

陈默问：“她明天几点到那个路口。”

“七点。”林兰抖了抖伞上的水，“她爸送。”

“她爸顺路？”

“对，他上班经过那儿。”林兰把伞靠在门边，看了陈默一眼，“你问这么细做什么。”

陈默没答。他早上七点。纸上是下午两点七分。中间差着七个小时零七分。他把钥匙收进兜里，拇指无意识地压住页角那半行“14:07”。林兰没看见他手里拿着书，转身也回了屋。门关上。

陈默站在走廊里。手机手电的白光照着书页边缘，那半行压痕下方，隔着一道纸纹的距离，正慢慢浮出极淡的第二笔。他凑近看，看不出是什么字。

楼道尽头的拐角，无人处。老屋里没关紧的水龙头滴下水来，一下，又一下。
