# 第5章 替人挡

走廊铁门开合的声响，在三点十七分后彻底停了。声控灯灭掉，整层楼静得被抽干了声音。陈默坐在桌边，种子书平摊在台灯底下，光圈拢住那一页。

“停留：138秒”，他读了多少遍已经数不清。字沉在纸纹里，不再变化。他合上本子，塞回抽屉，又拉出来。三回。纸上的字不多一笔，不少一笔。

第三次合上本子，他没再开抽屉，就压着书脊坐着。屋里静得能听见灯管镇流器的电流声。他打算起身关灯，瞥见书页边角露出一线蓝黑，刚才分明没有。

他掀开封皮，摊平。页角那行旧痕下方多出一行小字，墨渍潮润，在灯下反着光：

明 07:12 停留处有车刹不住

笔迹是他父亲的。起笔重，收笔顿，像墨斗线绷在纸上弹了一道。他没写。那支蓝黑钢笔从昨天傍晚起就没拔过笔帽。可这行字就是从这页纸上自己洇出来的。

他伸手碰了一下刹字。指腹蹭过纸面，干燥。字是沉的，嵌进纤维里，跟下面那行“停留：138秒”吃的是同一道墨。他关掉台灯，屋里黑了。那行字还在原处。他又把灯打开。字没消失，也没多出一笔。他翻到封底，又翻回这一页。那行字生了根，横竖撇捺都长在纸里，挪不走。

他把本子立起来，凑到灯罩边，沿光看纸背。封面内衬贴着一页竖格纸，边角翘起。他小心揭开一角，纸背透出几行极浅的铅笔字。他抽出铅笔，贴着纸背轻轻扫过去，灰铅痕底下另有一行字浮出来，更浅，像是早被年月磨过：

改写是替人挡。不是替天改。

陈默把纸翻回正面。正面是“不可贪”三个斜字。他才发觉这两个意思之间隔着一条细线，那行更浅的字才是这条线的底。他父亲一生做木工，留在本子上的字向来很短。这行字躲在内衬背面，不带日期，不带编号，只能给后来人看。

改一笔，只是替人挡一下。挡开眼前这一下，不替人把以后的日子都过了。贪，是以为能替人改完一整条命。他想起父亲刨木料时的规矩：料子多厚，刨刀就进多深，从来不贪那一刀。原来他留在本子上的话，也是这个意思。

他捏住纸边的指节在发白。纸角被他折出一个印子，又慢慢抚平。他把内衬纸贴回去，压平边角，合上本子，又翻开，再看一眼那行浅字。字还在。他拿指腹沿那行字的凹痕摸过去，像摸一道刨过的木纹。父亲的手劲他认得，收笔时总习惯往右带一点，这行字收笔也往右带了一点。

拿过手机，翻到林兰的号码，拨出去。等待音很短，两秒后换成机械女声：您拨打的用户已关机。他挂断。屏幕角落显示04:26。离07:12剩一百六十六分钟。

如果林兰接电话，他可以请她明天换条路送孩子，绕开东门街的那条口子。她关机。普通的路已经堵死。他又拨了一遍，还是关机。第三遍拨出去之前，他停住，把手机扣在桌上。再拨也是同一个结果，他只是不想承认自己已经走到那条线的边上。

四点五十分，他翻回本子前页，重新读父亲留下的记录。每一则都短：时间、一个地点、一个动作，收在纸角，像下料前先在木头上画的那道墨。而他昨天在楼道口为周航写的那一笔，用字不算多，今天却已经想不起昨天中午吃过什么。多写一个字，就有多写一个字要从他自己身上匀出去。

他数了数昨天那则的字数，又数了数父亲记录里最长的几则。父亲最长的一则用了二十一个字，收在“案：0317”那页的背面。陈默把那段话在灯下读了又读，写的是一辆货车在雾里刹不住，撞上护栏，人只擦破皮。二十一个字，换一个人擦破皮。他父亲最后那几年，本子上这样的记录越来越短，到后来只剩地点和秒数，像一个人说话越来越省。

五点十二分，他拧开笔帽，翻到一张空白页，先写日期：3月17日。

然后写：

林果果，07:12，东门街路口，因鞋带散开蹲下系鞋带，停留至绿灯转红后第3秒才起身。

身字最后一撇收住。笔离纸面，他后脑像被抽走一条线，太阳穴跟着抽痛。脑子里有一段东西被挪走了，留下一个边缘光滑的缺口。他试着去够那个缺口的边缘，够不到，像伸手去摸一盏刚灭的灯，灯罩还是温的，光已经不在了。

他合上本子，压在胳膊底下，不敢翻回去看。

低头，左手小鱼际的纹路里多出一道蓝黑痕迹。墨顺掌纹走了半弯，像从皮肉底下渗上来的。他拿拇指搓了两下，搓不掉。他又用指甲刮了一下，那道痕长在皮里，不痛不痒，就是抹不去。他想起昨天为周航写那一笔之后，掌心什么也没多。这一次，代价来得更快了。

他试着回想昨天午饭。白瓷碗、竹筷，碗边上有一道磕口。再往下，空的。那段记忆被人从中间截走了，只留筷子和碗沿。他记得自己吃过午饭，记得碗沿那道磕口，却不记得菜是什么味道，也不记得吃完之后自己去了哪。一页纸被从中间撕走一段，前后还连着，中间断了。

掌心那道墨痕比刚才深了一度。页角的位置，无声浮出一串数字：0319。

跟封面内页那串0317在同一个位置。像同一串账目往下续了一行。他盯着那两个数，喉咙发干。0317是他父亲的。0319是他的。中间缺了一个。他不知道那缺着的一笔是谁的账，也不知道自己的这一笔会记到哪里去。

门外的楼道里传来脚步声。鞋底落在水泥台阶上，不快，一步一步压着节拍上来。到门口，停了。

陈默握住桌沿。十秒过去，脚步没离开，也没敲门。门缝底下漏进一线走廊的灯光，被一道影子挡住大半。

那道影子俯下来，一个压低的女声贴着门缝，说了一句话。嗓音有一点哑，尾音往下压，像是隔着门板认准了人。陈默攥着桌沿没动。

女声又说了一遍：“陈默，我知道你醒着。你爸让我带句话，他留了东西在楼下信箱里。明天七点前，去取。”
