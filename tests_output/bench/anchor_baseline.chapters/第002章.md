# 第2章 留下的话

雨下到后半夜停了。陈默推开出租屋的门，屋里还留着他走前的样子：泡面碗立在桌上，水没喝完，插头连着空手机。他没开灯，在床边坐了一会儿，把背包侧袋里那本笔记本抽出来。

纸箱里的遗物还摊在地板上。衣物、账本、收据分了三堆，他爸的木工工具单独搁在墙角，刨刃上的油味没散。他蹲下，把笔记本放进桌子最里层的抽屉，没有锁。手在抽屉边上停了一瞬，才推回去。

手机弹出消息。房东那边又续了一条，红点压在月底两个字上。他没回，直接翻到拨号界面，照旧纸箱里抄来的号码按下去。这是他爸的旧手机号。他拨之前已经想好，通了就提销号，不通就再等两天。

听筒响了半声，停了。机械女声报完“您拨打的用户已关机”后，屏幕落出一条通知，时间戳是十一天前，夹在一串系统消息中间。

“有一条通话录音待播放。”

他拇指在通知上停了片刻。十一天前，他爸人走那天。他点下去。

录音前几秒是一阵杂响。布料蹭过硬物的声音，抽屉拉开又合上，有人弯下腰喘了口气。随即他爸的声音响起来，低低的，不像说话，像在清点什么东西时顺口带出的碎念。

“这套新做的，边角没磨净，别给了。”

“刨刃得还老王，欠他一块板。”

声音时断时续，中间是物件磕碰的闷响。陈默听得出这是在他爸放工具的屋里。他爸习惯一个人干活时自言自语，说给手里的木料听，说给墙听。陈默帮他爸盘了二十年账，听过无数次这种碎念，却从没一次隔着录音听。声音从听筒里出来，隔了一层水，近，又够不着。

中段静了一会儿。再响的时候，声音离拾音的位置更近了，压得很低，像怕被门外的谁听见。

“本子留给陈默。”

陈默的手指收紧，抵着手机壳的棱边。

“告诉他，账不是命运收的，是——”

录音断了。最后一截被一阵尖利的门铃掐没，剩下几秒空白，沙沙地转着。

他倒回去重听。第二遍，第三遍，第五遍。门铃响得太准时，正好压住句尾的几个字。他反复放同一段，把那段话的间隙掰碎了听，想从门铃下再抠出两个音节来。没有。那句话被门缝夹住，有什么东西本来要递到门外，又被铃响拽了回去。

他想起白天林兰递钥匙时咽回去的半句话。“你爸过世前说，有个东西要留给你。”她说的是账本，还是录音里这个本子？林兰知道多少，她有没有听过这段录音？陈默把手机放到桌上，指节抵着桌沿，没动。

放第六遍的时候，他听见刚才忽略的底噪。门铃起之前一秒，杂声底下有一道电子播报，声线平直，超市广播似的一个字一个字往外蹦：

“您有新的外卖订单，编号0317。”

他按停录音。

手机屏幕的光照着他半张脸。他拉开抽屉，从旧纸箱里翻出白天那张外卖单。单据压在背包内层，边角被钥匙硌出折痕，单号区四个数字印得清清楚楚：0317。同一个数字落在同一天里，页角、取件码、录音底噪，已经第三次。

他抽开抽屉，把那本笔记本取出来，翻到写有“案：0317”的那一页。纸角上不知是谁的字迹，铅笔压得很深，收笔果断。他从笔筒里抽出一支笔，笔尖抵在案字一侧，0317四个数字下方。纸面被压出一个凹痕。他没落墨。

他不知道该写什么，也没想好要让这串数字变成什么样。他爸那句没说完的话在脑子里转：账不是命运收的。账是谁收的？他想起页角那行铅笔字，压痕深，收笔果断，不像他爸的笔迹。他爸写字偏右倾，这笔字正得近乎板正。写这行字的人，他爸认识吗？

合上本子按进枕头底下，关灯躺下。

凌晨两点十七分，他翻身碰到枕头下的硬角。手机亮着，不知何时自动回到了拨号记录界面。通话记录里那串号码没有标红，运营商备注栏还剩一行小字：服务期内。他按了重拨。

这一次通了。听筒里没有机械女声，一个熟悉的嗓音慢慢响起来，是他爸自己录的，语速很慢，像在给谁留话：

“您拨打的用户已在服务区外。请留言。”

话音落下，听筒里一片静。预设的留言提示音没有响，屏幕上的通话时长却一秒一秒走着。陈默没挂。他等着任何一个后续的声音，等电话那头像白天录音里那样，再补出半句话来。什么也没来。通话沉默地持续到二十四秒，忙音响了。

手机退回通讯录页面，“爸（老宅）”这行备注下压着一行创建于三年前的小字。他以前从没往下翻过这栏。

“0317，他生日。”

陈默反复确认他没记错，这串数字在他自己的档案里出现过很多遍。他点开备注栏下方的更多信息，停留在一个入口前——

备注这行小字底下，一条提示横幅跳出来，顶着他的备注栏，占住了大半屏：

“你有一条3月17日的备忘录待查看。”

他没有去点。楼下有人启动一辆电动车，发动机低沉地响了一阵，没有驶远。他把手机屏幕按灭，窗帘漏出一条缝，路灯底下，一只黄头盔反了一下光，又暗下去。备忘录的提示横幅在锁屏上转了一会，熄灭。

他解锁，点开了那条备忘。

黄头盔在路灯下又挪了一个位置，像是停稳了。陈默的拇指悬在屏幕上，屏上那行字已经点开。

“3月17日22:47，去东门街路口。”

窗外那辆电动车始终没走。发动机低低地哼着，像有人坐在车上，等着谁先动。陈默盯着那行字，又把屏幕往上划了一截。备忘录的创建时间在页面底部，日期是三年前的3月1日。三年前，他爸还没生病，老屋还没划进拆迁红线。22:47。他低头去看那只表。表盘上的指针仍停在十和十一中间，分针压着四十七分的位置。他爸在备忘录里记下的时间，和这块表停住的时间，是同一个。

楼下电动车发动机的声音又响起来，这一次，轮胎碾过湿路面的声音由近及远。陈默起身走到窗边，路灯下那顶黄头盔已经拐出巷口，车尾灯在雨后的路面上拖出一小片红。他低下头，手机屏幕还亮着，那行备忘停在原地。他爸要他在3月17日22:47去东门街路口。今天是多少号，他记不清了。他点开日历，屏幕跳出来的日期让他停住了手。

3月16日。离那个时间，还有一天。
