# examples/ —— 示例项目说明

> 这个目录放**示例项目结构与导入说明**。示例书数据本身（本地调试产物）不入库，
> 只有说明文档随仓库走（`.gitignore` 用 `examples/*` + 白名单放行本目录下的 `.md`）。

## 一个「书」长什么样

千笔一文的一本书 = 磁盘上一个普通文件夹。应用判断一个目录是不是写作项目，
只看它有没有这四个子目录（`app/project.py` → `is_project`）：

```
我的书/
  设定/    题材定位 · 选题信息 · 世界书 · 正则 · 简介与标签 · 世界观/角色/势力/
  大纲/    大纲.md · 单元总纲.md · 细纲_第NNN章.md
  正文/    第NNN章_章名.md
    .versions/     保存驱动版本（应用生成）
    .annotations/  章级生成配置快照 + 批注（应用生成）
    .drafts/       防抖草稿（应用生成）
  追踪/    角色状态 · 伏笔 · 时间线 · 上下文 · 章节摘要 · 全局摘要
  pipeline_state.json
```

前四类是你（和 Agent）可读可改的 Markdown；`.versions/`、`.annotations/`、`.drafts/`
与 `pipeline_state.json` 由应用生成与维护，手工改动有风险。

## 怎么导入

1. 按上面的结构准备好一个文件夹（或把朋友给你的书目录原样拷来）；
2. 应用内 **书架 → 打开目录**（或「关于 → 打开数据目录」找到 `Documents\千笔一文\`
   后把文件夹放进去，重启在书架可见）；
3. 缺少 设定/大纲/正文/追踪 任一子目录时，应用会提示「该目录不是写作项目」，
   不会半打开——按报错补齐目录即可。

## 注意

- 示例书只作本地调试/学习用，不随安装包发布；
- 不要把带真实 API Key 或个人信息的书目录分享出去——对话记录（`.dialogue/`）
  与报障包同理，分享前先看一眼。
