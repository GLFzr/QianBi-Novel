# docs 导航（按读者找文档）

本目录里既有**用户文档**，也有大量**开发过程档案**（收口裁决、成本台账、工作指南、
实验报告——含失败与负优化，全部留档）。这份索引按「你是谁」分三条路，别在 90 个
文件里裸搜。

## 新用户（第一次用）

| 顺序 | 读什么 | 干什么 |
|---|---|---|
| 1 | [../README.md](../README.md) | 这是什么、下载、3 分钟了解两档模式 |
| 2 | [用户手册_v2.md](用户手册_v2.md) | 完整手册（0.20.2 口径）：安装 → 演示 → 贴 Key → 建书 → 共写六阶段 → 自动档与门 → 世界书 → 反哺 → 备份 → Agent 指令 → 排障与 FAQ |
| 3 | [../examples/README.md](../examples/README.md) | 示例书结构（书=普通文件夹）与外部设定导入 |
| 4 | [排障_v1.md](排障_v1.md) | 报错文案对照表 + 报障包出口；出问题先来这里 |
| 5 | [PRIVACY.md](PRIVACY.md) | 数据在哪、联网行为逐条列出 |

没有 Key 也可以先跑应用内 5 分钟演示（书架空态入口），不花钱看完全流程。

## 关于本目录的其余文件

其余 ~80 份 `.md` 是开发过程档案（工作指南 / 实验报告 / 计划 / 裁决），按主题平铺、
不做二次整理；需要考古时用 GitHub 目录检索或本地 `grep -r`。用户日常只需要上面
三条路里出现的几份。
