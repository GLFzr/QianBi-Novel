## 2. E0 探针怎么跑（明早第一件事，¥2-4）

**两个现成脚本的差别要先说清**（今晚核过代码）：
- `scripts/cache_depth_probe.py` 已经回答过"深节点是否活着"：阶梯前缀＋静置 N 秒再打最深请求，
  实测**同章内逐级深命中、跨章界退回 ~⌊in/256⌋×256**；
- `scripts/replay_request_probe.py` 按 **消息条数** `--slice N` 切请求，**不能按 token 长度扫**。

⇒ **要补的是一个 10 行小改**：给 replay 探针加 `--truncate-tok N`（按 token 预算截前缀），
才能回答 L4 的问题"多长的稳定头能被后来请求命中"。今晚先不跑（零真机纪律），明早跑：
1. 先改探针（纯离线，安全）；
2. 拿第 53 章那 416k 真实字节，按 8k/16k/32k/48k/64k/128k/256k 截前缀，各发 1 次（尾巴固定），
   记每发 `prompt_cache_hit_tokens` 与 miss；同一会话内串行、间隔 <60s；
3. 判据：画 **hit 深度 vs 前缀长度** 台阶图。台阶只出现在 32k 整数倍 ⇒ L4 作废，主攻改"请求形状"
   （让章界那一笔与前缀同构：见 §3 备择方案）；命中随长度连续增长 ⇒ L4 可做，直接进 A/B。

## 3. 如果 L4 被判死（32k 粒度），备择方案 B'

不重建栈，而是**把章界那一笔变成"同形状追加"**：
- 现状每章开幕 = `开幕声明 + 章头(可变的 5 节) + 指令` ⇒ 章头在中间，破坏了"与上一章末笔同前缀"的形状；
- 改法：开幕轮**只放增量**（新章头里逐字节未变的节改引用行＝L2/②-d 的旗标），把"真新增内容"排在尾部；
- 目标：章界那一笔的 miss 从 ~32k 压到"真实新增"（~12-15k tok），预期 −¥0.03～0.05/章。
这条与 L1/L2 共用同一套引用行机制，**一次改造吃两档**。

## 4. 硬约束与纪律（不变）

- **旗标默认关**：L1/L2/L4 全部旗标化（`s4_header_dedupe`、`rewrite_delta`、`head_rebuild`），
  关着＝字节不变，`prefix_lint` 与字节锁必须全绿。
- **格式决策权在程序**：绝不让模型自选"补丁还是全文"（AdaEdit：DeepSeek 选对率 25.34%、57.85% 不产生改动）。
- **闸门相位不省思考**：审校/清算终审是漏检的唯一闸（E9' 关推理换来 59% 引文不实）；
  级联预扫必须配 **5-10% 无条件全量抽检**，否则降档数字不可信。
- **不做**：事后删栈（`E×N > 30.4×T` 永亏）、通用提示压缩（省读 27.9% 但输出 +1.8%，我们输出价 95 倍 ⇒ 全赔）、
  百炼显式 `cache_control`（逐字节全等＋5min TTL ⇒ 必付 125% 创建费）、`max_tokens` 当思考帽、
  相位外迁便宜模型、为保活发心跳（要付输出钱）。
- **三票不要串行化**：我方 8 个变体数据否证（副本票 miss 138～425 tok vs 首票 3.1k～7.6k，副本更便宜）。

## 6. 判据口径（先让数可信，再谈降了多少）

  单独报 `blind_tok`；钱一律给**账面/真实**两数（差额必须能全部归因到盲区）。

## 8. 极致压缩配置 v10（理论预注册，2026-09-10 深夜，zcode）

> 用户口径修正：**综合命中率 = 命中 ÷（命中 + 未命中 + 输出）**，三者加总算。
> V8 现状（同口径）：hit 2.39M ÷（2.39+1.02+0.52）M = **60.8%**。
> 目标：理论综合 ≥ **90%** 再开测。已离线确证的机制：E0 连续命中（L4 头合法）、
> **缓存写延迟 ≈ 一个发次**（E0 附带实锤）、**audit 鲸鱼 = 确定性 -65~-81pp**
> （13/13 章清算首笔在审校末笔 99% 之后 2-5 秒只记到 ~头部 8-12k——审校→清算
> 无写延迟窗口，逐章复现零例外，看板/本节为证）。

### 8.2 理论综合命中率

**hit = 342k ｜ miss+output = 15k + 8k + 12k = 35k**
**综合 = 342 ÷ (342+35) = 90.7% ✓（≥90%）**

每章成本 = 342k×$0.007 + 23k×$0.22 + 12k×$0.66 = $0.0154 ≈ **¥0.111/章**
（V8 ¥0.362 → **-69%**；较 0.19.0 基线 ¥0.386 → -71%）
