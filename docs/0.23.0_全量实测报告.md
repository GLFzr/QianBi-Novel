**「前所未有的成熟度」80% 标准未达成**，两项归因：
1. **外部通道**（主因）：stealth 网关对 >10 分钟非流式生成结构性不可用 + 模型单发思考消耗 30-47k tok——自动档吞吐被锁死；产品侧无对应缺陷。

## 八、结论

**0.23.0 的机制集在真实模型+真实工作流下全部真实运行并落账**：六阶段共写、合同化校验（真实拦截）、supervisor 比对（真实缺口报告）、F1/F2 出口与派单、写作规约沉淀与注入、状态卡、读改揣摩、反哺回写、维护四查、四账本、设定清算、预算宪法（5 次实弹熔断）、G2 截断识别、失败现场、断点续跑——无一缺席。共写档达到理想分；全自动档被外部网关的「>10 分钟非流式生成墙」锁死吞吐（1 章完整 + 1 章失败链），产品侧在该墙下每一次都正确收口。

**总分 72.5%（带缺陷可用）**。达 80% 的路径明确：换稳定通道（deepseek 级）重跑自动档 3-5 章 + 字数双带精化（压缩下限保护/扩写带内收敛）。实测期产出的 3 项阻断修复（非流式路由下沉/坏 JSON 留痕/总时钟死线）对任何非流式模型永久有效。
