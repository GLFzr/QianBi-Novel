- 全程 **48 发**：入 336,053 tok + 出 426,188 tok；总耗时 ~9,250s；空响应（st=empty）11 发。
- 分段（含失败重试）：核心设定 6 发 / 大纲 1-2 发 / 世界书 8 发 / 单元+细纲+校验 12 发 / 第1章全链 4+ 发 / 第2章+反哺 7 发。
