## 四、A 层：同题对比（第3章细纲、同一提示装配、双稿盲评）

- **如实声明**：本地 llama.cpp 停机，「qwen 臂」回退 stealth——本层实为 **同模型双采样对比**（T=0.7），测的是评委一致性与采样方差，不是模型差。
- 结果：两评委**一致**判甲胜（7.9 vs 7.0）；理由高度一致（乙「说明腔重、模板化转折」）。
- **附带炸雷**：同题 one-shot 新稿盲评 7.0-7.9，而管线产的第3章只有 2-6——**管线的会话/扩写/压缩链可能在净损伤质量**（需按 §五 验证后定论）。

## 五、工程行动清单（按证据强度排序）

1. **会话轮上下文治理**（证据最强）：单发 179k tok 的章级会话轮与盲评劣化曲线强相关——需实验「会话历史摘要化/滑动窗口/逐章冻结」三方案对盲评分的影响（预期把自动章从 1-5 拉回 5+）。
2. **AI 味句式压制进 deslop 规则**：「不是…而是…」2.08×、陈词 2.8×——这两个模式已有词表（M6/M9），但只进读数不设规则；升格为阻断/建议规则并在扩写/去味 prompt 中点名。
3. **开篇抓力专项**：共写与自动章的最大分差维度——章首三段由独立小调用生成（与正文分离、可单独重试），或把「前三段禁排比/禁回顾式开场」写进章头约束。
4. **承接链强制闭环**：S2 的 prev_hook_answered=false 章应在下一章细纲装配时注入「上一章钩子必须应答」硬约束（0.23 的钩子账本已有数据，缺注入回路）。
5. **钩子类型多样性**：5/7 章收在「危机迫近」——细纲模板应轮换钩型。
6. **扩写环防堆料**：第6章 0.44 的 3-gram 复现证明补尾/全量扩写会复制已有文块——扩写稿需要跨章查重闸。

## 六、对总评分的修正

二测报告的 90%（结构分）维持有效，但按本计划，「前所未有的成熟度」的完整口径应表述为：

> **结构与机制 90%（达标）· 产物质量 4/7（57%，未达标）——机制完备、交付物未达可发布级。**

瓶颈明确且可执行：不是护栏、不是账本、不是流程——是**会话上下文治理 + AI 味句式 + 开篇工程**三件事。
