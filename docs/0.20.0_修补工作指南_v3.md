## 0. 新增纪律

- **R13 · 覆盖面必须有锁**：新增"每次都该发生"的行为（落盘、记录、脱敏），必须配一条**覆盖率断言**：故意制造一条绕过路径，测试必须红。**只写"通常在 X 时会做"不算完成**——这正是本轮四处变异存活共同的形状。
- **R14 · 任何新增落盘 = 隐私变更**：新写的文件必须同时满足五件——①内容脱敏（Key/凭据一律不得入档，复用 `secrets.redact_text`）；②位置在界面可发现（不是"自己去数据目录翻"）；③可关闭；④`PRIVACY.md` 与设置面板文案同步说明"存在、在哪、装什么、不上网、如何关"；⑤滚动/上限，不许无界增长（`app/logger.py:34-35` 的 2MB×5 是范式）。**做不到五条中的任一条，就停下问用户**（历史事故：PRIVACY 与便携说明写错过书稿默认路径，照旧文案备份会丢全部书稿）。
- **R15 · 计数与"绿"必须附命令原文**：你上轮报 `1233 passed + 5 skipped`，主代理按 `python -m pytest tests/unit -q` 实测 `986 passed, 4 skipped`。多半只是口径不同，但**没附命令就只能靠猜**——从此每条计数写成「命令 → 输出末行原文」两行。

## B. 新增两件（用户 2026-09-17 明确指派，属本轮范围，不是越界）

### WP-27 · 所有 Agent/用户对话全量落盘（P0）

**现状（用户与我核过）**：默认**零落盘**。共写转写虽存在 `state.json`（`co_dialogue.py:27-46`），但按阶段截断（`TRANSCRIPT_MAX`）且只覆盖共写档；流水线各阶段**发给模型的内容与模型的完整回复**只在卷会话开启时按卷落 messages 文件，而该开关**默认关、且不覆盖所有调用**——`stages.py:350` 的 `_stream()` 之外还有路由/清算等独立单发路径。用户要的是：**每一次 Agent 与用户的往来都留得下来。**

做：
1. **落点唯一化**：在真正的调用咽喉处记（`_stream()` 已是 P2 生成配置快照的咽喉，沿用同一条链），并把**所有绕过咽喉的独立单发路径**收进来或显式登记——每条路径要么被记录、要么被门禁抓住。
2. **记什么**：阶段/相位、章号、模型与槽位、**完整 prompt**（或哈希+可复原引用）、**完整回复**、思考是否降级、耗时、token 与缓存命中、成败（**含失败、重试、abort**——上轮台账就记着"重试与 abort 花的钱账上为 0"，这条因本功能顺带收口，见 §C 边界更新）。
3. **存哪**：书内目录（与书稿同行，随项目 zip 备份走），**不进** `state.json`（避免污染既有状态文件与快照口径）；命名与 `.annotations/第N.json` 同族，可发现、可回看。
4. **R14 五条**：脱敏（Key 一律不入档）、界面可发现、可关闭、`PRIVACY.md`+设置面板同步、滚动上限（长书 100 章的体量要给上限策略与"每章多少 KB"的实测数）。
5. **R13 覆盖面锁**：造一条"新路径绕过记录"的变异 ⇒ 必须红；并给一条**数量一致性断言**：某章的调用记录条数 == 实际发出请求数（重试/降级各算一条）。
6. 明确 **默认态**：按用户意图，**默认开**（本地落盘，不上网）。若你判断默认开会带来体积/性能风险，先报数再问，不要自行改成默认关。

### WP-28 · 导出对话与程序日志（P0）

**现状**：导出只有正文（`app/export.py` 的 txt/epub）与项目备份 zip，**对话与 log 完全缺失**。用户要能一键拿走。

做：
1. 导出对话框加两类出口：**对话记录**（按章/按阶段，可选 JSONL 与可读 txt 两形态）与**程序日志**（当前 + 轮转分片，可选崩溃/失败现场 dump）。
2. **报障包**：一键生成单个 zip（对话 + 日志 + 版本号 + 配置摘要），**必须脱敏**——Key/凭据/用户机器路径按 R14 处理，且要有一条测试**故意塞一个假 Key 进 config** 验证它不会出现在包里。
3. 与公测闭环接线：`README`/Issue 模板指到这个包怎么生成、贴到哪（现状是 0 open issue、无任何使用遥测——**这是你目前唯一能收到外人反馈的通路**，做这条的价值在此，不在"功能清单多一项"）。
4. 大文件护栏：包体上限与"只取最近 N 天/最近 M 章"的选择，避免 100 章长书一键导出几百 MB。
5. 验收：真跑一次导出并**贴包内文件清单**；`probe_export` 家族扩到新两类出口，且失败会退非 0（WP-24）。
