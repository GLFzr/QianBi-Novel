# 0.23.0 质量深测计划（预注册 · Phase 5）

- **动因**：一测/二测只测了结构与机制（阶段完成度/账本落账/护栏触发/字数带），**没有一个字的质量评价**——没人读过生成的正文。本计划补上质量层，并固化为可重复执行的测试流程。
- **被测语料**：二测项目 `or_二测_改命笔记` 全部 7 章（共写 2 + 全自动 5）；A/B 层另生成对照稿。
- **判据纪律**：预注册，测后不改。执行器：`tests/quality_suite.py`（每个子命令可独立重跑）。
- **语料纪律**：真人语料（7 部连载长篇、14,547 章，本地合法留存）只做**本地聚合统计**；报告中只出现聚合数字与「真人基线」泛称，**不出现书名与原文**。

## 一、分层设计

### M 层：机器度量（零主观、全本地）

| 项 | 口径 | 真人基线 |
|---|---|---|
| M1 14 项 deslop 指标 | `deslop_metrics.compute_metrics` 逐章产出；千笔 7 章覆盖率必须 100%；关键读数（重复率/句长/AI 高频词密度等）与基线中位比值 | 每书随机抽 30 章 ×7 部 = 210 章同口径计算 |
| M2 45 规则命中密度 | `gates.scan_deslop` 阻断+建议数 / 千字；千笔中位 vs 基线中位比值 ∈ **[0.5, 2.0]** = 达标（同量级；过低=未暴露，过高=过度模板化） | 同上 |
| M3 跨章模板化 | 相邻章 3-gram 复现率（本章 3-gram 在上一章已出现的比例）；千笔均值 ≤ 基线均值 **×1.5** = 达标 | 每书内相邻章对同口径 |

### S 层：语义审计（LLM 参与但产物可核对）

| 项 | 口径 | 判据 |
|---|---|---|
| S1 设定遵循（canon_audit） | 采集 Phase 2 逐章已在盘的 `追踪/设定清算_第NNN.json`（= `audit_chapter` 语义级审计产物：违反/硬伤/可收编自创），另对 1 章用 **stealth 独立通道复审计**交叉验证 | 硬伤=0；违反逐条人工核读进报告 |
| S2 钩子兑现 | 逐章 LLM 审计：章末是否有效钩子（7 型词表口径）、上一章钩子是否被本章应答 | 钩子有效率 ≥80%；应答率 ≥80% |
| S3 爽点兑现 | 逐章 LLM 审计：细纲「本章爽点节拍/兑现承诺」字段 vs 正文实际兑现 | 兑现率 ≥70% |

### B 层：盲评（匿名化 + 结构化 rubric + 双评委）

- **匿名化**：章节文本去章号/书名，编为「稿 A-1…A-7」乱序呈现。
- **评委**：① 本地 qwen（自评偏置已知——同模型写与评）；② stealth（独立通道评委， OpenRouter key 复用一测授权，2-3 发小额）。双评委独立打分后并陈，**不合并平均**（评委间分歧本身就是发现）。
- **rubric（10 维，各 1-10 分 + 必须给原文引句作证）**：开篇抓力 / 节奏推进 / 人物一致性 / 对话自然度 / 爽点兑现 / 钩子力度 / 文笔流畅 / **AI 味读感**（反向计分：越像 AI 越低分）/ 前后文连贯 / 平台合规。
- **判据 B1**：两评委 10 维均分（各评委内）**≥6.0 = 可发布级**；任一评委 <5.0 的维度逐章列缺陷。
- **防漂移**：评分定义写死在 prompt；输出强制 JSON；温度 0.2。

### A 层：A/B 同题对比（消融模型变量）

- 同一细纲（第3章）+ 同一提示装配路径，**双模型各写一稿**：qwen（本地）vs stealth（远程）。
- 两稿匿名乱序 → 双评委按同一 rubric 打分并排winner。
- 判据 A1：观察性记录（N=1），不设硬阈；揭示「机制相同、模型不同」的质量差基线。

## 二、执行顺序

1. `python tests/quality_suite.py baseline` → 真人基线分布（一次构建，落 `_quality_baseline.json`）
2. `python tests/quality_suite.py machine` → 千笔 7 章同口径 + 对照表
3. `python tests/quality_suite.py semantic` → S1 采集 + S2/S3 LLM 审计（本地模型）
4. `python tests/quality_suite.py blind` → B 层双评委
5. `python tests/quality_suite.py ab` → A 层双模型同题
6. `docs/0.23.0_质量深测报告.md` → 按 §三 评分

## 三、评分（并入总评分卡作「质量指标」板块的细化）

| 板块 | 判据 | 分 |
|---|---|---|
| M 层 | M1/M2/M3 全达标=2；一项超界=1；两项以上=0 | /2 |
| S 层 | S1 硬伤 0 且 S2/S3 达标=2；硬伤 0 但 S2/S3 一项未达=1；硬伤>0=0 | /2 |
| B 层 | 双评委均 ≥6.0=2；一评委 ≥6.0=1；双 <6.0=0 | /2 |
| A 层 | 完成并如实记录=1（观察性） | /1 |

质量深测总分 **7 分制**：≥6 = 质量达标（此前两测的「质量指标」板块按本表重估）。

## 四、已知风险

1. 本地模型自评偏置（qwen 评 qwen）——由 stealth 独立评委对冲；两评委分歧大的维度单独标注。
2. 真人语料是成名作品（头部偏差）——报告标注「对照对象为商业头部作品，下探空间 intentional」。
3. LLM 审计的判分稳定性——rubric 写死、JSON 强制、温度 0.2；同稿重复评审 1 次取均值（B 层每评委每稿 2 发）。
