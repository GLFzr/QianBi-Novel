第 002 章 转折（写作中 · 预览）

陈默把那支笔在指间转了半圈，笔尖悬在契约书的落款处，迟迟没有落下。窗外的霓虹把桌面切成红蓝两半，像一份没人签字的最后通牒。

他知道对面的人等不了太久——茶几上的手机屏幕亮了第三次，来电备注是那个他躲了半年的号码。

（↓ 点击任意段落体验 R1 聚焦模式；顶部开关切换 K1 版心）

笔尖落下的一瞬，纸面上浮起一行只有他能看见的小字：【代价已登记：三日内的某段记忆。】

他没有停。有些转折，本来就是拿记忆去换的。

行距 1.85 · 宋体栈：思源宋→内置文楷兜底（K2）
K1 版心：旧版正文 contentWidth=窗口全宽，1600px 窗下一行 90+ 字。新版 maximumWidth=字号×42 字当量（640-700px）居中，两侧留白透出 bgPage。K2 字体栈：硬编码单字体名改为多族回退 + 内置子集化霞鹜文楷（OFL 可随包分发）。R1 聚焦：当前段全亮、前后段降灰 40%，可选拉字机滚动（衔接 M3 设计文档的 immersive 状态机）。
旧版：无版心（contentWidth = 窗口全宽，本视图约 90 字/行）

旧版阅读器把正文铺满整个窗口宽度。在 1400 到 1600 像素宽的窗口里，一行中文轻松超过九十字，眼睛从行尾跳回行首的距离太长，扫读时容易串行，长时间校对疲劳感明显上升。这是中文长文排版的经典问题：行宽没有上限。

更隐蔽的是字体栈：主题里 serifFont 硬编码为单一字体名，没有回退列表。没装思源宋体的机器会静默退回系统默认黑体——阅读器的衬线形态名存实亡，而用户只会觉得「好像哪里不对」。

新版：版心 680px（≈42 字/行）+ 字体栈兜底 + 聚焦模式

新版阅读器给正文加了版心：内容列最宽六百八十像素，居中放置，两侧留白与页面底色同色，不画分界线。每行落在四十个字上下，正好在中文舒适行长三十五到四十五字的区间里——这是 W3C《中文排版需求》与多家字库厂商共同给出的经验值。

字体从「单名硬编码」改为「多族回退列表」：用户装了思源宋体就用思源宋体，没装就回退到随包内置的霞鹜文楷屏幕阅读版——它本身就是为屏幕长时间阅读调校过的字重，体积经三千五百常用字子集化后可控，许可证 OFL 允许随商业应用分发。

再往上叠一层段落聚焦：定稿后人工润色时，当前段保持全亮，前后段降灰到三成，视线自然只落在要改的那一段。整个状态机复用 M3 设计文档已定稿的 immersive 属性，不另起炉灶。
