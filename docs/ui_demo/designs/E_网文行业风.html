第 002 章 · 紫微星动

待发布 共 2,814 字 · 已加载 8/34 段 · 点击段落进入校稿聚焦

子时三刻，观星台上的铜壶滴漏恰好敲过三响，李衍掀开厚重的毡帘，一股寒气顺着领口灌了进去。

台顶的浑天仪覆着一层薄霜，黄铜刻环在月色下泛着冷光。他哈了口气，搓了搓僵冷的手指，才把眼睛凑上窥筒。

紫微垣里，那颗本该黯淡下去的辅星，此刻亮得刺眼。

“不可能……”李衍猛地直起身，重新调校刻度，再看——辅星非但没有转暗，反而又向外洇开了一圈光晕，像是有人藏在星幕后头，缓缓推开了一道门缝。

《开元占经》有云：紫微星动，非迁即变。这句他早在父兄的手札里读过，当时只当是老掉牙的陈词。如今这八个字活生生悬在头顶，压得他后脊发凉。

台下忽然传来急促的脚步声。老监正裴远提着灯笼登上台阶，灯笼纸被夜风吹得哗哗作响：“三更半夜，又在看那颗星？”

李衍没有回头：“裴监正，今夜之后，钦天监的名册，恐怕要重写了。”

裴远手里的灯笼停在了半空。良久，他才压低嗓子：“这句话，出了观星台，一个字也不许再提。”

设计说明 · 方向 E「网文行业工作台」

设计方向

起点 / 番茄作家助手血统的行业编辑器：白底亮色、橙红 #ff6a3d 主色、大字重数字直给，把 AI 流水线翻译成网文作者心智里的「生产车间」——细纲车间、正文车间、审校质检、上架包装，而不是开发工具的面板与图标。

与现状的三点关键差异

  1. 长任务成本首次可见（K1/K3/M4）：hit / miss / phase 落盘数据接成「笔迹带」点阵、命中率色点与本章成本条；运行中显示「第 N 笔 · 已 x 秒」，46 笔 / 77 分钟不再是黑箱。
  2. 行动收敛（M1）：原来的 8+ 等权按钮收敛为每屏唯一 primary「继续写第 002 章」，其余全部降为次级 / 文字按钮，眯眼测试视线只有一个落点。
  3. 行业语境（R1）：章节表引入卷-章两级分组与发布语义徽章（草稿 / 待发布 / 已发布 / 审核退回，含退回原因），替代无语境的「定稿」；阅读器给 680px 版心与 1.85 行距，校稿不再一行扫到边。

适用人群

从起点 / 番茄等作家助手后台迁移而来的网文作者（本项目目标用户）。他们的心智关键词是：今日更字数、全勤、均订、推荐票、上架、催更——所以数据卡按这个优先级排布，AI 成本（¥）与稿酬（¥）放在同一张「本周收支」卡里对照。
