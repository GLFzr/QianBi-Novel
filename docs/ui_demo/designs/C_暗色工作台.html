与现状的 3 条差异
  1. 落盘数据直接上屏：现版长任务只有 hit / miss / phase 几枚小药丸；这里把已落盘的阶段数据摊成终端表 —— 每阶段 CALLS / TOK(out) / HIT% / COST / LAT 逐行可见，46 笔、77 分钟、¥0.24/章 一屏可读。
  2. 按钮墙收进命令面板：现版同屏 8+ 等权按钮互相竞争；本方向同屏只保留 1 个 primary，其余动作全部收进 Ctrl+K 命令面板，键盘流优先（squint test 只剩一个蓝块）。
  3. 结构补齐：章节按「卷-章」两级分组（M4），git 式状态点一眼分清定稿 / 带注 / 写作中；阅读器给 680px 版心 + 1.85 行距 + 段落聚焦（R1），长文不再顶满屏宽。
