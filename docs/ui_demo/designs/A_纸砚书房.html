山门外的雾比往日更沉。陈砚之立在青石阶下，掌心那半块青玉硌得生疼——三日前它还温润如水，如今却像一块烧不尽的炭。

「灵根测出个废字，也配回山？」身后的讥笑声不重，却顺着雾气爬进耳朵。他没有回头。师尊临终前只留了一句话：玉裂之时，便是你登顶之日。

他抬手，将青玉按在石阶中央的刻痕上。裂痕里渗出一线微光，细得像针，却把整段石阶照得透亮审校注：此处「刻痕」前文第001章作「剑痕」，需统一。雾，霎时向两侧退开。

阶上之人尽数变色。执剑长老的手按上剑柄，声音发紧：「守阁老祖的封印——被一个废灵根解了。」陈砚之收回手，青玉已碎成齑粉，随风散去。

他终于抬头，望向那座困了他七年的问剑阁。这一次，眼里再没有雾。

与现状的三条差异

  1. 暗色软件界面 → 纸墨书房：正文纸底墨字、衬线主导，行长从 90+ 字压进 680px 版心（K1），段落可聚焦（R1）；
  2. 8+ 等权重按钮 → 同屏唯一朱砂 primary「继续写作」，其余 ghost、重写为朱砂描边 danger-ghost（K3）；
  3. 长任务只有状态 pills → 阶段时间线 + 成本小结条：每阶段笔数 / token 迷你条 / 命中率色点、「第 N 笔 · 已 x 秒」实时态，¥ 与命中率直读（M1），章节按卷分组折叠（M4）。

适用人群

  1. 长期伏案、日均盯 1–3 章流水线的长篇作者；对纸书与宋体排版有情感偏好的写作者；需要成本与命中率可审的「监工型」用户。反过来说：偏好科技感仪表盘或深色依赖的用户会更适合方向 B。
