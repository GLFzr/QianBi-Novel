雨停在黎明之前，程隅把最后一张字条压进抽屉底层。字条上只有四个字：不要回头。

三天前，旧城区的钟楼在无风的午夜自己响了一声。守钟人从此失踪，只留下一串湿脚印，从钟座一路延伸，尽头是一面完好无损的墙。

「如果墙后面有路，」老周把烟摁灭在鞋底，声音压得很低，「那走路的东西，就不是人。」他说完这句话的第二天，铺子就再没开过门。

程隅不信鬼神，他只信账本。可这一页账，从钟楼响起的那晚开始，无论他怎么算，都整整差着七个小时——像是有人从他的夜里，撕走了一段时间。

他沿着脚印走到墙前。指尖触到砖面的一瞬，整条街的路灯同时暗了半拍，像有什么东西贴着墙的另一侧，轻轻应了一声。

「谁？」他问。墙没有回答。墙里传出一声极轻的、纸页翻动的声音，一页，又一页，不紧不慢，仿佛有人在读一本写着他名字的书。

程隅后退半步，握紧了口袋里那半块铜钥匙。字条上的字迹他认得——那是他自己的字，落笔于他还没有记忆的三岁。

天光将亮未亮。他终于明白，转折从来不是命运的馈赠，而是账单到了。

已应用的设计原则

  • 结构即信息：阶段编号 01–08 编码真实执行顺序；状态点/徽章只承载状态语义，不做装饰。
  • 动效只响应用户：无自动入场动画；操作按钮 hover/键盘聚焦才浮出， Esc/点击即退出聚焦。
  • 把大胆集中在一处：每屏唯一 primary「继续写作」，其余全部降为线框或静默 ghost。
  • 层级靠字重与灰度：同字号用 400/500/600 与三级灰分层，几乎不引入新色相。
  • 单一主导 CTA + 渐进披露：眯眼测试下最亮的只有主按钮；明细（输出/命中明细）收进行内操作。
  • 可达性底线：正文对比 ≥ 4.5:1（按钮白字 5.1:1）、焦点环可见、尊重 prefers-reduced-motion。

与现状差异（3 条）

  • 现状暗色高密度面板，层级平、行长失控。本方向：近白窄壳 960/680，留白分组，行长受控，可长时间驻留。
  • 现状8+ 个等权蓝主按钮争夺注意力。本方向：唯一 primary，次级操作静默 hover 浮出——工具退后，内容靠前。
  • 现状长任务盲跑（46 笔 / 77 分钟）无成本可视，hit/miss/phase 已落盘未接 UI。本方向：小结卡常驻 ¥0.24/章 · 27 笔 · 93.4% 达标徽章，阶段行透出耗时/Token/命中率（对应计划项 K1 / K3 / M1 / M4 / R1）。

适用人群

  • 被「工具感」疲劳的写作者：日更 4–8 小时长驻界面，希望软件安静、像纸面一样可读。
  • 在乎成本的存稿型作者：需要一眼看到本章花了多少钱、命中率是否达标，而不是盯进度条干等。
  • 键位流用户：⌘K 搜索、1/2/3 切视图、⌘1/⌘2 切卷章，手不离键盘。
