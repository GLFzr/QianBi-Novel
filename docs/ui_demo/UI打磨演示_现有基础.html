对比方式：点上方开关在「现状 / 打磨后」之间切换，面板本身 250ms 过渡。

观察点：① 杂乱间距 → 4/8 网格的呼吸感；② 多层阴影 → 单一投影的干净海拔；③ 粗边框 → 发丝线；④ 字号杂值 → 五档字阶；⑤ 圆角混杂 → 6/10 两档；⑥ primary 平涂 → 微渐变 + 内描边高光；⑦ 图标粗细 → 统一 1.6px 对齐像素网格。
  1. 间距节奏 4/8 网格padding 13px、gap 15px 等杂值 → 12 / 16杂值让视线每次都"磕绊"，统一节奏带来呼吸感与下意识的秩序感。
  2. 两级海拔制panel(0) / raise(1) 两档背景 + 唯一投影 0 8px 24px rgba(0,0,0,.35)，禁多层阴影克制：层级只用一种语言表达，眼睛不必解码多种阴影含义。
  3. 发丝线边框统一 1px rgba(255,255,255,.06)，分割线 .04边框负责"分区"而不是"描边"，近不可见才显精致。
  4. 字阶收敛13 / 14 / 16 / 20 / 26 五档 + 行高配对（1.3 标题 / 1.6 正文），数字全部 tabular-nums一致性：字号档位少而准，层级靠对比而不是靠"再大一点"。
  5. 圆角两档控件 6 / 容器 10（现状 4–12 混杂）两档半径让"控件"与"容器"身份一目了然，混杂半径则全部失焦。
  6. primary 微渐变顶部亮 4%（#5aa9f2→#4d9fec）+ 内描边高光 inset 0 1px 0 rgba(255,255,255,.16)1px 高光模拟受光面，是"实体按键感"最廉价也最有效的来源。
  7. 图标统一描边stroke-width 统一 1.6px，坐标对齐像素网格（避免半像素模糊）图标粗细不一最暴露"拼凑感"，统一后整套 UI 立刻像一个人画的。

2 · 组件级映射（真实组件名）

AppButton#01/#02：pressed 态 scale 0.97，恢复用 Behavior on scale { NumberAnimation { duration: Theme.dur(150); easing.type: Easing.OutBack } }；hover 用 Behavior on color { ColorAnimation { duration: Theme.dur(120) } }；primary 背景改 gradient（top +4% 亮度）+ 内描边高光 Rectangle 1px；焦点环用覆盖的 Rectangle：border 2px accent、外圈 4px rgba 柔光，visible: activeFocus + opacity Behavior 80ms。
AppCard#海拔：只允许 elev 0/1 两档——elev 0 用 panel 底色无边框阴影，elev 1 用 raise 底色 + 发丝线 1px rgba(255,255,255,.06) + 唯一投影；radius 收敛为 6（内嵌控件）/ 10（容器）。
StepPills / StageStepper / StageStepperCW#03/#04：胶囊指示器为绝对定位 Rectangle，x/width 绑定 currentIndex 对应 pill 的几何值，加 Behavior on x/width { NumberAnimation { duration: Theme.dur(250); easing.bezierCurve: Theme.mEaseOut } }；状态点运行中用 SequentialAnimation on opacity { loops: Animation.Infinite }（1.4s，paused: !visible）；完成时 SequentialAnimation scale 0.4→1.15→1 共 200ms，running: isDone && !popPlayed，只播一次。
ThinProgress#05：bar 宽度 Behavior 900ms bezier(.22,1,.36,1)；流光为上层 Rectangle 线性渐变纹理做 translateX 循环 8s，alpha ≤ .09，running: active && visible && !Theme.reduceMotion。
ConsoleDock / LogView#06：按「句」（而非 token）追加 delegate，新 delegate 初始 opacity 0 / y +3，Behavior on opacity, y { NumberAnimation { duration: Theme.dur(150) } }；ListView 需设 cacheBuffer ≥ 600 并随 StackLayout.visibility 暂停循环动画。
AppStatTile / 主窗口状态栏#07：显示值用代理属性 shownValue，真实值变化时 Behavior on shownValue { NumberAnimation { duration: Theme.dur(300) } }；文本右对齐 + 等宽数字（Qt 6.7+ 可用 font.features: { "tnum": 1 }，或选等宽数字 fallback 字体），避免 count-up 期间抖动。
PipelinePanel 折叠组 / ChapterPanel / QueueRow#08/#10：折叠用 wrapper Item + clip，height Behavior 200ms bezier；子项 opacity 逐个 Behavior { delayed: i * 30ms }（用 Timer 或 transition delay）；列表选中条为 ListView 覆盖层 Rectangle，y/height 绑定 currentItem.y，Behavior 250ms；delegate hover Behavior on color { ColorAnimation { duration: 80 } }。
ToastManager（新组件，挂主窗口右下）#09：Column + add/removed Transition（y +8、opacity 0 → 归位 200ms bezier）；每条 Toast 内 Timer { interval: 4000; onTriggered: dismiss() }；dismiss 走退出 Transition 250ms 纯 opacity；堆叠 spacing 8，同屏 ≤ 3 条。
主题切换（Theme 单例）#11：所有页面根容器 Behavior on color { ColorAnimation { duration: Theme.dur(250) } }，子项颜色全部绑定 Theme 属性，切主题时整树同步过渡；夜间 ↔ 羊皮纸两套 token 表替换即可，过渡期间禁用大面积 repaint 特效。
WizardDialog / AppField 骨架态#12：骨架条 = 圆角 Rectangle + 渐变纹理 translateX 循环 1.6s（alpha ≤ .08）；禁止再用旋转圈（旧 spinner 移除或仅作兜底）；骨架出现/内容替换均走 150ms fade-up。

3 · 性能红线

  • 禁大面积 blur：FastBlur / GaussianBlur 不允许全屏或面板级使用；只允许 ≤32px 小控件或预烘焙贴图。
  • 禁逐帧 JS 动画：不允许 Timer/onXxxChanged 手写插值驱动视觉动画；一律 Behavior / NumberAnimation / Transition（走渲染线程）。
  • 布局属性动画收敛：x/y/width/height 会触发布局，优先 opacity / transform（scale、rotation、translate）；高度折叠包一层 clip wrapper。
  • ListView/GridView：delegate 内任何 Infinite 动画必须 running: visible（或 paused: !visible）；cacheBuffer 设为一屏以上（建议 600）；delegate 保持轻量、避免 Loader 嵌套。
  • layer.enabled 仅在旋转/透明合成必要时开启，用完置回 false；禁止整窗 layer。
  • 循环动效存在感上限：流光 alpha ≤ .09、骨架扫光 ≤ .08、呼吸 opacity 摆幅 ≤ .55——动效是"低语"不是"喊话"。

4 · reduced-motion 降级开关

  • 设置页新增「减少动效」→ Theme.reduceMotion；本页顶栏开关即该降级态的现场演示。
  • 时长统一经 Theme.dur(ms)：降级时归 0，但保留 ≤80ms 的 opacity 淡入作底线（完全无过渡会让状态变化不可感知）。
  • 循环类（呼吸 / 流光 / 扫光）降级时直接 running: false，停在静态中间帧。
  • count-up 降级时直接落终值；Toast 降级时瞬时出现、停留延长到 6s 保证可读。
  • 焦点环、选中条、✓ 完成态等"位置/状态"信息降级后必须仍然可见——动效可以省，信息不能省。
