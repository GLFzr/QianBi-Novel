**裁决二（Q1-b 架构）**：三臂盲评统计无差（±0.07），机器指标亦全部进真人区间——**在 W2/W3/W4 修复就位后，上下文架构对质量不再敏感**。这意味着三测的「单调劣化」主凶不是纯注意力稀释，而是破坏性改写链（P0-2）+ 生成侧零防味（P1-3）+ 无开篇工程（P1-4）的组合；P0-1 的权重被三测归因高估。

**修正后的因果结论**（供后续迭代参考）：质量修复的主力是 W2（改写环去破坏化+净增益闸）与 W3/W4（防味+开篇工程）；W1 的价值转为**成本**（-93% 输入 token）与**稳定性**（退出 192k 窗口的 90% 占用区，给长书留余量），而非盲评质量本身。
