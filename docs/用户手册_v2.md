## 0. 这份手册怎么用

三类读者，三条最短路径：

| 你是谁 | 最短路径 |
|---|---|
| **还没装** | 第 1 章（安装）→ 第 2 章（5 分钟演示，不用 Key）→ 第 3 章（贴 Key）→ 第 4 章（建书）→ 第 5 章（共写六阶段） |
| **急着出第一章** | 第 1 章 → 第 3 章 → 第 4 章 → 第 5 章的「阶段⑥正文写作」小节（应用会在你进正文阶段时自动打开第 1 章稿纸） |
| **已经写了几十章的老手** | 第 7 章（世界书与正则）→ 第 8 章（追踪与反哺）→ 第 10 章（Agent 指令速查）→ 第 9 章（备份） |

两个贯穿全书的事实，先说在前面：

- **你的数据全在本机**。书稿是普通文件夹（默认 `Documents\千笔一文\`），配置与账本在
  `%USERPROFILE%\.qianbi_novel\`；唯一自动对外请求是检查更新（可关）。
  逐条清单见 [PRIVACY.md](PRIVACY.md)。
- **你是作者，AI 是共写伙伴**。每一步「确定」都等你按下；每一道质量门停靠时都会说清
  拦了什么、继续与回退各会发生什么。它不会在你不知情时改稿、不会无限重试烧钱。

## 1. 安装与首次启动

### 1.1 下载与安装

- 去 [Releases](https://github.com/GLFzr/QianBi-Novel/releases/latest) 下载：
  - **安装版**（推荐）：`QianBi-Novel-v<版本号>-setup.exe`，免管理员安装（per-user），
    创建桌面快捷方式，可在「设置 → 应用」里卸载（卸载保留书稿）；
  - **便携版**：`QianBi-Novel-v<版本号>-portable.zip` 解压双击即用，不写注册表、
    不建快捷方式、无卸载入口——删文件夹即清除。包内附《使用说明.txt》。
- 每个版本都附 `SHA256SUMS.txt`，不确定文件有没有被动过就核对一下哈希
  （PowerShell：`Get-FileHash <文件> -Algorithm SHA256`）。
- **双击时 Windows 可能弹蓝底的「已保护你的电脑」**：安装包没有代码签名证书
  （独立项目年费不划算，这是明说的取舍），那是缺证书，不是文件坏了——点
  **「更多信息」→「仍要运行」**。系统要求 Windows 10/11 x64，无需安装 Python。

### 1.2 首次启动：两步向导

第一次打开应用会出**两步向导**：

1. 第一步是使用协议勾选，勾上才能下一步；这一步同时会做一次更新检查
   （默认开、24 小时最多一次、只下载约 1KB 公开清单，可在「更新」面板关掉——
   关掉后启动阶段零请求；离线机器等它逐条试完不影响进入应用）。
2. 第二步是**连接就绪清单**：写作 / 辅助 / 审校三个槽位各自的 Key 与模型
   配齐状态一目了然，按清单去 **设置 → 连接与模型** 配好（见第 3 章），
   三槽亮齐就能开写。

### 1.3 你的数据在哪（两个目录，备份要一起拷）

| 里面装什么 | 位置 |
|---|---|
| 配置、预设、日志、用量账本、自动备份 | `C:\Users\你\.qianbi_novel\` |
| **全部书稿**（正文/设定/大纲/追踪/版本历史/草稿） | `C:\Users\你\Documents\千笔一文\<书名>\`（新建书时可改保存位置） |

程序本体（安装目录）里**没有**你的任何数据：安装、升级、卸载都只动程序目录。
**手动备份 = 把上面两个目录各拷一份**——只拷 `.qianbi_novel` 会丢掉全部书稿
（应用内自动备份见第 9.4 节，但异机拷贝仍靠你自己）。

## 2. 先看 5 分钟演示（无需 Key）

第一次打开应用，书架是空的。空态里有 **「先看 5 分钟演示（无需 Key）」** 入口：
它用一本演示书把「贴 Key → 建书 → 六阶段 → 出正文」整个流程演一遍，
**不花一分钱、不碰你的任何配置**——演示全部内容来自随包回放数据，
演示模式下任何真实 API 调用都会被拦下并提示（`演示模式不调用真实 API`）。

- 演示的书叫**《种子书》**（都市悬疑，随包内置），它本身就是一本真实 API 生成的
  完整项目：设定、大纲、正文、追踪四个目录齐全。演示之外你也可以直接读它的文件——
  源码仓库在 `assets/demo/book/`，安装用户随包同款。
- 看完想上手自己的书：演示面板点 **「跳过演示」** 退出，回书架点 **「新建项目」**。
- 演示书打有标记，随时可关，不会混进你的书架。

## 3. 贴上 API Key（BYOK）

千笔一文自带模型连接，不内置任何 Key——你自己去模型服务商开个账号、建一个
API Key，贴进应用就行（「自带钥匙」= BYOK，费用直接按你的用量付给服务商，
本应用不抽成）。

### 3.1 推荐路径（五步）

1. 打开 **设置 → 连接与模型**。出厂已预置 12 家平台（DeepSeek / 阿里云百炼 / 智谱 /
   Kimi / 火山方舟 / 腾讯混元 / MiniMax / 硅基流动 / OpenRouter / Gemini / xAI / Groq）。
2. 选 **「DeepSeek 官方 Flash（推荐）」**——出厂三个任务槽位（写作/辅助/审校）
   都指向它，填一把 Key 就能跑通全流程。
3. 把 Key 粘贴进表单，点**保存**。Key 立即存入 **Windows 凭据管理器**，
   配置文件（`config.json`）里只留一个指向它的指纹，**不落明文**。
4. **选模型（最容易被漏掉的一步）**：表单有候选下拉，也可以点**「拉取」**
   拿你账号的实时模型列表。出厂预设**故意不带模型名**（模型是各家变得最快的参数，
   写死必过期）。「测试连接」通过 ≠ 能写作——0.20.2 起，测试连接时会顺带检查：
   连接通但没选模型，会给你**黄牌提示**「连接正常，但这条连接还没选模型」，
   配置类错误在花一分钱之前就暴露。
5. 点**测试连接**，通过且模型已选，就可以去第 4 章建书了。

### 3.2 三槽位与换模型

- 三个槽位（写作 / 辅助 / 审校）可以指同一条连接，也可以各配各的——
  审校槽用便宜些的模型是常见省钱配法。
- 内置提示词按 DeepSeek 的参数习惯调校。其他 OpenAI 兼容平台协议上是通的
  （中转与本地 Ollama / LM Studio 走「自定义（OpenAI 兼容）」），但写作质量与
  闸门收敛不保证同一水准——换模型后建议先跑三章，看看闸门判不判得住。
- 0.20.2 起客户端带**容错四件套**：超时/断流自动重试、空回复换法重发、
  失败原因人话化（详见 [排障页](排障_v1.md) 前 12 条）。

### 3.3 Key 的安全边界

- Key 只进 Windows 凭据管理器，日志与崩溃现场统一脱敏，不出现在明文配置里。
- **删除一个连接 = 它的 Key 一起从凭据管理器里删掉**（应用会两步确认）；
  只剩最后一条连接时不允许删。
- 升级/退役出厂预设行时，改过、在用、存过 Key 的连接一律原样保留。

## 4. 建第一本书

书架 → **新建项目**：填书名（唯一必填），选一套**题材预设**（修仙·凡人流 /
都市改命 / 克苏鲁 / 规则怪谈 / 无限流 / 末日废土 / 历史权谋……共 10 套，
每套带 6 阶段特化提示），选平台与目标字数，选保存位置（默认 `Documents\千笔一文\`）。

- **新书默认进共写档**（老书保持原来的档位，升级不会偷偷改）。
- 创建成功的提示会**按档位指路**：共写档新书提示的是「共写第一步：在共写区
  『选题』填一句话灵感」；此时流水线面板原来的「开始」按钮位置会变成
  **「去共写 · 创建项目」**，点它直接定位到共写区当前阶段。
- 手里已有几十章旧稿？外部设定/正文导入走书架的**导入**入口
  （Agent 只拆文档里真有的部分，预览映射确认后才落盘），
  完整说明见 [examples/README.md](../examples/README.md)。

## 5. 共写六阶段（默认档）逐阶段指南

共写档把长篇拆成六步，每一步都是「你和对应的 Agent 讨论 → 满意了点 **✓ 确定**
定稿 → 进下一阶段」。共写区顶部的六张阶段卡（创建项目 → 核心设定 → 剧情总大纲 →
世界书与正则 → 单元细纲 → 正文写作）随时可点回看已完成阶段的产物。

每个阶段都支持两条路：直接在对话区聊（「主角动机太顺了，加一个代价」），
或点 **「生成草案」** 让 Agent 先出一版你再挑毛病。**空对话点「确定」会被拦**
（提示你先聊出实质内容再定稿）——这是防止拿空产物落盘。

### 5.1 阶段① 创建项目（选题）

- 左侧是**选题表单**：题材、平台、目标字数、一句话灵感。填完保存，
  提示「选题信息已保存，点『确定』进入核心设定」。
- 本阶段对话区暂不收自由文本（留痕提示，不算故障）——要聊先按表单定盘子。

### 5.2 阶段② 核心设定 / 阶段③ 剧情总大纲

- 各自与设定 Agent / 大纲 Agent 多轮讨论，或点 **「生成草案」** 出初稿。
- 点 **「✓ 确定」** 触发一次总结定稿（一次 LLM 调用，约 30-60 秒），
  产物落盘并交接给下一阶段。定稿成功后 toast 会**预告下一步**是什么、怎么走。

### 5.3 阶段④ 世界书与正则

- 与世界书 Agent 讨论产出**世界书**（设定条目）与**正则约束**（规则清单）。
- 「正则」默认语义是**逻辑约束规则集=必须成立的规则清单**——不用懂正则表达式；
  要写机判规则才用正则语法（见第 7 章）。
- 硬规则（must 级）会注入之后每一章的写作 prompt，并在章成稿后确定性复检。

### 5.4 阶段⑤ 单元细纲

- 先登记**单元范围与主题**：范围默认预填 `1 ~ 10`（±10 章内可浮动，跨度超限
  登记时就会提醒「建议拆单元——细纲质量在小批次更稳」）。
- 点 **「↻ 生成下一批」** 滚动生成下一批 5 章细纲；点 **「✓ 确定细纲」**
  定稿本单元——定稿前会校验衔接/世界书/正则契约，**阻塞项逐条列出**，改了再验。
- 细纲生成时带**章首/章尾钩子**约束：0.20.2 起钩子走受控词表
  （悬念缺口/危机迫近/反转揭示/两难抉择/承诺威胁/意象异变/情绪定格七型），
  按剧情压力分档路由，低压章不强求钩子。

### 5.5 阶段⑥ 正文写作

- 进入本阶段时应用会**自动打开第 1 个未锁章的稿纸**（toast 交代「已为你打开
  第 N 章」）；也可在共写区或「章节」面板自己开章。
- 点 **「生成草案」** 出第一版正文 → 不满意就在对话区说哪里不对，或手改后让
  读改 Agent 揣摩 → 满意点 **「✓ 确定」**。
- 「确定」后**主 Agent 做跨章衔接比对**：结论是放行/需调整/有疑问三种，
  「需调整」不会直通锁定；你确认无碍可「仍要锁定」——越权出口会留痕。
- 终稿要锁定时，**审校结论与阻断问题摆在你面前**，你放行才落库（详见第 6.3 节）。

### 5.6 实操节奏三句话

- **对草稿不满意就聊**：Agent 改完你再「确定」；
- **可以直接下指令**：「回退到去味之前」「重写第 2 章，铺垫再足一点」「重新生成
  第 3 章的细纲」——Agent 真的去操作应用，破坏性操作先归档留底
  （「关于 → 打开数据目录」下可取回），执行结果回显在对话区（速查表见第 10 章）；
- **定稿前的门会停**：不会跳过你落库。

## 6. 自动档与九道门

### 6.1 两种档位

流水线面板顶部两个互斥选项：

- **共写**（默认）：六阶段，每步插手，适合精写；
- **全自动**：你定方向，流水线自己跑完每章微循环（草稿 → 字数闸门 → 去味 →
  六维审校 → 清算 → 落库），适合批量补章。

### 6.2 决策门预置：决定流水线「停不停下来问你」

「全自动」档下，面板上有**决策门**区两个互斥开关（可同时关）：

| 状态 | 行为 |
|---|---|
| **全放行**（两开关同关） | 一路连写不停靠（见术语表「连写旁路」） |
| **逐步确认** | 每道决策门都停，等你确认 |
| **边界确认** | 只在你勾选的大节点停（出厂勾大纲/开写/审校/定稿） |

- 每道门停靠时都会说清三件事：**拦的是哪一条、当前值 vs 阈值、继续与回退分别
  会发生什么**。
- 被拦还可以**强锁**（「仍要锁定」），强锁逐条留痕——「关于」弹窗的
  「强锁审计痕」区可回看，另有「打开门回退归档」「打开 Agent 归档」入口。
- 0.20.2 护栏：扩写环后插入**字数预算断路器**——稿子远超字数预算（出厂 3 倍，
  可配）时直接熔断标「待人工」，不把无效稿送进后续闸门烧 token；
  审校/去味反馈环依旧 3 轮熔断，不收敛的章标「待人工」。

### 6.3 三层审校与人工审校模式

- **L0 确定性预检**（本地、零成本）：专名错写、数字失配、复读段、AI 味特征先扫一遍；
- **6 维 LLM 终审**：含**引证验真**（审校引用的原文必须真实存在，编造的引证当场
  作废，三票投票降噪）；
- **反馈环定向修复**：REJECT 带根因与修法再改，3 轮不收敛标「待人工」。
- **人工审校模式**：不想让审校模型花钱？设置里开启后，定稿门里**你自己填阻断问题
  （每行一条）**，AI 只按「最小改动纪律」修你指的问题——审校模型调用归零。

### 6.4 去味与度量（0.20.2）

- 去味改写环（最多 2 轮）由本地 **AI 味扫描**（零成本正则）驱动；0.20.2 起带
  **度量层**：AI 味特征密度、节奏、连接度等指标随章记录落盘，改写前后可比。
- 采纳去味改写稿前有**双重复扫**：去味规则复扫 + must 契约指纹复扫——
  改写稿若比原稿**净新增**违规（或复用同族口癖），本轮改写直接拒绝并回退。
  改写接受还有**字数保持率护栏**（不许借去味大幅缩水或膨胀）。

## 7. 世界书与正则契约

### 7.1 世界书：设定怎么被记住

世界书是**条目化**的：设定按条目登记、按锚点激活、按预算注入——长设定不会在
500 章后被整团截断。写作时按「**常驻 > 本章命中 > 近章登记 > 节权重**」的优先级
把条目装进本轮预算，装不下的整条放弃并留痕（`activated` / `dropped` 都有账）。

- 四种写法都认：粗体反哺行 / `### 名` + 属性行 / `- 名：述` / 表格行；
  同名条目按「归一化名#节」合并。
- 正文里冒出来的新设定会经**剧情反哺**自动回写世界书与追踪表（见第 8 章）。
- 「关于」弹窗 → 「打开书稿目录」→ `设定/世界书.md` 直接编辑也行——
  它就是普通 md 文件，应用下次装配按文件现状读。

### 7.2 正则契约：硬规则怎么被兑现

`设定/正则.md` 里的规则分两档：

- **must 级（硬约束）**：注入每一章的写作 prompt，成稿后由本地确定性扫描复检——
  命中禁止模式/缺失要求模式会进阻断清单拦锁定。带正则 `pattern` 的规则可机判；
  自然语言规则注入有效但机判不了（复检跳过，不算错）。
- **建议级**：注入 prompt 提醒，不机判。
- 诚实边界：**注入不等于执行**——模型仍可能偶尔越界，这正是确定性复检存在的
  理由：越界会在锁定前被机器抓出来，而不是靠你通读 300 章去发现。

## 8. 追踪文件与剧情反哺

每本书的 `追踪/` 目录有四份可读文件（普通 md/json，随时可查）：

| 文件 | 记什么 |
|---|---|
| `角色状态.md` | 出场角色的当前状态（含近章更新） |
| `伏笔.md` | 埋设/回收状态与**回收窗口**（如「第40-45章」） |
| `时间线.md` | 故事内时间推进 |
| `章节摘要.md` / `全局摘要.md` | 摘要链（前情注入的来源） |

- **剧情反哺**：正文里冒出来的新设定（新人物/新规则/伏笔变动）自动回写世界书与
  追踪表，让后面的章节接着用——而不是各写各的。反哺有幂等与对账护栏；
  0.20.2 起若出现「已锁定但反哺未跟上」的不一致，主界面会出**常驻横幅点名**
  相应章节，一键补跑即可。
- **伏笔到期对照（0.20.2）**：超期伏笔在生成细纲与审校时会被自动核对——
  超期又没有「回收/改期」安排的伏笔会出声提醒（warn + 事件账），不阻断但瞒不住。
- 0.20.2 起每章开写前注入**七栏状态卡**（当前位置 / 下一章承诺 / 活跃伏笔·
  作者真相 / 核心角色状态 / 长期约束 / 近三章速记·读者已知 / 连贯性风险），
  全部由本地追踪文件算出、零 LLM——「下一章」不靠对话记忆，靠账本。

## 9. 阅读器、版本、导出与备份

### 9.1 阅读器

全屏沉浸（F5）、三主题（夜间/羊皮纸/纯白，Ctrl+T 循环）、选中文字可三色高亮 +
批注 + 灵感直通创作笔记，每章记住读到哪，支持多书签。

### 9.2 版本与草稿

- **保存驱动**：只有点「保存」才产生版本（每章保留 30 版，Ctrl+B 看版本历史，
  可 diff 可回退）；
- 另有 5 秒防抖草稿暂存，崩溃/断电后再开应用会问你要不要恢复；
- 自动档断点实时落盘（`pipeline_state.json`），重启从断点续跑，不重跑已完成的章。

### 9.3 导出

工具条 **「导出」**：txt / epub 一键导出（带排版选项与即时预览，导出后见报告）；
另有「导出对话记录 (可读TXT / JSONL)」。

### 9.4 备份与自动备份（0.20.2）

- 手动：设置 → 项目备份 → **「立即备份 zip」**（全量 zip）。
- **自动备份（默认开）**：三个时机会对打开过的书自动 zip 一份——**打开项目时 /
  关书换书时 / 退出应用时**；同一本书同一天只备一份，自动保留**最近 5 份**，
  落在 `%USERPROFILE%\.qianbi_novel\backups\<书名>\`。开关在
  设置 → 项目备份。自动备份是兜底不是替代——跨机迁移仍请把第 1.3 节两个目录拷走。

## 10. Agent 对话指令速查

在共写对话区（或自动档 Console）可以直接下指令，Agent 会去操作应用。
规则说不清的会交给 LLM 兜底理解；**破坏性操作（回退/重写/重生成）会先归档留底**。
高频指令与例句：

| 你想做什么 | 可以这样说 |
|---|---|
| 撤掉某一步重跑 | 「回退到去味之前」「把断点回退到扩写那一步」「从审校重新来一遍」 |
| 重写某一章 | 「重写第 2 章，铺垫再足一点」「刚才那章的结尾太仓促了，重来一遍」 |
| 重出细纲 | 「重新生成第 3 章的细纲」「细纲和正文对不上，推倒细纲重新排」 |
| 看某章正文 | 「看看第 3 章正文」「看看最新这章」「读一下当前章」 |
| 问进度 | 「现在进度怎么样」「写到第几章了」（也有 `/状态`） |
| 开关设置 | 「开启离峰挂机」「开启连写模式」「把 AI 审校关掉，我自己来」 |
| 世界观对账 | 「帮我做一次世界观对账」 |
| 细纲体检 | 「校验一下本批细纲衔接」「细纲体检」 |
| 存个想法 | 「把我的选题备注存一下」「记一下选题想法」 |

三条纪律：

- 指令要**有宾语**：「重写」「回退一下」这种没头没尾的会被当作普通聊天
  （宁可不理解，不能猜错对象）；
- 回退/重写类操作**先归档再执行**，归档在书的 `pipeline_debug/` 下，
  「关于 → 打开数据目录」可取回；
- 越是破坏性强的指令，回执越完整——执行了什么、影响哪些章，都会回显在对话区。

## 11. 对话记录与报障包

### 11.1 对话记录落盘（默认开，仅本地）

每一次 AI 调用（完整提问、回复、模型与槽位、成败、耗时与 token）都会写进
**书内 `.dialogue/` 目录**（JSONL 分片，单片 5MB、默认 40 片封顶自动删最旧）。
它**只存在你机器上、不上网**；流水线面板有「对话记录」开关，可整体停写、
可一键「打开对话记录」目录。这项记录随项目备份 zip 一起走。

### 11.2 用量账本（token 花在哪，逐笔可查）

- `%USERPROFILE%\.qianbi_novel\usage\usage.jsonl` 每行一条调用记录，字段：
  `ts/ymd`（时间）、`slot`（写作/辅助/审校）、`model`、`in/out`（token）、
  `hit/miss`（缓存命中/未命中）、`phase`（章节与步骤）、`reasoning`、`latency`。
- 应用内工具条的**用量统计**面板（今日/本月/按模型，本地数据）读的就是它；
  0.20.2 起有**准实时告警**：单章成本超阈值、下一章开写而上一章在台账里没有记账
  等异常会主动出声。
- 离峰挂机：DeepSeek 高价时段（北京时间白天）流水线可自动等待半价时段再跑
  （流水线面板「离峰挂机」开关）。

### 11.3 一键报障包

遇到问题要反馈时，**导出对话框**里有两个按钮：

- **「一键报障包（含书稿正文，Key 已脱敏）」**——对话记录 + 程序日志 + 版本 +
  脱敏配置摘要打成一个 zip，开发者能直接看到现场；
- **「报障包（仅日志，不含书稿）」**——对话记录就是书稿正文，你有权只发日志。

两种包都做了脱敏：Key 相关字段整段剔除、家目录路径替换成 `<HOME>`、日志只取尾部、
对话只取最近分片。发 [Issue](https://github.com/GLFzr/QianBi-Novel/issues/new/choose)
时附上报障包，是最有效的反馈方式。

## 12. 出问题了怎么办

**先去 [排障页（出问题了怎么办）](排障_v1.md)**——22 条报错文案对照表，
每条都是「你看到什么（屏幕原文）→ 意味着什么 → 现在做什么 → 还不行就报障包」，
文案逐字取自源码、由 `scripts/check_docs.py` 钉死不漂移。速记版：

- **安装被拦**（蓝框「已保护你的电脑」）→ 缺证书不是坏文件，「更多信息 → 仍要运行」；
- **连接类报错**（401 / 超时 / 域名解析失败 / 没选模型）→ 排障页 1-12 条逐一对症；
- **保存失败 / 阶段没推进** → 排障页 13-15 条（都不会静默丢稿）；
- **点「开始」被拦** → 大概率你的书在共写档，「开始」是自动档的按钮——
  从共写区当前阶段继续，或在流水线面板切「全自动」；
- **更新装不上 / 指纹不符** → 排障页 20 条，完整性闸门拦的就是来路不明的包。

**现场保命三招**（崩溃 / 断电 / 改崩了）：

1. **断点续跑**：`pipeline_state.json` 记录流水线断点，重开应用接着跑；
2. **防抖草稿 + 版本**：5 秒防抖草稿 + 30 版/章，diff 与回退随意；
3. **审校不收敛不会烧钱**：3 轮熔断标「待人工」，不会无限重试。

**日志与现场三件套**的位置、报障包怎么打，见排障页文末。
安全漏洞报告渠道见仓库根 [SECURITY.md](../SECURITY.md)。

## 13. 常见问题 FAQ

**Q1：双击安装包，Windows 说「已保护你的电脑」？**
安装包没有代码签名证书（明说的取舍），SmartScreen 会对没有声誉记录的新文件拦一道。
点「更多信息 → 仍要运行」；不放心就先核对 SHA-256 与 Release 页列出的一致。

**Q2：我的 API Key 存在哪？安全吗？**
存 Windows 凭据管理器（系统级加密存储）。`config.json` 里只有一个指向它的指纹，
日志、崩溃现场、报障包都做了脱敏。明文 Key 只在你粘贴后进一次系统凭据库。

**Q3：删除连接，Key 会残留吗？**
不会残留，也**不会单独删**：删除连接 = 它的 Key 一起从凭据管理器消失（两步确认）；
只剩最后一条连接时不许删。退役的出厂预设行只清理「没改过、没在用、没存过 Key」的。

**Q4：怎么更新？**
左栏出现下载角标 → 打开「更新」面板（或「关于 → 更新…」），四条路同一屏：
GitHub 连得上就一颗按钮 **「下载并自动安装 v<版>（会退出应用）」**——下载、验签、
5 秒可取消倒计时、自动安装一气呵成：应用自动退出、安装器静默跑完、自动重开并提示
「已更新到 vX」；连不上就手动下包后「选择已下载的安装包」对哈希，对上后点
「立即安装 v<版>」；连清单都拿不到就「导入离线清单」。清单要过 Ed25519 验签、
安装包要对上 SHA-256，两条有一条不过，安装按钮不会出现。
若启动时提示「上次更新没有完成」，按提示用面板里保留的安装包手动装一次即可。

**Q5：断网了还能用吗？**
阅读、编辑、批注、导出、备份都是本地的，断网可用；**生成正文必须联网调模型 API**。
应用不会宣称「离线也能下包」——它做的是把「有没有新版」降成 1KB 清单、
把离线导入的路修好，但下载安装包本身总得有一次连通。

**Q6：换别的模型行不行？**
协议上通（OpenAI 兼容均可，含本地 Ollama / LM Studio），但提示词按 DeepSeek 调校，
质量与闸门收敛不保证同一水准——换后先跑三章看看。

**Q7：写一本书大概花多少钱？**
两个口径都为真，看你怎么用（N-35 收口口径）：测试脚本压到极限是 5 章 ≈ ¥0.07
（加速档 + 固定文本，不是产品默认配置）；产品默认配置完整跑（含审校/清算/反哺）
量级参考 ¥0.25/章（v0.19.8 同书同渠道 13 章真跑、离峰价）。挂机离峰跑批更省。
**每笔调用都记在 `usage.jsonl`**（第 11.2 节），花在哪看得见——别信任何人的
一口价，包括我们的，信你自己的账本。

**Q8：升级会不会弄丢我的书？**
不会，这是有机器保证的：安装器只写程序目录，书稿与配置都在它之外；卸载只删程序文件；
新版读旧配置按键补齐，看不懂的键与你自建的连接都保留；配置万一损坏，先另存
`config.json.broken-<时间戳>` 再回落默认，不静默丢弃。另外 0.20.2 修掉了
多线程同时写配置丢更新的一类隐患（保存前重读合并）。

**Q9：写到一半崩溃/断电了怎么办？**
断点状态实时落盘（`pipeline_state.json`），重启后从断点续跑；正文有 5 秒防抖草稿
与 30 版/章的版本历史兜底；崩溃现场自动留档（已脱敏），可打包发我们。

**Q10：我的书稿会被上传吗？**
不会。数据不出本机，唯一自动对外请求是检查更新：默认开、24 小时最多一次、
只**下载**约 1KB 公开清单、不上传任何内容，面板里可关（关掉后启动阶段零请求）。
遥测默认关闭且只写本地文件；对话记录本地落盘且可关。详见 [PRIVACY.md](PRIVACY.md)。

**Q11：`usage.jsonl` 打开是乱的，怎么读？**
JSONL = 每行一个独立 JSON 对象，记事本看着挤是正常的；用任何支持 JSON 的编辑器
按行看。字段说明见第 11.2 节。它是纯文本，删除即清零（统计面板随之归零），
删前想想是否要留着对账。

**Q12：换电脑怎么迁移？**
拷第 1.3 节两个目录到新机同位置（`.qianbi_novel\` 与 `Documents\千笔一文\`）。
注意 **Key 不会跟着走**（凭据管理器是系统级的），新机重新贴一次即可；
在写的书建议先「立即备份 zip」一份带过去，双保险。

**Q13：安装版和便携版能换着用吗？**
能，两种版本共用同一套数据目录，换着用书稿不丢。区别只在程序本体装不装：
安装版有快捷方式与卸载入口，便携版什么都不写。升级时各升各的，别交叉覆盖程序目录。

**Q14：能同时写好几本书吗？演示书怎么删？**
能，书架就是多书管理，书与书互不干扰。自动备份按书名分目录各自保留。
演示书是随包资产，不在你的书稿目录里，不需要删；退出演示即可。

**Q15：自动备份在哪？能关吗？**
`%USERPROFILE%\.qianbi_novel\backups\<书名>\`，同书同日一份、保留最近 5 份。
开关在 设置 → 项目备份。关掉后只剩手动「立即备份 zip」——不建议关，
它每天最多写一个 zip，开销可忽略。

## 14. 术语表

界面上会碰到这些词，都是「圈内黑话」的精简版：

| 术语 | 意思 |
|---|---|
| **两档制** | 共写档（默认，六阶段每步插手）与全自动档（批量跑章）两种运行方式，同一套质量内核，切换在流水线面板 |
| **门停靠** | 流水线跑到某道决策门时停下来，说清「拦了哪条 / 当前值 vs 阈值 / 继续与回退的后果」，等你放行 |
| **强锁** | 门拦着但你确认要过——「仍要锁定」。不是后门：逐条留痕，「关于」弹窗的强锁审计痕区可回看 |
| **must 契约** | 正则约束里的硬规则（must 级）：注入每章 prompt + 成稿后本地确定性复检，越界拦锁定 |
| **引证验真** | 审校引用的「原文」必须在正文里真实存在，编造的引证当场作废；三票投票降噪 |
| **清算** | 正文写完后，拿它跟世界观底册逐条对账：真冲突（违反）/ 合理新料（收编）/ 应回写台账（台账回写）三分类。便宜模型先预扫，有硬伤才请强模型复核疑点 |
| **反哺** | 正文里冒出来的新设定（新人物/新规则/伏笔变动）自动回写世界书与追踪表，让后面的章节接着用 |
| **状态卡** | 0.20.2 起每章开写前注入的七栏账本摘要（当前位置/下一章承诺/活跃伏笔/角色状态/长期约束/近三章速记/连贯性风险），全部本地算出，零 LLM |
| **钩子** | 章首/章尾的悬念设计。0.20.2 起走七型受控词表（悬念缺口/危机迫近/反转揭示/两难抉择/承诺威胁/意象异变/情绪定格），按剧情压力分档，低压章不强求 |
| **度量层** | 0.20.2 起随章记录的文本指标（AI 味特征密度/节奏/连接度等），去味改写前后可比，零 token 成本 |
| **离峰挂机** | 流水线在模型高价时段自动等待、半价时段再跑（DeepSeek 分时价口径） |
| **命中价** | 模型服务商对「缓存命中的输入」按折扣计价（DeepSeek 缓存命中约为原价十分之一）。提示词装配架构（稳定前缀 + 章会话）就是为把输入尽量变成命中价设计的 |
| **连写旁路** | 决策门两开关同关时，流水线不停靠任何闸门直接连写到底。快，但没人拦你，适合挂机跑批 |
| **报障包** | 一键打包含现场（对话记录/日志/版本/脱敏配置）的 zip，两档：含书稿 / 仅日志。发 Issue 时附上它最有效 |
