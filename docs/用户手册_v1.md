# 千笔一文 · 用户手册 v1

> **读者**：第一次使用千笔一文的作者。这份手册只讲「你怎么把书写出来」，
> 不讲内部实现——想看设计取舍与裁决记录的，去 `docs/` 其他文档。
> 口径对应版本：0.20.0（待发布）。有出入时以应用内界面为准，并欢迎提 Issue 指出来。

---

## 1. 安装与首次启动

### 1.1 下载与安装

- 去 [Releases](https://github.com/GLFzr/QianBi-Novel/releases/latest) 下载：
  - **安装版**（推荐）：`QianBi-Novel-v<版本号>-setup.exe`，免管理员安装，创建桌面快捷方式；
  - **便携版**：`QianBi-Novel-v<版本号>-portable.zip` 解压双击即用，不写注册表，删文件夹即清除。
- 每个版本都附 `SHA256SUMS.txt`，不确定文件有没有被动过就核对一下哈希。
- **双击时 Windows 可能弹蓝底的「已保护你的电脑」**：安装包没有代码签名证书（独立项目
  年费不划算，这是明说的取舍），那是缺证书，不是文件坏了——点
  **「更多信息」→「仍要运行」**。系统要求 Windows 10/11 x64，无需安装 Python。

### 1.2 首次启动：先看 5 分钟演示

第一次打开应用，书架是空的。空态里有 **「先看 5 分钟演示（无需 Key）」** 入口：
它用一本演示书把「贴 Key → 建书 → 六阶段 → 出正文」整个流程演一遍，不花一分钱、
不碰你的任何配置。演示书打有标记，随时可以关掉——看完直接建你自己的书就行。

### 1.3 你的数据在哪（两个目录，备份要一起拷）

| 里面装什么 | 位置 |
|---|---|
| 配置、预设、日志、用量账本 | `C:\Users\你\.qianbi_novel\` |
| **全部书稿**（正文/设定/大纲/追踪/版本历史/草稿） | `C:\Users\你\Documents\千笔一文\<书名>\`（新建书时可改保存位置） |

程序本体（安装目录）里**没有**你的任何数据：安装、升级、卸载都只动程序目录。
**备份 = 把上面两个目录各拷一份**——只拷 `.qianbi_novel` 会丢掉全部书稿。

## 2. 贴上 API Key（BYOK）

千笔一文自带模型连接，不内置任何 Key——你自己去模型服务商开个账号、建一个 API Key，
贴进应用就行（「自带钥匙」= BYOK，费用直接按你的用量付给服务商，本应用不抽成）。

### 2.1 推荐路径

1. 打开 **设置 → 连接与模型**。出厂已预置 12 家平台（DeepSeek / 阿里云百炼 / 智谱 / Kimi /
   火山方舟 / 腾讯混元 / MiniMax / 硅基流动 / OpenRouter / Gemini / xAI / Groq）。
2. 选 **「DeepSeek 官方 Flash（推荐）」**——出厂三个任务槽位（写作/辅助/审校）都指向它，
   填一把 Key 就能跑通全流程。
3. 把 Key 粘贴进表单，点**保存**。Key 立即存入 **Windows 凭据管理器**，
   配置文件（`config.json`）里只留一个指向它的指纹，**不落明文**。
4. 选模型：表单有候选下拉，也可以点「拉取」拿你账号的实时模型列表（出厂预设故意不带
   模型名——模型是各家变得最快的参数）。
5. 点**测试连接**，通过了就可以去建书。

### 2.2 关于换模型

内置提示词按 DeepSeek 的参数习惯调校。其他 OpenAI 兼容平台协议上是通的
（其余中转与本地 Ollama / LM Studio 走「自定义（OpenAI 兼容）」），但写作质量与
闸门收敛不保证同一水准——换模型后建议先跑三章，看看闸门判不判得住。

### 2.3 Key 的安全边界

- Key 只进 Windows 凭据管理器，日志与崩溃现场统一脱敏，不会出现在明文配置里。
- **删除一个连接 = 它的 Key 一起从凭据管理器里删掉**（应用会两步确认）；
  只剩最后一条连接时不允许删。
- 升级/退役出厂预设行时，改过、在用、存过 Key 的连接一律原样保留。

## 3. 建第一本书

书架 → **新建**：填书名，选一套**题材预设**（修仙·凡人流 / 都市改命 / 克苏鲁 /
规则怪谈 / 无限流 / 末日废土 / 历史权谋……共 10 套，每套带 6 阶段特化提示），
选平台与目标字数，选保存位置（默认 `Documents\千笔一文\`）。

0.20.0 起，**新书默认进共写档**（老书保持原来的档位，升级不会偷偷改）。

## 4. 共写六阶段（默认档）怎么走

共写档把长篇拆成六步，每一步都是「你和对应的 Agent 讨论 → 满意了点**确定**定稿 →
进下一阶段」：

| 阶段 | 你在和谁聊 | 「确定」之后发生什么 |
|---|---|---|
| ① 创建项目 | — | 立项信息落盘 |
| ② 核心设定 | 设定 Agent | 总结定稿，交接给下一阶段 |
| ③ 剧情总纲 | 大纲 Agent | 定稿大纲 |
| ④ 世界书与正则 | 世界书 Agent | 逐条对账契约（硬规则以 must 级注入之后每一章） |
| ⑤ 单元细纲 | 细纲 Agent | 校验衔接，滚动生成下一批 5 章细纲 |
| ⑥ 正文写作 | 写作 Agent | 主 Agent 做跨章衔接比对 → 终稿锁定 |

实操节奏就三句话：

- **对草稿不满意就聊**：直接在对话区说哪里不对（「主角动机太顺了，加一个代价」），
  Agent 改完你再「确定」；
- **可以直接下指令**：「回退到去味之前」「重写第 2 章，铺垫再足一点」「重新生成第 3 章的
  细纲」——Agent 真的去操作应用，破坏性操作先归档留底（可在「关于 → 打开数据目录」取回），
  执行结果回显在对话区；
- **定稿前的门会停**：正文要锁定时，审校结论与阻断问题会摆在你面前，你放行才落库。

## 5. 自动档与门开关

### 5.1 两种档位

- **共写档（默认）**：六阶段，每步插手，适合精写。
- **自动档**：你定方向，流水线自己跑完每章微循环（草稿 → 字数闸门 → 去味 → 六维审校 →
  清算 → 落库），适合批量补章。切换入口在**流水线面板**。

### 5.2 门预置：决定流水线「停不停下来问你」

流水线面板上有两个互斥按钮（可同时关）：

| 状态 | 行为 |
|---|---|
| **全放行**（两按钮同关） | 一路连写不停靠（见术语表「连写旁路」） |
| **逐步确认** | 九道闸门每道都停，等你确认 |
| **边界确认** | 只在你勾选的大节点停（出厂勾 G2 大纲 / G5L 开写 / G8 审校 / G9 定稿） |

每个门停靠时都会说清三件事：**拦的是哪一条、当前值 vs 阈值、继续与回退分别会发生什么**；
被拦还可以「强锁」，强锁会逐条留痕（「关于」弹窗里可回看）。

### 5.3 人工审校模式

不想让审校模型花钱？设置里开启后，定稿门里**你自己填阻断问题（每行一条）**，
AI 只按「最小改动纪律」修你指的问题——审校模型调用归零。

## 6. 阅读器、版本与导出

- **阅读器**：全屏沉浸（F5）、三主题（夜间/羊皮纸/纯白，Ctrl+T 循环）、选中文字可三色
  高亮 + 批注 + 灵感直通创作笔记，每章记住读到哪，支持多书签。
- **版本**：保存驱动——只有点「保存」才产生版本（每章保留 30 版，可 diff 可回退）；
  另有 5 秒防抖草稿暂存，崩溃/断电后可恢复。
- **导出**：txt / epub 一键导出。
- **备份**：项目 zip 一键备份；每日自动备份默认关，可在设置开启（打开项目时触发）。
  自动备份之外，定期把第 1.3 节那两个目录拷走最保险。

## 7. 对话记录与报障包

### 7.1 对话记录落盘（默认开，仅本地）

每一次 AI 调用（完整提问、回复、模型与槽位、成败、耗时与 token）都会写进
**书内 `.dialogue/` 目录**（JSONL 分片，单片 5MB、默认 40 片封顶自动删最旧）。
它**只存在你机器上、不上网**；流水线面板有「对话记录」开关，可整体停写、
可一键打开目录。这项记录随项目备份 zip 一起走。

### 7.2 一键报障包

遇到问题要反馈时，**导出对话框**里有两个按钮：

- **「一键报障包（含书稿正文，Key 已脱敏）」**——对话记录 + 程序日志 + 版本 +
  脱敏配置摘要打成一个 zip，开发者能直接看到现场；
- **「报障包（仅日志，不含书稿）」**——对话记录就是书稿正文，你有权只发日志。

两种包都做了脱敏：Key 相关字段整段剔除、家目录路径替换成 `<HOME>`、日志只取尾部、
对话只取最近分片。发 Issue 时附上报障包，是最有效的反馈方式。

## 8. 常见问题 FAQ

**Q1：双击安装包，Windows 说「已保护你的电脑」？**
安装包没有代码签名证书（明说的取舍），SmartScreen 会对没有声誉记录的新文件拦一道。
点「更多信息 → 仍要运行」；不放心就先核对 SHA-256 与 Release 页列出的一致。

**Q2：我的 API Key 存在哪？安全吗？**
存 Windows 凭据管理器（系统级加密存储）。`config.json` 里只有一个指向它的指纹，
日志、崩溃现场、报障包都做了脱敏。明文 Key 只在你粘贴后进一次系统凭据库。

**Q3：删除连接，Key 会残留吗？**
不会残留，也**不会单独删**：删除连接 = 它的 Key 一起从凭据管理器消失（两步确认）；
只剩最后一条连接时不许删。退役的出厂预设行只清理「没改过、没在用、没存过 Key」的。

**Q4：怎么更新？**
左栏出现下载角标 → 打开「更新」面板，四条路同一屏：GitHub 连得上就「下载并校验」
一键装；连不上就手动下包后「选择已下载的安装包」对哈希；连清单都拿不到就
「导入离线清单」。清单要过 Ed25519 验签、安装包要对上 SHA-256，两条有一条不过，
「立即安装」按钮根本不会出现。

**Q5：断网了还能用吗？**
阅读、编辑、批注、导出、备份都是本地的，断网可用；**生成正文必须联网调模型 API**。
另外说明白：安装包 51MB，应用不会宣称「离线也能下包」——它做的是把「有没有新版」
降成 1KB 清单、把离线导入的路修好，但下载安装包本身总得有一次连通。

**Q6：换别的模型行不行？**
协议上通（OpenAI 兼容均可，含本地 Ollama / LM Studio），但提示词按 DeepSeek 调校，
质量与闸门收敛不保证同一水准——换后先跑三章看看。

**Q7：写一本书大概花多少钱？**
两个口径都为真，看你怎么用：测试脚本压到极限是 5 章 ≈ ¥0.07（加速档 + 固定文本，
不是产品默认配置）；产品默认配置完整跑（含审校/清算/反哺）量级参考 ¥0.25/章
（v0.19.8 同书同渠道 13 章真跑、离峰价）。挂机离峰跑批更省一半。
每笔调用都记在 `~/.qianbi_novel/usage/usage.jsonl`，花在哪看得见。

**Q8：升级会不会弄丢我的书？**
不会，这是有机器保证的：安装器只写程序目录，书稿与配置都在它之外；卸载只删程序文件；
新版读旧配置按键补齐，看不懂的键与你自建的连接都保留；配置万一损坏，先另存
`config.json.broken-<时间戳>` 再回落默认，不静默丢弃。

**Q9：写到一半崩溃/断电了怎么办？**
断点状态实时落盘（`pipeline_state.json`），重启后从断点续跑；正文有 5 秒防抖草稿
与 30 版/章的版本历史兜底；崩溃现场自动留档（已脱敏），可打包发我们。

**Q10：我的书稿会被上传吗？**
不会。数据不出本机，唯一自动对外请求是检查更新：默认开、24 小时最多一次、
只**下载**约 1KB 公开清单、不上传任何内容，面板里可关（关掉后启动阶段零请求）。
遥测默认关闭且只写本地文件；对话记录本地落盘且可关。详见 `docs/PRIVACY.md`。

## 9. 术语表

界面上会碰到这几个词，都是「圈内黑话」的精简版：

| 术语 | 意思 |
|---|---|
| **清算** | 正文写完后，拿它跟世界观底册逐条对账：真冲突（违反）/ 合理新料（收编）/ 应回写台账（台账回写）三分类。便宜模型先预扫，有硬伤才请强模型复核疑点——省钱且不放过硬伤 |
| **雷章** | 故意埋了已知缺陷的「考卷章」，用来测审校能不能抓住问题。审校漏检雷章，说明审校本身要修 |
| **反哺** | 正文里冒出来的新设定（新人物/新规则/伏笔变动）自动回写世界书与追踪表，让后面的章节接着用——而不是各写各的 |
| **连写旁路** | 门预置全关时，流水线不停靠任何闸门直接连写到底。快，但没人拦你，适合挂机跑批 |
| **门预置** | 决定九道闸门「停不停」的三档开关：全放行 / 逐步确认（全停）/ 边界确认（只停勾选的大节点） |
| **两档制** | 共写档（默认，六阶段每步插手）与自动档（批量跑章）两种运行方式，同一套质量内核，切换在流水线面板 |
| **命中价** | 模型服务商对「缓存命中的输入」按折扣计价（DeepSeek 缓存命中约为原价十分之一）。提示词装配架构（稳定前缀 + 章会话）就是为把输入尽量变成命中价设计的——这是本应用成本能压下来的主力 |
