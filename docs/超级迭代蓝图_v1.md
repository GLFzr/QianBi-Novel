## 1. 超级迭代定义：这次大跨越跨越什么

从「能用的 AI 网文写作工具」跨到「**同类中工程最成熟的确定性写作引擎 + 双形态生态位**」。五个可验收的跨越面（每个都有预注册判据，见 §5 各 Wave）：

1. **「写不崩」从主张变实测**：补上 T3-1 暴露的系统性缺口——失败全被局部 handler 消化成良性 info、聚合裁决层缺位（底稿 §C3）。落点是 G1-G7 护栏 + CW 护栏 + 聚合裁决层 + 预注册长跑验证。
2. **「写得爽」从手感变机制**：伏笔到期引擎（S）、爽点节奏账本（M）、7 钩型受控词表（M）、桥段码账本（M-L）——全部基于已在真实项目数据上跑通的原型（底稿 §C2：4 原型复跑逐字节一致、抓到 2 个真实缺陷）。
3. **去 AI 味成为专属战场**：qianbi 将是唯一「GUI 内置离线确定性 lint（28 规则→45）+ must 机器验收契约改写 + 前后指标对比」本地闭环者（底稿 §C4；竞品空白：oh-story 无闭环无指标、humanizer 英文向）。
4. **双形态生态位**：3 个 skill 包（金标全过、MIT 合规、关键路径 4-5 人日）作为上游漏斗——在对手漏斗上游插旗，防 oh-story 独占「agent 写网文」人群（底稿 §D1-D2）。
5. **成熟度 24/40 → 31+/40**：i18n 声明（0.5→3）、静默安装（判据 A）、自动备份、ruff 门禁、文档第二层、onboarding 撞墙清零——12 条 1.0 判据达成 10/12 即登顶（底稿 §B3/E2/E4/E5）。

## 2. 战局一页纸

- **竞品**：skill 形态吃流量（头部 7.2k★、44.7★/天），GUI 形态刚起步且头部已现维护衰减；五家独立收敛到同一范式「事实账本+确定性门禁+预算注入+schema 写后提取」，绝大多数可移植（底稿 §A1-A2）。
- **需求**：7/7 竞品均有安装门槛、模型兼容、一致性三类痛点；去 AI 味是 skill 头部最大单品痛点；洗稿/破限/移动端/多语言/收费全是伪需求（底稿 §A5）。
- **我方**：「写不崩」底座已达第一梯队（12 项已有）；劝退级硬伤一条（新手第一步必撞墙，修复方案已到文案级）；共写桥接层 3 个隐蔽实伤（F1-F3，修复设计到 diff 级）；唯一 M 级遗留欠账 H-4（底稿 §B2/B4/B5）。
- **增长**：skill 流派发源地可考证（linux.do 帖 1397944）；自家数据已证明发版是唯一星触发器（4 天 10 星 ≈2.5★/天）；促销片 90% 完成只烂在硬编码数字（底稿 §A6）。

## 3. 三个候选战略

| | A 写作引擎纵深 | B 双形态生态破圈 | C 成熟度登顶 1.0 |
|---|---|---|---|
| 核心主张 | 一致性+爽点机制做到竞品没有 | skill 包引流+五渠道引爆 | 12 条判据达成 10 条 |
| 关键证据 | 五家收敛范式；原型已验证；F1-F3 实伤 | ZenStory 漏斗实例；金标全过；linux.do 源头 | 记分卡 24/40；更新链 95% 已好；最短木板全有 S 级修法 |
| 人日 | 首两波 6-8 + T1/T2/T5 再 8-12 | 关键路径 4-5 + 发布物料防腐 0.5-1 | Wave 0 债 8 + 快赢进取版 11-12 + M 级项 8-10 |
| 主要风险 | B3 切段是 T1 硬前置；F1-F3 不修则 T2 成第四剧场 | 维护面（drift check 防）；品牌稀释（核心账本不导出防）；红线：检测率零承诺 | 非核心编码维度，不直接产出卖点；社区轨迹不可工程补齐 |
| 预注册判据 | G1-G7/CW 护栏验收条；T1-T5 各自判据（底稿 §C1/C3/C4） | skill 包金标+npx skills add 可装+发版日五渠道齐发 | 12 条判据清单（底稿 §B3） |

**三者的关系不是三选一**：A 是主线（产品差异化本体），B 是放大器（让 A 被看见），C 是地基（让 A/B 站得稳）。冲突点只在排期，见 §4。

## 4. 推荐主线：Wave 0-4 路线图

**排序原则**：先还阻塞债与止血（撞墙/F1-F3/`<think>` 容错），再上引擎机制，发版放在引擎第一批可见成果后，导出 skill 在发版前 T-14 天反向倒排预热。

- **Wave 0（第 1-2 周，≈19-20 人天）债与快赢**
  - 结构债最小开工集 B0+B4+B3(+B7)≈8 人天（B3 切段是 T1 硬前置；B7 是静默安装硬前置）。
  - 0.21 快赢批进取版 ≈11-12 人天：撞墙修复组（onboarding S1-S9 + F1-F3，全池单位人日价值最高）+ 信任基建组（`<think>` 过滤——「写坏用户书」级、finish_reason 捕获、B7 补测、三通道一致校验、latest.json stats 回填）+ 文档防腐组（hero 去重/数字校正/check_docs 报警器先行）+ i18n A 路声明。
  - 验收：新手零 Key 10 分钟走通演示书；撞墙率 100%→0；<think> 不再入库；README 数字一条命令可复现。
- **Wave 1（第 3-4 周）引擎第一批 + 0.21 发版**
  - T3 伏笔到期引擎（S，纯本地零 LLM）+ deslop 度量层 S 档 + 规则 30→45 + G1/G3 护栏 + P2 状态卡/P4 质检接入。
  - **0.21 发版 + 五渠道同日引爆**（linux.do 回源帖/V2EX/知乎/B 站/GitHub trending 机制）；促销片半天防腐 pass 先行。
  - 验收：发布 checklist 重走全绿；发版日五渠道齐发；deslop 改前改后 Δ 报告可产出。
- **Wave 2（第 5-8 周）双形态 + 编排**
  - skill 包发布（GLFzr/qianbi-skills，T-14 倒排即本周启动设计）；阶段路由 UI（A 方案）+ 成本面板（B 方案）+ 端点容错清单（D）。
  - 静默安装 U-A（2-3d）+ R3 引导回滚 + 自动备份（S-M）。
  - 验收：npx skills add 可装三个 skill；更新 ≤2 点击；关项目自动 zip。
- **Wave 3（第 9-12 周）纵深第二批 + 清账**
  - **H-4 主体（Wave 3 首项，与 C 同批——跨线程丢更新直接威胁长跑）**；T1 爽点节奏账本（B3 已备）+ T2 钩子链账本（挂 supervisor，F1-F3 已修前提下）；批量挂机 C（G6/G3 硬前置已备）；文档手册 v2+内嵌帮助。
  - 验收：爽点跨章三判据可测；钩型账本进台账；批量挂机带预算熔断。
- **Wave 4（第 13 周+）验证与登顶**
  - T5 桥段码账本（版权绿档路径：框架直通+打法卡自写+n-gram 出仓过滤+公版书跑 CI）；爽点盲评 A/B（待所有者拍板，协议与预算四档已备：20+20 章 ≈¥12-21 起）；T3 v3 预注册长跑（开成本栈四旗标+护栏全开）；1.0 判据收口（12 条达成 10 条）。
  - 验收：盲评四出口之一落地；长跑零静默停摆；1.0 判据表逐条打勾。

**理想完整还债**（9 批 22.5 人天）中 13 天可插队不占功能窗口；「永不还」清单照 w4_refactor_plan（Bridge 保留层、13 条良性边等）。
