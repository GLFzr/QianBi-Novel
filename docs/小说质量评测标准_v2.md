# 小说质量评测标准 v2（全书级量化评测，服务成本优化实验）

> 版本：v2 ｜ 日期：2026-09-06 ｜ 配套机器可读文件：`tests/quality_rubric/rubric_v2.json`、`tests/quality_rubric/judge_prompt.md`
>
> 定位：在成本优化实验（`docs/成本测试方案_v2.md` 的 E 系列）中回答一个问题——**"钱省下来之后，小说能力是否下降"**。本标准只定义"怎么评"，不定义"怎么写"；评测的执行是后续流水线的事，本文档与 rubric 文件本身不做任何 LLM/API 调用。

---

## 0. 设计原则（先立规矩）

| # | 原则 | 说明 |
|---|---|---|
| Q1 | **兼容既有六维** | `app/prompts/review.py` FINAL_REVIEW_PROMPT 的 A-F 六维是章级审校事实标准，v2 将其升格为全书级一级维度（映射见 §2），不另起炉灶 |
| Q2 | **锚定优先于形容词** | 每个维度只接受"锚定量表"：1/3/5/7/10 分各配具体文字样本或可数特征清单。评委不得用"文笔不错/略显不足"类模糊词 |
| Q3 | **商业性/文学性双轨** | 网文评测的每一维都有商业轨（留存/追读/均订逻辑）与文学轨（工艺底线），评分以商业轨为主、文学轨为地板——一本书可以文学性平平但商业性合格，反之不可（见 §3 双轨说明） |
| Q4 | **证据必须可验真** | 每维评分必须附原文引文，引文被程序逐字验真；编造引文=该票作废（沿用六维"强制原文引证"纪律） |
| Q5 | **评委便宜、流程防偏** | 评委用 flash 档 + rubricPrompt；双评委盲评 + 顺序随机化消位置偏差；只在分歧时加第三票（见 §6） |
| Q6 | **与埋雷法互通** | 评测发现的可疑缺陷可晋升为埋雷锚定样本；埋雷召回率反过来是评委称职度的验证器（见 §8） |
| Q7 | **成本有上限** | 单章评测成本封顶（§7），超预算的评测设计（如人肉逐段精评）不进流水线 |

## 1. 依据（深度调研，2026-09-06；每维度 ≥2 来源）

### 1.1 网文行业标准（商业轨的直接依据）

1. **黄金三章与签约**：起点社区流传"黄金前三章"决定编辑与读者第一印象，但编辑实际审稿看 1-3 万字开篇整体——<https://www.zhihu.com/question/65768324/answer/360064730>；签约三大核心中"开篇即时吸引力"（黄金 1-3 万字）是签约生死线——<https://www.wangwen666.com/post/8.html>
2. **追读与推荐**：编辑看追读比（追读人数/收藏数）决定推荐位；案例：500 收藏但追读 230+ 即有机会拿上架推荐——<https://www.jfdaily.com/wx/detail.do?id=1055014>；新书榜从签约起算 30 天/20 万字下榜，签约节奏影响推荐——<https://zhuanlan.zhihu.com/p/658952522>
3. **均订=商业成绩核心指标**（起点官方口径）——<https://m.qidian.com/ask/qforhfoclwz>；白金作家评选门槛：至少一本完本、订阅超一万——<https://baike.baidu.com/item/起点白金作家/8017393>
4. **免费模式=完读率逻辑**：番茄用 10 万字完读率替代留存考核（脑洞文 ≥15%、传统文 ≥10% 及格线），达标才给第二波放量——<https://zhuanlan.zhihu.com/p/1942928412256741116>；番茄总编辑谢思鹏：免费模式下用户留存、章节读完率对作者全程透明，按字数读完率发奖励——<https://cn.chinadaily.com.cn/a/202006/09/WS5edf5680a31027ab2a8cf38f_1.html>
5. **白金作家方法论**：白金作家小刀锋利自述无大纲习惯"不是良好习惯"，即兴发挥剧情会跑偏崩盘——<https://write.qq.com/portal/content/12896795604350601>；作家酒徒：写大纲前先答"这本书写给谁看、燃点在哪"——<https://www.chinawriter.com.cn/n1/2021/1015/c441011-32254266.html>
6. **爽点节奏**：压抑积累→爆发释放是读者感知爽点的机制，删 1/3 爽点延后释放反而制造期待感——<https://zhuanlan.zhihu.com/p/2046638747630957698>；约每 3000 字一个爽点 + 6 种章末钩子设计——<https://maliangwriter.com/blog/novel-pacing-hook-design-guide/>；打脸四部曲（装逼→质疑→反转→打脸）标准结构——<https://www.wangwen666.com/post/186.html>

### 1.2 经典叙事工艺（文学轨的结构依据）

7. **Save the Cat 15 节拍**（小说版）：开场画面→催化→争执→进入第二幕→玩闹与游戏→中点→坏人逼近→一无所有→灵魂黑夜→进入第三幕→结局→终场画面，各节拍有百分比落位——<https://www.jessicabrody.com/2020/11/how-to-write-your-novel-using-the-save-the-cat-beat-sheet/>；节拍功能逐条拆解——<https://kindlepreneur.com/save-the-cat-beat-sheet/>
8. **场景=目标-冲突-挫折（+反应单元）**：Swain《Techniques of the Selling Writer》的 Scene（Goal→Conflict→Disaster）与 Sequel（Reaction→Dilemma→Decision）交替单元，及句子级 MRU（刺激-反应）——<https://www.septembercfawkes.com/2021/09/scene-structure-according-to-dwight-v.html>
9. **MICE 配额**：Orson Scott Card 四类线索（环境 Milieu / 悬问 Inquiry / 人物 Character / 事件 Event）各有独立开闭条件；多线索嵌套按开闭顺序管理张力，线索数决定篇幅——<https://writingexcuses.com/16-35-what-is-the-m-i-c-e-quotient/>
10. **四部结构**：Larry Brooks《Story Engineering》Setup→Response→Attack→Resolution 四部各有不可互换的上下文使命（第一情节点/中点/第二情节点分割）——<https://writetodone.com/writing-success/>
11. **人物弧光**：正面改变弧=角色相信"谎言"→受挫→拥抱"真相"；Want 驱动情节、Need 承载弧光（"wants as the plot, needs as the character arc"）——<https://www.helpingwritersbecomeauthors.com/write-character-arcs/>；<http://blog.janicehardy.com/2021/05/making-sense-out-of-character-wants-and.html>

### 1.3 中文写作质量可操作维度（文笔轨依据）

12. **AI 味的词汇/句式共性**：中国社科院语言所——智能写作偏好高频中性"安全词汇"，用语同质化，词汇/句式/结构三层有显著共性指纹——<http://ling.cass.cn/news/xuejie/202607/t20260703_6057568.html>；AI 文本的"滴水不漏的完美感"即过度标准化——<https://news.sciencenet.cn/htmlnews/2025/10/553334.shtm>
13. **平台检测维度可量化**：网文平台判定 AI 痕迹基于统计特征（词汇多样性、**句长波动**、短语重复等 8 维加权）——<https://developer.volcengine.com/articles/7609936833770127386>；检测分统计特征层（n-gram 分布、句长分布、标点频率）与语义特征层——<https://blog.csdn.net/qq_41627274/article/details/161522671>
14. **具象 vs 抽象（show, don't tell）**：用物理/行为/感官细节替代情绪命名——<https://www.enchantingmarketing.com/show-dont-tell-storytelling/>；《Emotion Thesaurus》系情绪外化线索库——<https://writershelpingwriters.net/show-dont-tell-help/>
15. **对白区分度**：声口差异来自句长节奏、用词、口头禅与心理根基；"盖住对话标签仍能认出说话人"是可操作检验——<https://writersinthestormblog.com/2021/07/5-steps-to-creating-a-unique-character-voice/>；<https://www.writersdigest.com/write-better-fiction/5-tips-for-creating-character-voice-readers-will-love>

### 1.4 评测方法论（流程设计的依据）

16. **MT-Bench / Chatbot Arena**（arXiv:2306.05685）：LLM 评委与人类一致率 >80%，但存在**位置偏差、冗余偏差、自我增强偏差**，缓解=交换位置+多评委——<https://arxiv.org/abs/2306.05685>
17. **FairEval**（arXiv:2305.17926）：仅改变候选顺序即可操纵评委（Vicuna-13B 借顺序操纵在 80 题中 66 题胜 ChatGPT）；提出平衡位置校准——<https://arxiv.org/abs/2305.17926>
18. **创意写作 LLM 评测基准**：EQ-Bench Creative Writing v3 用混合 rubric+Elo，显式检测 LLM 高频重复词/过度用词——<https://eqbench.com/creative_writing.html>；其配套 **Judgemark** 专测"评委模型评创意写作的可靠性"——<https://github.com/EQ-bench/creative-writing-bench>；WritingBench 覆盖 6 大写作域 100+ 任务——<https://arxiv.org/html/2503.05244v1>
19. **文风与实质分离**：LMSYS style control 证明排版/长度/文风显著扰动对战排名，控制后排名明显移动——评测必须把"文笔指纹"单列维度而非混入总分——<https://www.lmsys.org/blog/2024-08-28-style-control/>

**依据小结**：商业轨给了"为什么这些维度重要"（完读率/追读/均订与开篇、爽点、钩子直接挂钩）；工艺轨给了"单元怎么算合格"（节拍/场景单元/线索配额/弧光）；文笔轨给了"什么可机器化检测"（句长波动、词族配额、具象密度）；评测轨给了"怎么评才可信"（锚定、盲评、随机化、多评委、评委可靠性自检）。

### 2.2 与埋雷法（`tests/planted_defects/defects.json`）的互通

- 埋雷文本天然是**低分锚定样本**：v2 各维量表的 1-3 分锚定直接引用雷集文本（见 §4 各维"1 分长这样"），量表与雷集同源，评委校准与雷集轮换保持同步（每 2 轮轮换 30% 时，同步替换受影响维度的锚定例句）；
- 评委称职度自检：评委对已知雷章的相应维度应打 ≤4 分；漏检（≥6 分）记评委失效票；
- 缺陷晋升流程见 §8。

### 2.3 与成本实验闸门（`docs/成本测试方案_v2.md` P4）的衔接

P4：总分 ≥ 基线−0.5、单章地板 ≥7.5、埋雷召回不降、假阳性不升。v2 的回归判定（§6.4）与其完全兼容：本标准默认地板 7.0，**接入 P4 实验时自动取更严者（7.5）**，两套参数都在 `rubric_v2.json` 的 `regression_gate` 中显式给出。

### 2.4 校准集指定（首次双评锚定材料）

`tests_output/bench/baseline_e01.chapters/`（第 001-006 章，各约 1600-2400 字，0.19 全流程真实基线）为本标准的**校准集**。使用方式：

1. **首次双评**：6 章逐章做"人工编辑视角评分 × LLM 评委评分"双评；人工分为锚；
2. **评委验收**：LLM 每维与人工差值 ≤1.0 视为评委合格；连续 2 个维度超差 → 修 rubric 锚定文本后重验；
3. **漂移检测**：每 2 轮实验用校准集回归评委一次（评委模型/prompt 变更后必做），得分与首次基线差 >0.5 的维度需重新锚定；
4. 校准集已有手工确认的亮点（如第 001 章物件开场、第 003 章种子书落账）与缺陷面，可作为 §4 各锚定档的真实参照。

## 4. 锚定量表（每维 1-10 分；1/3/5/7/10 各档锚定）

> 评分只允许整数分。7 分档给出**文字样本**（摘自校准集或按其风格构造），1/3 分档锚定多取自雷集 `defects.json`（标注雷 ID）。

### D1 黄金开篇与首章粘性（权重 12）

- **1 分**：纯环境/天气/身世铺陈开场，500 字内零冲突零异象。锚定（雷 A01）："晾衣绳上的水滴了七天，墙皮鼓起三块白斑。雨不大，但一直下……倒映着灰白的天。"
- **3 分**：有动作但与主线冲突脱节；或冲突在第 1000 字后才出现。锚定（雷 A02）："清晨的野球场上人声鼎沸……笑着朝对面招手：再来一场。"（热闹但与债务/种子书主线无关）
- **5 分**：500 字内有冲突苗头（数字压力/任务结构/危机之一），但开篇信息不足以让读者回答"主角要什么、拦着什么"。
- **7 分（文字样本，校准集第 001 章实文）**："钥匙串上拴着一截灰蓝色尼龙绳，接口磨出毛边。他爸用了七年，人走那天，钥匙还挂在这扇门上。"＋"手机里躺着两条消息：房东周五催租……房租差一千六，他还没想好去哪凑。"——特征清单：①首段即具象物件+死亡/异象底色；②两段内给出数字压力（差一千六）；③章内出现金手指异象（停在 10 与 11 之间的表、0317 复现）；④章名"旧物"如实承诺正文。
- **10 分**：7 分全部特征 + 首章末尾已造成"不点第二章会死"的信息缺口，且第二章开篇 200 字内兑现首章承诺（黄金三章链完整，第 3 章内完成第一次爽点闭环）。

### D2 爽点与情绪闭环（权重 12）

- **1 分**：细纲承诺的爽点被替换/推迟，当章不结。锚定（雷 B01）："算了吧，他对自己说，这笔账改日再算也不迟。"
- **3 分**：爽点兑现但反转弱（无代价/无风险）或缺结算镜头。锚定（雷 B02）："三个回合，蒋霸就仰面倒在拳台上，裁判读秒到十。人群让开一条缝。"（赢了，但无可截图结算：无进账数字、无地位符号、无旁人态度反转特写）
- **5 分**：三拍完整（压抑铺垫+反转动作+围观反应），但情绪单一（只有爽，无先抑的真实窘迫感），积累明显不足。
- **7 分（文字样本，校准集第 003 章实文）**："他写：'周航，3月17日清晨，滨河道12号一楼台阶，右手握紧扶手，停住半步。'纸面安静，没有异样。……十五秒后，楼道口传来一声闷响。陈默冲出去。"＋"但他知道它动过了，他添了一笔不知道什么时候会收的账。"——特征清单：①有明确落笔动作→异象延迟兑现（悬念升级为双钩）；②兑现的同时附加代价认知（账要收回来），爽中带压；③后果具体可见（汤水沿地砖缝接在昨日水渍延长线上）。
- **10 分**：7 分特征 + 本章爽点位于全书压抑-释放曲线的正确位置（前文有 ≥2 章的可见积累），且结算镜头三选一齐备并"可截图"；读者能复述出"这次爽比上次多还了什么"。

### D3 章尾钩子与追读动力（权重 10）

- **1 分**：章末入睡/总结陈词/纯心理宣告，零事件钩。锚定（雷 F02）："他回到小屋，把桌上摊着的东西一样样归拢好，关了灯，沉沉睡去。这一天没有什么大事发生，他想，明天大概也一样。"
- **3 分**：有钩但为预告句/计划陈述（AI 味残留），信息缺口为零。锚定（雷 F01）："他不知道的是，这一夜，街对面的黑暗里有一双眼睛……"
- **5 分**：有未决冲突定格，但冲突是本章已解决矛盾的余波，无新信息缺口；仅靠惯性追读。
- **7 分（文字样本，校准集第 001 章实文）**："四楼那扇半开的窗，玻璃忽然反了一下光。像有人从里面，把它又推开了一点。"——特征清单：①事件钩（可指认的异象动作，非心理宣告）；②信息缺口明确（谁在里面？与 0317 何干？）；③与本章已埋线索（反锁的门、推开一半的窗）直接勾连。
- **10 分**：7 分特征 + 钩子烈度分层经营：普通章留信息缺口钩，每 3-5 章出现一次"不点下一章会死"级大钩（人生危险/核心谜团半揭晓），卷末章为双钩（本卷冲突爆点+下卷新局）。

### D4 情节一致性与因果账本（权重 12）

- **1 分**：凭空大额资源/凭空前情，依赖从未发生的前提。锚定（雷 D02）："银行短信：您尾号 7392 的账户入账五十万元整。他愣了几秒，想不起谁会转给他这笔钱。"
- **3 分**：因果可解释但缺关键衔接句；新人物/新规则凭空登场无铺垫（六维 D 的 marginal 档全书化）。锚定（雷 D01）："想起老周昨天在楼道里说过的话：这种催租短信，拖着就好……"（老周从未出场）
- **5 分**：本章自洽，与最近三章摘要/时间线无冲突；但跨卷数值（金额/期限/年龄）未对账，账本粒度不足。
- **7 分（特征清单，校准集第 003 章实证）**："汤水……不偏不倚，接在昨日那滩旧水渍的延长线上，又往前渗了半寸才停住。"——①本章全部关键转折可回指到已写正文（水渍→第 1 章老屋渗水线）；②数字（0317、3月17日、11 秒通话）全部入账可查；③金手指每次落笔均有来源（写了什么→发生什么→代价记账）；④无一处"上次说过"式幻影引用。
- **10 分**：7 分特征 + 三账本（数值/时间线/伏笔）全书连续：任意抽 10 个数字均可机器对账回收；伏笔开闭有账本记录，无超期未回收（超过设定回收窗口的伏笔=本维扣分）。

### D5 金手指与设定边界（权重 8）

- **1 分**：越界使用（白名单外对象/未声明能力/超上限无代价）。锚定（雷 C01）："写下：让父亲在昨夜的高速上活下来。墨迹在纸上洇开……一行小字浮出来：已受理。"（对已闭合事件落墨且生效）
- **3 分**：未越界但副作用含糊无机制感。锚定（雷 C02）："除此之外没什么感觉，就是有点累。"
- **5 分**：使用合规、代价有机制，但代价不随使用强度/等级变化（固定成本），升级曲线平淡。
- **7 分（文字样本，校准集第 003 章实文）**："种子书在背包夹层。他拿出本子和蓝黑墨水笔，翻开空白页，笔尖抵在纸面上，停住。他只知道录音里那句没说完的话，不知道这一笔落下去，账要从哪里开始算。"——特征清单：①使用前置疑（代价可见）；②落笔格式与设定一致（人名+时间+地点+动作）；③效果延迟且留账（"不知道什么时候会收的账"）；④超范围试探被设定自然拒绝（写"让父亲活下来"式操作未出现）。
- **10 分**：7 分特征 + 升级曲线可见：能力边界随剧情阶段拓宽（新用法有铺垫解锁），代价梯度递增，且每次边界拓宽都推动主线而非游离支线。

### D6 人物声口与弧光（权重 10）

- **1 分**：台词可互换说话人/弧光倒退。锚定（雷 E01）："「这事儿吧，你放心，我心里有数，回头一定给你办得漂漂亮亮的。」王教授扶了扶眼镜。「这事儿吧……办得妥妥当当的。」刀疤堵在巷口，叼着牙签。"
- **3 分**：口癖复用或声口与身份轻微不符。锚定（雷 E02）：三个不同身份角色共用口癖"讲道理"。
- **5 分**：声口可区分，但主角本章无变化（无态度/认知/选择的微小位移），配角行为动机可但扁平。
- **7 分（特征清单，校准集第 003 章实证）**：陈默对周航只说"没怎么。慢点，滑。"（外冷内查的账房式克制，与其帮父盘账二十年的人设一致）；林兰台词带具体生活事务（垫布、七点科创营、她爸顺路送）——①在场 ≥2 角色台词盖住标签可辨；②主角有微小位移（从"看一眼台阶"到主动落笔记账）；③配角行为符合其既有处境（单亲母亲对邻里的分寸感）。
- **10 分**：7 分特征 + 弧光跨章可见：角色"谎言"（如陈默认为"把账理清就安全"）在第 3-10 章内出现至少一次被现实打脸的位移；配角有独立欲望线（不围绕主角旋转的工具人=扣分）。

### D7 节奏与信息密度（权重 10）

- **1 分**：连续两段以上无新信息无情绪推进的注水；或整章一个场景单元都没演完（D7 与 D4 双低）。
- **3 分**：场景单元不完整（有目标无挫折，或有冲突无结算），章内信息密度不均——开头密集结尾注水。
- **5 分**：每个场景有目标-冲突-挫折骨架，但 Sequel（反应单元）拖拍：决策前的心理复盘超过一段；转场靠"午后/傍晚"硬切无信息钩连。
- **7 分（特征清单，校准集第 003 章实证）**：全章 5 个场景单元（晨起异常→赶回老屋→落笔记账→闷响后果→傍晚页痕新字+邻家对话），每单元 ≤400 字完成"刺激→反应"，转场句自带信息（"闹钟响时雨停了。床头柜上摊着一张外卖单底联，单号区印着0317"——转场即推进）；无任何一段超过 150 字不含新信息。
- **10 分**：7 分特征 + 张弛配速：高压单元后有 ≤200 字的反应/呼吸段再入下一冲突；全章信息密度均匀（机器可测：新信息点间隔 ≤400 字）；章内节拍与全书位置匹配（过场章不硬造高潮，蓄力章不提前泄压）。

### D8 文笔与去AI味（权重 10）

- **1 分**：结构指纹重度命中（≥2 类）：凝视循环（"盯着/看向/望向/注视/目光"≥8 处/2 千字）、否定刹车句成串、≤15 字单句独立段 >45%（与 `app/prompts/writing.py` 去AI味红线同源）。锚定（雷 F03 注入段）："他盯着手机屏幕，目光落在那串数字上。他看向窗外，视线扫过街角……"
- **3 分**：模板腔命中（"不是A而是B""仿佛""他知道"高频）、四字套话堆砌、句长分布均匀无波动（统计特征层可测 [13]）；情绪靠命名不靠外化（"他很紧张"）。
- **5 分**：无明显指纹，但具象密度不足：关键情绪/场面靠抽象概括带过；比喻陈旧（"像被针扎了一样"级陈词滥调）。
- **7 分（文字样本，校准集第 001 章实文）**："凉茶罐还立在桌上，旧报纸摊开在他爸倒下那天的日期上。开窗，窗轴生锈，卡在半截。"＋"他爸是木匠，刨刀养着油，油味盖过灰。"——特征清单：①情绪全部外化为物件与动作（丧父→报纸日期、没喝的凉茶）；②句长有节奏（长句铺陈后接短句收力："锁门。锁芯涩，他转了三次才锁严。"）；③行业具象细节（刨刀养油）替代身份说明；④视线词族每 2 千字 ≤4 处、无"深吸一口气""瞬间/蓦地"滥用。
- **10 分**：7 分特征 + 全章零模板腔、零陈词滥调；比喻全部自语境生成（"像被谁吸了进去"式）；朗读节奏平滑（句长标准差落在人写区间 [13]），且文风与本书叙事声音一致（账房式冷静贯穿，不串戏）。

### D9 对白质感（权重 8）

- **1 分**：台词功能性丧失：复读已知信息（"你我是兄弟，当年一起出生入死"式说明腔）或全员同腔。锚定同雷 E01/E02。
- **3 分**：对白可区分但全是直给：无潜台词，人物说要什么就有什么，信息释放无控制（telling 通过台词完成）。
- **5 分**：有潜台词与留白，但对白推动力弱：删掉对白章节情节仍可推进（对白不承担因果）。
- **7 分（文字样本，校准集第 003 章实文）**："'陈默，钥匙串落你家了。'林兰收了伞，'果果，喊陈叔叔。'……'明天一早七点，果果要去东门街那边上科创营，她爸顺路送。我还愁这雨，下到半夜估计能停。'"——特征清单：①每句对白同时在办三件事（还钥匙=人情分寸、喊叔叔=关系定位、科创营七点=未来场景与时间线钩）；②生活语流自然（"我还愁这雨"不是情报腔）；③陈默的应答短促（"你说明早？"）与林兰的绵密形成对照。
- **10 分**：7 分特征 + 对白即冲突：章内至少一组对话有立场交锋（一方想套话一方避让）；信息释放有控制（关键信息由最不该说的人在不利的时机说出）；方言/职业语汇点睛不滥用。

### D10 长期期待感与伏笔账本（权重 8；卷级/全书级为主）

- **1 分**：无长期悬念：主线目标每章即结即弃，读者没有任何"想看下一卷"的理由；或伏笔只有埋设无账本，回收全靠即兴。
- **3 分**：有主线悬念但静态（谜团不随章节加深/变形）；伏笔埋后超期未回收（超过设定窗口）。
- **5 分**：悬念分级管理（章钩/卷谜/书谜三层），但线索开闭无序：MICE 意义上环境/悬问/事件线交叉开闭，读者分不清当前主线是哪条。
- **7 分（特征清单，校准集第 1-3 章实证）**：三层悬念并行——书谜（种子书与父亲之死：撕痕、被水渍泡烂的"陈默"）、卷谜（0317 与 3月17 日反复复现）、章钩（每章末新异象）；①每条悬念有可指认的复现节拍（0317：外卖单→页角→通话尾号，三章三次递进）；②伏笔入账（页痕"14:07 东门街路口"埋设即有回收指向——次日七点科创营）；③新悬念开线时旧悬念不悬空（15 秒闷响当章给结果，账留代价）。
- **10 分**：7 分特征 + 节拍结构落位：全书卷划分对应 Brooks 四部（Setup/Response/Attack/Resolution [10]）或 Save the Cat 节拍的网文化排布（每卷有类中点反转与卷尾"一无所有"）；期待感有明确的"下一次释放"预告结构（读者能说出"我在等什么"）；MICE 四类线索各有开闭清单且嵌套深度 ≤3（超过=读者认知过载）。

## 5. 三套评测口径（章级 / 卷级 / 全书级）

| 口径 | 适用维度 | 权重处理 | 输入依赖 | 频率 |
|------|----------|----------|----------|------|
| **章级**（成本实验主口径） | D1-D9 全评；D10 只评"本章伏笔钩挂账"子项（是否入账、是否有回收指向） | 按 §3 全权重 | 本章正文 + prev_context（最近 2 章摘要 + 伏笔表摘录） | 每章 |
| **卷级** | D1-D9 取卷内均值；D10 全权重（悬念分层、伏笔开闭清单、卷契约达成）；D4 加评"卷级数值总账" | D10 权重上调至 15，D1/D3 相应下调（归一化后保持合计 100） | 卷内全部章节 + 伏笔账本 + 卷大纲 | 每卷（实验中常以"章 1-6"模拟） |
| **全书级** | D10 全权重 + 节拍结构专评（Save the Cat/Brooks 四部落位）；D5 加评升级曲线；D6 加评弧光完成度 | D10 权重 15、D5/D6 各 +2，其余下调归一 | 全书大纲 + 卷摘要 + 账本全量 | 书末或里程碑 |

章级评分与六维审校的关系：FINAL_REVIEW_PROMPT 六维是**生成侧门禁**（pass/marginal/fail 三值，卡发布）；本标准章级评分是**评测侧量化**（1-10 分，卡回归）。两者共享锚定与引证纪律，但不互相替代：门禁失守的章必然在本标准对应维度 ≤4 分；门禁全过的章仍可能在本标准仅 6 分（门禁是及格线，不是质量分）。

## 6. 评分流程（双评委盲评 + 聚合 + 回归判定）

### 6.1 评委配置

- 评委模型：**便宜档（DeepSeek flash）**，temperature 依流水线默认；评委提示词 = `tests/quality_rubric/judge_prompt.md`（rubricPrompt 思路：把 {rubric_section} 锚定文本直接注入）；
- 每章 2 票独立盲评：评委 A/B 使用**不同随机种子**，各自重新洗牌维度块顺序（消位置偏差 [16][17]）；
- 评委不接收细纲承诺之外的任何信息（防止被"承诺"补偿实际执行）；评 D2 时可注入细纲爽点承诺行（判断"承诺是否兑现"必需）。

### 6.2 输出 schema（评委每维必出，缺字段=票作废）

```json
{"dim": "D3", "score": 8, "evidence_quote": "四楼那扇半开的窗，玻璃忽然反了一下光。", "one_line_why": "事件钩+信息缺口，与已埋线索勾连"}
```

- `score`：1-10 整数；
- `evidence_quote`：必须**逐字**来自 {chapter_text}，程序做子串验真；验真失败该维按 1 分计并记评委违规；
- `one_line_why`：≤40 字，必须引用可数特征（如"视线词 9 处>8"）而非形容词。

### 6.3 聚合规则

1. 每维：两票 |Δ|≤2 → 取均值（0.5 进位向下取 0.5 粒度）；|Δ|>2 → 召**第三票**（新种子、顺序再洗牌），三票取**中位数**，该维标 `divergent=true` 入人工抽检队列；
2. 加权总分 = Σ(score_i × w_i) / 100，保留 1 位小数（0-10 制）；
3. **防聚拢自检**（沿六维 flash 聚拢防御）：单票全部维度分数方差 <0.8 或全部 ≥7 → 判聚拢票，作废重评；
4. **评委称职度抽检**：每 20 章注入 1 章已知雷章（雷集轮换池），评委对被埋维度打出 ≥6 分 → 该评委降权/重锚定。

### 6.4 回归判定（实验变体 vs 基线，全部满足才算"质量未降"）

| # | 判据 | 阈值 |
|---|------|------|
| R1 | 加权总分回归 | 变体总分 ≥ 基线总分 − 0.5 |
| R2 | 单章地板 | 变体任一章加权总分 ≥ 7.0（**接入成本实验 P4 时取更严者 7.5**） |
| R3 | 单维跌幅 | 任一维度变体均值 − 基线均值 ≥ −1.5（跌幅不得超过 1.5） |
| R4 | 埋雷召回 | 变体雷集召回率 ≥ 基线召回率；假阳性数不升 |
| R5 | 引文真实性 | 抽查 ≥10 条 evidence_quote 验真通过率 ≥90% |

任何一条不满足 → 该变体记"质量回归"，即使成本达标也不采纳（P4 优先于成本结论）。

## 7. 成本核算（单次评测 token 预算）

价目按台账口径（`docs/成本测试方案_v2.md` P6：flash 缓存命中 $0.007/M、未命中 $0.22/M、输出 $0.66/M；off-peak；汇率 7.2；promptfoo 内置促销旧价必须覆盖，禁用）。

单评委单章输入估算：judge 模板 ~1.2k tok + {rubric_section} ~1.5k tok + {prev_context} ~1k tok + {chapter_text} ~3k tok ≈ **6.7k tok/票**；输出（10 维 JSON + 汇总）≈ **1.5k tok/票**。

| 项 | 数值 |
|----|------|
| 每章票数（双评 + 25% 概率第三票） | 期望 2.25 票 |
| 每章输入（期望，按 90% 缓存命中） | ~15k tok → 15k × (0.9×0.007 + 0.1×0.22)/1M ≈ $0.0004 |
| 每章输出 | ~3.4k tok × 0.66/1M ≈ $0.0022 |
| **每章期望成本** | **≈ $0.0026 ≈ ¥0.02** |
| **每章封顶（全 miss 最坏情形 + 一次重评）** | **¥0.05** |
| 3 章实验盲评预算 | ≤ ¥0.2 |
| 6 章实验盲评预算 | ≤ ¥0.4 |
| 卷级评测（6 章卷，输入含全卷文本） | ≤ ¥1.0 |

预算超限即调整（按序）：缩 {rubric_section}（只注入该口径用到的维度）→ 缩 {prev_context}（摘要压至 500 字内）→ 仍超则上报，不得静默换贵模型。

## 8. 与埋雷法的接口（缺陷晋升流程）

**方向一：评测 → 集合（晋升）**

1. 双评/三评中若同一缺陷模式在 ≥2 个独立章节被 ≥2 位评委引证（`one_line_why` 语义聚类），记为"可疑缺陷模式"；
2. 人工判定：该模式是否落在 FINAL_REVIEW_PROMPT 六维明文硬规则或本标准某维 red_flags 上？不落规则的不入集（防主观雷）；
3. 可注入化检查：能否按雷集四种 inject 模式（replace_regex / after_title / before_end / at_end）构造确定性注入文本？能 → 起草雷条目（id 按 `dim 首字母+序号` 续编）；
4. **双人独立核验**"确实违反明文硬规则"（雷集 v2 policy），通过后写入 `tests/planted_defects/defects.json`，进轮换池（每 2 轮轮换 30%）；
5. 晋级后同步：受影响维度的量表锚定例句更新（保持量表与雷集同源）。

**方向二：集合 → 评测（反哺校准）**

- 雷章是评委的"考卷"：评委漏检已知雷（§6.3 第 4 条）即评委失职；雷集召回率同时是**生成侧审校**与**评测侧评委**两套系统的共同 KPI（R4 判据）。
