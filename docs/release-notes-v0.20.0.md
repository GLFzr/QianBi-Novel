# v0.20.0 发布说明（共写默认档 · 两档制 · 确认感与可观测 · 大版本收口）

> **为什么这次隔了比较久**：上一版（v0.19.9）是 9 月 13 日发的，到今天隔了 12 天——
> 因为这一版不是小修小补，而是一次大工程：**默认写作方式改版（共写档成为默认主推）+
> 档位架构重构 + 三十多项底层加固**。我们选择把它整体做完、测透再发，而不是拆成
> 一堆小版本挤牙膏。本版起测试基线为**单元测试 1122 项 + 离线探针舰队 49 支**，
> 并首次在干净 CI 环境全量通过。

---

## 一、最大的变化：共写档成为默认主推

从这一版起，**新安装和新项目默认进入「共写档」**——一种对话式的写作方式：界面左侧是
六阶段导航（创建项目 → 核心设定 → 剧情总大纲 → 世界书与正则 → 单元细纲 → 正文写作），
你和「设定 Agent」像聊天一样推进每个阶段，它生成草案、你点「确定」或「打回」，
随时可以插话提要求、下指令（比如「帮我审校」「去一下味」「回退到上一阶段」）。

- **老用户完全不受影响**：升级不会改你已有项目的档位。表过态的项目保持原样，
  没表过态的旧项目继续按全自动跑。
- 自动档没有被删也没有被藏：批量补章、熟手连跑照旧，共写/自动随时互切，
  切换时会告诉你哪些产物保留、哪些信息需要注意。
- 共写档的 Agent 听得懂自然语言了：审校、去味、写草案、回退阶段、世界观对账、
  读章、细纲校验、记想法——九支工具直接用说话驱动，做不到的事会明确拒绝并指路，
  不再石沉大海。

## 二、档位架构重构（两档制）

- 原来四个档位（全自动/逐步确认/边界确认/共写）循环点击、语义重叠，现改为
  **「全自动 | 共写」两段式切换**。
- 全自动档的决策门收敛为**两颗开关**：「逐步确认」（每步都停）与「边界确认」
  （勾选哪些步骤停）。旧配置自动迁移，行为等价。
- **九个决策门全部接线成真门**（原先 G1/G3 是灰显占位）。每个门停下时，界面能
  答出三件事：**拦的是哪一条 / 当前值与阈值差多少 / 继续、回退分别会发生什么**。
  强制锁定时会列出全部违规项（不再只显示第一条），回执逐条点名被绕过的闸门。
- G8 人工审校改多行录入，回车换行不再误触过门。

## 三、每次 AI 调用都留底 + 一键报障

- **对话全量落盘（默认开启，仅本地，绝不上网）**：每一次 AI 调用的完整提问、回复、
  模型与槽位、成败（失败/重试/中止各算一条）、耗时与 token，写入书内 `.dialogue/`
  目录。单分片 5MB、默认 40 片封顶自动删最旧；流水线面板可一键关闭或打开目录。
- **一键报障包**：出问题时一键打包「对话记录 + 程序日志 + 版本 + 脱敏配置摘要」，
  Key 和家目录路径自动脱敏；介意隐私可选「仅日志」档（不含书稿正文）。
  现在远端 issue 是我们收到反馈的唯一通路，遇到问题请优先用这个。

## 四、写作管线新能力（实验性，默认关闭，总开关在配置里）

- **爽点引擎**（`writing.satisfaction_engine`）：细纲携带「压抑 → 反转 → 结算」三拍
  节拍字段（允许本章显式无节拍），正文按节拍兑现，成书前本地确定性预检推迟语式
  与结算段。该能力仍在盲评验证中，故默认关闭。
- **开幕轮压缩**（`cost.a8_opening_compress`）：正文开幕轮中与系统前缀重复的内容
  收敛为短引用，实测每章约省 2000 字符级 token。默认关闭。

## 五、界面与字体

- **MiSans 四字重随包内置**（免费商用），界面文字不再依赖系统字体回落。
- 视觉体系整体升级：中性色阶、语义柔色、卡片浮起阴影、控件聚焦环、弹窗出入场
  动画、章完成一次性徽标、完本庆祝、队列增删过渡；设置页新增**「减少动态」总闸**
  （关闭呼吸/脉冲类循环动画）。
- 用量对话框柱状图升级（渐变、悬停明细）；编辑器顶栏功能分组。
- README 全套截图与头图已按新版界面重录。

## 六、修复清单（挑重要的说，全部带回归护栏）

**崩溃与数据安全**
- 修复：新用户点「测试连接」直接崩溃（空地址/协议不支持/超时/DNS 失败现在都是
  人话报错）。
- 修复：正文写盘改为原子替换——断电/崩溃不再留下被误判为"已完成"的半截章；
  同一章改标题不再残留双文件；状态文件写盘加互斥锁。
- 修复：状态文件损坏时先留证据（`.corrupt`）再继续，不再被静默覆写；
  批注库损坏同样留证并告警。
- 修复：审校环节停止/异常不再被吞成"审校通过"——停止原样上抛、异常一律转人工。
- 修复：写作中关闭窗口可安全收尾退出（192 个界面槽位统一加守护）；
  未捕获异常的完整调用栈会落盘。

**模型行为**
- 修复：思考型模型把 token 预算花在思考上导致**空回复**时，应用会按渠道能力
  换一种发法重试（关思考 → 降推理档 → 抬预算），不再原样重发白花两遍钱。
  已在真实端点复测。

**升级与配置**
- 升级保持：老配置里被旧版本"地板"吃掉的审校修复环上限（1，实际一直按 3 跑），
  升级后自动回填为 3；之后你显式改成 1 会被尊重。
- 修复：单实例锁失效时不再静默多开（会提示可能有另一实例在运行）。
- 修复：对话记录分片清理方向错误（原会误删最新的小分片，现按时间删最旧）。

**说真话专项**
- 修复了一批"回执说做了其实没做"的界面谎言（约 26 项台账缺陷清零）：
  暂停/继续/停止有成功回执、保存有回读校验、删除连接如实报告 Key 删除结果、
  "已登记上游重做请求"这类没实现的话术删除。
- 文档对齐现实：README 成本数字双口径标注（测试脚本口径 vs 真跑口径）、
  出厂槽位描述与代码一致、测试计数校准。
