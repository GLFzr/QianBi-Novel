## 这次更新做了三件事（阅读导览）

**① 改变了"怎么写"——共写档成为默认，档位架构推倒重做。**
**② 改变了"怎么知道它在干嘛"——每次 AI 调用留底，每个决策留凭据。**
**③ 改变了"能不能信它"——一百多项缺陷集中清账，说谎的界面全部纠正。**

---

## ① 写作方式：共写档成为默认主推

从这一版起，**新安装和新项目默认进入「共写档」**：左侧六阶段导航（创建项目 → 核心设定
→ 剧情总大纲 → 世界书与正则 → 单元细纲 → 正文写作），你和「设定 Agent」像聊天一样推进
每个阶段——它出草案、你点「确定」或「打回」，随时插话下指令。

- 九支共写工具（审校 / 去味 / 写草案 / 回退阶段 / 世界观对账 / 读章 / 细纲校验 / 记想法 /
  落稿编辑器）**全部可用自然语言驱动**；做不到的事明确拒绝并指路，不再石沉大海。
- **老用户完全不受影响**：升级不回填任何已有项目的档位；表过态的项目保持原样，未表态的
  旧项目继续按全自动跑。共写/自动随时互切，切换时明确告知哪些产物保留。

## ② 档位架构推倒重做（两档制）

- 原来的四档循环胶囊（全自动 / 逐步 / 边界 / 共写，语义重叠、误触即换档）改为
  **「全自动 | 共写」两段式切换**。
- 全自动档的决策门收敛为两颗开关：**逐步确认**（每步停）与**边界确认**（逐门勾选）。
  旧 `run_mode` / `step_confirm` 配置自动迁移，行为严格等价。
- **九个决策门全部接线成真门**（原先 G1/G3 是灰显占位）。每个门停下时界面必须答出三件事：
  **拦的是哪一条 / 当前值与阈值差多少 / 继续、回退分别会发生什么**。
  强制锁定列出全部违规（不再只显示第一条），回执逐条点名被绕过的闸门；
  G8 人工审校改多行录入。

## ③ 每次调用留底，每个决策留凭据

- **对话全量落盘（默认开、仅本地、绝不上网）**：每一次 AI 调用的完整提问、回复、模型与
  槽位、成败（失败 / 重试 / 中止各算一条）、耗时与 token，写入书内 `.dialogue/`。
  单分片 5MB、40 片封顶自动删最旧；面板可关、可一键打开。
- **一键报障包**：对话 + 日志 + 版本 + 脱敏配置摘要打成单个 zip（Key 与家目录自动脱敏），
  另有「仅日志」档（不含书稿正文）。远端反馈全靠它，遇到问题请优先使用。
- 章完成 / 卷完成 / 完本 / 暂停 / 继续 / 停止 / 门决策——**每个动作都有回执**；
  章完成一次性徽标、锁徽标两档统一、强锁审计痕界面可回看。

## ④ 信任修复：一百多项缺陷集中清账

这 12 天里最重的工程其实是"还账"。几个代表：

- **数据安全**：正文写盘原子化（断电不再产生被误判"已完成"的半截章）、同章双文件收敛、
  状态文件写盘互斥锁、状态/批注损坏先留证（`.corrupt`）绝不覆写。
- **不再崩溃**：新用户点「测试连接」崩溃修复（四类错误翻译成人话）；写作中关窗安全收尾
  （192 个界面槽位统一守护）；未捕获异常完整调用栈落盘。
- **不再烧冤枉钱**：思考型模型空回复时按渠道能力换发（关思考 → 降档 → 抬预算），
  不再原样重发白付两遍；审校停止/异常不再被吞成"审校通过"。
- **界面不再说谎**：「已删除连接及其 Key」「已登记上游重做请求」等一批"回执说做了其实
  没做"的文案全部纠正（L2 台账 25 项说谎类缺陷清零）。
- **升级不偷改**：老配置里被旧版地板吃掉的审校修复环上限，升级时显式回填并留痕；
  此后用户显式设置一律尊重。

- README 全套截图与头图按新界面重录。

## ⑥ 实验室（默认关闭，不影响任何现有行为）

## 升级指引

**老用户**：直接覆盖安装。你的档位、配置、书稿都不动；唯一会感觉不同的地方是决策门
停下时信息更全了。
**新用户**：安装 → 首启有 5 分钟零 Key 演示 → 贴 Key → 跟着共写六阶段走。
**SmartScreen**：本版仍未购买代码签名证书，首次运行遇蓝色拦截点「更多信息 → 仍要运行」，
可用 `SHA256SUMS.txt` 核对安装包。

## 已知边界（诚实清单）

- 爽点引擎/开幕轮压缩为实验开关，默认关闭；盲评验证与 60 章压力终验进行中，
  结果将在验证完成后公布。

  与应用侧护栏无冲突——字数硬上限与审校均正常拦截）。
- 无签名证书 → SmartScreen 必拦一次（设计取舍，文档已写透点击路径）。
