# 隐私说明（千笔一文 Novel）

最后更新：2026-09-04

## 一句话总结

**你的书稿、配置和 API Key 全部保存在你自己的电脑上。** 没有任何数据上报给本项目作者：对外流量只有两处——你自己在设置里填的 LLM 服务商，以及开机时那一份公开版本清单的下载（下面第 2 条，可关）。匿名统计默认关闭、开启后也只保存在本机。

## 数据存放位置

| 数据 | 位置 | 说明 |
|---|---|---|
| 书稿项目（正文/设定/大纲/追踪） | `~/Documents/千笔一文/<书名>/`，新建时可改保存位置 | 完全本地 |
| 程序本体 | `%LocalAppData%\Programs\QianBi-Novel\`（或便携版解压目录） | 里面**没有**你的书稿，安装/升级/卸载都只动它 |
| 应用配置 | `~/.qianbi_novel/config.json` | 不含 API Key 明文（见下） |
| API Key | Windows 凭据管理器 | config.json 只留指向凭据管理器的引用；旧版明文 Key 会在首次保存时自动迁移 |
| 运行日志 | `~/.qianbi_novel/logs/` | 滚动覆盖（2MB×5），已做 Key 脱敏 |
| 崩溃现场 | `~/.qianbi_novel/crashes/` | 已做 Key 脱敏，仅在你主动分享时才会离开本机 |
| 更新缓存 | `~/.qianbi_novel/updates/` | 只有公开清单那份 JSON 的原文，和你选择下载的安装包；没有书稿、没有配置、没有 Key |
| 匿名统计（可选） | `~/.qianbi_novel/telemetry/pending.jsonl` | 默认关闭；开启后也仅写入本机文件，当前版本不上传 |

## 联网行为

应用只在你执行以下操作时访问网络：

1. **调用你配置的 LLM 服务商**（DeepSeek / 通义百炼 / OpenAI 兼容接口）生成文本——请求发往你自己填写的 API 地址，使用你自己的 API Key。
2. **检查更新**（v0.18 起开机**默认开启**，可在「更新」面板关掉）——具体到只有一个请求：
   - 向本项目 GitHub 仓库（或你在面板里自填的镜像地址）拉一份约 1KB 的公开 JSON 版本清单。
     通道依次为 自定义镜像 → GitHub raw → GitHub Pages → jsDelivr，第一条成功就停手。
   - **不上传任何东西**：不带书名、不带配置、不带 API Key，请求里也没有设备标识符。
   - 有节流：默认 24 小时内最多问一次（间隔可在面板里选 6/12/24/72 小时），不是每次启动都问。
   - 只在本地写两份文件：`~/.qianbi_novel/updates/manifest.json`（原样存那份公开清单，用于重启后
     立刻恢复图标状态，不掺任何本机信息）和——只有你真的下载了新版才会出现——`updates/setup-<版本>.exe`。
   - 关掉这个开关后，启动阶段不产生任何网络请求。
   - **多通道不等于随便信**：应用不会照着清单下载或执行任何程序，除非那份清单用源码里 pin 住的
     Ed25519 公钥（`app/update_check.py` 的 `PUBKEYS`）验签通过、且安装包的 SHA-256 与清单一致。
     未验签的清单只会被显示出来给你看，「立即安装」按钮根本不会出现。
3. **打开外部链接**（如更新下载页）——由你主动点击。

## 匿名统计（opt-in）

- 默认**关闭**。开启方式：主界面「关于」对话框里勾选（即时生效）。
- 内容仅限：事件名（如 app_start / chapter_done）、应用版本、时间。
- **不包含**：任何书稿内容、API Key、提示词、生成文本。
- 当前版本数据只写入本机文件，不做网络上传。

## 你可以随时

- 关闭匿名统计：同一个「关于」对话框取消勾选（即时生效）。
- 彻底清除本机数据：删除 `~/.qianbi_novel/` 目录（会删除书稿，请先备份）。
- 查看源码验证以上全部行为：本项目以 MIT License 开源。
