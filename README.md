# 千笔一文 Novel — AI 网文自动写作台

人定主题，AI 写书。主写 AI 引擎驱动的独立桌面应用：输入题材与灵感，自动完成设定、大纲、细纲与正文，全程可介入。

> P0 重构定位：从"AI 辅助人写"的工作台，变为"AI 自动写、人随时介入"的写作流水线。

## 核心理念

> 套路 = 确定性的情绪满足 · 先定情绪，再定故事 · 无细纲不写正文

## 它怎么工作

```
立项（你输入：题材/平台/一句话灵感/预计字数）
  → 核心设定（读者契约/主角代理权/金手指/世界观骨架）
  → 全书大纲（阶段划分 + 卷级大纲 + 终局储备边界）
  → 章节细纲（五段式细纲契约，分块生成、断点续传）
  → 章节微循环 ×N（每章全自动）：
      上下文组装 → 草稿 → AI味扫描(本地零成本) → 去味改写(仅阻断级) → 审校 → 定稿落库
  → 完本
```

- **AI 先跑，人随时介入**：暂停 / 停止 / 重写本章 / 编辑任意文件后从断点续跑
- **断点续跑**：`pipeline_state.json` 记录进度，关软件、改天再开都能接着写
- **记忆链**：追踪四文件（伏笔/时间线/角色状态/上下文）+ 全局摘要 + 章节摘要链，每章定稿自动更新

## 质量闸门（每章自动过）

- **本地 AI 味扫描**（零 API 成本）：破折号 / 不是A而是B / 音量反差腔 / 否定排比 / 章末预告 / 一级禁用词表…
- **阻断级 > 0** → 自动去味改写（最多 2 轮），仍有则标「待修」继续写，章节队列里一眼可见
- **一致性审校**（审校槽，`gates.review_enabled` 可关）：定稿前对照全局摘要/角色状态/伏笔/时间线做一致性检查，阻塞问题自动修改 1 轮
- **失败策略**（`gates.strategy`）：`mark_continue`（默认）标待修继续写；`strict` 自动暂停等人处理
- **字数闸门**：不足目标 90% 自动扩写一次

## 可靠性

- **LLM 分级重试**：网络错误/超时/429/5xx 指数退避重试（`config.llm` 可调），其余错误立即报错
- **细纲降级**：一批细纲生成失败自动拆半重试，单章失败跳过不阻断
- **失败现场**：异常时把最后 prompt 与日志写入 `{项目}/pipeline_debug/failure_*.md`
- **日志落盘**：`~/.qianbi_novel/logs/qianbi.log`（滚动 2MB×5）

## 模型接入（酒馆式，只两家）

- 连接管理：**DeepSeek / OpenAI / 自定义 OpenAI 兼容**（含 OpenCode Go 等中转/网关，如 `https://opencode.ai/zen/go/v1`），填 Base URL + API Key，可测试连接、拉取模型列表
- **三槽位路由**：写作槽（正文/设定）、辅助槽（细纲/摘要/追踪）、审校槽（一致性检查），每槽独立绑定连接与模型
- 状态栏实时显示累计 tokens 与估算成本（120 章全书约几元到十几元）
- **DeepSeek 系模型提示**：官方与 OpenCode Go 的 deepseek-v4-* 默认开启深度推理，长输出任务（大纲/正文）易被推理 token 吃光输出上限而返回空——在连接档案勾选「禁用模型思考」（发送 `thinking: {"type": "disabled"}`）即可解决，实测完整输出且速度提升数倍

## 使用

```bash
pip install PySide6 httpx
python run.py
```

或双击 `dist/QianBi-Novel.exe`（单文件，57.9 MB，无需 Python 环境；打包：`python build_exe.py`）。

**桌面快捷方式**：打包后运行 `.venv/Scripts/python.exe scripts/install_shortcut.py`，桌面会出现「千笔一文 Novel」图标，双击即启动。

1. 「连接与模型」配好 DeepSeek 或 OpenAI 的 API Key
2. 「书架」新建项目：书名 + 题材 + 平台 + 预计总字数 + 一句话灵感
3. 「流水线」点「▶ 开始」，然后看着它写
4. 点任意章节可阅读/编辑；右键章节可「重写本章」

## 项目结构

```
{书名}/
├── 设定/   (选题信息.md/题材定位.md)
├── 大纲/   (大纲.md/细纲_第XXX章.md)
├── 正文/   (第XXX章_章名.md)
├── 追踪/   (伏笔/时间线/角色状态/上下文/全局摘要/章节摘要.md)
├── pipeline_debug/   (失败现场/审校发现，异常排查用)
└── pipeline_state.json   (断点状态机)
```

## 技术栈

- Python 3.13 + PySide6（**Qt Quick / QML**「深夜编辑部」设计系统：暖黑 + 琥珀金 + 宋体正文）
- httpx（OpenAI 兼容接口调用）
- 纯本地文件存储，无云端依赖

## 路线图

- **P0（当前）**：自动闭环——主写引擎、微循环、摘要链、断点续跑、三槽位路由、QML 监控台
- **P1**：一致性审校 Agent、失效传播（改上游自动标下游失效）、L2 关键词检索、统一细纲 schema 升级
- **P2**：书架看板增强、向量记忆（可选）、成本统计面板、完本导出/报告
