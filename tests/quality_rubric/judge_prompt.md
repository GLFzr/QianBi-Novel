# 评委提示词模板（小说质量评测标准 v2）

> 用途：成本实验盲评流水线按本模板渲染评委 prompt，喂给**便宜档（DeepSeek flash）**评委模型，每章 2 票独立盲评。
> 占位符：`{chapter_text}`（本章正文全文）、`{rubric_section}`（本次评测口径用到的维度锚定块，从 `rubric_v2.json` 的 `dimensions[].anchors` 渲染）、`{prev_context}`（最近 2 章摘要 + 伏笔表摘录，≤500 字）。
> 本文件只是模板，不发起任何调用。

---

## 渲染规则（流水线执行，评委不可见）

1. **顺序随机化（消位置偏差，依据 MT-Bench arXiv:2306.05685 / FairEval arXiv:2305.17926）**：每次调用用独立随机种子对 `{rubric_section}` 中的维度块洗牌；评委输出顺序即洗牌后顺序，解析端按 `dim` 字段归位。同章两评委必须用不同种子。把实际顺序记入输出的 `randomized_dim_order` 字段供审计。
2. **盲评**：不注入细纲承诺（D2 除外：只注入细纲的"爽点承诺行"原文，用于判"承诺是否兑现"）；不注入生成侧审校的 pass/fail 结论。
3. **验真**：`evidence_quote` 由程序对 `{chapter_text}` 做逐字子串验真，失败该维按 1 分计并记评委违规。

---

## 评委提示词（渲染后的完整正文如下）

```
你是网文责编做质量盲评。请只依据【评测正文】与【前情摘录】独立打分，不要臆测本书其他内容。

## 评分维度与锚定量表（按给定顺序逐维评，顺序本身无含义）
{rubric_section}

## 评分纪律（违反任何一条=该票作废）
1. 每维给 1-10 **整数**分，严格对照锚定档：先找"7 分长这样"的特征清单逐条数，再决定上下浮动；不许用"文笔不错/略显不足"等形容词替代锚定比对
2. 每维必附 `evidence_quote`：必须**逐字**摘自评测正文（程序会验真，编造或记错=该维按 1 分计）——宁可少引，不可假引
3. 每维 `one_line_why` ≤40 字，必须写**可数特征**（如"视线词 9 处>8 阈值""无结算镜头"），不许写纯形容词
4. 各维独立判定：不许用"整体不错"补偿某一维，也不许因某一维差而连带压其他维
5. 反聚拢指令：即使全章优秀，也必须指出至少 2 个最接近降档的具体疑点（写进对应维的 one_line_why 或 worst_quote）
6. red_flags 命中 → 该维封顶 5 分，并在 one_line_why 里点名命中的红线
7. 不要因为"作者不容易"放宽——你在替老板回答"这章能不能对标基线"

## 输出格式（严格 JSON，不要多余文字、不要 markdown 代码块标记）
{
  "chapter_id": "{chapter_id}",
  "judge_id": "{judge_id}",
  "randomized_dim_order": ["按你实际评的顺序列出维度ID"],

    …（每个注入的维度一条）
  ],
  "total_weighted_score": 7.6,
  "worst_quote": "全章最差一句，逐字摘自正文"
}

## 前情摘录（辅助定位，不参与评分）
{prev_context}

## 评测正文（全 prompt 最后的变量段——此前全部内容对所有章节逐字节共享）
{chapter_text}

## 少样本锚定示例（两条，示范打分粒度，禁止把示例文本当作正文内容）

示例 1（低分锚定）：
正文片段："他回到小屋，把桌上摊着的东西一样样归拢好，关了灯，沉沉睡去。这一天没有什么大事发生，他想，明天大概也一样。"
→ {"dim": "D3", "score": 1, "evidence_quote": "他回到小屋，把桌上摊着的东西一样样归拢好，关了灯，沉沉睡去。", "one_line_why": "章末入睡+总结陈词，零事件钩零信息缺口（命中red_flag，封顶已不足需打1）"}

示例 2（高分锚定）：
正文片段："他写：'周航，3月17日清晨，滨河道12号一楼台阶，右手握紧扶手，停住半步。'纸面安静，没有异样。他合上书页，心跳撞着肋骨。十五秒后，楼道口传来一声闷响。"
→ {"dim": "D2", "score": 8, "evidence_quote": "十五秒后，楼道口传来一声闷响。", "one_line_why": "落笔→延迟兑现→具体后果，且附'不知何时收的账'代价认知，缺围观反应拍未满10"}
```

## 流水线侧补充约定（不进评委 prompt）

- `{chapter_id}`、`{judge_id}`（含随机种子，如 `flash-A-seed731`）由流水线填入；
- 聚合按 `rubric_v2.json` 的 `aggregation`：两票 |Δ|≤2 取均值，|Δ|>2 召第三票（新种子+再洗牌）取中位数；聚拢票（全维方差<0.8 或全 ≥7）作废重评；
- 回归判定按 `rubric_v2.json` 的 `regression_gate`：总分 ≥ 基线−0.5、单章地板 ≥7.0（接成本实验 P4 时取 7.5）、单维跌幅 ≤1.5；
- 单章评测成本封顶 ¥0.05（见 `rubric_v2.json` 的 `cost_budget`）。

> 场景下锚定纪律为主、位置偏差为次，已双评委独立采样兜底）。
